* Goal

Extract platform-agnostic desktop integration logic from =packages/niri/= into a new =packages/desktop-common/= package so both niri (Linux) and macOS packages can share it without duplication.

* What to extract

** Status file I/O
- =StatusFileWriter= class: writes ={ status, windowId, pid, projectName, sessionTitle, updatedAt }= JSON to =~/.spell/status/<id>.json=
- =StatusFileReader= class: polls =~/.spell/status/= directory, parses status files, detects stale entries (PID check or mtime threshold), emits session list
- =StatusDir= constant: =path.join(os.homedir(), ".spell", "status")=
- Status file types: =SessionStatusFile= interface

** Agent status derivation
- =AgentStatus= type (idle, running, needs_input, user_paused, error, completed, pending_approval)
- =deriveAgentStatus()= pure function extracted from =NiriOverviewController.#deriveStatus()=
- =AgentContext= interface (the minimal state needed to derive status)

** Snapshot building
- =OverviewSnapshot= and its child types (=TodoItemSnapshot=, =TodoPhaseSnapshot=)
- =buildOverviewSnapshot()= pure function extracted from =NiriOverviewController.#buildSnapshot()=
- =TodoItemView=, =TodoPhaseView= — the input types from the context

** Status colors (platform-neutral)
- =STATUS_COLORS= map but as hex values (not ANSI escapes)
- =StatusColorPalette= type: =Record<AgentStatus, { bg: string; fg: string; label: string }>=
- ANSI escape conversion stays in niri package as a thin wrapper
- QML/HTML conversion available for macOS QML popover

** Focus-window abstraction
- =FocusWindowFn= type: =(windowId: number | string) => Promise<void>=
- Platform implementations live in their respective packages (niri uses IPC, macOS uses =osascript=)
