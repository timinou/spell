* Intention & Purpose

Implement the 9 =SchemeHandler= traits at =crates/pi-natives/src/code_path/uri/=. Each handler resolves a scheme-specific URI (=artifact://=, =memory://=, =skill://=, =agent://=, =jobs://=, =local://=, =pi://=, =rule://=, =mcp://=) to a =NodeRef= and identifies the downstream dialect for any =::Query= continuation.

* Context & Narrative

Spec authority: =specs/code-graph/code-path-dialects/00-uri.md= (32 test stubs across 9 schemes + cross-cutting). Per architecture decision, =SchemeHandler= trait lives in =pi-code-path=; concrete impls live in =pi-natives= because each requires environment-bound context (artifact store, session manager, internal-url-router, MCP discovery).

Reference behaviour: =packages/coding-agent/src/tools/read.ts::#handleInternalUrl= already handles all 9 schemes today via =InternalUrlRouter=. This item ports that logic to Rust and exposes via the =SchemeHandler= trait.

* Edge Cases

- =foo:bar= without =//= → not a URI; FS dialect.
- =foo://= empty path → =Diagnostic::EmptyUriPath=.
- Backtick-quoted URI in code-axis context → literal text, not parsed as locator.
- Stale =artifact://= handle: session expired or artifact GC'd → =ArtifactNotFound= diagnostic; never panics.
- =memory://root/...= relative path validation: must stay within memory tree; reject =../=.
- =skill://name= alone vs =skill://name/path= disambiguation: bare resolves to SKILL.md; with path resolves to that file.
- =agent://id/.foo[10]= where field is array of <10 elements → =Diagnostic::IndexOutOfRange=.
- =jobs://j-123= where job not found → =Diagnostic::JobNotFound=.
- =local://MY_PLAN.md= when not found → =Diagnostic::SuffixSuggestion= with closest plan match.
- =mcp://server/path= when MCP server not registered → =Diagnostic::McpServerNotFound=.
