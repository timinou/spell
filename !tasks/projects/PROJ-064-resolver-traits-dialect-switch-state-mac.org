1. *Trait surface*: =Resolver= (top-level), =CodeResolver= (per-language tree-sitter), =EdgeResolver= (graph axis), =UriResolver= (scheme dispatch), =SchemeHandler= (per-scheme), =FormatExtractor= (#text routing — already in =PROJ-text-resolver=), =FsAnchorContext= (¶code/¶image/¶doc context).

2. *Dialect-switch state machine*: per spec §3 of =code-path-extensions.md=. Initial scope = FsDialect; =§file= match → switch to file's code dialect; first =§line=/=§chunk=/=§para= → text dialect; text→code mid-file rejected; =→= edge → cross-file new dialect; URI Locator → scheme dialect → delegate.

3. *Set-ops compositor*: =A | B=, =A & B=, =A - B= over =Stream<NodeRef>=. Streaming-aware union (dedup on canonical locator), intersect (materialise both), except (filter A by absence in B's set).

4. *Projection lowering*: =limit=, =head=, =tail=, =context= flattens to canonical CodePath suffix. Round-trip property: lowered path renders to same canonical string that parses back to same AST.

* Edge Cases

- =§file= match yielding zero files → no dialect transition; resolver emits empty stream; =Diagnostic::NoMatches= optional.
- Multiple =§file= matches → fan out to multiple per-file dialect resolvers; results concatenated.
- =→= edge crossing into a file with no registered LanguageProfile → fall back to text dialect; emit =Diagnostic::UnknownLanguage=.
- URI scheme not registered → =Diagnostic::UnknownLocatorScheme { available: [...] }=.
- Set-op =A - B= where B is unbounded → blocks until B completes; document; consider =Diagnostic::SetOpUnbounded= warning if B has no upper bound.
- Projection =head: 0= or =limit: 0= → empty stream; =Diagnostic::ZeroLimit= optional info.
- Projection =tail: N= requires materialisation; document buffer cost.
- Cancellation mid-batch: emit completed NodeRefs, then =Diagnostic::Cancelled=, then end.
