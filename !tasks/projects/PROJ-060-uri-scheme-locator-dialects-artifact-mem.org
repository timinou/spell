* Scope

First-class CodePath Locator schemes for the seven internal URI kinds. Each scheme is a small =LanguageDialect= registered in the Locator parser's scheme table. After URI resolution, structural queries delegate to the appropriate downstream dialect (text/markdown/json/fs).

Authoritative design: =specs/code-graph/code-path-extensions.md= §2.3.

** In scope
- Kernel grammar extension: =Locator := UriLocator | FsLocator=
- Scheme registry → dispatch table to dialect resolvers
- =artifact://session/agent/tool/N.ext= — slices into stored artifacts
- =memory://root= and =memory://root/<path>= — markdown payload, delegates to MD/Org dialect
- =skill://name= and =skill://name/<path>= — skill SKILL.md or relative file
- =agent://id= and =agent://id/<jq-path>= — JSON field extraction (new JSON sub-dialect)
- =jobs://job-id= — job state document (new Job sub-dialect)
- =local://<filename>.md= — completed plan artifacts; delegates to FS dialect
- =pi://<path>= — internal Spell docs; delegates to FS dialect rooted in pi tree
- =UnknownLocatorScheme= diagnostic with available-schemes hint for typos

** Out of scope
- Implementation of artifact storage, memory system, job tracking (existing systems — wrap, don't reimplement)
- =data:// dataContent= concept (different system, reference-only via FS)
- Tool surface deletion (separate FEAT)

** Existing patterns
- =packages/coding-agent/src/internal-urls/= — current URI resolvers (artifact-protocol.ts, memory-protocol.ts, skill-protocol.ts, agent-protocol.ts, jobs-protocol.ts, local-protocol.ts, pi-protocol.ts)
- =packages/coding-agent/src/tools/read.ts= — current dispatcher logic to URI resolvers; behavior to preserve
- =serde_json::Value= traversal — pattern for JSON sub-dialect
- Memory system in =crates/pi-org-recall= and memory_summary.md storage

** Edge Cases

- Unknown scheme: =Diagnostic::UnknownLocatorScheme { tried, available }= with the seven supported schemes listed
- =foo:bar= (no =//=): treated as FS path, not URI — disambiguates from time strings, port numbers
- Stale artifact handle (file deleted between resolution and content read): emit =Diagnostic::ArtifactStale= attached to NodeRef; partial results returned
- Cross-session artifact references: respect existing signed-URL/auth boundary; failures emit =Diagnostic::ArtifactAuthFailure=
- =memory://root/skills/<name>/SKILL.md= parses as memory + path; resolves to file
- =agent://= with malformed jq path (=...[abc]= where number expected): =Diagnostic::JsonPathError= with span
- =jobs://= for finished job vs running job: state document includes both =result= and =stdout=; running jobs may have partial fields
- URI containing query string or fragment (=memory://root#section=): the kernel =#qualifier= takes precedence over URL fragment; URL fragments not supported in v1
- Backtick-quoted URI in non-Locator position: not parsed as URI scheme
