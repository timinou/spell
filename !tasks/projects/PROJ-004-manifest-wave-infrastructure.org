** Step 1: Define wave types in =packages/org/src/wave-parser.ts=       :foundation:
#+begin_src typescript
export interface WaveEntry {
  orgItemId: string;
  step: string;
}

export interface Wave {
  name: string;
  entries: WaveEntry[];
}

export interface WaveManifest {
  waves: Wave[];
}
#+end_src

** Step 2: Implement TS fallback parser in =packages/org/src/wave-parser.ts= :foundation:
- Function: =extractPlanWaves(orgBody: string): WaveManifest | null=
- Uses =parseOrgHeadings()= to parse org body
- Finds child heading titled "Execution Manifest"
- Under it, finds sub-headings tagged "wave"
- For each wave heading, extracts list items containing =[[id:...]]= links via =extractIdLinks()=
- Step text = list item text after the =[[id:...]]= link
- Returns null if no wave structure found (backward compat)

** Step 3: Export from =packages/org/src/index.ts=                        :foundation:
- Export types: WaveEntry, Wave, WaveManifest
- Export function: extractPlanWaves

** Step 4: Create =packages/org/elisp/tools/org-extract-plan-waves.el=    :core:
- Register as MCP tool: =org-extract-plan-waves=
- Input schema: ={ file: string }= (path to PLAN .org file)
- Parse with org-element: find "Execution Manifest" section (by raw-value)
- Under it, find headings tagged =:wave:=
- For each wave heading:
  - name = heading raw-value
  - entries = extract items containing =[[id:...]]= links from body paragraphs/lists
  - step = text following the link
- Return JSON: ={ waves: [{ name, entries: [{ orgItemId, step }] }] }=

* Edge Cases
- PLAN body has no Execution Manifest heading: return null
- Execution Manifest has no =:wave:= headings: return null (backward compat)
- Wave heading with no entries: empty entries array
- Entry with =[[id:...]]= but no description: step = "" (empty string)
- Multiple =[[id:...]]= links in same list item: first one used for orgItemId, rest ignored
- Emacs not running: TS fallback parser used seamlessly
- org-element parse failure in elisp: return error JSON, TS caller catches and falls back
- Wave name with special characters: heading raw-value is used as-is
