* Intention & Purpose

Define and ship the trait surface that every dialect's =#qualifier= and =[¶anchor]= will
resolve against. Currently =QualifierSpec.resolver= is universally a =StubResolver= that
returns 0..0 byte ranges and =AnchorPattern.matcher= is a fn pointer that's defined per
dialect but **never invoked at query time**. This item delivers the framework + spec doc
+ Rust dialect as the pilot implementation. FEAT-672..679 (per-dialect work) all build
on these contracts.

* Context & Narrative

Per audit (=memory://root= / agent://33-Spec): all 8 dialects register =QualifierSpec=
entries with names like =body=, =name=, =sig=, =decorators=, =return-type=, etc., but
the =resolver: Box<dyn QualifierResolver>= is universally =StubResolver= which returns
=Range { start: 0, end: 0 }=. So =foo.ts::Bar#body= parses correctly, the qualifier is
attached, but its byte range is wrong → the get tool returns the entire file or nothing.

Anchors have a similar issue. =AnchorPattern.matcher: fn(node, src) -> bool= is defined
per dialect but =CodeResolver.evaluate_query= does not call it for =Predicate::AnchorFilter=
or =Head::AnchorName=. So =foo.ts::Bar[¶return]= (filter to functions containing a return)
silently no-ops.

This item ships:
1. A real =QualifierResolver= trait + invocation point in =CodeResolver=
2. A real =AnchorEvaluator= surface invoked for =[¶name]= predicates and =¶head= locators
3. The Rust dialect's qualifiers and anchors as the proof-of-concept pilot

The remaining 7 dialects are subsequent FEAT items.

  - =#where= — return =where ...= clause range if present
  - =#attrs= — concat attribute ranges; if multiple, return aggregate byte span
  - =#visibility= — =pub=/=pub(crate)= range if present
  - =#match-arm[N]= — Nth match arm in a =match= expression
  - =#unsafe-block= — first =unsafe { }= block range within node
- Each returns =NodeRef= with =Content::Text { start, end }= byte range; failures emit a
  =Diagnostic= but do NOT panic

* Edge Cases

- Tree-sitter parse failure → diagnostic, qualifier returns 0..0 with error
- Qualifier =#body= on node without body (=const X = 1=) → empty range + warning diagnostic
- Anchor matcher returning =true= for non-applicable nodes — guard with kind check
- Multiple anchors of same name in a node — =[¶X]= is boolean, dedup not relevant
- =#match-arm[N]= where N exceeds arm count → empty range + diagnostic
- Performance: anchor matcher fired per candidate node; cache nothing for now (FUP target)
