* Initial Message

how would you implement the full vision of codepath v3? in a way that replaces the need for the find and the read tools? and maybe even for the grep tool, not sacrificng any flexibility?

* Scope

Implement the Text dialect as a baseline component of =crates/pi-code-path=. Every file regardless of code dialect supports a parallel text view via =§line=/=§chunk=/=§para=/=§span= node kinds. Bypasses tree-sitter entirely for cost. Replaces both =read= (slice + content delivery, including format-aware extraction) and =grep= (regex search, optionally cross-file via FS-glob locator).

Authoritative design: =specs/code-graph/code-path-extensions.md= §2.2, §3, §4.

** In scope
- Node kinds: =§line= (1-indexed), =§chunk= (N-line block, default N=20), =§para= (blank-line-separated), =§span= (regex match span)
- Combinators on text nodes: =<<= and =>>= specialized for adjacent lines (context windows)
- Predicates: =[text~="re"]=, =[match="literal"]=, =[len>N]=, =[multiline]=, =[startsWith="…"]=, =[endsWith="…"]=, =[a..b]= (line slice), =[last]=, =[-N..]=
- Qualifiers: =#raw=, =#text= (format-aware), =#match=, =#captures[N]=, =#lines[a..b]=, =#bytes=, =#image=, =#thumbnail[size]=
- Lazy line-byte index built on first text-axis use
- Multiline regex via inline =(?m)= / =(?s)= flags (no separate option)
- Format-aware =#text= extraction routed by MIME: PDF, DOCX, JSON-pretty, HTML-readable
- Streaming match iterator over lines for cross-file glob locators
- Encoding: UTF-8 default with latin-1 fallback (parity with =read.ts=)

** Out of scope
- FS dialect (proj-fs-dialect)
- URI scheme dialects (proj-uri-dialects)
- Code-dialect parsing — text dialect deliberately bypasses tree-sitter
- Tool surface deletion (separate FEAT)

** Edge Cases

- Files >100 MiB: stream lines; never load whole file unless =#raw= or =#bytes= explicit; emit warning diagnostic
- Binary file in text query: =[¶text]= filter excludes; =#text= refuses with =Diagnostic::BinaryFile=; =#bytes= always works
- Multiline regex spanning huge windows: cap window size to 16 lines by default; emit =Diagnostic::MatchWindowTruncated= when capped
- Encoding: UTF-8 default; emit =Diagnostic::EncodingFallback= for latin-1 fallback (parity with read.ts)
- CRLF: line index normalizes; line numbering preserved; rendering preserves original line endings
- =§para= over a file with no blank lines = entire file as one para
- =§chunk[n=N]=: N parsed from predicate args; default 20
- =[text~=…]= against a binary file: predicate yields zero matches (not error) when no text bytes detected
- Capture groups beyond what the regex defines: =Diagnostic::InvalidCaptureIndex=
- =#thumbnail[size]= for non-image: =Diagnostic::NotAnImage=
