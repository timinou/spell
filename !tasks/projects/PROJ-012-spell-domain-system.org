## Edge Cases

- Missing .spell/domain.json: fall back to heuristic then default
- Invalid domain name in config: error with available domains
- Domain manifest missing required fields: schema validation error
- Coding domain must work identically to current behavior (no regression)
- Domain with empty tools.include: error (agent needs at least some tools)

## Acceptance Criteria

- Running `spell` in a dir with `.spell/domain.json: {"domain":"growth"}` loads growth domain manifest
- Running `spell --domain coding` in same dir overrides to coding
- Running `spell` in a normal code dir defaults to coding with no behavior change
- All existing tests pass (backward compatibility)
- Domain tool filtering works: growth domain excludes coding-specific tools (lsp, ast_grep, ast_edit)
- Domain prompt assembly replaces persona while preserving tool documentation
