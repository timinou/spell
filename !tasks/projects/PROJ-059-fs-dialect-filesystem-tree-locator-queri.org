* Initial Message

how would you implement the full vision of codepath v3? in a way that replaces the need for the find and the read tools? and maybe even for the grep tool, not sacrificng any flexibility?

* Scope

Implement the FS dialect as a baseline (always-present) component of =crates/pi-code-path=. Every CodePath whose Locator is a project-relative filesystem path resolves through this dialect. Standalone =FsLocator= queries (no =::Query=) yield a NodeSet of files, replacing the =find= tool surface.

Authoritative design: =specs/code-graph/code-path-extensions.md= §2.1, §3, §4.

** In scope
- =FsName= NamePayload: glob path with =*=, =**=, =?=, =[abc]=, ={a,b}= operators
- Node kinds: =§dir=, =§file=, =§symlink=
- Anchors: =¶hidden=, =¶ignored=, =¶lockfile=, =¶code=, =¶doc=, =¶image=, =¶binary=, =¶large=
- Predicates: =[ext=…]=, =[lang=…]=, =[size>N]=, =[mtime>…]=, =[name="glob"]=, =[depth=N]=, =[empty]=, =[text]=
- Qualifiers: =#listing=, =#tree[depth=N]=, =#stat=
- Streaming walker on =ignore= crate; respects =.gitignore= by default; hidden files included by default (parity with current =find=)
- Suffix/typo fuzzy fallback when zero matches (parity with current =read= behavior)
- =NodeRef= emission with =metadata= populated for =#stat=

** Out of scope
- Code-tree resolution past the FS layer (PROJ-052 dialect-switch resolver)

** Edge Cases

- Glob crossing project root via =..=: rejected at parse unless =root= projection option overrides
- Symbolic-link cycle: =ignore= crate detects and skips; document behavior
- Permission-denied entries: emit =Diagnostic::Inaccessible= as per-NodeRef diagnostic, do not abort walk
- Globstar with no slash separator (=foo**bar=): reject at parse with span diagnostic
- Path containing CodePath-significant chars (=::=, =/=, =#=): require backtick quoting (Q-1 from dialects README)
- =[name=…]= predicate uses leaf-name only matching, not full path; matches =find -name= semantics
- =[size>…]= unit suffixes (=K=, =M=, =G=): supported
- =[mtime>…]= accepts RFC3339 datetime or =YYYY-MM-DD= shorthand
- Cross-file=NodeSet returned by =FsLocator= — combinators with =|=, =&=, =-= work uniformly
