* Scope

New NAPI function =executeCodePath= in =crates/pi-natives= that exposes the CodePath v3 query engine to TypeScript. Sits alongside existing =executeCodeBuffer= and =executeCodeGraph=.

** In scope
- New NAPI function =executeCodePath= accepting CodePath expression + command (get/edit)
- Input schema: ={ command: "get" | "edit", target: string, resolution?: number, offset?: number, limit?: number, actions?: Action[], root?: string }=
- For =get=: parse target as CodePath, resolve against tree-sitter AST + code graph, return result set
- For =edit=: parse target as CodePath, resolve to target node(s), apply actions
- Special targets: =:dead_code=, =:clusters=, =:status=, =:index= for manage-class commands
- Legacy targetId compatibility: =/file::Symbol.member/ is valid CodePath syntax (=Locator :: NamePayload=) — no shim needed
- =LegacyNameLexer= that accepts today's =Foo.bar= dotted format for all languages as fallback
- TypeScript types in =packages/natives/src/code-path/types.ts=
- Result types: =CodePathResult= with =nodes: ResolvedNode[]=, =content?: string=, =diff?: string=

** Out of scope
- Code tool surface changes (separate PROJ)
- The kernel parser and resolver (done in [[id:PROJ-052-pi-code-path-crate-codepath-v3-parser-as]])
- NameLexer implementations (done in [[id:PROJ-053-namelexer-implementations-for-all-8-code]])

** Edge Cases

- Malformed CodePath target: return structured parse error with span info
- Target resolves to zero nodes: return empty result with "no matches" message, not error
- Target resolves to multiple nodes for edit: return error "ambiguous target, N matches"
- File in locator not on disk: open as code buffer (may create), or error for get
- Graph not indexed: auto-index for edge axis commands, return cache_status
- Timeout during edge resolution (large graph): respect CancelToken
