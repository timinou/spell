* Edge Cases

- Symbolic-link cycle: walker skips (ignore crate handles); test fixture includes one cycle.
- Permission denied: per-NodeRef =Diagnostic::Inaccessible=; walk continues.
- Glob crossing project root via =..=: rejected at parse time (handled in =PROJ-061=); resolver assumes well-formed input but defensively rejects =..= segments with =Diagnostic::PathTraversal=.
- =[name=…]= matches leaf only, never project-relative path. Test D-6.
- =[size>1M]= power of 1024 (1048576), not 1000. Test D-7.
- =[mtime>2026-01-01]= start-of-day UTC. Test D-8.
- Cross-file NodeSet: =A | B= union via dedup-on-canonical-path. =A - B= with overlapping streams: stream A and skip any path matching B's set. =A & B= materialises both then intersects.
- =¶binary= UTF-8 sniff: first 8 KiB; reject on invalid sequence; emit =Diagnostic::EncodingFallback= if latin-1 retry succeeds.
- Suffix-fallback zero-result: emit =Diagnostic::NoMatches= with =SuffixSuggestion= as additional hint, not as result substitution. The caller decides whether to retry.
- Cancellation: token check inside the walker's batch boundary (every 100 entries) to bound abort latency.
