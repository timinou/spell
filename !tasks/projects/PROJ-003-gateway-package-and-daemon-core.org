** Edge Cases
- Stale socket file on disk: probe before bind, remove if dead (same pattern as QML bridge socketserver.cpp)
- Registry file doesn't exist on first run: initialize with empty ~{services: {}}~
- Registry file corrupted: backup to .bak, start fresh (same pattern as browser service-registry.ts)
- Managed process refuses to die: SIGTERM → 2s wait → SIGKILL → 3s wait → log error
- Multiple daemon instances: second bind attempt fails, log error pointing to existing daemon
- Session cleanup for non-existent sessionId: no-op, return success
- Service alias validation: lowercase alphanumeric + hyphens only, max 63 chars (DNS label rules)
