* Implementation
Preferred sequencing: elisp tool first, then TS wiring, then post-write hook, then tests.

** Step 1: Create =packages/org/elisp/tools/org-compute-waves.el=
- Register as MCP tool: =org-compute-waves=
- Input: =file= (path to org category directory or specific file)
- Algorithm:
  1. Collect all headings with CUSTOM_ID containing =::= (sub-outlines)
  2. Parse DEPENDS property for each sub-outline
  3. Build dependency DAG from sub-outline refs
  4. Detect cycles (reuse =org-mcp--detect-cycles= from dependency-graph.el)
  5. Topological sort into layers (BFS/Kahn's algorithm)
  6. Assign wave numbers to each sub-outline
  7. Set =:WAVE: N= property on each sub-outline heading
  8. Compute =:WAVES:= summary for parent headings
- Return JSON: ={ waves: [{ number: N, items: [{ customId, parentId, title }] }], warnings: [...] }=

** Step 2: Wire cmdWave in =packages/org/src/tool.ts= to include computation
- cmdWave now calls =org-compute-waves= (not just =org-next-wave=)
- Or: cmdWave calls =org-next-wave= for runtime queries, separate command for computation
- Decision: add =compute= option to cmdWave to trigger full computation vs just querying

** Step 3: Post-write hook in org tool
- After =cmdCreate= or =cmdUpdate= modifies DEPENDS property, call =org-compute-waves= for the category
- Capture warnings, inject as friendly prompt messages

** Step 4: Add WAVE to schema
- Add =WAVE= to =RECOMMENDED_PROPERTIES= in =defaults.ts=
- Add =WAVE_REGEXP= for validation: =/^[0-9]+$/= (single integer)
- Add =WAVES_REGEXP=: =/^[0-9]+(,[0-9]+)*$/= (comma-separated integers)

* Edge Cases
- No sub-outlines with CUSTOM_ID: return empty waves (backward compat)
- Sub-outline DEPENDS on top-level item (not sub-outline): valid -- top-level item is implicitly wave 0
- Very deep dependency chain: many waves, no limit (planner decides granularity)
- Multiple disconnected subgraphs: each gets independent wave numbering starting from 1
- Category with hundreds of items: full recompute may be slow -- benchmark and log timing
