* Edge Cases
- Loop start with same name as existing active loop: reject with error
- Loop done with no active loop: return error, do not crash
- Concurrent modification: two loop_done calls for same loop in rapid succession
- EventBus subscriber throws: must not crash loop kernel
- Empty task file at iteration start: pause loop, report error
