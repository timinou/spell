Implement =MutationResolver= for =FsResolver= (file-create / write / delete) and
=TextResolver= (line-level append / prepend / insert / replace / patch). Migrates the
work today done by =create.ts::fs.writeFile= + =edit.ts::applyHashlineEdits= behind
the kernel boundary.

- Race: two processes writing same file. Atomic rename ensures one wins; loser's
  Diagnostic includes =EDIT_RACE=
- Symlink: write through symlink writes the target. Document this
- Trailing newline preservation: detect line ending, preserve in writes
- BOM: detect, strip before logical operations, restore on write
- Hash algorithm: must match TS-side computeLineHash exactly. Cross-language test
  fixture verifying parity.
