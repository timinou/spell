The =FormatExtractor= trait is defined in =PROJ-063-text-resolver= (kernel side). This item provides the concrete impls that live in =pi-natives= because they require external binaries (markitdown), large parser deps (lol_html for readable mode), or complex state machines.

* Edge Cases

- markitdown binary missing: emit =Diagnostic::MarkitdownNotFound= with install hint =uv tool install markitdown= or =pip install markitdown=.
- Extraction times out (default 30s, configurable): emit =Diagnostic::ExtractionTimeout=; partial output discarded.
- Encrypted PDF: markitdown fails; emit =Diagnostic::ExtractionFailed { reason: "encrypted" }=.
- Massive output (>10 MiB extracted text): spill to artifact; return =Content::Bytes= handle.
- Concurrent extraction: serialised per-file (lock); avoid markitdown CPU contention.
- Non-UTF-8 in extracted text: latin-1 fallback; emit =EncodingFallback=.
- HTML with no readable content (pure boilerplate): emit empty string; no diagnostic.
