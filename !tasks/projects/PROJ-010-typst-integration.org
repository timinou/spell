* Edge Cases

- typst-ts WASM fails to load: show error in preview pane, editor still works
- Custom fonts not found: fall back to system fonts, warn in preview
- YAML data file malformed: show error in preview, highlight offending line
- Template references missing branding import: brand guardian catches before compile
- Large documents (100+ pages): typst-ts incremental compilation handles this, but test performance
- typst CLI not installed: PDF export fails gracefully with install instructions
- Multi-file project with circular imports: typst compiler catches, surface error

* Acceptance Criteria

- Typst source compiles to SVG in WebEngineView via typst-ts WASM in under 500ms for a 10-page document
- Monaco editor shows Typst syntax highlighting (keywords, strings, functions, math)
- Clicking a paragraph in SVG preview jumps editor cursor to corresponding source line
- YAML data.yaml values appear in rendered output
- Spell branding package compiles and produces visually correct output (screenshot artifact)
- Brand guardian rejects file without branding import, accepts file with correct branding
- =typst compile= produces valid PDF from any template + sample data
