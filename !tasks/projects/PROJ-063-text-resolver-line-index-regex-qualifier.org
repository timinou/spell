* Context & Narrative

* Edge Cases

- D-1: Encoding fallback UTF-8 → latin-1 emits =Diagnostic::EncodingFallback=.
- D-2: Large files: streaming only; =#raw= or =#bytes= or =#text= returns =Content= via the artifact store (handled at =pi-natives= NAPI layer for >threshold; this layer decides threshold).
- D-3: Multiline regex via inline =(?m)= / =(?s)=; no separate dialect option.
- D-4: =#text= routing → markitdown for PDF/DOC/DOCX/PPT/PPTX/XLS/XLSX/RTF/EPUB; native for JSON, HTML; fallback to =#raw= for unknown extensions. The dispatch logic lives here; concrete extractors in =PROJ-extraction-handlers=.
- D-5: Binary content NEVER inlined. =#bytes= and =#image= always return artifact handles. =#raw= on a binary file emits =Diagnostic::BinaryContent= and refuses inline transfer.
- D-6: =#captures[N]= post-processes already-matched NodeRef; out-of-bounds N → =Diagnostic::CaptureIndexOutOfBounds=.
- D-7: Overlapping spans from one line returned as separate NodeRefs; coalescing only on opt-in projection.
- D-8: CRLF normalisation: LineIndex on =
= only; =\r= preserved in content; rendering preserves source line endings.
- D-9: Empty file: §line, §chunk, §para empty sets; =#raw= empty string.
- D-10: Single line no trailing newline: line 1 valid; =[last]= = =[-1..]= resolves correctly.
