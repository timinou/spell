## Scope
IN: Configurable shell.qml via bridge.props (sidebar width 280px, panel list from domain, persistent bottom chat drawer, workspace layout switching). Workspace layout definitions (Research, Strategy, Create, Review, Campaign, General) as JSON configs in .spell/workspaces/ or domain/growth/workspaces/. Each workspace: panel arrangement (which panels visible, split ratios). Persistent bottom chat drawer: collapsible, multi-agent tabs (tab per agent, active chat focus), card overview (all agents' status summary). Panel state persistence to .spell/growth/panel-state.json (filter states, scroll positions, selections). Panel context emission: armed tools for deterministic queries (e.g. SQLite), bridge.send for visual events, agent prompt for interactive. Workspace switching activates default mode (tight coupling), overridable. Session persists across workspace switches.
OUT: Individual panel implementations (FEAT-A through FEAT-D). Mode behavior definitions (FEAT-E). Multi-agent subprocess architecture (FUP).

## Edge Cases
- Workspace config references panel that hasn't loaded yet: show placeholder, load when available
- Chat drawer resize beyond bounds: clamp to min 56px, max 50% of window height
- Agent tab for finished agent: keep tab, show 'completed' status, messages still readable
- Workspace switch during agent response: don't interrupt agent, continue receiving in background
- Panel state file corrupted: ignore, start fresh, log warning
