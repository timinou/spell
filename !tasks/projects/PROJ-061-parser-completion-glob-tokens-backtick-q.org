* Edge Cases

- =foo**bar= globstar without =/= boundary → =Diagnostic::ParseError= with span pointing to the second =*=.
- Unterminated backtick at EOF → ParseError; no silent close.
- Empty glob segment (consecutive =//=) → already handled as Descendant combinator; no ambiguity since CharClass starts with =[=.
- Brace with single alt ({foo}) → keep as Brace with one item; renderer emits ={foo}=.
- Nested braces ({a,{b,c}}) → flatten at parse time? Spec ambiguous. Decision: reject nested braces (=Diagnostic::UnsupportedGlob=); document.
- =[size>0]= → CompareOp::Gt with value 0 (zero-byte file matcher); not =[empty]= (alias).
- =[mtime>2026-01-01]= without time component → start-of-day UTC.
- =[name="*.test.ts"]= unquoted vs quoted: both accepted; quoted preserves leading/trailing whitespace.
- Recursive =[. Q]= depth: cap at 8 levels to prevent stack blow on adversarial input; emit =Diagnostic::SubqueryDepthExceeded=.
