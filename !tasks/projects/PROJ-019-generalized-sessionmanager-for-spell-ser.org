* Edge Cases
- RPC client crashes mid-session: =SessionManager= detects via exited promise, removes entry, persists state
- Concurrent =getOrCreate= for same key: second call waits for first spawn to complete; no double-spawn
- State file corrupted: catch parse error, start fresh with empty map
- Max sessions reached: throw descriptive error; caller handles
