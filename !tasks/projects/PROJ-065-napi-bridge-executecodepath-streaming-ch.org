* Intention & Purpose

Expose the CodePath resolver to the TypeScript tool layer via NAPI. Implement =executeCodePath= as a streaming chunked async-iterator function in =crates/pi-natives/src/code_path.rs=. This is the boundary between the Rust kernel (=pi-code-path= traits + resolvers) and the four generic TS tools (=get=, =edit=, =manage=, =create=).

* Context & Narrative

Per spec =code-path-extensions.md §6=, the NAPI surface carries 3 commands (=get=, =edit=, =manage=); =create= is a TS-side ergonomic wrapper that lowers to =edit { action: { kind: "create" } }= before crossing the boundary.

Streaming via NAPI threadsafe-functions emitting batches of =CodePathChunk= (default 64 NodeRefs/chunk). Cancellation via =AbortSignal= → Rust =CancellationToken=. Binary content (=Bytes=, =Image=, =ExtractedText for large outputs=) staged to artifact store; never inlined.

This item depends on =PROJ-064-resolver-traits= (the dispatch engine + traits) being shipped. The concrete sub-resolvers (Code, Edge, URI scheme handlers) are sibling items that this NAPI bridge composes.

User workflows:

1. Bare path get: =executeCodePath({ command: "get", target: "src/foo.ts" })= → stream of one NodeRef.
2. FS glob: =executeCodePath({ command: "get", target: "**/*.ts" })= → stream of file NodeRefs.
3. Text slice: =executeCodePath({ command: "get", target: "foo.ts", offset: 50, head: 100 })= → 100-line text.
4. Regex search: =executeCodePath({ command: "get", target: "src/** :: §line[text~=\"TODO\"]" })= → matching lines.
5. Code symbol: =executeCodePath({ command: "get", target: "src/foo.ts :: Bar.baz" })= → symbol NodeRef.
6. URI scheme: =executeCodePath({ command: "get", target: "memory://root" })= → memory file content.
7. Edit: =executeCodePath({ command: "edit", target: "foo.txt", actions: [{ kind: "replace", pos: "10#AB", end: "12#CD", content: "..." }] })= → success/diff result.
8. Manage: =executeCodePath({ command: "manage", manage: "save", target: "foo.ts" })= → save result.
9. Streaming: large query yields multiple chunks; each chunk has =done: false= except last.
10. Cancellation: AbortSignal aborts mid-stream; final chunk has =Diagnostic::Cancelled=.
11. Binary content: =target: "img.png#image"= → NodeRef.content is =Image= with =artifact://= handle, no inline base64.
12. Encoding fallback: latin-1 file with =#raw= → NodeRef.diagnostics contains =EncodingFallback=.
13. Suffix-fallback: typo path → result includes =Diagnostic::SuffixSuggestion=.
14. Diagnostics surface: every error path emits a typed =Diagnostic=, no panics.

* Edge Cases

- Empty target string → =Diagnostic::ParseError=.
- Target with =::Query= but no Locator → =Diagnostic::ParseError= ("locator required").
- Cancellation before stream starts → first chunk has =Diagnostic::Cancelled=, =done: true=.
- Target referencing a deleted file mid-stream → per-NodeRef =Diagnostic::FileNotFound=, stream continues.
- Edit action against non-existent file → =Diagnostic::FileNotFound= (not auto-create; use =command: "create"= or =action: { kind: "create" }= explicitly).
- =command: "manage"= with unknown subcommand → =Diagnostic::UnsupportedOperation=.
- Concurrent calls share session: each call gets its own =CancellationToken=; no cross-call interference.
- NAPI threadsafe function backpressure: if TS side pulls slow, queue grows; cap at 4 chunks queued; emit =Diagnostic::Backpressure= if exceeded; drop oldest? policy decision: block sender (preserves correctness over throughput).
- Binary content over 100 MiB → reject with =Diagnostic::ContentTooLarge=; require explicit chunked read.
