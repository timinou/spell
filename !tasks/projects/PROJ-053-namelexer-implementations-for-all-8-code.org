* Scope

Implement =NameLexer= + =LanguageDialect= (anchors, qualifiers, edge_kinds) for all 8 language dialects specified in =specs/code-graph/code-path-dialects/=. Each dialect registers into its =LanguageProfile= in =crates/pi-code-engine/src/language/mod.rs=.

** In scope
- TypeScript NameLexer: dotted identifiers (=Foo.bar.baz=), JSX elements, private fields (=#field=), computed properties, overload signatures
- Rust NameLexer: =::=-separated paths (=crate::module::item=), turbofish (=parse::<i32>=), impl-for (=impl_Trait_for_Type=), macro invocations
- Python NameLexer: dotted identifiers (=module.Class.method=), decorators as =[decorator=...]= attribute
- Go NameLexer: dotted identifiers (=Package.Function=), receiver methods (=(Type).Method=)
- Haskell NameLexer: module-qualified (=Data.Map.lookup=), operators in parens (=(<$>)=), typeclass instances
- HTML NameLexer: CSS-selector-like (=#id.class tag=), text-content based (heading by quoted text), XPath attribute semantics for =@=
- CSS NameLexer: selector strings (=.class-name #id tag=), property names, at-rule payloads (=@media (...)=)
- Markdown/Org NameLexer: heading text (quoted or unquoted), code block language, list position
- Per-dialect anchor, qualifier, and edge_kind registries per dialect spec
- Extend =LanguageProfile= with optional =LanguageDialect= field
- Each NameLexer backed by winnow sub-parser, composable with kernel grammar

** Out of scope
- Kernel parser (done in [[id:PROJ-052-pi-code-path-crate-codepath-v3-parser-as]])
- NAPI bridge and code tool changes

** Edge Cases

- Go and Haskell have dialect specs but may not have tree-sitter profiles in pi-code-engine yet — need to verify and potentially add stub profiles
- HTML =@= rebinding: must be clearly scoped to HTML dialect only, no leakage to other dialects
- CSS =@media= payload containing parens: winnow parser must handle nested parentheses
- Haskell =(<$>)=: operators with special chars must be quoted in payload parser
- Markdown heading levels: =#= conflicts with qualifier sigil — heading level is part of NamePayload, not a qualifier
- Cross-dialect ambiguity: =.class= is a CSS selector vs TS member access — locator determines dialect
