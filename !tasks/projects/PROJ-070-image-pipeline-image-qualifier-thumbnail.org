* Edge Cases

- Image with corrupted header: =Diagnostic::InvalidImage=.
- SVG with embedded JS: strip to safe SVG before display? Out of scope; pass through.
- Animation (GIF, animated WEBP): use first frame for =#image=; =#thumbnail[N]= same.
- EXIF-rotated JPEG: respect rotation before resize.
- Image too small to thumbnail: skip upscale, emit hint.
- =#thumbnail= without args: default size 512.
- Image qualifier on non-image file: =Diagnostic::UnsupportedQualifierForExtension=.
- Concurrent image processing: per-file lock (avoid re-decoding).
