After the unified config loader ships, =.spell/domain.json= becomes a legacy fallback. This follow-up tracks:

1. Adding a deprecation log warning in =detectDomain= when =domain.json= is used (done as part of FEAT-313)
2. Updating any documentation that references =domain.json= to point to =spell.kdl=
3. Eventually removing =domain.json= support (not in this plan — requires a major version bump)

* Not Blocking
This is informational. The deprecation warning ships with FEAT-313. Full removal is a separate future decision.
