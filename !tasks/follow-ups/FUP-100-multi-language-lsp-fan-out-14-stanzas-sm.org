* Scope cut

The original FUP-094 plan called for per-language fixture + integration test. Recut to two complementary tests instead:

1. =each_language_dispatch_survives_smoke_query= \u2014 iterates 14 sample files (one per language), dispatches =#diagnostics= against each. Asserts dispatch produces at least one chunk and no errors. Catches misconfigured KDL stanzas (wrong =file-types=, malformed =args=, etc.) without LSP installation requirements.

2. =python_hover_dispatches_via_pyright= \u2014 #[ignore]-gated, runs only when =pyright-langserver= is on PATH. Demonstrates the integration-test pattern; future languages get one line each.

Smoke + one-installed-LSP per batch is sufficient. Real end-to-end coverage scales linearly with PATH availability, not with code.
