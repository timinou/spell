* Problem

=#executeRender()= calls =markTreeDirty()= every frame, marking ALL Containers dirty. The =#dirty= / =#cachedLines= / =#cachedWidth= caching logic in =Container.render()= never returns cached because everything is always dirty when render executes. ~20 lines of caching infrastructure that never activates.

This was a deliberate compromise in PLAN-138: leaf components (Editor, Input) mutate internal state without Container operations, so the tree must be fully dirtied to ensure their changes render. The caching was kept as scaffolding.

* Options

** Option A: Remove dead caching (simplify)
Remove =#cachedLines=, =#cachedWidth=, cache check from =render()=, =markTreeDirty()= call from =#executeRender=. Keep =markDirty()= / =#parent= as public API. Update container-dirty tests that assert cache identity (=== same reference).

** Option B: Enable caching via leaf dirty signaling (full fix)
Add an optional =onDirty= callback mechanism: Container sets it on children during =addChild()=, leaf components call it when state changes. This lets specific subtrees stay clean when only one leaf changed. Requires touching Component interface or adding a convention for leaf components.

* Decision needed
Option A is simpler but loses the infrastructure. Option B delivers the original optimization but requires Component interface changes across coding-agent.
