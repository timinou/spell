PLAN-320 deferred item #5: batch glob operations for the unified edit surface.

When a CodePath target is a glob (e.g. `src/**/*.ts :: oldName`), the edit dispatch should expand it to a file list and apply the same op to each file.

**Missing infrastructure:**
- `Op::Clone` — Op variants contain non-Clone fields (SymbolTarget wraps CodePath which wraps query trees)
- `Op::set_target_codepath()` — no setter for replacing the CodePath in an Op
- `render_fs_locator()` — no function to convert FsLocator segments back to a glob string
- `match_glob_in_root()` — no function to walk a directory with a GlobSet and return matching file paths

**Implementation plan:**
- `FsLocator::render()` — join segments back to a path string
- `Op::clone()` — derive Clone for Op and all its contained types
- `Op::with_target()` — builder-style setter returning a new Op with replaced target
- `glob_util::match_in_dir(glob_set, root) -> Vec<PathBuf>` — walk directory, return matches
- Wire into `napi.rs:581` — before `file_groups` construction, for glob targets, expand to file list
