* Initial Message

PLAN-318 W4 adds the =#hover= qualifier returning *written* signature text from =SymbolNode.detail= (extracted by tree-sitter from declaration sites). Example output for TypeScript:

#+begin_example
function processItems(items: Item[], opts?: Options): Promise<Result>
#+end_example

What it CANNOT do without type inference:

#+begin_example
const result = computeValue();        // result: <unknown>
//   ^ hover                          // LSP would show: result: Promise<string>
#+end_example

This FUP scopes adding inferred-type rendering inside =pi-code-graph= (NOT an LSP bridge — staying static, per direction).

* Design Space (open — needs design pass before implementation)

** A. Mini type-checker per language
Build a minimal forward-inference pass: literal types, function-return-type propagation, simple generics. Skip union narrowing, control-flow refinement, conditional types.

Pros: stays static, fast.
Cons: per-language re-implementation; never matches a real type-checker.

** B. Embed compiler-as-library
- TypeScript: =@typescript/vfs= + bundled =typescript= for partial inference on a synthetic =Program=.
- Rust: =rust-analyzer= internal crates (not stable API), or =rustc_private=.
- Python: =pyright= core extracted.

Pros: matches LSP precision.
Cons: huge deps, slow cold start, version churn.

** C. Hybrid annotation-first
Default to written types (W4 behavior). Add =#hover_inferred= qualifier that opts into the mini type-checker for that query only.

Recommendation: C, mini-checker is option A scoped tight.

* Workflows (when picked up)

1. =find { target: "src/foo.ts::result #hover_inferred" }= returns inferred type for unannotated locals.
2. Return-type inference for arrow functions without annotation.
3. Generic instantiation in hover: =Array<string>= not =Array<T>=.
4. Confidence level surfaced: =annotation= (W4) vs =inferred-strong= (forward-flow) vs =inferred-weak= (literal-only).

* Out of Scope

- Type-error diagnostics (separate concern).
- Full type-checking (use compiler).
- LSP bridge.

* Dependencies

- PLAN-318 W4 (=#hover= qualifier and =SymbolNode.detail= extraction) must land first.
- Type-aware reference resolution FUP shares infrastructure (they likely both depend on a per-language =TypeOracle= trait inside =pi-code-graph=).
