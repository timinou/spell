* Edge Cases
- Unknown manifest nodes should round-trip without silent loss or be surfaced as unsupported.
- Partial invalid documents should render recoverable validation errors rather than crashing the editor.
- Concurrent file changes between load and save need stale-write detection.
- Optional Telegram configuration remains optional in the form and output.

* Acceptance Criteria
- A user can load =.spell/autonomy.kdl=, edit supported fields, and save a valid manifest.
- Round-trip tests prove semantic preservation for supported fields.
- QML journey coverage proves the editor is usable end-to-end.
- Unsupported or invalid manifest content is surfaced explicitly, not discarded.
