* Scope
- True multi-agent sessions: independent agents with own tool sets and conversation histories running in parallel
- Agent session multiplexing
- Shared workspace locking to prevent concurrent write conflicts
- Inter-agent communication protocol
- QML tab routing per agent for independent UI surfaces

* Rationale for Deferral
MVP uses main agent + task subagent (subprocess visibility) which handles the majority of workflows. Promoting to first-class multi-agent sessions requires rearchitecting session management, which is out of scope until the single-agent growth workflows are validated.
