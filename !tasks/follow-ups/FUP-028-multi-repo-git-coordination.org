* Scope
When multiple autonomy goals share the same =cwd=, coordinate git operations safely. Reuse the loop-system worktree pattern for concurrent execution, serialize =git pull= per repo with a mutex, and pause/notify affected goals when repo sync fails.

* Edge Cases
- Goals pointing at nested paths inside the same repo must collapse to one repo lock domain.
- A repo already mid-run when another schedule fires should avoid duplicate pull work.
- Worktree cleanup must happen even when goal execution crashes.
- Pull failure handling must distinguish auth/network errors from merge/conflict failures.

* Acceptance Criteria
- Shared-repo goals run in isolated worktrees with coordinated pulls.
- =git pull= happens once at a time per repo root.
- Pull failures pause and notify only the affected goals, with clear diagnostics.
