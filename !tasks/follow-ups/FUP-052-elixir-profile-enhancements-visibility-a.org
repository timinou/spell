* Scope

After the base Elixir outline support lands (FEAT-519), these enhancements can be added:

** Exported/private visibility

Currently all Elixir symbols default to =exported: false=. The fix:
- Add =exported_default: Option<bool>= to =DeclarationPattern=
- In =is_exported()=, if =exported_default= is Some, use it directly
- Set =exported_default: Some(true)= for def/defmacro patterns
- Set =exported_default: Some(false)= for defp/defmacrop patterns
- Set =exported_default: Some(true)= for defmodule

** Additional keywords

Add =DeclarationPattern= entries for:
- =defstruct= (kind: "struct") -- shows struct fields
- =defimpl= (kind: "impl") -- protocol implementation, class-like container
- =defprotocol= (kind: "protocol") -- protocol definition, class-like container
- =defguard= / =defguardp= (kind: "guard" / "guardp")
- =defdelegate= (kind: "delegate")

** navigate.rs name_text unification

Replace the local =name_text()= function in navigate.rs with =declaration_name()= from outline.rs to get consistent name extraction including =name_from_arg= support.
