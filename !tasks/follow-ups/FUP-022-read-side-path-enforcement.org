* Scope
Implement =paths_read= enforcement in sandbox policy so read-side tools cannot escape declared boundaries. Cover =read=, =grep=, =find=, and =bash= code paths where read-like access can be inferred from arguments. This is hardening work for unattended autonomy runs and should land only after the sandbox-policy enforcement feature is complete.

* Edge Cases
- Symlink traversal resolving from an allowed root into a disallowed target.
- Globs that expand partly inside and partly outside allowed roots.
- Empty =paths_read= meaning no filesystem reads, not unrestricted reads.
- Tools that infer cwd or default search paths when the caller omits a path.

* Acceptance Criteria
- All read-side filesystem tools fail closed outside =paths_read=.
- Errors identify the rejected path and policy boundary.
- Shared matcher logic prevents drift between tool implementations.
- Tests prove traversal, globbing, and shell-based escapes are blocked.
