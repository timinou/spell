* Scope
Add a =depends_on= field to autonomy goal config. Before scheduling a goal run, the scheduler should check the last-run status of every dependency and only fire when all dependencies most recently succeeded. This also requires DAG cycle detection at manifest validation time.

Use persisted last-run state consistently so dependency semantics survive daemon restarts.

* Edge Cases
- A dependency with no prior run should block dependents unless explicitly seeded.
- Multiple dependencies should require all-success semantics, not any-success.
- Manual restart/resume flows must respect dependency state instead of bypassing it silently.
- Cycle errors should point to the actual dependency chain.

* Acceptance Criteria
- Manifest validation rejects cyclic or unknown dependencies.
- Scheduler dispatch is blocked until all dependency last runs succeeded.
- Dependency checks use persisted state so behavior is stable across restarts.
