## Scope
IN: Ad gallery QML panel. Filter toolbar (advertiser name search, keyword filter, date range, ad format checkboxes, active/inactive toggle). Grid/list view toggle. Ad cards (thumbnail, advertiser, text preview, date, status badge, format icon). Detail side drawer on card click (full ad text, spend/impressions ranges, landing page URL, creative assets, annotation tools). Annotation: tag, note, star/favorite. 'Analyze' button triggers agent creative analysis. All data from SQLite via armed tools (no LLM round-trip for filtering/sorting).
OUT: Scraper execution (PROJ-C). Agent analysis logic (FEAT-I). Background monitoring (FEAT-H).

## Edge Cases
- 1000+ ads: virtual scrolling in grid, paginated queries
- Ad with no thumbnail: show placeholder with format icon
- Filter returns 0 results: 'No ads match filters' message
- Side drawer open + workspace switch: drawer closes, state preserved for return

## Acceptance Criteria
- Ad gallery renders with seeded data, cards show correct info
- Filtering by advertiser name returns matching ads only
- Clicking card opens detail drawer with full ad info
- Star/tag annotation persists in SQLite
- 'Analyze' button sends ad data to agent via chat
