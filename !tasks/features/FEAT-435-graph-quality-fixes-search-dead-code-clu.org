* Context

The code tool's graph commands (search, dead_code, clusters) have known quality issues identified in the assessment. Search uses BM25 with naive tokenization that doesn't split camelCase or snake_case, so exact symbol lookups fail. Dead_code reports thousands of false positives because it has no concept of entry points, test files, or confidence. Clusters uses Kosaraju SCC which produces hundreds of trivial 1-file clusters instead of meaningful module boundaries.

These fixes are in the existing =pi-code-graph= crate, not the new =pi-code-engine= crate. They don't require the engine to be built first (they depend only on the foundation item for workspace compilation).

* Goal

Fix the 3 weakest graph subtools to bring them from 2/5 to 5/5:
1. Search: camelCase/snake_case tokenization + exact-match boost
2. Dead code: entry point filtering + confidence scoring + test file exclusion
3. Clusters: weakly connected components + minimum size + sort by size

Also add diff-aware graph queries and incremental indexing.

** New Tokenizer
#+begin_src rust
fn tokenize(text: &str) -> Vec<String> {
    let mut tokens = Vec::new();
    for part in text.split(|c: char| !c.is_ascii_alphanumeric() && c != '_' && c != '-') {
        if part.is_empty() { continue; }
        let lower = part.to_ascii_lowercase();

        // Always include the full token
        tokens.push(lower.clone());

        // CamelCase splitting: FluidOrchestrator → [fluid, orchestrator]
        let camel = split_camel_case(part);
        if camel.len() > 1 {
            for seg in &camel {
                let seg_lower = seg.to_ascii_lowercase();
                if seg_lower != lower {
                    tokens.push(seg_lower);
                }
            }
        }

        // snake_case splitting: build_system_prompt → [build, system, prompt]
        if lower.contains('_') {
            for seg in lower.split('_').filter(|s| !s.is_empty()) {
                tokens.push(seg.to_string());
            }
        }
    }
    tokens.sort();
    tokens.dedup();
    tokens
}

fn split_camel_case(s: &str) -> Vec<String> {
    let mut parts = Vec::new();
    let mut current = String::new();
    let chars: Vec<char> = s.chars().collect();
    for i in 0..chars.len() {
        let c = chars[i];
        if c.is_uppercase() && !current.is_empty() {
            // Check if this starts a new word:
            // - Previous char was lowercase: "fluidO" → split before O
            // - Next char is lowercase: "FLUIDo" → split before the last uppercase
            let prev_lower = i > 0 && chars[i - 1].is_lowercase();
            let next_lower = i + 1 < chars.len() && chars[i + 1].is_lowercase();
            if prev_lower || (next_lower && current.len() > 1) {
                parts.push(std::mem::take(&mut current));
            }
        }
        current.push(c);
    }
    if !current.is_empty() {
        parts.push(current);
    }
    parts
}
#+end_src

* Clusters Fix (query.rs)

** Current Algorithm (wrong)
Uses Kosaraju SCC (strongly connected components). Produces hundreds of 1-file clusters because most files aren't in cycles.

** New Algorithm: Weakly Connected Components

Replace =kosaraju_scc= with a simple BFS/DFS on the undirected graph:

#+begin_src rust
pub struct ClusterOptions {
    pub min_size: usize,     // default 2 (filter out singletons)
    pub limit: usize,        // default 20
}

pub fn graph_clusters(&self, options: &ClusterOptions) -> Vec<GraphCluster> {
    let graph = self.graph();

    // Build undirected adjacency: for each edge, connect both directions
    let mut visited = HashSet::new();
    let mut components = Vec::new();

    for node_index in graph.node_indices() {
        if visited.contains(&node_index) { continue; }

        // BFS from this node, following edges in both directions
        let mut component = Vec::new();
        let mut queue = VecDeque::new();
        queue.push_back(node_index);
        visited.insert(node_index);

        while let Some(current) = queue.pop_front() {
            component.push(current);
            // Outgoing edges
            for edge in graph.edges_directed(current, Direction::Outgoing) {
                if visited.insert(edge.target()) {
                    queue.push_back(edge.target());
                }
            }
            // Incoming edges
            for edge in graph.edges_directed(current, Direction::Incoming) {
                if visited.insert(edge.source()) {
                    queue.push_back(edge.source());
                }
            }
        }

        components.push(component);
    }

    // Convert to GraphCluster, filter by min_size, sort by file count desc
    let mut clusters: Vec<GraphCluster> = components.into_iter()
        .enumerate()
        .filter_map(|(id, component)| {
            let files = /* extract file nodes */;
            let symbol_count = /* count symbol nodes */;
            if files.len() < options.min_size { return None; }

            // Compute cluster name from common path prefix
            let name = common_path_prefix(&files);

            Some(GraphCluster { id, files, symbol_count, name })
        })
        .collect();

    clusters.sort_by(|a, b| b.files.len().cmp(&a.files.len()));
    clusters.truncate(options.limit);
    clusters
}

pub fn build_incremental(&self, options: &BuildGraphOptions) -> Result<GraphBuildOutcome> {
    let current_fingerprint = self.compute_fingerprint(&options.root)?;
    let cached = self.cache.load(CACHE_NAME)?;

    if cached.is_none() {
        return self.build(options); // No cache, full build
    }

    let cached = cached.unwrap();
    let old_fingerprint = /* stored fingerprint from cache */;

    let changed = current_fingerprint.changed_files(&old_fingerprint);
    let removed = current_fingerprint.removed_files(&old_fingerprint);

    if changed.is_empty() && removed.is_empty() {
        return Ok(/* cache is fresh */);
    }

    let mut graph = cached.graph; // Start from cached graph

    // Remove all nodes/edges for changed + removed files
    for path in changed.iter().chain(removed.iter()) {
        remove_file_from_graph(&mut graph, path);
    }

    // Re-extract and add only changed files
    for path in &changed {
        let extracted = self.extract_file(path)?;
        add_file_to_graph(&mut graph, extracted);
    }

    // Re-resolve imports for changed files (edges may point to new/removed symbols)
    resolve_imports_for_files(&mut graph, &changed)?;

    // Save updated graph
    self.cache.save(&graph, &current_fingerprint)?;
    Ok(GraphBuildOutcome { graph, fingerprint: current_fingerprint })
}
