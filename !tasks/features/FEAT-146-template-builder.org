* Edge Cases
- Template with zero sections: save disabled, user shown inline validation message
- Component dropped on invalid target: drop rejected, original position unchanged
- Template name collision: append numeric suffix, do not silently overwrite

* Acceptance Criteria
- User can create a new template from component palette by dragging components into sections
- Saved template appears in template selector for use in reports
- Template Mode toggle in editor panel activates/deactivates builder without losing editor state
