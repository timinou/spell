* Problem
The new =pi-embedding-worker= binary must be built alongside the .node native addon and distributed in the same locations so it can be found at runtime.

* Solution
Extend =packages/natives/scripts/build-native.ts= to also build and install the worker binary.

* Design Decisions
- Worker binary built via =cargo build -p pi-embedding-worker= (same profile as the .node file)
- Binary installed to the same =native/= directory as the .node file
- Named =pi-embedding-worker= (or =pi-embedding-worker.exe= on Windows)
- Cross-compilation uses the same =CROSS_TARGET= env var
- The binary must also be included in the =embed:native= script for compiled binary distribution
- No variant suffixes needed (the binary links statically, ISA is handled by the Rust target)

// Build the embedding worker binary
console.log("Building pi-embedding-worker...");
const workerBuildResult = await $`cargo build ${isDev ? "" : "--release"} -p pi-embedding-worker ${crossTarget ? `--target ${crossTarget}` : ""}`.cwd(repoRoot).nothrow();
if (workerBuildResult.exitCode !== 0) {
    console.warn("Warning: pi-embedding-worker build failed (semantic features will be unavailable)");
    // Non-fatal: the .node file is the primary artifact
} else {
    // Find and install the worker binary
    const workerNames = process.platform === "win32"
        ? ["pi-embedding-worker.exe", "pi_embedding_worker.exe"]
        : ["pi-embedding-worker", "pi_embedding_worker"];

    let workerSourcePath: string | null = null;
    for (const dir of profileDirs) {
        for (const name of workerNames) {
            const fullPath = path.join(dir, name);
            try {
                await fs.stat(fullPath);
                workerSourcePath = fullPath;
                break;
            } catch {}
        }
        if (workerSourcePath) break;
    }

    if (workerSourcePath) {
        const workerDestName = process.platform === "win32" ? "pi-embedding-worker.exe" : "pi-embedding-worker";
        const workerDestPath = path.join(nativeDir, workerDestName);
        console.log(`Installing worker: ${workerDestPath}`);
        await installBinary(workerSourcePath, workerDestPath);
    } else {
        console.warn("Warning: pi-embedding-worker binary not found after build");
    }
}
#+end_src

* Important Notes
- The worker binary build is NON-FATAL. If it fails, the .node file is still installed and spell works without semantic features.
- The =installBinary()= function already handles atomic rename (used for .node files), reuse it for the worker binary.
- The =cargo build= command uses the same RUSTFLAGS, CROSS_TARGET, and profile as the main build.
- On Cargo workspace level, building pi-embedding-worker is a separate crate build — it does NOT affect the pi-natives cdylib.
