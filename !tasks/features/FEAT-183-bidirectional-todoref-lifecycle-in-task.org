* Scope
** In scope
- When =task= tool spawns a subagent with =todoRef=, auto-mark the parent's todo item =in_progress= with delegation metadata (=sessionId=, =transcriptPath=, =taskToolId=)
- On subagent completion: auto-mark parent's todo item =completed= with result summary
- On subagent failure: mark parent's todo item with error info (keep status =in_progress= so parent can decide)
- Add =sessionId= field to =SingleResult= in task types
- Serialize todo state mutations through the existing exclusive-lock mechanism to prevent race conditions from concurrent subagent completions
- Emit =todo:change= event after each state mutation so TUI/niri/QML update
** Out of scope
- Nested sub-task propagation (separate item)
- Result forwarding to dependents (separate item)
- Changes to normalizeInProgressTask (done in FEAT-B)
** Boundary rationale
This is the core bidirectional link. It makes todoRef read-write instead of read-only. Needs the delegation field from FEAT-B.

** Implement todoRef state mutations
:PROPERTIES:
:CUSTOM_ID: FEAT-D::todo-mutations
:DEPENDS: FEAT-D::session-tracking
:END:
- File: =packages/coding-agent/src/task/index.ts=
- In the execution path (both sync and async), after spawning each subagent:
  1. If =task.todoRef= is set, resolve the parent's todo phases via =this.session.getTodoPhases()=
  2. Find the task by ID using =findTask=
  3. Set =task.status = "in_progress"= and =task.delegation = { taskToolId: task.id, sessionId, transcriptPath }=
  4. Call =this.session.setTodoPhases(phases)= and emit =todo:change=
- After subagent completes:
  1. Set =task.status = "completed"= and =task.result = { output: truncatedOutput, exitCode }=
  2. Call =this.session.setTodoPhases(phases)= and emit =todo:change=
- After subagent fails:
  1. Set =task.delegation.error = errorMessage= (keep status in_progress)
  2. Emit =todo:change=
- Wrap all mutations in a serialization mechanism (lock or queue) to prevent concurrent subagent completions from corrupting state

* Edge Cases
- Race condition: 3 subagents finish within milliseconds. State mutations must be serialized.
- Subagent session fails to create (e.g., no API key): mark delegation with error, don't mark in_progress
- Parent calls todo_write to mark delegated task =abandoned=: this overrides the delegation. Subagent still runs but its completion update is a no-op (task already terminal)
- todoRef references a task in a completed phase: warn, skip mutation
- Session has no todo phases set: todoRef is a no-op (warn in logs)
