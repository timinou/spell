* Initial Message

how would you move all of spell's config to spell.kdl config? What would it look like? Could you import bits inside other bits? would it be better to have blocks per mode?

* Reference
Read =specs/kdl-config-migration.md= Sections 4.14 and 4.15 for the complete design.

* Context
Users with existing config.yml, models.json, and keybindings.json need a migration path to spell.kdl. This item creates the =spell migrate= CLI command and adds a startup warning when legacy files are detected.

* Design Decisions
- New files: =packages/coding-agent/src/cli/migrate-cli.ts=, =packages/coding-agent/src/commands/migrate.ts=
- Modified: =packages/coding-agent/src/cli.ts= (register command), =packages/coding-agent/src/main.ts= (startup warning)
- =spell migrate= converts YAML/JSON config files to KDL and writes =~/.spell/spell.kdl=
- Does NOT delete legacy files — user verifies then deletes manually
- Startup warning uses =logger.warn= (goes to log file, not TUI)
- =spell migrate --dry-run= shows what would be generated without writing

#+begin_src typescript
import { parse as parseKdl, format as formatKdl, Document, Node } from "@bgotink/kdl";
import { YAML } from "bun";
import * as path from "node:path";
import { getAgentDir, getConfigRootDir, isEnoent, logger } from "@oh-my-pi/pi-utils";
import chalk from "chalk";

export interface MigrateCommandArgs {
  flags: { dryRun?: boolean };
}

export async function runMigrateCommand(args: MigrateCommandArgs): Promise<void> {
  const agentDir = getAgentDir();
  const configRoot = getConfigRootDir();
  const outputPath = path.join(configRoot, "spell.kdl");

  // Check if already migrated
  const exists = await Bun.file(outputPath).exists();
  if (exists && !args.flags.dryRun) {
    process.stdout.write(chalk.yellow(`${outputPath} already exists. Use --force to overwrite.
`));
    return;
  }

  // Detect legacy files
  const configYml = await tryLoadYaml(path.join(agentDir, "config.yml"));
  const modelsJson = await tryLoadJson(path.join(agentDir, "models.json"));
  const keybindingsJson = await tryLoadJson(path.join(agentDir, "keybindings.json"));

  if (!configYml && !modelsJson && !keybindingsJson) {
    process.stdout.write(chalk.green("No legacy config files found. Nothing to migrate.
"));
    return;
  }

  // Generate KDL
  let kdl = "// Migrated from legacy config files by `spell migrate`

";
  if (configYml) kdl += settingsToKdl(configYml) + "
";
  if (modelsJson) kdl += modelsConfigToKdl(modelsJson) + "
";
  if (keybindingsJson) kdl += keybindingsToKdl(keybindingsJson) + "
";

  if (args.flags.dryRun) {
    process.stdout.write(chalk.dim("--- dry run: would write to ") + outputPath + chalk.dim(" ---
"));
    process.stdout.write(kdl);
    return;
  }

  await Bun.write(outputPath, kdl);
  process.stdout.write(chalk.green(`Migrated to ${outputPath}
`));
  process.stdout.write(chalk.dim("Legacy files kept as backup. Delete them after verifying.
"));
}
#+end_src

Converter functions:
- =settingsToKdl(rawSettings)=: Group settings by KDL block using =KDL_SETTINGS_MAP=. Generate block nodes with child value nodes.
- =modelsConfigToKdl(modelsConfig)=: Generate =providers { ... }= block from JSON provider configs.
- =keybindingsToKdl(keybindingsConfig)=: Generate =keybindings { ... }= block from JSON keybindings.

These converters produce KDL TEXT (not Document objects) — simpler to implement and debug. Use string templates, not programmatic AST construction.

Helper:
#+begin_src typescript
async function tryLoadYaml(filePath: string): Promise<Record<string, unknown> | undefined> {
  try {
    return YAML.parse(await Bun.file(filePath).text()) as Record<string, unknown>;
  } catch { return undefined; }
}

async function tryLoadJson(filePath: string): Promise<Record<string, unknown> | undefined> {
  try {
    return await Bun.file(filePath).json();
  } catch { return undefined; }
}

import { Command, Flags } from "@oh-my-pi/pi-utils/cli";
import { runMigrateCommand } from "../cli/migrate-cli";

export default class MigrateCommand extends Command {
  static override description = "Migrate legacy config files to spell.kdl";
  static override flags = {
    "dry-run": Flags.boolean({ description: "Preview without writing" }),
    force: Flags.boolean({ description: "Overwrite existing spell.kdl" }),
  };

  async run(): Promise<void> {
    await runMigrateCommand({
      flags: { dryRun: this.flags["dry-run"], force: this.flags.force },
    });
  }
}

// Detect legacy config files and warn
const legacyFiles = await detectLegacyConfigFiles();
if (legacyFiles.length > 0) {
  logger.warn("Legacy config files detected. Run `spell migrate` to convert.", {
    files: legacyFiles,
  });

async function detectLegacyConfigFiles(): Promise<string[]> {
  const agentDir = getAgentDir();
  const files = ["config.yml", "models.json", "keybindings.json"];
  const found: string[] = [];
  for (const file of files) {
    try {
      const exists = await Bun.file(path.join(agentDir, file)).exists();
      if (exists) found.push(file);
    } catch { /* ignore */ }
  }
  return found;
}

* Edge Cases
- config.yml with settings that don't have KDL mappings → skip with warning
- models.json with TypeBox-specific format → convert to KDL provider syntax
- keybindings.json with arrays (multiple keys per action) → KDL node with multiple arguments
- Unicode in config values → preserved in KDL strings
- File permissions: ~/.spell/spell.kdl might need parent dir creation → =Bun.write()= handles this
