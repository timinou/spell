* Intention & Purpose

Rewrite the memory pipeline so stage 1 emits =episode= org items and
stage 2 emits/updates =concept= org items, both via =executeOrg::remember=.
Delete =MEMORY.md= writing entirely; replace =memory_summary.md=
generation with a deterministic projection over the concept graph
rendered through a Handlebars template. The =bun:sqlite= job queue at
=packages/coding-agent/src/memories/storage.ts= stays — only its outputs
change.

* Context & Narrative

Spec: =specs/org-graph-memory.md=. Today =applyConsolidation=
(=memories/index.ts:928,929=) writes =MEMORY.md= and =memory_summary.md=
from an LLM blob; =MEMORY.org= is opt-in when the LLM emits structured
=memory_entries= (line 943). After this FEAT:

- Stage 1 (per-rollout extraction) emits =memory_entries=; each entry
  becomes one episode item under =<repo>/.spell/memory/episodes/<YYYY-MM-DD>.org=
  via =remember({ kind: "episode", ... })=.
- Stage 2 (cross-rollout consolidation) dedupes via vector cosim ≥ 0.92
  using the recall vector lane; new or updated concept items written via
  =remember({ kind: "concept", distilled_from: [...] })=.
- =MEMORY.md= writing is deleted from =applyConsolidation=.
- =memory_summary.md= is regenerated on every consolidation as a deterministic
  projection: =recall({ profile: "session-start", scope: ["concept"], limit: 12 })=
  rendered through =packages/coding-agent/src/prompts/memories/session-start.md.hbs=.
- Existing =memory://root/memory_summary.md= URL keeps resolving.

* Edge Cases

- Stage 1 schema regression: LLM emits old MEMORY.md format → schema validation fails; job marked failed-for-retry; logged warning
- Concept dedup ties at exactly 0.92: tie-break by id ascending for determinism
- =renderSessionStartSummary= when no concepts exist yet: render an empty-but-valid summary with a short greeting
- Repo without =.spell/memory/= dir: =FEAT-641= handles creation; this FEAT calls =executeOrg.remember= which delegates layout to FEAT-641
- Supersedes-chain pruning races with active subscribers reading old concept: subscribers see a Deleted patch for the trimmed item; UI must handle gracefully
- Migration: pre-existing =MEMORY.org= still works (read by recall as concept items if it parses); not deleted by this FEAT
