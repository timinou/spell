* Context

All implementation in =/home/user/code/ora/spell/packages/coding-agent/=.

Currently screenshots save to =/tmp/spell-sshots-{snowflake}.png= or user-specified path.
Generated images save to =/tmp/spell-image-{snowflake}.{ext}=. Neither integrates with
the artifact:// system.

After [[id:FEAT-165-artifact-uri-extension-and-subdirectory]], =allocateOutputArtifact=
accepts =(toolType, ext?)= and returns ={ id, path, uri }= where =uri= is the full
session-scoped artifact URI like =artifact://14b64b/main/screenshot/0.png=.

Change both tools to save into the session artifact directory and emit artifact:// URIs.

** Decision: Screenshot storage

When no user-specified path (=params.path= is empty/absent):
- Allocate artifact path via =this.session.allocateOutputArtifact("screenshot", "png")=
- Save full-resolution PNG to artifact dir
- Include URI in tool result text (e.g., =Artifact: artifact://14b64b/main/screenshot/0.png=)
- Continue sending compressed image to model as before

When user specifies a path:
- Save to user-specified path as before
- ALSO save to artifact dir
- Tool result includes both paths + artifact URI

** Decision: Generated image storage

For each generated image:
- Determine extension from MIME type (=getExtensionForMime= exists in gemini-image.ts)
- Allocate artifact path via =allocateOutputArtifact("generate_image", ext)=
- Save to artifact dir instead of tmpdir
- Include URI in response summary
- Keep returning images to model as before

*** =src/tools/gemini-image.ts=

1. Add =saveImageAsArtifact= helper:
#+begin_src typescript
async function saveImageAsArtifact(
  image: InlineImageData,
  allocate?: (toolType: string, ext?: string) => Promise<{ id?: string; path?: string; uri?: string }>
): Promise<{ path: string; uri?: string }> {
  const ext = getExtensionForMime(image.mimeType);
  if (allocate) {
    try {
      const { path: artPath, uri } = await allocate("generate_image", ext);
      if (artPath) {
        await Bun.write(artPath, Buffer.from(image.data, "base64"));
        return { path: artPath, uri };
      }
    } catch { /* fall through to tmpdir */ }
  }
  return { path: await saveImageToTemp(image) };
}
#+end_src

describe("saveImageAsArtifact", () => {
  it("saves to artifact dir when allocator provided", async () => {
    const tmpDir = await fs.mkdtemp(path.join(os.tmpdir(), "img-art-"));
    const artDir = path.join(tmpDir, "generate_image");

    const allocate = async (tool: string, ext?: string) => {
      await fs.mkdir(path.join(tmpDir, tool), { recursive: true });
      return {
        id: "0",
        path: path.join(tmpDir, tool, `0.${ext ?? "txt"}`),
        uri: `artifact://test/main/${tool}/0.${ext ?? "txt"}`,
      };
    };

    const image = { data: Buffer.from("fake-png").toString("base64"), mimeType: "image/png" };
    const result = await saveImageAsArtifact(image, allocate);

    expect(result.uri).toBe("artifact://test/main/generate_image/0.png");
    expect(await Bun.file(result.path).exists()).toBe(true);
    await fs.rm(tmpDir, { recursive: true, force: true });
  });

  it("falls back to tmpdir when no allocator", async () => {
    const image = { data: Buffer.from("fake").toString("base64"), mimeType: "image/png" };
    const result = await saveImageAsArtifact(image);
    expect(result.uri).toBeUndefined();
    expect(result.path).toContain(os.tmpdir());
  });
});
