* Edge Cases
- spell binary not found: check =Bun.which("spell")= at startup, fail fast
- Process crashes mid-response: detect exit code, emit error to bridge, attempt respawn
- Stdin write after process died: catch EPIPE, mark session dead
- Multiple rapid messages to same chat: queue in RpcClient, process sequentially
- stdout buffer contains partial JSON line: buffer until newline
- Session file corrupted: catch JSON parse error, start fresh
