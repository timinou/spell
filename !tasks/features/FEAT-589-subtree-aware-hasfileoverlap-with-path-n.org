* Target
- packages/coding-agent/src/task/mutable-dag.ts
  - MutableDag.hasFileOverlap
  - Helper: normalizeOverlapPath (new, non-exported)

* Change
- Rewrite hasFileOverlap(leftId, rightId) to be subtree-aware:
  - Normalize each path: resolve to absolute (treat cwd-relative as absolute from process.cwd()), strip trailing slash.
  - Overlap(P, Q) := P == Q OR P is ancestor-dir of Q OR Q is ancestor-dir of P
  - Empty filesDeps on either side: return false (no overlap contribution). This is the policy flip; old "empty = touches everything" goes away here.
- Pair check: any p in left.filesDeps and any q in right.filesDeps overlap by the predicate above.

* Edge Cases
- Windows-style paths are not a current concern; stay POSIX.
- Symlinks: do not resolve; use path-string semantics. Overlap is a best-effort hint, not a filesystem promise.
- Duplicate entries: already deduped by caller; do not dedupe here.

* Acceptance
- New unit tests in packages/coding-agent/test/task/mutable-dag.test.ts (or new file mutable-dag-overlap.test.ts) covering:
  - exact same path overlap
  - directory ancestor overlap (/a/src vs /a/src/foo.ts)
  - sibling directories do not overlap (/a/src vs /a/lib)
  - trailing-slash normalization (/a/src/ vs /a/src)
  - empty filesDeps on either side returns false
- bun test packages/coding-agent/test/task/ passes.
