- New org-ql predicates for manifest tickets:
  - =ticket-state(STATE)=: match tickets by org TODO state

  - Batch property get/set for manifest operations
  - BLOCKER/TRIGGER-aware property updates (validate ID references)
- Full org-element AST export as JSON:

- Manifest-specific tools:
  - =manifest-ticket-summary=: return ticket table (id, title, state, blockers, effort) as JSON for all tickets in a directory
  - =manifest-dependency-order=: return topological sort of tickets by BLOCKER edges
- Wire all new tools through the existing =packages/org/elisp/tools/= registration pattern
