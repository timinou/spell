** 3. Add socket bridge config section

Explain: "The socket bridge enables local =spell= CLI sessions to forward blocking events (plan approvals, agent questions) to the server. When combined with Telegram session-notifications, operators can respond to agent questions from their phone."

** 4. Update API route listing

** 5. Add bearer token auth mention
In the "Manual Webhook Trigger" section, the doc shows HMAC auth. Add a note that =auth="bearer"= is also supported, using goal tokens configured in =server.kdl=:

#+begin_src kdl
http port=8787 {
  auth username="admin" password="change-me-now" // pragma: allowlist secret
  goal-token "manual-test-run" "my-secret-token" // pragma: allowlist secret
}
#+end_src

Then trigger with:
#+begin_src bash
curl -X POST \
  -H "Authorization: Bearer my-secret-token" \
  http://127.0.0.1:8787/trigger/manual-test-run
#+end_src
