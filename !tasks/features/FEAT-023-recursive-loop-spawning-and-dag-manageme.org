** In-scope

- Depth limit enforcement (default 3, configurable)
- Escalation at depth limit: request human approval to go deeper
- Child completion protocol: child signals parent with ChildCompletionSignal
- Policy-per-edge: each dependency declares failure policy (retry count, onFail: block|skip|escalate)
- Default policy: retry(2)-then-block
- DAG model: topological validation, cycle prevention via ancestor chain check
- Parent waits for required children before advancing
