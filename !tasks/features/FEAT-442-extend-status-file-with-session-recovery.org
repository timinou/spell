* Initial Message

give me the commands to relaunch all the spell sessions that were on before my computer ran out of battery, then make the feature to recover that. Bonus if it brings back the niri workspaces too

* Goal

Extend the status file (~/.spell/status/<windowId>.json) with enough information to recover crashed sessions: session ID, session file path, working directory, and niri workspace name. Add a method to read crashed (stale) sessions without cleaning them up.

* Context

Currently ~SessionStatusFile~ has: status, windowId, pid, projectName, sessionTitle, updatedAt. After a power loss or crash, these files survive (clean exits remove them), but they lack the session ID and cwd needed to resume. ~StatusFileReader.readAll()~ actively deletes stale files, destroying recovery evidence.

* Design Decisions

- Add 4 new OPTIONAL fields to ~SessionStatusFile~: ~sessionId: string~, ~sessionFile: string~ (JSONL path), ~cwd: string~, ~workspaceName: string | null~. Optional for backwards compat.
- ~StatusFileWriter~ gets two new methods: ~setSessionInfo(info: { sessionId: string; sessionFile: string; cwd: string })~ and ~setWorkspaceName(name: string | null)~. Called once at init. ~writeIfChanged~ pulls these from stored state — its signature does NOT change.
- ~StatusFileReader~ gets ~readCrashed(): Promise<SessionStatusFile[]>~ that returns dead-PID entries WITHOUT deleting them. The existing ~readAll()~ keeps its cleanup behavior.
- Add ~queryFocusedWorkspace()~ to ~packages/niri/src/niri-query.ts~: runs ~niri msg -j workspaces~ + ~niri msg -j focused-window~, returns ~{ id: number; name: string | null; idx: number } | null~.
- ~NiriOverviewController~ queries workspace at init (~#initWindowId~) and calls ~writer.setWorkspaceName(name)~.
- ~NiriOverviewContext~ extended with ~getSessionId(): string~ and ~getSessionFile(): string~ on ~sessionManager~.
- Interactive-mode provides sessionId and sessionFile through the context it passes to the niri controller.

*** 3. Add readCrashed to StatusFileReader (packages/desktop-common/src/status-file.ts)

#+begin_src typescript
/** Read status files for sessions that crashed (PID dead). Does NOT clean up. */
async readCrashed(): Promise<SessionStatusFile[]> {
  let entries: string[];
  try { entries = await fs.readdir(this.#statusDir); } catch { return []; }
  const results: SessionStatusFile[] = [];
  for (const entry of entries) {
    if (!entry.endsWith(".json")) continue;
    try {
      const data: SessionStatusFile = await Bun.file(path.join(this.#statusDir, entry)).json();
      if (!data.status || !data.pid) continue;
      if (!isProcessAlive(data.pid)) results.push(data);
    } catch { /* skip corrupt */ }
  }
  return results;
}
#+end_src

*** 4. Add workspace query (packages/niri/src/niri-query.ts)

#+begin_src typescript
export interface NiriWorkspaceInfo {
  id: number;
  name: string | null;
  idx: number;
}

export async function queryFocusedWorkspace(): Promise<NiriWorkspaceInfo | null> {
  try {
    const [winResult, wsResult] = await Promise.all([
      $\`niri msg -j focused-window\`.quiet().nothrow(),
      $\`niri msg -j workspaces\`.quiet().nothrow(),
    ]);
    if (winResult.exitCode !== 0 || wsResult.exitCode !== 0) return null;
    const win = JSON.parse(winResult.text()) as { workspace_id?: number };
    const workspaces = JSON.parse(wsResult.text()) as Array<{ id: number; name: string | null; idx: number }>;
    const ws = workspaces.find(w => w.id === win.workspace_id);
    return ws ? { id: ws.id, name: ws.name, idx: ws.idx } : null;
  } catch { return null; }
}
#+end_src
