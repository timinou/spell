* Intention & Purpose
Make `manage save`, `manage index`, `manage languages`, `manage buffers`, `manage undo`, `manage redo`, `manage status`, `manage watcherStatus`, `manage lockStatus` work. Currently all return "parse failed at position 0" because `execute_code_path_inner` parses the (empty) target unconditionally — no `command:"manage"` branch exists.

* Context & Narrative
`crates/pi-natives/src/code_path/napi.rs:247-344 execute_code_path_inner` has a `command:"edit"` branch (FEAT-686) and a default query path. NO `command:"manage"` branch. `manage.ts` calls `executeCodePath({command:"manage", manage:params.command, target: params.file ?? ""})` — empty target hits `parse_code_path` at `crates/pi-code-path/src/parser.rs:53-59` which returns "parse failed at position 0".

Manage subcommands are mostly workspace-level (no CodePath target needed): save flushes dirty buffers; index triggers code-graph indexing; languages lists registered language profiles; buffers lists open managed buffers; undo/redo replay buffer history; status reports session state; watcherStatus/lockStatus report broker state. `diff` takes a target.
