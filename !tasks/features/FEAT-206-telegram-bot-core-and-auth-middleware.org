* Edge Cases
- Bot token invalid: grammy throws on bot.start(), catch and show clear error
- Telegram API unreachable: grammy handles retries, but log failures
- Race: two guests claim same token simultaneously: first wins, second gets "token already claimed"
- Owner sends /invite in group chat: only allow in private chat with bot
- Token file corrupted: catch parse error, start fresh (tokens are ephemeral)
- grammy + Bun compatibility: grammy uses node:http under the hood; Bun supports this but test early
