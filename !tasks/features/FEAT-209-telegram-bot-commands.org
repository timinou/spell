* Edge Cases
- /unlock when already unlocked: reply "Already in full access mode"
- /lock when already locked: reply "Already in read-only mode"
- /project with unknown name: reply "Unknown project. Available: spell, infra"
- /mode with unknown name: reply "Unknown mode. Available: telegram-readonly, telegram-full"
- /clear while agent is streaming: abort first, then clear
- /btw with very long question: truncate to reasonable length (4096 chars)
- Inline keyboard callback after timeout: reply "Selection expired, try again"
- Multiple rapid command presses: grammy handles sequentially per chat
