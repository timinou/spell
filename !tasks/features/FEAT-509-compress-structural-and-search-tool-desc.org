* Design Decisions

1. **ast-grep.md** — The metavariable rules (=$= vs =$$$=, =$_= wildcard, partial-text prohibition, contextual =sel= mode) are genuinely non-obvious and cause real errors. Keep ALL constraint bullets. The 8 examples — keep 3 (multi-pattern, contextual sel, method body fragment). Delete 5 that teach basic call matching.

2. **ast-edit.md** — Same structure as ast-grep. Keep metavariable rules, contextual =sel= rewrite semantics. Keep 2 examples (rename call site, contextual method rewrite). Delete basic examples.

3. **grep.md** — Compress instruction to constraint list. Keep regex syntax note. Delete prose explanations of parameters.

4. **find.md** — Already small. Light compression — remove prose, keep constraint list.

5. **lsp.md** — Operations list (diagnostics, definition, references, hover, etc.) is useful as a lookup. Compress to one-line-per-operation. Keep =symbol=, =occurrence= semantics (non-obvious).

6. **code-search.md** — The "good queries vs bad queries" examples teach grep-style query formation. Keep 3 good examples, delete 3 bad examples (the model understands the contrast from the instruction).
