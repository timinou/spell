** browser:get_favicon Implementation
In SpellBrowser.qml =executeActiveCommand= switch:
#+begin_src javascript
case "browser:get_favicon":
    var iconUrl = webEngineView.icon
    if (iconUrl && iconUrl.toString().length > 0) {
        // QML Image to canvas to base64 approach
        // Or grab via webEngineView.icon property which is a QUrl
        emitResult(cmd, true, { faviconUrl: iconUrl.toString() })
    } else {
        emitResult(cmd, true, { faviconUrl: null })
    }
    break
#+end_src
Note: =WebEngineView.icon= is a URL, not raw data. To get base64, use a hidden =Image= element that loads the icon URL, then render to =Canvas= and =toDataURL()=. Alternatively, return the icon URL and let the TS side fetch it.
