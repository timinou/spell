* Intention & Purpose
The full main-pane view for an opened session: four tabs — Stream (xterm.js viewport rendering the agent event stream as ANSI-colored lines, with a prompt input box), Bash (full xterm.js terminal driving the RPC ~bash~ command for sandboxed shell-style use), State (model, queues, identity, ownedBy), Artifacts (list + inline PDF/image viewer using signed URLs).

* Context & Narrative
Render fidelity is the value proposition. Stream tab MUST behave like a familiar terminal: monospaced, scrollback, copy-paste-friendly, ANSI color, theming. Bash tab MUST feel like a real terminal pipe; backed by RPC ~bash~ command which executes one bash invocation at a time and returns ~BashResult~ with stdout/stderr lines. We compose the illusion of a continuous shell by chaining commands (each ⏎ submits an RPC ~bash~ call; output streams back via ~tool_execution_update~ events).

External (read-only) sessions: Stream tab renders ~event_log~ entries chronologically; Bash tab is hidden; prompt input is hidden; Artifacts and State tabs reduced.

* Edge Cases
- Very fast text_delta bursts → batched via requestAnimationFrame to avoid xterm.js render thrash.
- Terminal resize (split view) → addon-fit reflows; emits a virtual no-op back to RPC (we do NOT propagate resize since RPC doesn't model PTY).
- Bash command very long-running → keep subscription alive; UI shows spinner; ~^C~ abort works.
- PDF with auth-protected resources → signed URL is single-use-ish (TTL 60s); regenerate on iframe error.
- Switching tabs mid-stream → terminal preserved (instance retained even when hidden via ~display:none~).
- External session with no event_log entries (older CLI without ~SPELL_BRIDGE_EVENT_LOG=1~) → Stream tab shows banner explaining how to enable it on that session's process.

* Acceptance Criteria
- Stream tab renders text_delta in real time at 60fps for bursts ≤ 5 KiB/s.
- Bash tab pipes stdout from a real RPC ~bash~ call (manual smoke test).
- PDF artifact opens inline; image artifact opens inline; other types offer Download.
