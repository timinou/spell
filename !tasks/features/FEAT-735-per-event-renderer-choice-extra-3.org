* Scope
Allow multiple ~attach~ bindings, each scoped to a subset of event kinds, so different
event kinds can use different renderers:

#+begin_src kdl
renderer "pdf"  { command "bash" "render/typst.sh"   mime "application/pdf"  extension "pdf" }
renderer "diff" { command "bash" "render/diff.sh"    mime "application/pdf"  extension "pdf" }

attach renderer="pdf"  { transcript "full"      on "plan_approval" }
attach renderer="diff" { transcript "last-turn" on "ask" "hook_input" }
#+end_src

This is a refinement of the FEAT-sendDocument-attach binding — that one ships with
single-binding semantics; this FEAT adds multi-binding precedence rules.
