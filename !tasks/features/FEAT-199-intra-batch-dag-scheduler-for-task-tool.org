** Boundary rationale

* Edge Cases
- Empty blockers array ~[]~: same as ~undefined~ (no dependencies)
- Self-referencing blocker ~{id: "A", blockers: ["A"]}~: cycle detection catches it
- Diamond dependency: task dispatched only when ALL predecessors complete
- All tasks have blockers but no root: cycle detection catches it
- Abort during mid-batch: pending tasks not dispatched, running tasks get abort signal, results collected for completed/failed
- Task completes after abort signal: result still collected, dependent dispatch suppressed
- ~maxConcurrency=1~: purely sequential execution
