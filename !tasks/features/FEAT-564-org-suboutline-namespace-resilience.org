* Edge cases

- Cross-parent suboutlines: if suboutline left side matches a DIFFERENT
  sibling child's numeric prefix, do NOT rewrite (ambiguity). Validator should
  surface `invalid-suboutline-namespace` with a specific hint pointing at the
  actual owner.
- Triple `::` (e.g. `BUG-1::a::b`): reject with suffix-charset rule; the rule
  still excludes `::` from `[A-Za-z0-9_-]+`.
- Body has no suboutlines: rewrite returns body unchanged, no errors — existing
  behavior preserved.
- `:DEPENDS:` lines using comma instead of space: not supported today, not
  introduced. Add no new syntax.
