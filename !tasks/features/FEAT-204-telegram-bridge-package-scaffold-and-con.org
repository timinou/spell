* Edge Cases
- Config file missing: exit with clear error and example config path
- Bot token file missing or unreadable: exit with permission-specific error
- Project path doesn't exist: warn but don't fail (might be created later)
- User ID as string vs number: yaml may parse bare numbers; coerce to string
- Empty users map: bridge starts but rejects all messages with "not authorized"
