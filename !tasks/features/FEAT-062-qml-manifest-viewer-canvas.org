* Scope
QML canvas window for monitoring loop manifests: ticket table with state badges, dependency graph visualization, gate summary, auto-approve toggle.

** In-Scope
- QML window launched via canvas tool when loop is in any active state
- Ticket table view:
  - Columns: ID, title, state (with color badges), effort, priority, blockers, gates
  - Row click expands to show acceptance criteria, findings, iteration history
  - State badges: ITEM (gray), DOING (blue), DONE (green), BLOCKED (red), HOLD (yellow)
- Dependency graph view:
  - Directed graph of tickets with BLOCKER edges
  - Nodes colored by state
  - Layout: top-down topological order
- Gate summary panel:
  - Per-ticket gates with pass/fail indicators
  - Domain gates with last result
  - Manifest validation gates status
- Auto-approve toggle:
  - Armed tool so it fires directly without agent processing
  - Toggle sends =bridge.send({ _tool: "org", ... })= or direct LoopManager callback
- Real-time updates via loop events:
  - Subscribe to =loop:{loopId}:state=, =loop:{loopId}:iteration=, =loop:{loopId}:gate= channels
  - Update ticket states, gate results, progress metrics live
- Progress bar showing N/M tickets completed

** Out-of-Scope
- Interactive manifest editing (reorder, priority changes) -- view-only beyond auto-approve toggle
- Multiple loop windows simultaneously
