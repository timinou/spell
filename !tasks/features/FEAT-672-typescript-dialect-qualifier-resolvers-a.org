* Edge Cases

- Overloaded functions (D-1) → all overloads share the same name; resolver returns the
  resolved overload's body via existing CodeResolver overload-disambiguation logic
- Export default with no name (D-2) → CodePath =foo.ts::default= or =foo.ts/[¶default-export]=
- Module augmentation (D-3) → multiple decls of same name across different files
- Computed member (D-4) → =foo['bar']= access; matcher must skip these
- const-enum (D-5) → enum with =const= keyword
- JSX member (D-6) → =<Foo.Bar />= treated as JSX expression
- Decorator call (D-7) → =@dec()= node kind is =decorator=, not =call_expression=
