* Scope
In scope: improve scoped edit ergonomics for code files by supporting explicit `rawTextReplace` and a safe `findAndReplace` fallback for literal substring replacement inside a resolved target range. Primary regression: in Clojure, replacing only the string literal text `"live effects are prohibited"` inside a function scope failed even though full-line replacement worked.

Out of scope: unbounded whole-repo text replacement, regex replacement, semantic Clojure refactors beyond existing form-safe procedures, or making raw text edits bypass structural validation. Raw replacement must remain scoped to resolved target ranges and must preserve parser validity where the file has a semantic profile.

* Existing Patterns
- Tool schema/normalization: `packages/coding-agent/src/tools/code.ts`; `codeActionSchema` lists action kinds and `normalizeOperations()` sends `kind`, `find`, `content`, `occurrence` to native.
- Native action dispatch: `crates/pi-natives/src/code_buffer.rs`; `single_action()` dispatches `findAndReplace` to `apply_patches(buffer, start_byte, end_byte, &[Patch { ... }])` using `target_range()`.
- Patch safety: native patch application is already range-bounded and supports public occurrence selectors (`first`, `last`, `all`, numeric, unique). Tests exist around duplicate scoped `findAndReplace` matches in `packages/natives/test/code-buffer.test.ts`.
- Failure classification: `packages/coding-agent/src/tools/code-result.ts` classifies scope and execution errors. Do not hide real native failures.

* Tests
User workflows to cover first:
1. Agent replaces a string literal substring inside a Clojure `defn` with `findAndReplace`; it succeeds without requiring the full source line.
2. Agent explicitly uses `rawTextReplace` inside a Clojure function target; it succeeds and target summary shows `[rawTextReplace]`.
3. Duplicate substring matches require `occurrence` exactly as `findAndReplace` does.
4. `rawTextReplace` cannot edit outside the target declaration span.
5. Replacement that makes a semantic file structurally invalid is rejected and leaves disk unchanged.
6. TS action normalization forwards `rawTextReplace` correctly, preserving array-to-string normalization for `find`/`content`.

Test files:
- `packages/natives/test/code-buffer.test.ts`: native Clojure fixture tests for substring, raw action, duplicates, out-of-scope, invalid syntax rollback.
- `packages/coding-agent/test/tools/code.test.ts`: schema/normalization/formatting test for `rawTextReplace`.
- Add a focused Rust unit test if `apply_patches` is refactored into a helper.
