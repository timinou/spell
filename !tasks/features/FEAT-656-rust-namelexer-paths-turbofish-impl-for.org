* Edge Cases

- Turbofish with empty type list: =Vec::<>= → reject as parse error.
- Nested turbofish: =Vec::<Box<dyn T>>= → handle balanced =<>= pairs.
- =impl_for= variants with whitespace: =impl Write for Buffer= vs =impl_Write_for_Buffer= → both accepted; canonical form is =impl_Write_for_Buffer= (no spaces).
- =::= at start: =::std= absolute path → first segment is empty, treat as crate-root marker.
- Generic constraints in impl-for: =impl<T: Send> Foo<T> for Bar= → simplify to =impl_Foo_for_Bar= (drop generics in payload form).
