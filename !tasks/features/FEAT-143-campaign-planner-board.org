** In
- Kanban QML component for campaign management
- Columns: Planning, Active, Paused, Completed
- Campaign cards: title, budget, date range, status, assigned creative briefs
- Drag to reorder/move between columns

- Campaign budget alerting

* Edge Cases
- Empty columns render with placeholder text, not blank space
- Drag between non-adjacent columns (e.g. Planning → Completed) updates status correctly without intermediate state
- Card with missing/null budget renders gracefully with "—" and does not break sort

* Acceptance Criteria
- Kanban renders with all four columns populated from SQLite campaigns table
- Dragging a card moves it to target column and persists status change
- Agent can create a campaign card via armed tool and it appears in the correct column
