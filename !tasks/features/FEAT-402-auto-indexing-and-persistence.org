* Context — Why This Exists
The graph engine can build and query graphs. This item makes it *automatic* — the agent never needs to think about whether the graph is fresh. On first graph query, the system checks staleness and rebuilds if needed. The graph persists to disk for instant reload across sessions.

This is the "last mile" that makes the experience seamless. Without it, the agent would need to remember to run =code index= before every graph query, defeating the purpose.

Depends on [[id:FEAT-397-core-graph-engine-and-trait-interfaces]] for graph/cache types and [[id:FEAT-401-napi-bridge-and-code-tool-integration]] for the NAPI entry point that triggers ensure_fresh.

** Key Design Decisions
1. Staleness detection: compare stored git HEAD hash + file count against current state. If either differs, graph is stale.
2. Lazy rebuild: first graph query calls =GraphStore::ensure_fresh()=. If stale, rebuilds synchronously (user waits). Future: background rebuild with progress.
3. Cache location: =.spell/graph/graph.bin= (bincode) + =.spell/graph/meta.json= (IndexMeta).
4. =.spell/graph/= added to =.gitignore= template.
5. No file watcher in Phase 1. Explicit =code index= for manual refresh. Staleness check is cheap (one git command + stat).

pub fn is_stale(project_root: &Path) -> Result<bool> {
    let meta_path = project_root.join(".spell/graph/meta.json");
    let meta: IndexMeta = match std::fs::read_to_string(&meta_path) {
        Ok(json) => serde_json::from_str(&json)?,
        Err(_) => return Ok(true), // no cache = stale
    };
    let current_head = git_head(project_root)?;
    Ok(meta.git_head != current_head)
}

** 8. Git HEAD reading
Prefer reading =.git/HEAD= directly (no subprocess):
#+begin_src rust
fn git_head(project_root: &Path) -> Result<String> {
    let head_path = project_root.join(".git/HEAD");
    let content = std::fs::read_to_string(&head_path)?;
    if let Some(ref_path) = content.strip_prefix("ref: ") {
        let ref_path = ref_path.trim();
        let sha_path = project_root.join(".git").join(ref_path);
        Ok(std::fs::read_to_string(sha_path)?.trim().to_owned())
    } else {
        Ok(content.trim().to_owned()) // detached HEAD = direct SHA
    }
}
#+end_src

* Error Handling
- =.git/= not found → always stale (can't detect changes, rebuild every time)
- Bincode version mismatch after upgrade → =load= returns None, rebuild from scratch
- Disk full on save → log error, graph works in-memory only for this session
- Concurrent rebuilds → =arc-swap= handles this safely; last writer wins
