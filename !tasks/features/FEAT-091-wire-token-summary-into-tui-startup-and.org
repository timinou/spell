* Edge Cases
- Memory disabled: =onPhase1Complete= never called (=startMemoryStartupTask= returns early). No note displayed.
- Memory cooldown skip: =onPhase1Complete(null)= called. Startup note shows "Memory: skipped".
- Session with no model: =onPhase1Complete(null)= called. Same as above.
- =startup.quiet: true=: exit summary still shown (it's post-TUI). Startup note behavior depends on implementation choice.
- Very fast exit (Ctrl+C immediately): =shutdown()= fires, =getSessionStats()= returns zeros, summary says "no tokens recorded" — suppressed by the check.
- =getSessionStats()= throws: wrap in try-catch, skip summary silently.
