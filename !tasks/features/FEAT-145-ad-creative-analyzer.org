** In
- Agent-driven creative analysis of competitor ads from SQLite
- Copy pattern analysis: tone, length, CTA types, offers
- Visual pattern analysis: format distribution, color usage
- Strategic pattern analysis: targeting signals, seasonal timing

- Automated brief publishing

* Edge Cases
- Ad set with fewer than 3 ads: still runs analysis, brief notes limited sample size
- Ads with missing copy (image-only): skip copy analysis for those records, note count
- LLM output schema mismatch: surface parse error, do not persist partial result

* Acceptance Criteria
- 'Analyze' action on an ad set produces a structured competitive creative brief
- Brief correctly identifies copy/visual/strategic patterns across 10+ ads
- Brief can be exported as Typst PDF or saved as an org item
