* Implementation

** ~packages/coding-agent/src/prompts/system/plan-mode-active.md~

Add a section (probably near the PLAN item requirements or in the re-entry block) with these rules:

*** Revising plan items
- When updating a specific section of a plan item (e.g. just the Context or just the Verification), use ~org update~ with ~section~ parameter to target that heading. This preserves untouched sections.
- When restructuring the entire plan body, use ~org update~ with ~body~ for full replacement.
- Use ~org note~ only for timestamped observations that supplement (not contradict) the body. Notes are append-only — they cannot revise existing content.
- Before revising a plan item, ~org get~ it first to see current state. Do not blindly overwrite.

*** Re-entry block update
The existing re-entry procedure says "Update PLAN and linked child items to remove stale content". Refine this to:
- Read existing plan items via ~org get~
- Use ~org update~ with ~section~ to surgically revise specific sections
- Use full ~body~ replacement only when the structure itself changes
- Do NOT use ~note~ for corrections — it appends contradictory content
