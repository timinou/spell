* Intention & Purpose

Extend =pi-org-engine::graph= with typed-edge traversal so callers can ask
for the neighborhood around a node, the timeline of episodes about an
entity, or the shortest typed path between two items. Today =graph.rs=
only models the BLOCKERS DAG (cycle detection, waves, components). After
FEAT-631 lands, items carry typed relations; this FEAT exposes them as
queryable graph data without forcing every caller to hand-walk the
=relations= vector.

* Context & Narrative

Spec: =specs/org-graph-memory.md=. The hybrid recall pipeline (FEAT-636)
needs =graph.neighborhood(focus, hops, kinds)= to seed RRF fusion with
graph-walk hits. =timeline= powers the timeline op (FEAT-637) and the
agenda-style memory views. =path= surfaces audit trails (concept →
distilled_from → episode → produced → artifact) for provenance display.

The legacy DAG built from BLOCKERS keeps working because FEAT-631
synthesizes Blocks edges from the BLOCKERS property; this FEAT just
treats Blocks as one =EdgeKind= among many.

* Scope

* Existing Patterns

- =graph.rs= already maps =items: &[OrgItem] -> Dag= via =canonical_wave_items= + a HashMap fold over the BLOCKERS property. Extend the same fold to walk =item.relations= instead — Blocks is one branch of a match.
- =DepEdge= is the existing edge struct =(from, to)=; introduce =TypedEdge= with an =EdgeKind= field. Keep =DepEdge= for backward compat (=GraphResult.edges= consumers).
- Cycle detection (iterative DFS) is already in =graph.rs::detect_cycles=; reuse for typed graphs by ignoring kind during traversal.
- =EdgeKind= comes from =crate::edge= (FEAT-631).

* Edge Cases

- Self-loop (item points relation at itself): retained in graph; neighborhood treats as zero-hop visit; path returns 0-edge GraphPath
- Edge to non-existent target: kept in =out_edges= with no matching =GraphNode=; neighborhood includes it as a synthetic node with empty title and a =dangling=true= flag
- Massive in-degree (>10k incoming edges to one node): timeline + neighborhood remain O(hops × avg_degree); document the bound
- Concurrent mutation: this layer is read-only over an item slice; callers responsible for snapshot
- Subgraph with cycles: edges may appear once or twice depending on direction; deduplicate by =(from, to, kind)= tuple before returning
