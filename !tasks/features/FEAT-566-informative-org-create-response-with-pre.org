* Background

Today `cmdCreate` returns `{ success, id, file, category, state, body,
bodyLength }`. The agent has to infer the prefix for suboutline CUSTOM_IDs
from the `id` field, which is a late post-hoc correction and fails in ~50%
of cases because the prompt guidance earlier in the turn said `BUG-264::x`
is fine.

  `suboutlineRewrites` (only when non-empty).
