* Initial Message

show me the task tool and todo write tool system prompts

* Narrative

Agents participating in a swarm need a distinct system prompt that teaches them how to use the blackboard, handoff, spawn_successor, and URI-based task references. The existing =subagent-system-prompt.md= only covers delegated sub-tasks. A swarm-aware prompt layer adds:

- Blackboard read/write instructions (via org MCP tools)
- Handoff tool usage (when to use, what context to include)
- Spawn successor tool usage (when to extend the DAG)
- Artifact publication protocol (how to satisfy =data://= nodes)
- Inter-agent communication norms (what to share, how to reference peers)
- Branch-scoped awareness (how to query parent/sibling state)

* Design Decisions

1. New =swarm-agent-system-prompt.md= template, injected when swarm mode is active (alongside existing subagent prompt).
2. Swarm mode is activated by a setting or by the SwarmScheduler being the execution context.
3. The prompt uses Handlebars for conditional sections (available tools vary).
4. Existing =task.md= and =todo-write.md= get small conditional sections (=~{{#if swarmEnabled}}=) for swarm-aware guidance.
