* Initial Message

bro. now that the Task tool and the todo write tool are well integrated, can you have a thing where I see in the TUI when a subtask is being spun by an agent? And can you see how often subtasks are being launched, and if they are token efficient?

* Goal

When the session exits, append subtask aggregate stats to the existing exit summary line so the user can see at a glance how much of their session was spent on subtasks and whether they were token-efficient.

* Design Decisions

- Add a second line after the existing =Session: 45K in | 12K out | 8K think | 120K cache | $0.42= line
- Format: =Subtasks: 8 launched · 320K tokens · $1.23 · 40K avg/task · 72% cache=
- Only show if any subtasks were launched (totalLaunched > 0)
- Data comes from =SubagentTracker.getLifetimeStats()=
- Use =chalk.dim()= for the line (same as the existing session summary)

* Files to Modify

** =packages/coding-agent/src/session/token-summary.ts=

2. Add new function:
#+begin_src typescript
export function formatSubtaskExitSummary(info: SubtaskExitInfo): string | null {
  if (info.totalLaunched === 0) return null;
  const parts: string[] = [];
  parts.push(`${info.totalLaunched} launched`);
  if (info.totalTokens > 0) parts.push(`${formatTokenCount(info.totalTokens)} tokens`);
  if (info.totalCost > 0) parts.push(`$${info.totalCost.toFixed(2)}`);
  if (info.avgTokensPerSubtask > 0) parts.push(`${formatTokenCount(info.avgTokensPerSubtask)} avg/task`);
  if (info.cacheHitRate > 0) parts.push(`${Math.round(info.cacheHitRate * 100)}% cache`);
  return `Subtasks: ${parts.join(" | ")}`;
}
#+end_src

* Edge Cases

- No subtasks launched in session — no second line printed
- Subtasks still running at exit (user Ctrl+C) — print stats for what completed so far
- All subtasks failed — still show stats (tokens were consumed)
- Very short session with a single subtask — still show if totalLaunched > 0
- Cost is 0 (e.g., free tier or no cost data) — omit cost part

* Acceptance Criteria

- Session exit prints subtask aggregate line when subtasks were launched
- Line shows total launched, total tokens, total cost, avg/task, cache rate
- No extra line when no subtasks were used
- =bun check:ts= passes
- Manual verification: run a session that uses Task tool, exit, verify the summary line appears
