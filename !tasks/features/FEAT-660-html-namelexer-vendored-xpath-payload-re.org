* Edge Cases

- XPath predicates with quotes: =[@class="foo bar"]= — preserved; round-trip identity.
- Mixed CSS/XPath: =#app .save= with CSS shortcut → translated to =//*[@id='app']//*[contains(@class, 'save')]= internally.
- =//= as XPath descendant axis vs kernel descendant combinator: in HTML name payload, =//= is XPath; outside (between kernel steps) it's the kernel combinator. The NameLexer consumes within name boundary; kernel takes over after.
- =text()= function: =[text()='foo']= → text predicate; map to kernel =[text~="foo"]=.
- Namespaces: =svg:circle= → preserved verbatim.
