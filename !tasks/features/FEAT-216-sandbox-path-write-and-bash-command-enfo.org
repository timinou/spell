* Edge Cases
- Symlinks: resolve real path before checking against policy
- Trailing slash policy entries match nested descendants, not sibling prefixes
- Relative paths resolve against cwd before policy checks
- Bash pipes: command =echo foo | grep bar= checks first command segment for allow semantics
- Bash subshells: =$(rm -rf /)= embedded in an otherwise allowed command still checks full command string against deny patterns
- Empty =paths_write= blocks all writes when sandbox policy is active
- Empty =bash_allow= with non-empty =bash_deny=: all commands allowed except denied ones
- Empty both bash lists: no bash restrictions (backward compat)
