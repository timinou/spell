** Edge Cases
- QML bridge not available (no Qt installed): gateway works without systray, log info message
- QML bridge crashes: systray disappears, gateway continues working, reconnect attempts recreate systray
- Multiple gateway instances: only one systray (first wins, tracked by client ID)
- Desktop environment without systray support (tiling WM): QSystemTrayIcon.isSystemTrayAvailable() check, skip if false
- Menu update while menu is open: Qt handles this gracefully (menu rebuilds on next open)
- Large number of services (>20): group by status, add "Show all..." submenu
