* Implementation
1. Design system: all delegates use SpellTheme tokens. No borders on messages. Subtle 1px ~borderSubtle~ separator between messages. Role indicated by alignment/styling. Tool executions compact with monochrome status dot.
2. ~FlowAssistant.qml~: Item with MarkdownContent child. Top separator (thin Rectangle, borderSubtle). Streaming text updates reactively. No background rectangle. Font: fontFamily at fontSizeM.
3. ~FlowUser.qml~: Item with Text child. Subtle visual distinction (e.g. left-padding or muted prefix). No bubble, no background.
4. ~FlowTool.qml~: Row with status dot (8px: primary while running, success on done, error on fail) + tool name (monoFontFamily, fontSizeS, textTertiary) + collapsible details. Collapsed by default.
5. ~ThinkingBlock.qml~: Collapsible Item. Header: italic 'Thinking...' in textTertiary. Body: muted text. Animated height transition (durationNormal). Collapsed once response starts.
6. ~FlowImage.qml~: Image with fillMode PreserveAspectFit, max height 400px. cornerRadiusSmall. Click expands.
7. ~FlowMessageDelegate.qml~: Loader picking component based on ~role~ property (user/assistant/tool/thinking/image).
8. ~BrowseChatPanel.qml~: ColumnLayout with ScrollView + ListView bound to messagesModel. FlowInputBar at bottom. handleMessage() dispatcher matching ChatPanel handler pattern but using FlowMessageDelegate. Auto-scroll: track if near bottom, follow if so.
9. ~FlowInputBar.qml~: TextField, borderDefault 1px, no heavy background. Send icon button. Abort button when streaming.
