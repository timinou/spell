* Initial Message

kk look online what code-specific vector embeddings do and how that could help with the `code search` task

* Goal
Wire the hybrid graph+vector search through =pi-natives= N-API bindings and the =coding-agent=
package so the agent can use semantic code search via the =code search= subcommand.
This includes the opt-in flow for semantic indexing (=--semantic= flag), model download
with progress reporting, and graceful degradation when vectors aren't built.

* Background
=crates/pi-natives/src/code_graph.rs= exposes =CodeGraphOptions= as the N-API interface.
The =command= field dispatches to graph operations (=search=, =context=, =impact=, etc.).
The =index= command rebuilds the graph and returns status output.

On the TypeScript side, the =code= tool in the coding-agent dispatches subcommands through
=executeCodeGraph()= from the =pi-natives= package.

* Design Decisions
- =CodeGraphOptions= gains a new optional field: =semantic: Option<bool>=
- When =command == "index"= and =semantic == Some(true)=, build both graph and vectors
- When =command == "search"= and vectors are available, hybrid search is automatic
- Model download progress is printed to the result output (no callback needed — the operation
  is async via =task::Async= already)
- =pi-natives= Cargo.toml enables the =semantic= feature of =pi-code-graph= and adds
  =pi-code-vectors= as a dependency
- The coding-agent's tool description for =code search= is updated to mention semantic search capability
- A new =code= subcommand variant =semantic_status= (or include in =status=) reports whether
  vectors are built and what model is in use

*** Cached EmbeddingEngine for query embedding
The search path needs to embed the query string into a vector. Model loading takes 1-2s,
so we cache the engine in a =OnceLock= at module level:
#+begin_src rust
use std::sync::OnceLock;
use pi_code_vectors::EmbeddingEngine;

static EMBEDDING_ENGINE: OnceLock<EmbeddingEngine> = OnceLock::new();

fn get_or_init_engine() -> napi::Result<&'static EmbeddingEngine> {
    EMBEDDING_ENGINE.get_or_try_init(|| {
        EmbeddingEngine::new(false)
            .map_err(|e| napi::Error::from_reason(format!("Failed to load embedding model: {e}")))
    })
}
#+end_src

Note: =EmbeddingEngine= must be =Send + Sync= for this. fastembed's =TextEmbedding= is
internally thread-safe (uses =ort::Session= which is =Send + Sync=). Verify this during
implementation — if not, wrap in =Mutex=.

"index" => {
    let (graph, fingerprint_info, rebuilt) = ensure_graph(...)?;
    let mut sections = vec![format_status(...)];

    if options.semantic.unwrap_or(false) {
        // Build vector index
        let engine = pi_code_vectors::EmbeddingEngine::new(true)?; // show download progress
        let chunks = pi_code_vectors::extract_chunks(graph.persisted(), 30)?;
        let texts: Vec<&str> = chunks.iter().map(|c| c.text.as_str()).collect();
        let vectors = engine.embed_batch(&texts, None)?;
        let entries: Vec<_> = chunks.iter().zip(vectors).map(|(c, v)| {
            pi_code_vectors::VectorEntry { node_index: c.node_index, vector: v }
        }).collect();
        let vector_index = pi_code_vectors::VectorIndex::new(entries, 768);
        // Persist vectors
        let persisted_vectors = vector_index.to_persisted(
            "jina-embeddings-v2-base-code",
            compute_fingerprint_hash(&fingerprint),
        );
        save_vector_cache(&cache, &persisted_vectors)?;
        sections.push(format!("Semantic: {} vectors indexed", vector_index.len()));
    }

    Ok(CodeGraphResult { output: sections.join("
"), ... })
}

For the ="search"= command:
#+begin_src rust
"search" => {
    let (graph, fingerprint_info, _) = ensure_graph(...)?;
    let fingerprint_hash = compute_fingerprint_hash(&fingerprint_info);

    // Attempt to load vectors and embed query
    let (code_graph, query_vector) = match load_vector_cache(&cache, fingerprint_hash) {
        Some(vectors) => {
            // Vectors available — embed the query
            match get_or_init_engine() {
                Ok(engine) => match engine.embed_query(query) {
                    Ok(qv) => (CodeGraph::with_vectors(graph, vectors), Some(qv)),
                    Err(_) => (CodeGraph::new(graph), None), // degrade gracefully
                },
                Err(_) => (CodeGraph::new(graph), None), // model not available
            }
        }
        None => (CodeGraph::new(graph), None), // no vectors cached
    };

    let hits = code_graph.search(query, query_vector.as_deref(), limit);
    Ok(CodeGraphResult { output: format_search(&hits), ... })
}
#+end_src

This ensures:
1. When vectors exist AND the model is loaded: full hybrid search
2. When vectors exist but model fails to load: BM25 fallback (degrade, don't crash)
3. When no vectors: BM25 only (zero change from today)

*** Vector cache helpers
#+begin_src rust
fn compute_fingerprint_hash(fingerprint: &GraphFingerprint) -> u64 {
    // Hash the fingerprint deterministically (e.g., hash of serialized bytes)
    use std::hash::{Hash, Hasher};
    let mut hasher = std::collections::hash_map::DefaultHasher::new();
    // Hash root + git_head + sorted file entries
    fingerprint.root.hash(&mut hasher);
    fingerprint.git_head.hash(&mut hasher);
    for (path, fp) in &fingerprint.files {
        path.hash(&mut hasher);
        fp.size.hash(&mut hasher);
        fp.modified_at_ms.hash(&mut hasher);
    }
    hasher.finish()
}

fn save_vector_cache(cache: &CacheStore, vectors: &PersistedVectorIndex) -> napi::Result<()> {
    let path = cache.directory().join("workspace-vectors.bin");
    let file = fs::File::create(path)?;
    bincode::serialize_into(BufWriter::new(file), vectors)
        .map_err(|e| napi::Error::from_reason(e.to_string()))
}

fn load_vector_cache(cache: &CacheStore, expected_hash: u64) -> Option<VectorIndex> {
    let path = cache.directory().join("workspace-vectors.bin");
    let file = fs::File::open(path).ok()?;
    let persisted: PersistedVectorIndex = bincode::deserialize_from(BufReader::new(file)).ok()?;
    if persisted.graph_fingerprint_hash != expected_hash {
        return None; // stale vectors
    }
    Some(VectorIndex::new(persisted.entries, persisted.dimensions))
}
#+end_src

* Edge Cases
- =semantic: true= but model download fails (network error) -> return clear error in output,
  graph is still built successfully
- Vector cache exists but graph was rebuilt -> fingerprint mismatch, vectors discarded,
  search falls back to BM25
- =semantic= field not provided (undefined in JS) -> defaults to false (backward compatible)
- Very large codebase (>50K symbols) -> embedding takes minutes, ensure the async task
  doesn't time out (=timeout_ms= should be respected, with progress output)
- ort/ONNX shared library not found at runtime -> meaningful error message, not a crash
