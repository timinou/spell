* Initial Message

looking at the typst and org integrations to pi-code-engine, what would you want to implement for your markdown usage to be a delight?

* Context

With markdown profile, custom procedures, and tool result injection in place, the code tool's main prompt (~packages/coding-agent/src/prompts/tools/code.md~) needs minor updates to:
1. List markdown as a supported language in the ~languages~ operation description
2. Document that custom operations exist (without listing every language's ops — that's the injection's job)
3. Add a markdown example to the examples section

** Design Decisions

- Keep the main prompt language-agnostic — don't enumerate every language's custom ops in the system prompt
- Add a single note that language-specific operations are available and will be shown on first use
- Add one markdown example showing section-as-declaration usage
- Update the ~languages~ operation description to include Markdown
