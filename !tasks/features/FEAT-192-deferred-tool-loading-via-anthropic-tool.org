NOTE [2026-04-01]: Implemented tool tiering (core/standard/specialized), auto-activation via resolveUnknownTool hook in agent-loop, system prompt deferred tool listing, and all tests passing.

Spell-native tool tiering: only register core+standard tools initially. Specialized tools auto-activate on first call.

* Problem
35 tool definitions consume ~18.7k tokens in the API =tools= parameter. Most tools go unused in any session.
The system prompt itself is relatively lean (skills already render as name+description catalog).

* Approach: Tier + auto-activate

** Tool tiers
Add =tier= field to tool factory registry in =BUILTIN_TOOLS=:

| Tier        | Tools                                                                                     | ~Tokens |
|-------------+-------------------------------------------------------------------------------------------+---------|
| core        | read, edit, write, grep, find, bash, lsp, task, ask                                       |  ~8,000 |
| standard    | ast_grep, ast_edit, todo_write, org, emacs_code, fetch, web_search, cancel_job, await     |  ~5,000 |
| specialized | canvas, puppeteer, notebook, render_mermaid, python, ssh, inspect_image, browser,         |  ~6,000 |
|             | checkpoint, rewind, calc, code_search, generate_image, loop_*, gateway                    |         |

Hidden tools (exit_plan_mode, resolve, submit_result, report_finding) already gated — no change needed.

** Auto-activation mechanism
When the model calls a tool not in the active set:
1. =agent-loop.ts= L529-536 currently returns "Tool X not found" error
2. Change: check if tool exists in =toolRegistry= (inactive but registered)
3. If yes: activate it via =setActiveToolsByName()=, execute the call, return result
4. The prompt rebuilds automatically (=setActiveToolsByName= calls =rebuildSystemPrompt=)
5. Next turn, the model sees the tool's full description

This is zero extra round-trips. The model calls the tool, Spell silently activates it.

** System prompt update
Add a line listing specialized tools by name so the model knows they exist:
"Additional tools available (auto-loaded on use): canvas, puppeteer, notebook, ..."
