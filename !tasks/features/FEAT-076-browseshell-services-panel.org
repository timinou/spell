** Design Note: BrowseShell Profile Model
BrowseShell tabs share the default ='spell-browse-mode'= WebEngineProfile (hardcoded in =BrowserPanel.qml=). Service-specific sessions launch in STANDALONE =BrowserWindow= instances with the service's storageName. The 'Open' action in the services panel launches a BrowserWindow via bridge event, NOT a new BrowseShell tab. This is because each service needs its own WebEngineProfile, and BrowseShell's =BrowserPanel= shares a single profile across all tabs.
