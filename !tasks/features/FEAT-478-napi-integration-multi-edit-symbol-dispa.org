* Initial Message

How would you make the edit experience with the code tool so ergonomic it's even more ergonomic than giving line diffs in the language?

* Context

The NAPI layer (=crates/pi-natives/src/code_buffer.rs=) dispatches tool calls from
TypeScript to the Rust engine. This item integrates all new Rust operations into
the NAPI interface and adds two new capabilities:

1. *Multi-edit batching*: accept an =edits= array, apply all in one call
2. *Symbol dispatch*: route operations via =symbol= field instead of =line + node_type=
3. *Annotated diff response*: return human-readable diffs with symbol context headers

* Design Decisions

1. The existing =edit_operation()= function is refactored to accept symbol targeting
2. New function =resolve_edit_target()= handles the symbol → byte range resolution
3. Multi-edit: new top-level match arm in =execute_code_buffer= for =command: "edit"= when =edits= array is present
4. =node_type= field is removed from content operations (replace, insert-before, insert-after, kill). These now use =symbol= for targeting. Line-based targeting remains for positional ops (drag, splice, clone, transpose).
5. Annotated diff: after edits are applied, generate a diff between pre-edit and post-edit buffer states using =diff_from(snapshot)=. Annotate each hunk with the enclosing symbol name using the outline.
6. Response format changes:
   - Old: ={"version": N, "changedRanges": [...], "inputEdit": {...}}=
   - New: ={"version": N, "diff": "annotated diff string", "editCount": N}=

fn single_edit_operation(
    buffer: &CodeBuffer,
    profile: &LanguageProfile,
    options: &Value,
) -> Result<Vec<TextEdit>> {
    let operation = options.get("operation").and_then(Value::as_str)
        .ok_or_else(|| json_err("Missing: operation"))?;

    match operation {
        // Symbol-targeted operations (new)
        "patch" => {
            let resolved = resolve_target(buffer, profile, options)?;
            let patches = parse_patches(options)?;
            apply_patches(buffer, resolved.start_byte, resolved.end_byte, &patches)
                .map_err(engine_err)
        },
        "replace-body" => {
            let resolved = resolve_target(buffer, profile, options)?;
            let content = required_str(options, "content")?;
            replace_body(buffer, &resolved, content).map_err(engine_err)
        },
        "wrap" => {
            let resolved = resolve_target(buffer, profile, options)?;
            let template = required_str(options, "content")?;  // template in content field
            wrap_node(buffer, &resolved, template).map_err(engine_err)
        },
        "rename" => {
            let resolved = resolve_target(buffer, profile, options)?;
            let new_name = required_str(options, "content")?;
            rename_symbol(buffer, &resolved, new_name).map_err(engine_err)
        },
        // Symbol-targeted but also accepting line (backward compat for kill)
        "replace" => {
            let resolved = resolve_target(buffer, profile, options)?;
            let content = required_str(options, "content")?;
            Ok(vec![TextEdit {
                start_byte: resolved.start_byte,
                old_end_byte: resolved.end_byte,
                new_text: content.to_string(),
            }])
        },
        "kill" => {
            let resolved = resolve_target(buffer, profile, options)?;
            Ok(vec![TextEdit {
                start_byte: resolved.start_byte,
                old_end_byte: resolved.end_byte,
                new_text: String::new(),
            }])
        },
        "insert-before" => {
            let resolved = resolve_target(buffer, profile, options)?;
            let content = required_str(options, "content")?;
            Ok(vec![TextEdit {
                start_byte: resolved.start_byte,
                old_end_byte: resolved.start_byte,
                new_text: content.to_string(),
            }])
        },
        "insert-after" => {
            let resolved = resolve_target(buffer, profile, options)?;
            let content = required_str(options, "content")?;
            Ok(vec![TextEdit {
                start_byte: resolved.end_byte,
                old_end_byte: resolved.end_byte,
                new_text: content.to_string(),
            }])
        },
        // Positional operations (line-only, no symbol)
        "splice" => { /* existing logic, uses line */ },
        "drag-up" | "drag-down" => { /* existing, uses line */ },
        "clone" => { /* existing, uses line */ },
        "transpose" => { /* existing, uses line + column */ },
        _ => Err(json_err(format!("Unknown operation: {other}"))),
    }
}

fn render_annotated_diff(
    buffer: &CodeBuffer,
    snapshot: BufferSnapshot,
    profile: &LanguageProfile,
) -> String {
    let hunks = buffer.diff_from(snapshot);
    if hunks.is_empty() {
        return String::from("(no changes)");
