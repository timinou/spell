when a subtask is associated to a todo (especially relelvant during plan/ultraplan/loop implementations), can you have a soft reminder when the task gets done to make sure to check its validation criteria, tests, artifacts (if any) and to commit ahead of marking the task as done?

* Implementation
** todo-write.md changes
- Add =orgItemId= to Task Anatomy section:
  - =orgItemId=: Org item ID this task is linked to. When set, completion directives include org item lifecycle updates.
- Add =verified= to Task Anatomy or a new Completion Protocol section:
  - =verified=: Set true on update op after verifying all gate requirements. Required to complete a gated task.
- Add a new "Completion Protocol" section explaining two-phase flow:
  - When a gated task is marked completed without =verified: true=, the tool rejects and returns a verification checklist
  - Agent must perform verification, then re-submit with =verified: true=
- Add example for gated completion:
#+begin_example
<example name="gated-completion">
Complete a gated task after verification:
1. First attempt (rejected with checklist):
   ops: [{op: "update", id: "task-1", status: "completed"}]
2. After verification:
   ops: [{op: "update", id: "task-1", status: "completed", verified: true}]
</example>
#+end_example
