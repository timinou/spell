- =packages/emacs/= package deleted entirely (all 76 combobulate .el files, MCP server, daemon management)
- =packages/org/elisp/= directory retained ONLY if org elisp files are needed for non-agent Emacs users; otherwise deleted
- All test files that mock or test EmacsSessionManager are updated or removed

* Edge Cases

- Concurrent sessions: without daemon, each org operation is stateless (file read → parse → respond). Mutex in OrgBufferRegistry handles concurrent access.
- softReset: no Emacs daemon to preserve, so softReset simply does nothing for org (was already the case — comment says "intentionally NOT touched")
- Settings migration: users with =emacs.path= in their config get a warning or the setting is silently ignored (prefer silent ignore — removed settings should not error)
