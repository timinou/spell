* Edge Cases
- Corrupt checkpoint JSON: fall back to event log replay
- Event log truncated mid-line: skip incomplete final line, log warning
- Org item deleted externally: create new from checkpoint on resume
- Disk full: log error, loop continues in memory (best-effort)
- Concurrent writes to same event log: file-level append lock
