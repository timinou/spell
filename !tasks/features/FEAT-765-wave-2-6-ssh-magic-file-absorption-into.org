* Goal

Absorb the Spell-owned SSH config files (=~/.spell/agent/ssh.json= and =<cwd>/.spell/ssh.json= and =<cwd>/ssh.json=) into =spell.kdl= as an inline =ssh= block.

* Why deferred from WAVE 2

SSH host entries have a rich shape (host, user, port, identityFile, jumpHost, options.compression, options.serverAliveInterval, etc.). Modeling all of it in KDL needs a small special-case writer (similar to existing =writeAllowedFolders=).

There are also THREE Spell-owned magic file locations (vs. two for the others), making the migrator's idempotency story a bit more involved.

* Proposed schema

#+begin_src kdl
ssh {
  host "prod" {
    hostname "prod.example.com"
    user "deploy"
    port 22
    identity-file "~/.ssh/prod"
    options compression=true server-alive-interval=60
  }
  host "staging" {
    hostname "staging.example.com"
    user "deploy"
  }
}
#+end_src

* Implementation surface

- =packages/coding-agent/src/config/settings-schema.ts= \u2014 add =ssh.hosts= Record<string, SshHostEntry>

- =packages/coding-agent/src/config/kdl-writer.ts= \u2014 add =writeSshHosts= helper
- =packages/coding-agent/src/config/kdl-reader.ts= \u2014 add =readSshHosts= helper

- =packages/coding-agent/src/migration/translate.ts= \u2014 ssh.json schema translator
- =packages/coding-agent/src/migration/detect.ts= \u2014 add ssh.json (3 locations) candidates
