* Narrative

Spell's =EventBus= (=utils/event-bus.ts=) uses =string= channel names and =unknown= payloads. Every subscriber must cast =data= to the expected type. There is zero compile-time safety: you can subscribe to ="todo:change"= and treat the payload as a string, and TypeScript won't complain.

For the swarm architecture, the event bus becomes the central nervous system -- todo state changes, artifact notifications, handoff signals, and scheduler commands all flow through it. Without type safety, this is a runtime bug factory.

The blessed pattern in the TypeScript ecosystem is a *typed event map*: a single interface mapping channel names to payload types, with generic =emit<K>()= and =subscribe<K>()= methods that constrain the payload type per channel. This is the pattern used by =ts-bus=, =typed-event-bus=, and recommended by DDD practitioners (Khalil Stemmler, Event-Driven.io).

This item extends the existing =EventBus= with generic type parameters while preserving full backward compatibility. Existing untyped callers continue to work. New callers get compile-time safety.

* Design Decisions

1. The existing =EventBus= class gains a generic parameter: =EventBus<E extends EventMap = Record<string, unknown>>=. Default =Record<string, unknown>= preserves backward compat.
2. =EventMap= is an interface mapping channel name strings to payload types.
3. =emit()=, =enqueue()=, =subscribe()= become generic over =K extends keyof E=. Payload type is inferred from the channel name.
4. A =FakeEventBus= test helper is created that records all emitted/enqueued events for assertion. This replaces ad-hoc mock patterns in tests.
5. Runtime behavior is unchanged. Type safety is compile-time only. No runtime validation of payloads (that would break perf for P0 sync emit).
6. Existing callers that use string literals for channels get automatic type inference when the =EventMap= is properly typed. Callers using dynamic channel strings fall back to =unknown=.

#+begin_src typescript
/** Base constraint for event maps. Channel name -> payload type. */
export type EventMap = Record<string, unknown>;

/** Extract payload type for a channel from an event map. */
export type EventPayload<E extends EventMap, K extends keyof E> = E[K];

/** Core swarm event map. Extended by consumers. */
export interface SwarmEventMap {
  "todo:task:created": { taskUri: string; kind: "work" | "data"; slug: string };
  "todo:task:status": { taskUri: string; from: string; to: string };
  "todo:task:blocked": { taskUri: string; blockerUri: string };
  "todo:task:unblocked": { taskUri: string };
  "todo:dag:node_added": { nodeUri: string; deps: string[] };
  "todo:dag:node_removed": { nodeUri: string; cascade: string[] };
  "swarm:artifact": { agentId: string; dataUri: string; storagePath?: string };
  "swarm:handoff": { fromAgent: string; toAgent?: string; context: string };
  "swarm:progress": { agentId: string; progress: number; total: number; label: string };
}
#+end_src
