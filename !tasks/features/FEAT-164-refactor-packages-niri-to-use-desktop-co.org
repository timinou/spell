** =packages/niri/src/overview-component.ts=
- Keep =STATUS_COLORS= as ANSI escape map, but derive from hex values in desktop-common:
  #+begin_src typescript
  import { STATUS_COLOR_PALETTE } from "@oh-my-pi/pi-desktop-common";
  export const STATUS_COLORS = Object.fromEntries(
    Object.entries(STATUS_COLOR_PALETTE).map(([k, v]) => [k, {
      bg: hexToBgAnsi(v.bg),
      resetBg: "\x1b[49m",
      fg: hexToFgAnsi(v.fg),
      resetFg: "\x1b[39m",
      label: v.label,
    }])
  );
  #+end_src
- Add =hexToBgAnsi()= / =hexToFgAnsi()= helpers (trivial hex→ANSI truecolor conversion)
