* Goal

Operational tooling for the full-KDL configuration:

** =spell config show [--tier local|project|user]=
Renders the resolved merged KDL or the single-tier view. Useful for debugging precedence.

** =spell config set <path> <value> [--tier]=
Typed write, validates against schema, persists to the requested tier file.

** =spell config doctor=
Scans known locations for orphan =*.yml=, =settings.json=, or stray =spell.kdl= files outside the canonical 3-tier set. Reports findings. Used post-migration to confirm clean state.

** KDL schema reference
Generate =kdl-schema.kdl= at build time from =settings-schema.ts= (SoT). Expose via =pi://spell/spell-kdl-schema=. Drives editor completion (VS Code KDL extension consumes it) and powers =/settings= header link to "open in editor".
