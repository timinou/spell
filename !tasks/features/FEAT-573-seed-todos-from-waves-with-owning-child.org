* Edge Cases

- `orgItemId` empty string: return undefined.
- No matching sub-outline and no preamble: undefined.
- Multiple wave entries pointing to same sub-outline: each gets a copy.
- `:PROPERTIES:` drawer inside sub-outline body: preserved.
- Fluid mode (`materializeFluidPlanToTodos(plan)`) unaffected: has its own `agent.body`.

* Acceptance Criteria

1. `bun test` passes for both test files.
2. `bun check:ts` passes.
3. After approving a PLAN with sub-outline waves, seeded todo list has `details` populated (observable via `/todo` command).
4. Subagent launched via `todoRef` sees the sub-outline implementation text in its `context` field (verified in transcript).
5. When `childItems` empty, todo seeding identical to current main-branch behavior.
