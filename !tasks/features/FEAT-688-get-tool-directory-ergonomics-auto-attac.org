* Intention & Purpose

The =get= tool currently fails its most common discovery use case (browsing a directory):

- =get { target: "specs" }= → =specs  [§dir]= (single useless marker)
- =get { target: "specs/" }= → empty output
- =get { target: "/abs/path" }= → same single marker
- =get { target: "specs#stat" }= → marker only (metadata never rendered)

The prompt =get.md= claims bare path returns "directory listing" but only files actually do. Users (and subagents) fall back to bash =ls=/=find=, defeating the unified-target goal of CodePath.

This feature makes =get= work for directories the way it works for files: zero-friction discovery by default, ergonomic params for recursion, qualifiers as escape hatch, accurate documentation.

* Context & Narrative

** Architecture (current)

- =packages/coding-agent/src/tools/get.ts= — TS wrapper around =executeCodePath= (native). Already auto-attaches =#raw= to bare paths resolving to existing files via =shouldAutoAttachRaw= + =fs.stat= guard (lines ~26–46).
- =crates/pi-code-path/src/dialects/fs/= — native fs dialect. =walker.rs= produces =§file= / =§dir= / =§symlink= nodes. =qualifiers.rs= already implements =#listing= (one level), =#tree[depth=N]= (recursive cap), =#stat= (metadata). All three work in native today.
- =packages/coding-agent/src/tools/codepath-result.ts= — TS formatters. =node-list= shows =loc  [kind]
text=, =simple-list= dedupes paths, =tree= groups by file. =§stat= node metadata is collected by walker but never rendered by any formatter.
- =packages/coding-agent/src/prompts/tools/get.md= — describes bare path as "whole file or directory listing"; doesn't list directories.

** Empirical verification

Direct invocations during planning (read-only):

#+begin_example
get { target: "specs" }                        → "specs  [§dir]"
get { target: "specs/" }                       → ""              (empty!)
get { target: "specs#listing" }                → ✓ full child list
get { target: "specs#tree[depth=2]" }          → ✓ recursive
get { target: "specs#stat" }                   → "specs  [§dir]" (metadata lost)
get { target: "specs/*" }                      → ✓ full listing
get { target: "specs", format: "simple-list" } → "specs"        (still 1 node)
#+end_example

The native side is sound; the TS wrapper and prompt are the leak.

** Settled decisions

1. *API:* top-level =recursive: boolean= and =depth: integer= params; qualifier (=#listing=, =#tree[depth=N]=) remains as escape hatch.
2. *Default render:* when all returned nodes are fs nodes (=§file= / =§dir= / =§symlink= / =§stat=) and =format= is unset, auto-promote to fs-listing layout: =<path>  <size>= for files, =<path>/= for dirs, key=value for stat. Explicit =format= always wins.
3. *Scope add-ons:* =#stat= metadata rendering + degenerate-result hint diagnostic.
4. *Absolute paths:* same auto-attach treatment as relative; consistent regardless of inside/outside project root.

function isFsKind(kind?: string): boolean { return !!kind && FS_KINDS.has(kind); }
function allFsNodes(nodes: NodeRefDto[]): boolean {
  return nodes.length > 0 && nodes.every(n => isFsKind(n.kind));

function formatBytes(n: number): string {
  if (n < 1024) return `${n}B`;
  if (n < 1024 * 1024) return `${(n / 1024).toFixed(1)}K`;
  return `${(n / 1024 / 1024).toFixed(1)}M`;
}
function formatStatValue(v: unknown): string {
  if (typeof v === "number" || typeof v === "boolean") return String(v);
  if (typeof v === "string") return v;
  return JSON.stringify(v);
}

2. New =buildFsListing(nodes)=:

#+begin_src ts
function buildFsListing(nodes: NodeRefDto[]): string {
  return nodes.map(n => {
    const path = formatLocator(n.locator).path ?? n.locator;
    const meta = n.metadata ?? {};
    if (n.kind === "§dir") return `${path}/`;
    if (n.kind === "§symlink") return `${path} → (symlink)`;
    if (n.kind === "§stat" || Object.keys(meta).length > 0) {
      const parts = Object.entries(meta).map(([k, v]) => `${k}=${formatStatValue(v)}`);
      return parts.length ? `${path}  ${parts.join(" ")}` : path;
    }
    if (n.kind === "§not-found") return `${path}  [not found]`;
    const size = (n.range?.end ?? 0) - (n.range?.start ?? 0);
    return size > 0 ? `${path}  ${formatBytes(size)}` : path;
  }).join("
");
}
#+end_src
