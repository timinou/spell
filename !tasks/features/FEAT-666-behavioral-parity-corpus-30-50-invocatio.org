* Edge Cases

- Diagnostic-class equivalence: legacy emits string error; new emits structured Diagnostic. Define mapping table (e.g. legacy "ENOENT: file not found" ≡ =Diagnostic::FileNotFound=).
- Output ordering: legacy may sort differently. Normalise both before comparison.
- Pagination differences: legacy uses absolute indices; new may chunk. Compare full materialised result sets.
- Diagnostic-only outputs: parity covers structure-of-error, not exact strings.
- Side effects (write, edit): use ephemeral tempdirs per test; assert post-state.
- ast-grep $A/$$$A captures: deferred per FUP; mark these tests as =it.todo=.
