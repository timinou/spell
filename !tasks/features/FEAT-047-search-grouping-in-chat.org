Key QML design:
- sourcesJson stored as string in ListModel (QML ListModel limitation — cannot store arrays)
- SearchGroupDelegate parses ~JSON.parse(sourcesJson)~ on load and when expanded
- Collapsed/expanded state toggled via property, with Behavior animation on implicitHeight
- Max 20 sources per group (web_search limit)

* Edge Cases
- Empty sources array: show header with 'No results' text
- Source with very long title: elide in collapsed view
- Multiple search groups in sequence: each has independent collapse state
- findings_batch without searchGroup field: create individual finding messages, not a group
- sourcesJson parsing failure: show error text, don't crash delegate
