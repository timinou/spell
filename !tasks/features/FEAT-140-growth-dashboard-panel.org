* Edge Cases
- No ads in database: show 'No competitor data yet. Run a scan?' with quick action button
- Org items not initialized: pipeline shows all zeros
- Large number of recent ads (100+): paginate feed, show 'Load more'
- Quick action while agent is busy: queue or show 'Agent busy' toast

* Acceptance Criteria
- Dashboard renders with seeded data showing correct metric values
- Clicking ad in feed emits open_ad_detail event
- Empty state shows helpful message with scan action
- Pipeline bar correctly reflects org item state counts
