* Edge Cases

- Operator names containing kernel sigils: =(::)= for Haskell type-cons → backtick-quote required (=\`(::)\`=).

- Type-application names =Foo @Int= → encoded with =@= preserved in payload (kernel doesn't reserve =@= post-FEAT-581 sigil revision).
