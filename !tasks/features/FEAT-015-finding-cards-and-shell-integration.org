* Implementation
1. ~packages/coding-agent/src/modes/browse-findings.ts~: Define ~BrowseFinding~ interface. Export ~createFinding()~ factory with auto-generated ID.
2. ~packages/coding-agent/src/modes/browse-event-mapper.ts~: Implement ~emitFinding(finding)~ that sends ~{ type: 'finding', ...finding }~ to QML bridge.
3. ~packages/coding-agent/src/modes/browse-mode.ts~: When agent emits custom message with ~customType: 'finding'~, call ~emitFinding()~. Handle 'view_in_tab' events from QML by sending tab:switch.
4. ~packages/coding-agent/src/modes/qml/panels/delegates/FindingCard.qml~: Styled card with:
   - Top: favicon placeholder + URL domain in textTertiary, monoFontFamily
   - Title: textPrimary, fontSizeM, fontWeightMedium
   - Excerpt: textSecondary, fontSizeS, max 3 lines with ellipsis
   - Tags: Row of small pill labels (surface1 background, textTertiary text)
   - 'View in tab' button emits ~{ type: 'view_in_tab', tabId }~ via bridge
   - Card background: surface0, borderSubtle bottom border, no rounded corners
5. ~FlowMessageDelegate.qml~: Add ~finding~ role routing to FindingCard
6. ~BrowseShell.qml~: Wire BrowseChatPanel as Chat tab content. Wire BrowserPanel for browser tabs. Handle 'view_in_tab' by switching to target browser tab.

* Edge Cases
- Finding with no tabId: 'View in tab' button hidden
- Finding with very long excerpt: truncated to 3 lines with ellipsis
- Finding with empty tags: tag row hidden
- 'View in tab' for a closed tab: open new tab to that URL

* Acceptance Criteria
- Agent can emit findings that appear as styled cards in chat
- Finding cards show URL domain, title, excerpt, and tags
- 'View in tab' switches to the associated browser tab
