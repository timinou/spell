* Intention & Purpose

Replace =pi-code-vectors::VectorIndex= flat brute-force scan with HNSW
ANN via the =hnswlib-rs= crate. Same external API (=new=, =search=,
=to_persisted=, =from_persisted=). Persistence becomes graph-bin +
vectors-bin in one container file. Flat code path is deleted (per
settled decision). Existing call sites in =pi-natives::code_graph= and
=pi-code-graph= must continue to work unchanged.

* Context & Narrative

Spec: =specs/org-graph-memory.md=. Today =index.rs= implements
=search()= as a linear scan with full sort: O(n × d) per query. At 10k
× 768-dim that is ~7 ms; at 100k+ it becomes the recall bottleneck.
=hnswlib-rs= (jean-pierreBoth, January 2026, 2024 edition, ~70 KiB SLoC)
provides decoupled graph + vector store: =Hnsw<NodeId, M>= owns the
graph; the caller supplies a =VectorStore= keyed by =NodeId=. =save_to=
/ =load_from= persist via std::io and bincode.

This FEAT is a self-contained crate refactor; downstream FEAT-635 uses
the new index from the embedding worker, FEAT-634 scaffolds the recall
crate that wraps it.

* Scope

* Existing Patterns

- Persisted format precedent: =index.rs::PersistedVectorIndex= already uses serde + bincode. Keep the wrapper struct; only the inner blob format changes.
- =VectorEntry { node_index, vector }= shape stays; pre-normalization stays (HNSW cosine distance benefits from it).
- Error type: =crate::error::Error= already enumerates =DimensionMismatch=; add =Error::IncompatibleIndexVersion= for legacy detection.
- Build settings: =hnswlib-rs= is pure Rust, no FFI; no changes to =build.rs=.

* Edge Cases

- Single-entry index: HNSW with one node still works; search returns that one hit
- All-zero vector: pre-normalize step would divide by zero. Detect ‖v‖ < 1e-9 → push as a sentinel zero-vector and skip normalization; document
- Persisted bytes truncated mid-graph-blob: serde error surfaces; caller drops the index and rebuilds from entries
- Index built with one M, queried after format change: header includes M; mismatch is treated as IncompatibleIndexVersion
- Crash during =to_persisted=: write to =foo.bin.tmp= then atomic rename. Recovery on next load: missing =foo.bin= is fine, rebuild from source
- =hnswlib-rs= panic on degenerate input: wrap inserts in =catch_unwind= and convert to =Error::Build=
