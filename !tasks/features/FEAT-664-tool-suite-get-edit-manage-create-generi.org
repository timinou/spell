8. Tree listing: =get { target: "src/", format: "tree" }= → tree-style output.
9. Image: =get { target: "img.png" }= → inline image.
10. Document extraction: =get { target: "doc.pdf" }= → extracted text.
11. Cancellation via tool-level abort signal.
12. Suffix-fallback: typo path triggers SuffixSuggestion in result.
13. Diagnostic surface: every error path returns diagnostic, not throw.

* Edge Cases

- =get= with empty target → ParseError diagnostic, not throw.
- =get= with locator-only (no =::Query=) yields locator-as-NodeRef (replaces =find=).
- =edit= with empty operations array → no-op success (matches existing edit semantics).
- =edit= LINE#ID stale → return diagnostic with fresh LINE#ID; tool layer formats as actionable error.
- =edit= with create action against existing file → =Diagnostic::FileExists=; require explicit =force= or use update action.
- =create= without force on existing file → =Diagnostic::FileExists=.
- =create= with bytes-handle pointing to expired artifact → =Diagnostic::ArtifactNotFound=.
- =manage= with unknown command → schema rejects at validation.
- =manage save= on file that doesn't exist as buffer → =Diagnostic::NoBuffer=.
- AbortSignal mid-stream: tool surfaces partial results + Cancelled diagnostic.
- Tool-level approval gates: =edit= and =create= require approval per existing policy; =get= and =manage= don't.
- Mode guards: =plan-mode= rejects =edit=/=create=/=manage save= in non-plan dirs unless allowlisted.
