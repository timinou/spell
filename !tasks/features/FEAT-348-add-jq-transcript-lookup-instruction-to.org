* Initial Message

Below the "Initial message" part of plans, add an instruction to say that they can use jq to look up information in the planning session transcript

* Goal

When a plan is approved and the execution session starts, the executing agent should be told it can use =jq= to look up information in the planning session transcript. This enables the executor to recover design decisions, Q&A, or other context from the planning conversation without that information needing to be exhaustively copied into the plan body.

* Design Decisions

- The planning session transcript path is captured from =sessionManager.getSessionFile()= *before* =handleClearCommand()= rotates the session in =#approvePlan=.
- The path is passed as a Handlebars template variable =planningTranscriptPath= to the =planModeApprovedPrompt= template.
- The instruction is rendered conditionally in the template (={{#if planningTranscriptPath}}=) below =={{planContent}}== (which contains the =* Initial message= heading).
- The path is NOT stored in the org item body — it is ephemeral and session-specific.
- If persist is disabled and no session file exists, the instruction is omitted.

* Implementation
