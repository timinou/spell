* Implementation
** Step 1: Replace todo initialization in plan-mode-approved.md
- Remove old 1-task-per-org-item instruction
- Add wave-based todo initialization:
  - Create one todo phase per wave, named after the wave
  - Each wave entry becomes a task in that phase
  - Set =orgItemId= (non-gating) on ALL tasks for lineage tracking
  - Set =orgItemClosingId= (gating) ONLY on the LAST wave task for each org item
  - Cross-wave blockers: if orgItemId X appears in wave N and wave N-1, wave N task blocks on wave N-1 task
  - Tasks within same wave: parallelize via =task= subagents with =todoRef=
  - Read child org items via =org get= to populate task details from matching sub-outline step
