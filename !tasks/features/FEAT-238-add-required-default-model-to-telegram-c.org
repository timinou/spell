* Scope

The spell-server's telegram bot spawns =spell --mode rpc= without a =--model= flag. The spawned process relies on whatever model is in =~/.spell/agent.db= or env vars. If nothing is configured, =session.prompt()= throws "No model selected" and the user gets a silent failure ("Assistant completed without a text response").

Fix: add a required =default-model= field to the telegram block in =channels.kdl=, validate it at config load time, and pass it as =--model <slug>= when spawning the RPC process.
