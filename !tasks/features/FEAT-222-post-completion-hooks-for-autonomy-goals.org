* Scope
** In scope
- HookDispatcher orchestration for post-completion hook execution after goal completion
- WebhookHookExecutor for HTTP POST/GET with simple template substitution
- TelegramHookExecutor via NotificationSender interface
- OrgHookExecutor for BUG/feature org item creation based on run outcome
- Hook ordering guarantees: fire sequentially in config order; one failure does not block later hooks
** Out of scope
- Agent-driven hooks
- Complex conditional hook routing
- Slack/Discord executors (follow-up via NotificationSender interface)
** Boundary
- Hooks execute only after goal completion; Goal Executor hands GoalResult to HookDispatcher
- Depends on FEAT-219 Goal Executor and FEAT-215 manifest schema/types

* Edge Cases
- Webhook URL unreachable: timeout after 5s, log warning, continue
- Template variable not found: leave ={{unknown}}= literal in output
- Org package not installed or repo not configured: catch import/config error and skip gracefully
- Telegram rate limit (429): rely on grammy retry behavior, but log if delivery exceeds 5s
- Hook fires during daemon shutdown: best-effort only; shutdown path does not wait for hook completion
