* Context

The =CodeTool= class in =packages/coding-agent/src/tools/code.ts= currently delegates all file-local commands to an Emacs daemon via =createCodeTool= from =@oh-my-pi/pi-emacs=. The native =pi-code-engine= (Rust) now provides all these capabilities via the =executeCodeBuffer= NAPI binding in =@oh-my-pi/pi-natives=.

This item rewires CodeTool to call the native engine directly, eliminating the Emacs dependency for code intelligence.

* Design Decisions

- Synchronous NAPI call via =executeCodeBuffer= from =@oh-my-pi/pi-natives=
- Auto-open semantics: the NAPI layer auto-opens buffers on first access (implemented in FEAT-446). CodeTool does NOT need to manage buffer lifecycle.
- Command mapping:
  - =buffers= agent command → =list= NAPI command
  - =references-local= navigate action → =references= (the Rust engine uses =references=; the old Emacs name is dropped)
  - =install_grammar= → removed entirely (grammars are compiled into the binary)
  - =languages= → new NAPI command (read-only, lists built-in profiles)
  - All other commands pass through: =read=, =outline=, =navigate=, =edit=, =undo=, =redo=, =diff=, =save=
- Graph commands (=index=, =status=, =context=, =impact=, =deps=, =flow=, =dead_code=, =clusters=, =search=) continue routing to =executeCodeGraph= — unchanged
- No Emacs fallback: if the native engine returns an error (unsupported language, parse failure), surface it directly
- The =getSession= / =EmacsSessionManager= dependency is removed from CodeTool

Rewrite =execute= method. The structure should be:
1. Check if graph command → route to =#executeGraphCommand= (unchanged)
2. Handle =install_grammar= → return error "install_grammar is no longer supported; grammars are built-in"
3. Build NAPI options object from params
4. Handle command mapping:
   - =buffers= → ={"command": "list"}=
   - For =navigate= with =action: "references-local"= → map action to ="references"=
5. Call =executeCodeBuffer(options)= synchronously
6. Check =result.error= flag and return appropriate =AgentToolResult=

The key implementation:
#+begin_src typescript
async execute(
    _toolCallId: string,
    params: CodeParams,
    _signal?: AbortSignal,
    _onUpdate?: AgentToolUpdateCallback,
    _context?: AgentToolContext,
): Promise<AgentToolResult> {
    const args = params as Record<string, unknown>;
    const command = String(args.command ?? "");

    if (command === "edit" || command === "save") {
        const file = args.file as string | undefined;
        if (file) enforceModeWrite(this.#session, file);
    }

    try {
        if (GRAPH_COMMANDS.has(command)) {
            return await this.#executeGraphCommand(params, _signal);
        }

        if (command === "install_grammar") {
            return {
                content: [{ type: "text", text: JSON.stringify({ error: true, message: "install_grammar is no longer supported. Grammars for TypeScript, Rust, Python, and Elixir are built-in." }) }],
                details: { error: true, command },
            };
        }

        // Build NAPI options
        const nativeCommand = command === "buffers" ? "list" : command;
        const options: Record<string, unknown> = { command: nativeCommand };

        // Copy relevant params
        if (args.file) options.file = args.file;
        if (args.resolution !== undefined) options.resolution = args.resolution;
        if (args.offset !== undefined) options.offset = args.offset;
        if (args.limit !== undefined) options.limit = args.limit;
        if (args.line !== undefined) options.line = args.line;
        if (args.column !== undefined) options.column = args.column;
        if (args.symbol) options.symbol = args.symbol;
        if (args.depth !== undefined) options.depth = args.depth;
        if (args.operation) options.operation = args.operation;
        if (args.content !== undefined) options.content = args.content;
        if (args.node_type) options.node_type = args.node_type;

        // Map navigate action: references-local → references
        if (command === "navigate" && args.action) {
            options.action = args.action === "references-local" ? "references" : args.action;
        }

        const result = executeCodeBuffer(options as CodeBufferOptions);
        const text = JSON.stringify(result.output, null, 2);
        return {
            content: [{ type: "text", text }],
            details: result.error ? { error: true, command } : { command },
        };
    } catch (err) {
        const msg = err instanceof Error ? err.message : String(err);
        logger.error("code tool error", { error: msg, command });
        return {
            content: [{ type: "text", text: JSON.stringify({ error: true, message: msg }) }],
            details: { error: true, command },
        };
    }
}
#+end_src
