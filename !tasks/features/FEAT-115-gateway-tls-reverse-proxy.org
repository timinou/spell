** Edge Cases
- Host header missing: return 400 Bad Request
- Host header has port number (~myapp.localhost:443~): strip port before alias lookup
- Backend returns connection refused: return 502, do not retry
- Backend response timeout (>30s): return 504 Gateway Timeout
- TLS cert expired: detect via file mtime, regenerate on daemon start if older than 825 days (mkcert default)
- Multiple concurrent requests to same starting backend: coalesce start attempts, all get 503 until ready
- CORS preflight (OPTIONS): proxy to backend, don't intercept
