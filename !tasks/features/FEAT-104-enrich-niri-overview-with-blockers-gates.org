Data flow today:
1. =todo-write.ts= =TodoItem= — full data
2. =modes/types.ts= =TodoItem= — slimmed (id, content, status, details)
3. =interactive-mode.ts= =todoPhases: TodoPhase[]= — slimmed type, but runtime data has all fields
4. =niri/controller.ts= =TodoItemView= — minimal (content, status)
5. =niri/controller.ts= =#buildSnapshot()= — strips to content + status
6. =niri/overview-component.ts= =renderTodoItem()= — renders only icon + content
