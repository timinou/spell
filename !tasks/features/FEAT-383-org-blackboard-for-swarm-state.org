* Narrative

In the current architecture, subagents are fully isolated: they receive a static assignment at launch and return a single result at completion. There is no way for a running agent to share intermediate findings with peers, announce that it discovered a dependency another agent needs, or leave structured state that survives beyond its session.

This is the "shared nothing" problem. It works for independent parallel tasks but breaks down for *interconnected swarms* where agents must collaborate: agent A discovers an API contract that agent B needs before it can generate callers; agent C finds a failing test that agent D should prioritize; agent E produces an artifact that agents F and G both consume.

The blackboard pattern solves this: a shared knowledge base where agents post entries (findings, artifacts, handoff records, progress) and query entries from peers. Other agents -- or the scheduler -- monitor the blackboard to make routing decisions.

We use *org items* as the blackboard substrate because:
- Org items are already the canonical state representation in Spell (plans, features, bugs all live in org).
- =OrgClient.callTool()= via MCP is already available to subagents.
- Org items are human-readable, persistent across sessions, queryable via =org query=, and support structured PROPERTIES + freeform body.
- Journal/NOTE entries provide append-only audit trails naturally.
- The =OrgFluidBridge= already demonstrates org-backed agent state lifecycle (ITEM->DOING->DONE).

Each swarm run creates a parent org item (=SWARM-<run-id>=). Agent-written entries are children of that parent. The blackboard is scoped to a single run; querying is fast because it's filtered by parent ID.

* Design Decisions

1. Blackboard entries are org items in a =swarm= category. Prefix: =SWARM=.
2. Each run creates one parent item: =SWARM-<run-id>-<slug>=. State: =DOING= while swarm runs, =DONE= when complete.
3. Agent writes create child items under the parent. Each child has PROPERTIES:
   - =:AGENT:= -- the agent ID that wrote it
   - =:TYPE:= -- one of: =artifact=, =finding=, =handoff=, =progress=, =contract=
   - =:TIMESTAMP:= -- ISO 8601 write time
   - =:ARTIFACT_PATH:= -- (optional) file path if the entry references an on-disk artifact
4. Body contains the payload: text, JSON code blocks, or org-structured content.
5. Agents interact via the existing MCP org tools: =org create= (write), =org update= / =org note= (amend), =org query= (read), =org get= (read single).
6. =SwarmBlackboard= is a thin TypeScript class that wraps these calls with typed helpers. It does NOT duplicate org logic -- it builds the correct =org create= / =org query= calls.
7. Swarm lifecycle events (agent start, completion, handoff, failure) are logged as =org note= entries on the parent item, providing an audit trail.

#+begin_src typescript
export type BlackboardEntryType = "artifact" | "finding" | "handoff" | "progress" | "contract";

export interface BlackboardEntry {
  id: string;           // org CUSTOM_ID
  agentId: string;
  type: BlackboardEntryType;
  timestamp: string;    // ISO 8601
  title: string;
  body: string;
  artifactPath?: string;
}

export interface SwarmRunMetadata {
  runId: string;
  parentOrgId: string;  // CUSTOM_ID of parent SWARM item
  startedAt: string;
  prompt: string;       // original user prompt
}

export interface HandoffRecord {
  fromAgent: string;
  toAgent?: string;     // hint; scheduler may override
  context: string;      // what the receiving agent needs to know
  partialResult?: string;
  reason: string;       // why handoff is happening
}

export interface ArtifactRecord {
  agentId: string;
  path: string;         // on-disk path
  description: string;
  mimeType?: string;
}
#+end_src

** =packages/coding-agent/src/swarm/blackboard.ts=
#+begin_src typescript
class SwarmBlackboard {
  constructor(private orgClient: OrgClient, private runMeta: SwarmRunMetadata) {}

  /** Initialize: create parent SWARM org item */
  static async init(orgClient: OrgClient, runId: string, prompt: string): Promise<SwarmBlackboard>;

  /** Write a new entry to the blackboard */
  async write(agentId: string, type: BlackboardEntryType, title: string, body: string, artifactPath?: string): Promise<string>;

  /** Read all entries, optionally filtered */
  async read(filter?: { agentId?: string; type?: BlackboardEntryType }): Promise<BlackboardEntry[]>;

  /** Read a single entry by ID */
  async get(entryId: string): Promise<BlackboardEntry | undefined>;

  /** Append a note to an existing entry */
  async annotate(entryId: string, note: string): Promise<void>;

  /** Log a swarm lifecycle event on the parent item */
  async logEvent(event: string): Promise<void>;

  /** Mark swarm run complete */
  async complete(): Promise<void>;
}
#+end_src
