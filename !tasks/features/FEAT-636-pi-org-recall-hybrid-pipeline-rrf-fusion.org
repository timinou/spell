* Intention & Purpose

Glue the three retrieval lanes (Tantivy BM25, HNSW vector, typed-graph
neighborhood) into a single =recall(query)= entry point that returns a
ranked Vec<RecallHit>. Fusion uses Reciprocal Rank Fusion (RRF) with
default weights bm25=0.3, vector=0.5, graph=0.2 and K=60. This is the
recall layer that =executeOrg::recall= (FEAT-637) and the
session-start memory_summary projection (FEAT-640) consume.

* Context & Narrative

Spec: =specs/org-graph-memory.md=. RRF beats both pure-dense and
pure-sparse on 60–80% of production hybrid-search benchmarks. Formula:
=RRF(doc) = Σ 1 / (K + rank(doc, source) + 1)= summed across the BM25,
vector, and graph rankings. Weights scale each source's contribution
before the sum.

Named profiles (e.g. ="session-start"=, ="priors-for-article"=) live in
config (=spell.kdl= recall blocks, surfaced through the existing
settings layer). For v1 the profile lookup is a string-keyed map
loaded once per process; KDL parsing is unchanged from current behavior.

* Edge Cases

- Empty BM25 hit set with non-empty vector: lane ranking is empty Vec; RRF skips it
- Tied RRF scores: secondary sort by id ascending for determinism
- Scope filter eliminates all candidates: return empty Vec, no error
- Focus id not in graph: graph lane returns empty; if focus was the only lane, returns empty
- Limit = 0: return empty Vec, no error
- Embedder failure: lane returns empty; RRF degrades to BM25 + graph
- Tantivy snippet failure: fall back to first 200 chars of body
