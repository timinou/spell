* Scope
** In scope
- Subscribe to =TASK_SUBAGENT_EVENT_CHANNEL= for todo-related events from subagents
- When a subagent emits =todo:change=, propagate its phases as children under the parent task in the parent's todo list
- Add =children?: TodoPhase[]= field to =TodoItem= for nested sub-tasks
- TUI rendering: nested sub-tasks indented under parent task in todo display
- Niri overview: nested sub-tasks visible in the QuickShell spell status widget
- Real-time updates: parent's todo list refreshes as subagent makes progress
** Out of scope
- Infinite nesting depth (limit to 1 level: parent -> children. Sub-sub-agents' todos stay in their own scope)
- Canvas fluid QML rendering of nested todos
** Boundary rationale
Real-time visibility into subagent progress at exactly 1 nesting level. Deeper nesting deferred.

* Edge Cases
- Subagent emits very frequent todo changes: debounce propagation (100ms)
- Subagent's session ends abruptly: last known children state is preserved
- Parent task completed before subagent finishes: ignore further propagation
- Children phases serialization: must not break journal/session file format
- Nesting depth > 1: sub-subagent todos stay in their own scope (not propagated to grandparent)
