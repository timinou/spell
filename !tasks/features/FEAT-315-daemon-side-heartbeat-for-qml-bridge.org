Add periodic heartbeat from the C++ daemon to all connected clients so clients can detect stale connections before the next command attempt. Consolidates all heartbeat work: C++ broadcast, protocol type, TS filtering, and stale detection (per Metis GAP-07).

* Scope
** In scope
- C++ daemon: QTimer-based heartbeat broadcast every 30s, ~broadcastEvent~ helper on SocketServer
- ~protocol.ts~: Add ~heartbeat~ to ~BridgeEvent~ union
- ~qml-process.ts~: ~#lastDataReceived~ timestamp tracking, stale detection at 90s
- ~qml-bridge.ts~ ~#handleEvent~: Ignore heartbeat (before window lookup)
- ~canvas-event-utils.ts~: Classify ~heartbeat~ as silent
- Tests for heartbeat arrival, filtering, and stale detection
** Out of scope
- Auto-reconnect logic (BUG-157 — heartbeat detection triggers the reconnect that BUG-157 implements)
- Socket-level reconnect mechanics (BUG-157)
- ~ping~ BridgeCommand (removed — dead protocol, GAP-08)

* Problem
Currently clients only discover a dead connection when they try to ~send()~ a command or when the OS closes the socket. An idle client may sit with a dead socket for minutes. The 10-minute ~waitForEvent~ timeout is far too long for liveness detection.

* Edge Cases
- *No heartbeat in stdio mode*: ~startHeartbeat()~ is only called in daemon mode (main.cpp conditional).
- *Client disconnects during heartbeat write*: ~writeEvent~ catches write failures and disconnects the client — this triggers the disconnect callback and orphan flow.
- *Heartbeat arrives during reconnect*: It updates ~#lastDataReceived~ and is otherwise ignored. No interference with reconnect flow.
- *Stale detection false positive*: 90s timeout (3 missed heartbeats) is conservative. System clock skew is a non-issue since we use ~Date.now()~ deltas.

* Acceptance Criteria
- Daemon sends ~{"type":"heartbeat"}~ every 30s to all clients when in daemon mode.
- No heartbeat in stdio mode.
- ~QmlProcess~ tracks last-data timestamp and detects stale connections.
- Heartbeat events don't trigger agent turns (classified as silent, not pushed to window queues).
