- =startLogViewer(config, sessionMap)=:
  - =Bun.serve()= on =config.logViewerPort=
  - Routes:
    - =GET /=: list active sessions (chat ID, project, uptime) as HTML
    - =GET /session/:chatId=: read session file, render as HTML
    - =GET /session/:chatId/raw=: return raw JSONL session file
  - Auth: check =Authorization: Bearer <token>= header or restrict to 127.0.0.1
  - Return if =logViewerPort= is undefined (feature disabled)

* Edge Cases
- Session file doesn't exist yet (new chat, no messages): show "no messages yet"
- Very large session file: stream response, don't load entire file into memory
- Port already in use: catch EADDRINUSE, log clear error, continue without log viewer
- Concurrent requests while session is being written: read snapshot, don't lock
