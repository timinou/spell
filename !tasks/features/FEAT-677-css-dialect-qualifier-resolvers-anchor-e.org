* Edge Cases
- Selector lists (D-1): =a, b= produces two QSelector entries
- Functional pseudos (D-2): =:is(.x, .y)= flattens; =:has()= depth-1 only
- Nesting (D-3): =&= reference handled via parent selector concat
- =@scope= (D-4): contained selectors limited to =@scope { }= scope
- Custom property cascade (D-5): =--name= matched as custom-prop anchor
- =!important= (D-6): boolean flag on declaration
- Duplicate declarations (D-7): all match; ordinal disambiguates
