* Goal
Register a =SubprocessToolHandler= for the ="bash"= tool so the parent task dispatcher tracks all bash commands executed by subagents. This data feeds into gate verification.

* Design Decisions
- The handler extracts ={ command, exitCode }= from each bash tool execution event.
- Extracted data is stored in =progress.extractedToolData["bash"]= as an array of ={ command: string, exitCode: number }=.
- The handler does NOT terminate the session (=shouldTerminate= returns =false= or is omitted).
- The handler reads =command= from =event.args.command= and =exitCode= from the =event.result=.
- For bash tool results: successful commands return =result.content[0].text= (output). Failed commands have =event.isError = true=. The exit code is NOT directly in the result details (=BashToolDetails= has no exitCode field). We infer: =isError ? 1 : 0=.
- The handler is registered via side-effect import in =executor.ts= (same pattern as =import "../tools/review"=).

* Implementation
#+begin_src typescript
// packages/coding-agent/src/task/bash-subprocess-handler.ts
import { subprocessToolRegistry } from "./subprocess-tool-registry";

interface TrackedBashExecution {
  command: string;
  exitCode: number;
}

subprocessToolRegistry.register<TrackedBashExecution>("bash", {
  extractData: (event) => {
    const command = typeof event.args?.command === "string" ? event.args.command : undefined;
    if (!command) return undefined;
    // Bash tool throws ToolError on non-zero exit, so isError means non-zero exit
    const exitCode = event.isError ? 1 : 0;
    return { command, exitCode };
  },
  // Do NOT terminate session on bash completion
});
#+end_src
