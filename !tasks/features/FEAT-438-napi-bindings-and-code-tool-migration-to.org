* Context

The =code= tool in Spell currently routes file-local commands (read, outline, navigate, edit, buffers, diff) through an Emacs daemon via socat + JSON-RPC, and graph commands through Rust NAPI bindings. This item completes the migration: ALL code tool commands route through Rust NAPI. The Emacs daemon is no longer used by the code tool.

Current routing (=packages/coding-agent/src/tools/code.ts=):
- Graph commands (index, status, context, impact, deps, flow, dead_code, clusters, search) → =executeCodeGraph= in =pi-natives=
- File commands (read, outline, navigate, edit, buffers, diff, languages, install_grammar) → Emacs daemon via =CodeToolDefinition= in =packages/emacs/src/tool.ts=

New routing:
- Graph commands → =executeCodeGraph= (unchanged, updated by graph fixes item)
- File commands → =executeCodeBuffer= (NEW NAPI binding in =pi-natives=)
- =languages= → can query the engine's =LanguageRegistry= (no Emacs needed)
- =install_grammar= → DROPPED (grammars are compiled into the Rust crate at build time)

* NAPI Binding: =executeCodeBuffer=

File: =crates/pi-natives/src/code_buffer.rs= (new file)

#+begin_src rust
use napi::bindgen_prelude::*;
use napi_derive::napi;
use pi_code_engine::{
    buffer::{BufferRegistry, CodeBuffer, TextEdit},
    language::LanguageRegistry,
    outline, navigate, edit,
};

#[napi(object)]
pub struct CodeBufferOptions<'env> {
    pub command: String,
    pub file: Option<String>,
    pub resolution: Option<u32>,
    pub action: Option<String>,
    pub line: Option<u32>,
    pub column: Option<u32>,
    pub symbol: Option<String>,
    pub operation: Option<String>,
    pub content: Option<String>,
    pub node_type: Option<String>,
    pub offset: Option<u32>,
    pub limit: Option<u32>,
    pub agent_id: Option<String>,
    pub save: Option<bool>,
    pub signal: Option<Unknown<'env>>,
}

#[napi(object)]
pub struct CodeBufferResult {
    pub output: String,
    pub error: Option<bool>,
}
#+end_src

Command dispatch:
- "open" → =registry.open(file)=, return buffer info
- "close" → =registry.close(file)=
- "list" → =registry.list()=, return JSON
- "read" → open buffer if not open, call =read(buffer, profile, resolution, offset, limit)=, return text
- "outline" → open buffer if not open, call =outline(buffer, profile)=, return JSON
- "navigate" → open buffer, call =navigate(buffer, profile, action, line, column, symbol, graph)=, return JSON
- "edit" → open buffer, dispatch to edit operation (replace, insert-before, insert-after, kill, splice, drag, clone, transpose), apply edits to buffer, optionally save
- "undo" → =buffer.undo()=
- "redo" → =buffer.redo()=
- "diff" → =buffer.diff_from_disk()= or =buffer.diff_from(snapshot)=
- "languages" → list =registry.languages()=

The =BufferRegistry= is held as a global singleton (=thread_local!= or =OnceCell=), initialized on first call.

The graph reference for navigate's references action: the NAPI binding can access the graph if it's been built (via the existing =executeCodeGraph= infrastructure). Pass it as =Some(&graph)= to =navigate()=.

#+begin_src typescript
const GRAPH_COMMANDS = new Set(["index", "status", "context", "impact", "deps", "flow", "dead_code", "clusters", "search", "diff"]);
const BUFFER_COMMANDS = new Set(["open", "close", "list", "read", "outline", "navigate", "edit", "undo", "redo", "buffers"]);

class CodeTool {
    #session: ToolSession;
    // No more #inner (Emacs)

    async execute(params) {
        if (command === "edit") { enforceModeWrite(this.#session, file); }

        if (GRAPH_COMMANDS.has(command)) {
            return this.#executeGraphCommand(params);
        }
        // ALL file commands go through Rust now
        return this.#executeBufferCommand(params);
    }

    async #executeBufferCommand(params) {
        const result = await executeCodeBuffer({
            command: params.command,
            file: params.file,
            resolution: params.resolution,
            // ... map all params
        });
        return {
            content: [{ type: "text", text: result.output }],
            details: result.error ? { error: true, command } : { command },
        };
    }
}
#+end_src
