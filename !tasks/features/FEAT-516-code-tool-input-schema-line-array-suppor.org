* Initial Message

yo. how would you gain by getting the code tool interface to be xml instead of json, when communicating with the LLM

* Goal

Restructure the code tool's input schema so code content uses =string[]= (array of lines) instead of requiring JSON-escaped single strings. Inspired by the hashline edit tool which uses =edits[].lines: string | string[] | null=.

This eliminates the JSON escaping pain when the LLM passes multi-line code as tool arguments: no more =
=, =	=, =\\=, =\"= escaping inside content fields.

* Design Decisions

- Accept =string | string[]= for all content-carrying fields
- When =string[]=, join elements with =
= before passing to native engine
- Native layer (=CodeBufferOptions=, =Patch= in =packages/natives/src/code-buffer/types.ts=) stays unchanged — it expects =string=
- Conversion happens in =code.ts= before calling =executeCodeBuffer()=
- Clean cutover: old single-string format still works (it's a superset), but prompt examples show the new array format

* Files to Modify

** =packages/coding-agent/src/tools/code.ts=

= and passes strings through
- In =CodeTool.execute()=, before building the =options= object for =timedCodeBuffer()=, normalize:
  - =params.content= → =normalizeLines(params.content)=
  - =params.patches= → map each patch's =find= and =replace= through =normalizeLines=
  - =params.edits= → map each edit's =content= through =normalizeLines=, and each edit's =patches= through the same normalization

** Normalization function:

#+begin_src typescript
function normalizeLines(value: string | string[] | undefined): string | undefined {
    if (value === undefined) return undefined;
    if (typeof value === "string") return value;
    return value.join("
");
}

function normalizePatches(patches: Array<{ find: string | string[]; replace: string | string[] }> | undefined): Patch[] | undefined {
    if (!patches) return undefined;
    return patches.map(p => ({
        find: normalizeLines(p.find) ?? "",
        replace: normalizeLines(p.replace) ?? "",
    }));
}
#+end_src
