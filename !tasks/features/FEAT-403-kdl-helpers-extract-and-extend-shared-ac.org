* Context
The KDL migration (=specs/kdl-config-migration.md=) requires shared accessor/mutator helpers for KDL nodes. Currently, =task-policies-kdl.ts= exports =getStringArgument=, =getBooleanArgument=, =getStringProperty= — but the expanded spell.kdl needs number accessors, boolean property accessors, child node navigation, and node creation helpers for the writer.

This item extracts existing helpers into a shared module and adds the missing ones.

* Design Decisions
- New file: =packages/coding-agent/src/config/kdl-helpers.ts=
- Move =getStringArgument=, =getBooleanArgument=, =getStringProperty= from =task-policies-kdl.ts= to =kdl-helpers.ts=
- Update =task-policies-kdl.ts= and =spell-kdl.ts= to import from =kdl-helpers.ts= instead
- Add new helpers: =getNumberArgument=, =getNumberProperty=, =getBooleanProperty=, =getStringArguments=, =getChildNode=, =getChildNodes=, =getDocumentNode=, =createStringNode=, =createBooleanNode=, =createNumberNode=, =createPropertyNode=
- All helpers use =@bgotink/kdl= 0.4.0 API: =Node.getArgument()=, =Node.getProperty()=, =Node.getName()=, =node.children?.nodes=, =Node.create()=, =Entry.createArgument()=, =Entry.createProperty()=
- Type imports: =import type { Node, Document } from "@bgotink/kdl"=, =import { Node, Entry, Document } from "@bgotink/kdl"= for runtime

** Step 3: Implement helpers
Implement all functions. Pattern for accessors:
#+begin_src typescript
export function getNumberArgument(node: Node, index = 0): number | undefined {
  const value = node.getArgument(index);
  return typeof value === "number" ? value : undefined;
}
#+end_src

Pattern for node creation:
#+begin_src typescript
export function createStringNode(name: string, value: string): Node {
  const node = NodeClass.create(name);
  node.addArgument(value);
  return node;
}
#+end_src

* Edge Cases
- =Node.getArgument(index)= returns =undefined= for out-of-bounds index — our wrappers already handle this
- =node.children= can be =null= (no children block) — =getChildNode/getChildNodes= must check for null
- =Node.create()= returns a node with empty entries — must call =addArgument()= or =addProperty()= after
- KDL values can be =null= (the KDL null literal) — number/string/boolean accessors should return =undefined= for null values
