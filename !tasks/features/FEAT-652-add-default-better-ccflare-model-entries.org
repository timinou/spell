* Intention &amp; Purpose

Add a ~"better-ccflare"~ key to ~packages/ai/src/models.json~ with essential Claude models so users can reference them as ~better-ccflare/claude-sonnet-4-20250514~ in their config.

* Context &amp; Narrative

The model system resolves models from the static ~models.json~ registry (~packages/ai/src/models.ts:14-21~). Provider keys in this file must exist for ~parseModelString("better-ccflare/claude-opus-4-7")~ to find a model. Without entries, the user would get a "model not found" error even if the provider plumbing is correct.

Models are identical to their ~"anthropic"~ counterparts except:
- ~provider: "better-ccflare"~
- ~baseUrl: "http://localhost:8080"~ (better-ccflare default)
- Same costs, context window, max tokens, input types, reasoning flags
