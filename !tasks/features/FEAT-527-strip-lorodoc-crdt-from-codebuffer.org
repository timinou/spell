* Goal

Remove the dead-weight LoroDoc CRDT from =CodeBuffer= in =pi-code-engine=.
The CRDT is initialized with a single peer (=PeerID(1)=), never merges, mirrors every
rope operation byte-by-byte, and adds failure modes with zero benefit. If CRDT ops
fail after rope/tree are mutated, buffer state is corrupted with no rollback.

Undo/redo already works independently via the =History= struct — it does NOT
depend on LoroDoc.

* Files to modify

- =crates/pi-code-engine/Cargo.toml= — remove =loro = "0.16"= dependency
- =crates/pi-code-engine/src/buffer.rs= — remove =crdt: LoroDoc= field, =use loro::*= imports, all CRDT operations in =from_str_with_path()= and =apply_text_mutation()=
