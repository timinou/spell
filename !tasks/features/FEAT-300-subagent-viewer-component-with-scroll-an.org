* Initial Message

is there a way for me to see what agents are doing beyond the one-line sumary in the task box in the TUI?

* Scope
The main viewer component: a modal that shows live, high-fidelity rendering of a running subagent's activity. Subscribes to EventBus, renders via ~SubagentViewerEventHandler~, provides scrolling and agent switching.

* Design

** Layout

│                                                                                    │

│  [tool execution component - grep]                                                 │
│  [tool execution component - read]                                                 │

** Core architecture
- Extends ~Container~, implements ~Component.handleInput~
- Header: border + agent selector (current agent label, navigation hint)
- Body: scrollable viewport over a ~Container~ that holds the rendered chat
- Footer: border + stats (tools, tokens, duration)

** Agent selection
- Track all active agents from ~TASK_SUBAGENT_PROGRESS_CHANNEL~ progress events
- Left/Right arrows or Tab cycle through agents
- When switching: unsubscribe from current event channel, clear body container, subscribe to new agent's events
- If only one agent, show it directly; if zero agents running, show "No active agents" placeholder

** Scrolling
Follow the ~DebugLogViewerComponent~ pattern from ~packages/coding-agent/src/debug/log-viewer.ts~:
- Track ~#scrollOffset~ integer (line-based)
- ~render(width)~ renders all children to lines, then slices ~[scrollOffset, scrollOffset + bodyHeight]~
- Up/Down/PageUp/PageDown adjust scroll offset
- Auto-follow mode: when scrolled to bottom, new content auto-scrolls. When user scrolls up, auto-follow pauses. Pressing End or G resumes auto-follow.

** EventBus subscription
- Subscribe to ~TASK_SUBAGENT_EVENT_CHANNEL~ in constructor
- Filter events by ~event.index~ matching the selected agent's index
- Forward matching ~event.event~ (the raw ~AgentEvent~) to ~SubagentViewerEventHandler.handleEvent()~
- Subscribe to ~TASK_SUBAGENT_PROGRESS_CHANNEL~ for agent list updates and stats (tokens, tools, duration)
- Unsubscribe both on close/dispose

** Keyboard handling
| Key | Action |
|-----+--------|
| Esc | Close viewer |
| Tab / Ctrl+Tab | Next agent |
| Shift+Tab | Previous agent |
| Up / k | Scroll up |
| Down / j | Scroll down |
| PageUp | Scroll up by page |
| PageDown | Scroll down by page |
| Home / g | Scroll to top |
| End / G | Scroll to bottom + resume auto-follow |
| Ctrl+O | Toggle expanded tool output |

** Lifecycle
1. Constructor receives ~EventBus~, ~TUI~, ~cwd~, ~terminalRows~
2. Static ~create(eventBus, ui, cwd)~ factory
3. Subscribe to progress channel immediately to discover agents
4. Auto-select first running agent
5. On close: unsubscribe all, call ~onClose~ callback
