New helper:
#+begin_src typescript
function isUnderAllowedFolder(
  resolvedTarget: string,
  allowedFolders: Record<string, string>,
  cwd: string,
): boolean {
  for (const folder of Object.keys(allowedFolders)) {
    const resolved = path.resolve(cwd, expandTilde(folder));
    const prefix = resolved.endsWith(path.sep) ? resolved : resolved + path.sep;
    if (resolvedTarget.startsWith(prefix) || resolvedTarget === resolved) {
      return true;
    }
  }
  return false;
}
#+end_src

#+begin_src markdown
##### Writable folders in plan mode

By default, plan mode is read-only. To allow writing to specific directories during planning, add `planMode.allowedFolders` to your config (`~/.spell/agent/config.yml` or project `.spell/config.yml`):

```yaml
planMode:
  allowedFolders:
    ./docs/plans: "Architecture notes and plan artifacts"
    ./scratch: "Temporary exploration files"
```

Keys are folder paths (relative to project root, absolute, or `~`-prefixed). Values are short descriptions — they appear in the agent's system prompt so it knows what each folder is for.

Deletes and moves are still blocked even in allowed folders.
```

* Edge Cases
- Folder paths may be relative (resolve against cwd) or absolute
- Tilde expansion (=~/docs=) must be handled
- Trailing slash in config should not matter
- Empty record = current behavior (no extra writable folders)
- Path traversal: =../../../etc= resolves fine through =path.resolve= — it's the user's config, they own it
- Prefix boundary: =/tmp/foo= must not match =/tmp/foobar= (separator check)
