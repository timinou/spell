* Context
The graph builder in =crates/pi-code-graph/src/indexer.rs= maintains a =symbol_nodes: BTreeMap<(PathBuf, String), NodeIndex>= lookup map. For every extracted symbol, it inserts TWO entries:
#+begin_src rust
symbol_nodes.insert((relative_path.clone(), symbol.name.clone()), symbol_index);       // bare name
symbol_nodes.insert((relative_path.clone(), symbol.qualified_name.clone()), symbol_index); // qualified name
#+end_src

The bare-name key collides when multiple symbols in the same file share a name. Example:
#+begin_src typescript
class Reader { parse() { ... } }
class Writer { parse() { ... } }
#+end_src
Both insert =("file.ts", "parse")=. The second silently overwrites the first. When =Reader.transform()= calls =this.parse()=, the reference resolves to =Writer.parse= — the wrong class.

The qualified-name key (=("file.ts", "file.ts::Reader.parse")=) is unique and correct. The collision is only on the bare-name shortcut.

* Design Decisions
1. *Drop bare-name keys entirely.* Only insert the qualified-name key into =symbol_nodes=.
2. For unqualified reference resolution (a call to =parse()= in =Reader.transform=), add a fallback scan: iterate symbols in the same file whose =.name= field matches the target name. If exactly one match, resolve; if zero or multiple, don't resolve (ambiguous).
3. The import-binding resolution path (=import_bindings= map) is unaffected — it maps =local_name -> (target_file, imported_name)=, which is already unique per file.

* Dependency
This item depends on [[id:FEAT-421-distinguish-type-only-imports-with-edgek]] because both modify the import-processing loop in =indexer.rs=. Sequential execution avoids merge conflicts in the same function body.

* Files to Modify
- =crates/pi-code-graph/src/indexer.rs=:
  - Symbol population loop: remove bare-name insertion
  - =resolve_reference_target()=: change primary lookup to qualified-name, add bare-name scan fallback
  - Import-binding symbol resolution: change from bare-name lookup to qualified-name lookup (the =imported_name= in bindings is already the exported symbol name — match against qualified names in the target file)

** Implementation
1. *indexer.rs* — In the symbol population loop, remove the bare-name insertion:
   #+begin_src rust
   // BEFORE (two inserts):
   symbol_nodes.insert((relative_path.clone(), symbol.name.clone()), symbol_index);
   symbol_nodes.insert((relative_path.clone(), symbol.qualified_name.clone()), symbol_index);

   // AFTER (qualified name only):
   symbol_nodes.insert((relative_path.clone(), symbol.qualified_name.clone()), symbol_index);
   #+end_src

2. *indexer.rs* — Rewrite =resolve_reference_target()=:
   #+begin_src rust
   fn resolve_reference_target(
       graph: &StableGraph<GraphNode, EdgeKind>,
       symbol_nodes: &BTreeMap<(PathBuf, String), NodeIndex>,
       import_bindings: &ImportBindingMap,
       from_file: &Path,
       target_name: &str,
   ) -> Option<NodeIndex> {
       // 1. Exact qualified-name match in the same file
       if let Some(&idx) = symbol_nodes.get(&(from_file.to_path_buf(), target_name.to_string())) {
           return Some(idx);
       }

       // 2. Bare-name scan: find symbols in same file whose name field matches
       let mut bare_matches: Vec<NodeIndex> = symbol_nodes
           .range((from_file.to_path_buf(), String::new())..)
           .take_while(|((path, _), _)| path == from_file)
           .filter_map(|((_, _), &idx)| {
               match graph.node_weight(idx) {
                   Some(GraphNode::Symbol(sym)) if sym.name == target_name => Some(idx),
                   _ => None,
               }
           })
           .collect();
       if bare_matches.len() == 1 {
           return Some(bare_matches[0]);
       }

       // 3. Dotted name resolution via import bindings (e.g., "Helper.work")
       if let Some((namespace, member)) = target_name.split_once('.') {
           if let Some((target_file, _)) = import_bindings
               .get(from_file)
               .and_then(|bindings| bindings.get(namespace))
           {
               // Try qualified name in target file
               let candidates: Vec<NodeIndex> = symbol_nodes
                   .range((target_file.clone(), String::new())..)
                   .take_while(|((path, _), _)| path == target_file)
                   .filter_map(|((_, _), &idx)| {
                       match graph.node_weight(idx) {
                           Some(GraphNode::Symbol(sym)) if sym.name == member => Some(idx),
                           _ => None,
                       }
                   })
                   .collect();
               if candidates.len() == 1 {
                   return Some(candidates[0]);
               }
           }
       }

       // 4. Simple import binding (non-dotted): local_name -> (target_file, imported_name)
       if let Some((target_file, imported_name)) = import_bindings
           .get(from_file)
           .and_then(|bindings| bindings.get(target_name))
       {
           // Scan target file for the imported name
           let candidates: Vec<NodeIndex> = symbol_nodes
               .range((target_file.clone(), String::new())..)
               .take_while(|((path, _), _)| path == target_file)
               .filter_map(|((_, _), &idx)| {
                   match graph.node_weight(idx) {
                       Some(GraphNode::Symbol(sym)) if sym.name == imported_name => Some(idx),
                       _ => None,
                   }
               })
               .collect();
           if candidates.len() == 1 {
               return Some(candidates[0]);
           }
       }

       None
   }
   #+end_src
   Note: This function now takes =&StableGraph= as an additional parameter to inspect node weights during bare-name scan. Update the call site in =build()= to pass =&graph=.

3. *indexer.rs* — The import-binding symbol resolution in the import loop also uses =symbol_nodes.get(&(target, imported_name))=. After removing bare-name keys, this lookup will fail for bare names. Change it to use the same scan pattern:
   #+begin_src rust
   // Find the symbol node in target file by name
   let symbol_match = symbol_nodes
       .range((target.clone(), String::new())..)
       .take_while(|((path, _), _)| path == &target)
       .find_map(|((_, _), &idx)| {
           match graph.node_weight(idx) {
               Some(GraphNode::Symbol(sym)) if sym.name == imported_name => Some(idx),
               _ => None,
           }
       });
   if let Some(symbol_index) = symbol_match {
       graph.add_edge(from_index, symbol_index, symbol_edge);
   }
   #+end_src

* Edge Cases
- Symbols with identical qualified names: This shouldn't happen (qualified name includes file + class + method), but if it does, =BTreeMap::insert= still overwrites. This is acceptable — qualified names are structurally unique.
- Performance: The bare-name scan iterates symbols in the same file. For files with ~100 symbols this is negligible. For pathological files with 1000+ symbols, the BTreeMap range scan is O(n) per reference, but n is bounded by symbols-per-file which is small.
- Existing tests: The fake extractor in existing tests uses unique names ("caller", "callee"), so the qualified-name-only keying won't break them. The qualified name format is "path::name", which the existing lookups should still find.
