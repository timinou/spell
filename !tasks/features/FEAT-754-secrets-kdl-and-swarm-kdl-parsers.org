* Goal

Eliminate magic-name Spell-owned config files. =spell.kdl= is the *single* entry point. All Spell-owned configuration that today lives in a separate file becomes an inline KDL block inside =spell.kdl=.

* Magic files absorbed

| current | replaces with |
|---------+---------------|
| =~/.spell/agent/secrets.yml= | =secrets { ... }= block in user =spell.kdl= |
| =<cwd>/.spell/secrets.yml= | =secrets { ... }= block in project =spell.kdl= |
| =~/.spell/agent/mcp.json= | =mcp { ... }= block in user =spell.kdl= |
| =<cwd>/.spell/mcp.json= | =mcp { ... }= block in project =spell.kdl= |
| =~/.spell/agent/ssh.json= | =ssh { ... }= block in user =spell.kdl= |
| =<cwd>/.spell/ssh.json=, =<cwd>/ssh.json= | =ssh { ... }= block in project =spell.kdl= |
| =<cwd>/.spell/domain.json= | =domain { ... }= block in project =spell.kdl= |

* Out of scope

- =.mcp.json= / foreign =settings.json= (Claude/Cursor/Gemini etc) — these are *foreign* conventions discovered by =settingsCapability=. They stay native.
- =AGENTS.md= — markdown documentation, not config.
- =swarm.yml= — user-authored ad-hoc workflow file passed by *path* to the swarm extension. Not a global magic name; format change is a separate, narrow concern under the swarm-extension package.
- Container directories (=memory/=, =plugins/=, =modes/=, =extensions/=, =skills/=) — legitimately scoped, one file per item with meaningful names.

* Schema

#+begin_src kdl
secrets {
  secret type=plain content="sk-proj-abc123def456"
  secret type=plain content="hunter2" mode=replace replacement="********"
  secret type=regex content="AKIA[0-9A-Z]{16}"
  secret type=regex content="postgres://[^\\s]+" mode=replace replacement="postgres://***" flags="i"
}

mcp {
  server "memory" command="mcp-memory" args="--db ./memory.db"
  server "github" {
    command "mcp-github"
    env GITHUB_TOKEN="$GITHUB_TOKEN"
  }
}

ssh {
  target "prod" host="prod.example.com" user="deploy" identity-file="~/.ssh/prod"
  target "staging" host="staging.example.com" user="deploy"
}

domain {
  override pattern="**/*.rs" language="rust"
  override pattern="src/legacy/**" project="legacy"
}
#+end_src

* Inline vs import

Inline preferred for single-user codebase. =./.local/spell.kdl= (gitignored, 4-tier model) absorbs machine-private secrets without exposure in committed =./spell.kdl=.

If file-scope isolation later becomes desirable (e.g., chmod 600 on secrets), add =load "./path"= directive — but not now. Don't reintroduce magic names.

* Migration

All seven legacy files routed through the one-shot migrator [[id:FEAT-753-one-shot-self-contained-yaml-json-kdl-mi]]. Translation is mechanical per-file → block-shaped fragment merged into the appropriate-tier =spell.kdl=.
