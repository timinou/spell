* Edge Cases
- CDN unreachable: page shows an explicit error message and the server still serves HTML successfully.
- No goals configured: dashboard shows =No goals configured= instead of an empty table.
- Very long run history: limit to last 50 runs or paginate; do not render unbounded history.
- Goal with no runs yet: render =Never run= in dashboard and detail views.
- Trigger button for non-webhook goals: hidden unless manual trigger semantics are intentionally exposed by the API.
