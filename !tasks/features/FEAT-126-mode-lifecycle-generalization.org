* Edge Cases
- *Backward compat*: Any code that directly accesses ~planModeState.enabled~ must work after refactor. Type guards ensure this.
- *exit_mode with no mode active*: Return error, don't crash. Same as current exit_plan_mode behavior.
- *Rename import paths*: All imports of ~plan-mode-guard~ must update to ~mode-guard~. Use LSP references to find all.
- *Tool name change*: ~exit_plan_mode~ -> ~exit_mode~ affects prompt templates, tool registry, and agent session tool decision enforcement. All must update atomically.
- *Subagent tool filtering*: ~packages/coding-agent/src/task/executor.ts~ filters tools for subagents. Must respect new mode-generic tool restrictions.
- *Concurrent session resume + mode discovery*: Discovery is async. Session resume must await mode config loading before reconstructing user mode state.
- *User mode extending plan exit*: When a user mode extends plan/ultraplan, exit_mode must walk the extends chain to determine base type and dispatch to plan-type exit including extractPlanWaves. Failure to do so loses wave data (GAP-02).
