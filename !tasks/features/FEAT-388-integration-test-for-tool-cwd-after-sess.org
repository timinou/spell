* Problem

The existing test suite (~packages/coding-agent/test/tools/org-cwd-change.test.ts~) proves tools react to a changing ~session.cwd~ getter, but it does so by directly mutating a ~cwdState~ object. It does not exercise the real ~SessionManager.moveTo()~ integration path that wires the dynamic getter in production:

#+begin_src typescript

#+end_src

A regression in the ~moveTo()~ wiring, the ~getCwd()~ method, or ~SessionManager~ state management could slip through while the unit tests still pass.
