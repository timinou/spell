* Context
The graph cache fingerprint in =crates/pi-code-graph/src/cache.rs= walks every file under the project root (respecting =.gitignore=). This includes =.spell/graph/= (the cache's own output), documentation, config files, images, etc. Non-source changes invalidate the cache and force unnecessary rebuilds.

The fix: accept a file-matching predicate from the caller (the =CodeGraphBuilder=) so only files that match a registered language extractor are fingerprinted. Also explicitly exclude the =.spell/= directory from the walk.

* Design Decisions

- =fingerprint_root()= gains a =matches_source: &dyn Fn(&Path) -> bool= parameter (trait object, not =impl Fn=, for storage/passing flexibility)
- =CacheStore::status()= also gains the predicate parameter (it calls =fingerprint_root= internally)
- =CodeGraphBuilder= exposes a =cache_status(&self, root: &Path) -> Result<CacheStatus>= method that wraps =self.cache.status(...)= with the registry-based predicate, so callers (NAPI bridge) don't need to construct the predicate themselves
- The =ignore::WalkBuilder= in =fingerprint_root= keeps =hidden(false)= (includes hidden files) and =git_ignore(true)= / =git_exclude(true)=
- Paths starting with =.spell/= are explicitly skipped before the predicate check
- The predicate receives the absolute path (matching extractor =matches_path= behavior which checks extensions)
* Files to Modify
- =crates/pi-code-graph/src/cache.rs=: Change =fingerprint_root()= and =status()= signatures to accept predicate
- =crates/pi-code-graph/src/indexer.rs=: Pass language-match predicate from =CodeGraphBuilder::build()=
- =crates/pi-natives/src/code_graph.rs=: Update =ensure_graph()= and =render_status()= if they call =cache.status()= directly (they do — pass a default predicate or the builder's registry)

** Implementation
1. *cache.rs* — Change =fingerprint_root= signature:
   =pub fn fingerprint_root(&self, root: &Path, matches_source: &dyn Fn(&Path) -> bool) -> Result<GraphFingerprint>=
   Use =&dyn Fn= (trait object) rather than =impl Fn= so callers can store and pass the predicate without monomorphization. Inside the walk loop, after computing =path= (absolute) and before computing =relative=, add:
   #+begin_src rust
   if relative.starts_with(".spell") { continue; }
   if !matches_source(&path) { continue; }
   #+end_src
   Note: filter on =relative= for =.spell/= (path-prefix check) and on =absolute path= for =matches_source= (extension check matches what extractors do).

2. *cache.rs* — Change =status= signature:
   =pub fn status(&self, name: &str, root: &Path, matches_source: &dyn Fn(&Path) -> bool) -> Result<CacheStatus>=
   Pass =matches_source= through to =self.fingerprint_root(root, matches_source)=.

3. *indexer.rs* — Add a public method to =CodeGraphBuilder=:
   #+begin_src rust
   pub fn cache_status(&self, root: &Path) -> Result<CacheStatus> {
       let root = std::fs::canonicalize(root)?;
       self.cache.status("workspace", &root, &|path| self.registry.match_path(path).is_some())
   }
   #+end_src
   Also update =build()=: the fingerprint construction inside =build()= already walks only matched files (the extractor loop). Ensure the =GraphFingerprint= saved to cache is built with the same source-only filter. Currently =build()= has its own walk that filters by =self.registry.match_path()=, and the =files= BTreeMap is populated only for those. This is already correct — the saved fingerprint only contains source files. The gap is only in =cache.status()= and =fingerprint_root()= which re-fingerprint everything.

4. *code_graph.rs* (pi-natives bridge) — Change =ensure_graph()= and =render_status()=:
   Currently both call =cache.status(CACHE_NAME, root)= directly. Replace with =builder.cache_status(&root)= (the new method from step 3). This means =render_status= also needs the =builder= parameter. Adjust its signature:
   =fn render_status(root: &Path, builder: &CodeGraphBuilder) -> napi::Result<CodeGraphResult>=
   Inside, call =builder.cache_status(root)= instead of =cache.status(...)=. For the =load()= call, use =builder.cache().load(CACHE_NAME)=.
