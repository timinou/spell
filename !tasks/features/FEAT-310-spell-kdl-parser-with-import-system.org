* Initial Message

I want to set up task policies in kdl with a command when I enter a new repository. like some sort of onboarding thing. what could that look like? finish with your completed summary

Parse =spell.kdl= — the unified project configuration file that replaces =.spell/domain.json= and =.spell/task-policies.yml= with a single KDL source of truth. Includes an import system that resolves dot-namespaced references (=spell.coding.typescript=) to built-in template files.

* spell.kdl Format

#+begin_src kdl
// spell.kdl — project root
domain "coding"
import "spell.coding.typescript"

layer "frontend" description="React components and pages"
layer "api" description="tRPC routers and middleware"

policy "frontend-quality" layer="frontend" {
    gate-commit true
    gate-cmd "bun test test/components/"
    gate-llm "Verify accessibility and responsive design"
    inject "Use design tokens from src/theme/"
}
#+end_src

* Node Types

| Node     | Arguments        | Properties    | Children       |
|----------+------------------+---------------+----------------|
| =domain= | name (string)    | —             | —              |
| =import= | namespace (string) | —           | —              |
| =layer=  | name (string)    | description   | —              |
| =policy= | name (string)    | layer         | gate-*, inject |

Policy children are identical to existing =task-policies-kdl.ts= format: =gate-commit=, =gate-cmd=, =gate-artifact=, =gate-llm=, =verify-cmd=, =inject=, =description=.

* Import Resolution

1. Parse =spell.kdl= top-level nodes
2. Collect =import= nodes, extract namespace strings
3. For each namespace, call =resolveTemplate(namespace)= from templates index
4. Parse each template with =parseTaskPoliciesKdl= (reuse existing parser)
5. Merge: template layers/policies form the base; local declarations override by name
   - Same merge semantics as existing =mergePolicies=: local overrides template by policy name
   - Layers: local wins on key conflict
   - Multiple imports: applied in order, each extends the accumulated base
6. Unknown import namespace → log warning, skip (not fatal)
