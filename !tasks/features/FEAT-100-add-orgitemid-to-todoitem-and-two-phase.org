* Initial Message

when a subtask is associated to a todo (especially relelvant during plan/ultraplan/loop implementations), can you have a soft reminder when the task gets done to make sure to check its validation criteria, tests, artifacts (if any) and to commit ahead of marking the task as done?

* Summary
Add =orgItemId= optional field to =TodoItem= so tasks know which org item they belong to. Implement two-phase gated completion: when a gated task is marked =completed= without =verified: true=, the status change is rejected and a verification checklist is returned instead.

* Files
- =packages/coding-agent/src/tools/todo-write.ts= — TodoItem interface, InputTask schema, update op schema, applyOps, formatSummary, gateDirectivesForTask, hasGate, TUI badge rendering
- =packages/coding-agent/src/modes/components/todo-reminder.ts= — add org badge
- =packages/coding-agent/test/tools/todo-write-gates.test.ts= — test field survival, two-phase flow, directive content

* Implementation
** Add orgItemId field
- Add =orgItemId?: string= to =TodoItem= interface
- Add =Type.Optional(Type.String({ description: "Org item ID this task is linked to" }))= to =InputTask= schema
- Preserve through all data paths: replace, add_phase, add_task, update ops
- Add to =hasGate()= — no. =orgItemId= should NOT be in =hasGate=; create a =hasRequiredGate(task)= function that returns true for gateCommit/gateArtifact/gateCmd/gateLlm/orgItemId. Use this for two-phase triggering. Keep =hasGate= unchanged (it already includes verifyCmd).

** Add verified flag to update op
- Add =verified?: boolean= to the update op in =todoWriteSchema=
- Description: "Set true after verifying all gate requirements. Required to complete a gated task."

** Two-phase applyOps logic
In the =update= case of =applyOps=, after finding the task:
#+begin_src typescript
// Two-phase gated completion
if (op.status === "completed" && hasRequiredGate(task) && !op.verified) {
    // Don't apply status change — add to pending verification list
    pendingVerificationTasks.push(task);
    break;
}
#+end_src

Add =pendingVerificationTasks: TodoItem[]= to =ApplyOpsResult=.

** Enhanced formatSummary
When =pendingVerificationTasks= is non-empty, render a "Verification Required" section:
#+begin_example
--- Verification Required ---
task-1 "Build feature" requires verification before completion:
  [ ] Run `bun test` (gateCmd)
  [ ] Verify artifact at dist/out.json (gateArtifact)
  [ ] Commit changes (gateCommit)
  [ ] Update org item FEAT-001-add-auth (orgItemId)

Complete these steps, then call todo_write with {op: "update", id: "task-1", status: "completed", verified: true}.
#+end_example

Keep existing gate directives for =completedGatedTasks= (fires when =verified: true= is used).

** TUI changes
- Add =[org: FEAT-001]= badge in =renderGateBadges= when =orgItemId= is set
- Add =[org]= badge in =TodoReminderComponent#gateBadges=
