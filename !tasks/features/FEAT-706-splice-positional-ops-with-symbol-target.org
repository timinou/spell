* Intention & Purpose
When `splice` (or any positional op) gets `line:N` outside a symbol target's declaration span, the current error is "line N is outside the target declaration span" with no context on what the span is or how to proceed. Settle the semantic: line numbers are ABSOLUTE; symbol target = scope check (line MUST fall within span). Improve the diagnostic so the agent can self-correct.

* Context & Narrative
`crates/pi-code-engine/src/line_target.rs:51-64 ensure_within_target_scope` produces `CodeEngineError::LineOutOfTargetScope { line, target_start, target_end }` but the message displayed at the tool layer drops the start/end. We considered relative-line semantics and rejected because (a) absolute composes with `pos`/`end` LINE#ID anchors uniformly, (b) get output prints absolute line numbers, (c) hybrid semantics are surprising.
