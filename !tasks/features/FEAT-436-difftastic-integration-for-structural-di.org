* Context

CodeBuffer needs a diff mechanism for two use cases: (1) =diff_from(snapshot)= comparing current buffer state against a previous snapshot, (2) =diff_from_disk()= comparing buffer against the file on disk. The initial CodeBuffer item (FEAT-431) implements these with basic line-based diff. This item upgrades to structural diff using difftastic.

Difftastic (=difftastic= crate on crates.io) provides tree-sitter-aware diffing: it parses both versions into syntax trees, then uses a Dijkstra-based algorithm to find the minimum-cost alignment between the two trees. The result is a structural diff that understands syntax — it won't show formatting-only changes as modifications, and it groups changes by syntactic units rather than lines.

* Goal

Integrate difftastic into pi-code-engine's =diff.rs= module. Provide a =structural_diff()= function that CodeBuffer's =diff_from= and =diff_from_disk= can delegate to. Also expose it as a standalone function for diff-aware graph queries.

pub struct DiffHunk {
    pub old_start_line: u32,
    pub old_end_line: u32,
    pub new_start_line: u32,
    pub new_end_line: u32,

pub enum DiffKind {
    Added,
    Removed,
    Changed,

pub fn structural_diff(
    old_source: &str,
    new_source: &str,
    language: Option<&tree_sitter::Language>,

If difftastic's Rust API is too tightly coupled to its CLI (check by reading its crate docs), fall back to using =imara-diff= (a pure-Rust Myers diff implementation) with tree-sitter node boundary annotations. The key requirement is that diff hunks align with syntactic boundaries, not arbitrary line cuts.

Research the difftastic crate API before implementing. If it doesn't expose a clean library API, use =imara-diff= with manual tree-sitter boundary snapping.

* Testing

** =test_structural_diff_detects_added_function=
Old: file without function. New: file with function added.
Assert exactly 1 hunk of kind Added covering the function's lines.

** =test_structural_diff_detects_removed_function=
Reverse of above. Assert 1 hunk of kind Removed.

** =test_structural_diff_ignores_whitespace_only=
Old and new differ only in trailing whitespace. Assert 0 hunks (or hunks marked as formatting-only).

** =test_structural_diff_groups_by_syntax=
Old: =function foo() { return 1; }=. New: =function foo() { return 2; }=.
Assert 1 hunk covering the changed expression, not 1 hunk per character.
