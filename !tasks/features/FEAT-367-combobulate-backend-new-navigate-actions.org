* Navigate actions to add

** =node-at= — Inspect target node before editing
Return the node at a given position with enough context to verify targeting.

Input: =file=, =line=, optional =column=
Output alist:
#+begin_src elisp
'((type . "function_declaration")
  (text . "function foo(a: string, b: number) {")  ;; first line only, truncated at 80 chars
  (line . 42)
  (end_line . 65)
  (parent . ((type . "export_statement") (line . 42))))
#+end_src

Implementation in =pi-navigate-execute=:
#+begin_src elisp
("node-at"
 (let* ((pos (point))
        (node (treesit-node-at pos))
        (parent (when node (treesit-node-parent node)))
        (text (when node
                (let ((full (treesit-node-text node t)))
                  (car (split-string full "
"))))))
   (if node
       `((type . ,(treesit-node-type node))
         (text . ,(if (> (length text) 80) (substring text 0 80) text))
         (line . ,(line-number-at-pos (treesit-node-start node)))
         (end_line . ,(line-number-at-pos (treesit-node-end node)))
         ,@(when parent
             `((parent . ((type . ,(treesit-node-type parent))
                          (line . ,(line-number-at-pos (treesit-node-start parent))))))))
     `((error . t) (message . "No node at position")))))
#+end_src

** =siblings= — List siblings for drag/reorder context
Find the node at position, get its parent, list all the parent's named children.

Input: =file=, =line=
Output:
#+begin_src json
{
  "current_index": 1,
  "siblings": [
    { "type": "function_declaration", "name": "foo", "line": 3, "end_line": 20 },
    { "type": "function_declaration", "name": "bar", "line": 22, "end_line": 40, "current": true },
    { "type": "class_declaration", "name": "Baz", "line": 42, "end_line": 80 }
  ]
}
#+end_src

Implementation notes:
- Find node at line via =treesit-node-at=
- Walk up to nearest "navigable" parent (skip punctuation nodes like ={ } , ;=)
- List parent's named children, marking which one contains the cursor position
- Use =pi-treesit-declaration-name= to get names where possible
- Filter out pure-punctuation children (type is single char or in a skip-list)

- Use =pi-treesit-declaration-name= and =pi-treesit-declaration-kind= for child metadata

* Edit operations to add

All three go in the =pi-edit--combobulate-op= function (the =(pcase operation ...)= dispatch).

** =splice-self= — Unwrap, keep only self
Calls =combobulate-splice-self=. Removes wrapper + siblings, keeps only the targeted node's content.

Use case: "Keep only the if-body, remove the if-wrapper and else-branch."

** =splice-down= — Unwrap, keep self + before
Calls =combobulate-splice-down=. Removes wrapper + siblings after, keeps self + siblings before.

Use case: "Remove the else branch and unwrap the if."

** =transpose= — Swap with next sibling
Calls =combobulate-transpose-sexps=. Swaps the node at point with its next sibling.

Use case: "Swap these two function arguments" or "swap these two class methods."

Implementation for all three — add to the =pcase= in =pi-edit--combobulate-op=:
#+begin_src elisp
("splice-self" (combobulate-splice-self))
("splice-down" (combobulate-splice-down))
("transpose" (combobulate-transpose-sexps))
#+end_src
