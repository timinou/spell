#+begin_src markdown
### `telegram` node

Properties and children:

- child `bot-token "<string>"`: Telegram bot token (inline).
- child `bot-token-file "<path>"`: Read bot token from file. Mutually exclusive with `bot-token`.
- child `owners <id> ...`: Numeric Telegram user IDs. Owners receive notifications and can use `/unlock`.
- child `upload-dir "<path>"`: Directory for file uploads. Default: `/tmp/spell-telegram-uploads`.
- child `idle-timeout <seconds>`: Default session idle timeout. Default: `300`.
- child `max-sessions <count>`: Maximum concurrent sessions. Default: `10`.
- child `log-viewer-port <port>`: Optional HTTP port for session log viewer.
- child `default-project "<name>"`: Default project for new sessions.
- child `project "<name>" "<path>"`: Named project (repeatable).
- child `user <numeric-id> { ... }`: Authorized user with sub-config:
  - `modes "<mode>" ...`: Allowed tool modes.
  - `default-mode "<mode>"`: Default mode on session start.
  - `idle-timeout <seconds>` or `idle-timeout null`: Per-user idle override.
  - `projects "<name>" ...`: Restrict to named projects.
#+end_src
