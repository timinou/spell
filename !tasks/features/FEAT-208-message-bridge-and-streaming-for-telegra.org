* Edge Cases
- sendMessageDraft not supported by grammy yet: use =ctx.api.raw.sendMessageDraft= or direct fetch to Bot API
- Draft text is plain text (not HTML): stream plain text in draft, convert to HTML only for final sendMessage
- Image download fails (Telegram CDN timeout): send error message, skip image
- File too large for upload dir: reject with size limit error (configurable, default 10MB)
- Agent produces empty response (only tool calls, no text): send summary of what tools did
- Rate limiting from Telegram (429 error): grammy auto-retries, but throttle draft updates proactively
- Multiple turn_end events in one agent_end (multi-turn tool loops): accumulate all text, send once at agent_end
- Unicode/emoji in responses: HTML mode handles these correctly
