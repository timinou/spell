* Scope

Server side: make a web =prompt= (and =abort=) to an *external* session reach its TUI over the
socket, instead of =WebSessionHub.send()= throwing "not steerable".

** SocketSessionRegistry (=packages/spell-server/src/socket/session-registry.ts=)
- Add =injectMessage(sessionId, {text, deliverAs}): {injectId} | null= — generates injectId,
  writes an =inject_input= frame to =entry.connection= (external only). Returns null if no
  live connection.
- Track pending injects (Map injectId→resolver) and =resolveInject(injectId, accepted, reason)=
  called when an =inject_ack= arrives. Optional: timeout → resolve accepted:false.
- =abort= for external: add =sendAbort(sessionId)= writing an =inject_input= with a sentinel? NO —
  prefer a distinct frame. SIMPLEST: reuse existing socket; add small =control= frame OR map
  web =abort= to a dedicated =inject_input deliverAs:"abort"=? Decide: add =deliverAs= value is
  wrong for abort. Instead add a separate optional =AbortSocketServerMessage= (type:"abort") in
  FEAT-792 scope IF needed; for W1 MVP, support =prompt= injection only and leave abort of
  external sessions as a documented follow-up (file BUG/FUP if it matters).

** Socket server (=packages/spell-server/src/socket/server.ts=)
- Handle inbound =inject_ack= in =#handleLine= → =registry.resolveInject(...)=.

** WebSubsystem dispatch (=packages/spell-server/src/web/ws/server.ts=)
- In =case "rpc"=: if target session kind === "external" and =command.type === "prompt"=,
  route to =registry.injectMessage()= and reply with =rpc_response= (success=accepted).
  Map =command.streamingBehavior=/explicit field → deliverAs (default "auto").
- Keep spawned-session path (=hub.send=) unchanged.
- For unsupported external commands, reply =rpc_response success:false error:"unsupported_for_external"=.

* Existing patterns

- =resolveEvent= / =cancelEvent= in the registry are the template for writing a frame to
  =entry.connection= and tracking state.
- =ws/server.ts #dispatch case "rpc"= and =case "answer_blocking_event"= show kind-based routing.

* Edge cases

- External session with dead/destroyed connection → rpc_response success:false.
- Ack never arrives → timeout (e.g. 10s) resolves accepted:false; do not leak the pending map.
- Spawned session unaffected.
