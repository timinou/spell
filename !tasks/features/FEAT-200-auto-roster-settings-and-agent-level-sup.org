* Edge Cases
- Setting changed mid-session via ~/config~: auto-roster behavior reflects current value on next dispatch.
- ~async.enabled=false~ + ~task.autoRoster=true~: sync dispatch still creates roster entries.
- ~task.autoRoster=true~ + agent ~roster: false~: suppressed (agent-level overrides global).
- ~task.autoRoster=false~ + agent ~roster: true~: suppressed (global overrides agent; global is the kill switch).
