** Define =planWavesToTodoPhases=
:PROPERTIES:
:CUSTOM_ID: FEAT-179-wave-based-auto-init-for-plan-execution::wave-converter
:END:
- File: =packages/coding-agent/src/orchestrators/fluid/plan-to-todos.ts= (or new file =packages/coding-agent/src/tools/wave-to-todos.ts=)
- PlanWave is defined in =exit-plan-mode.ts= — may need to move to a shared types location
- Logic:
  1. For each wave -> create a TodoPhase with name from wave.name
  2. For each entry -> create a TodoItem with content=entry.step, orgItemId=entry.orgItemId
  3. Tasks in wave N get blockers referencing all task IDs from wave N-1
  4. Last occurrence of each orgItemId gets orgItemClosingId
  5. Promote first unblocked task to =in_progress=
