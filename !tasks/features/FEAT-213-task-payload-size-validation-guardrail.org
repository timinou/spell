** FEAT-213::payload-size-check
In ~index.ts~, add a size check in the ~execute~ method after ~#validateTaskBatch~ (around line 486):
#+begin_src typescript
const payloadSize = (params.context?.length ?? 0) + rawTasks.reduce((sum, t) => sum + (t.assignment?.length ?? 0), 0);
if (payloadSize > MAX_PAYLOAD_BYTES) {
  const sizeKb = (payloadSize / 1_000).toFixed(0);
  const limitKb = (MAX_PAYLOAD_BYTES / 1_000).toFixed(0);
  return {
    content: [{
      type: \"text\",
      text: `Task payload too large (${sizeKb}KB, limit ${limitKb}KB). ` +
            `Write large content to local://<path> files and pass paths in context instead of embedding content in assignments.`,
    }],
    details: { projectAgentsDir: null, results: [], totalDurationMs: 0 },
  };
}
#+end_src

The error message tells the model exactly how to fix it (use local:// paths).
