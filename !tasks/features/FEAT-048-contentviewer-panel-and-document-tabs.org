* Scope
In-scope:
- New panel: ~packages/coding-agent/src/modes/qml/panels/ContentViewerPanel.qml~
  - Wraps MarkdownContent (~panels/markdown/MarkdownContent.qml~) in Flickable for scroll
  - Top bar: URL display (elided), search bar (TextInput for text search), copy-all button, 'Open in browser' button
  - Search: JavaScript iteration over visible Text elements to find matches, scroll-to-match on enter
  - Copy: copies raw markdown content to clipboard via clipboard API
  - 'Open in browser': emits ~viewInBrowser(url, title)~ signal
  - Receives content via handleMessage({type:'load_content', content, url, title})
- Content store in BrowseShell.qml: JS object map ~contentStore~ keyed by tabId. LRU eviction at 10 entries. Populated when document tab created from finding with contentBody
- Document tab type: extend ~browserTabsModel~ entries with ~tabType~ field ('browser'|'document'). Existing tabs default to 'browser'
- BrowseShell.qml three-way visibility:
  - chatLoader visible when activeTabId==='chat'
  - browserPanelLoader visible when active tab has tabType==='browser'
  - contentViewerLoader (new Loader) visible when active tab has tabType==='document'
- Tab bar: document tabs show document icon prefix instead of no icon
- Finding card 'View in tab': if finding has contentBody, create document tab and load content. If no contentBody, create browser tab with URL. Updated in BrowseShell.qml handleBridgeMessage for view_in_tab
- browse-mode.ts (~packages/coding-agent/src/modes/browse-mode.ts~): update view_in_tab handler to pass contentBody from finding to shell
- Tab persistence: extend browseSettings.tabsJson format to include tabType field. Content bodies NOT persisted (re-fetched on demand). On restore, document tabs that lost content show 'Content unavailable, open in browser' placeholder

* Edge Cases
- Content body > 50KB: truncate in content store, show 'Content truncated' note
- Empty content body: show placeholder 'No content available' with 'Open in browser' button
- Document tab URL is a PDF or image: show 'Open in browser' only (MarkdownContent cannot render these)
- Content store eviction while tab is active: show placeholder, don't crash
- Tab persistence migration: old sessions without tabType field default to 'browser'
- Three-way visibility: only one Loader visible at any time (chat XOR browser XOR document)
