* Design Decisions
1. Agent prompts have frontmatter (name, description, tools, model, thinking-level, blocking) — frontmatter stays untouched, only body gets compressed.
2. FUP-048 says agent prompts are "already exemplars of the declaration-of-being style" — expect minimal changes.
3. Compaction templates are consumed by summarization LLM calls — they must remain complete instructions.
4. Memory templates define JSON schemas — compress prose framing, keep schema definitions.
5. Subagent system prompts are consumed by subagent sessions — they must remain self-contained instructions.

* Edge Cases
- Agent frontmatter is YAML — parsed separately from body. Do not modify.
- Agent =description= field in frontmatter is used in the parent prompt's agent catalog listing. It must remain a truthful one-line capability statement.
- Compaction templates are consumed by non-main-agent LLM calls (summarization). They cannot assume tool context.
- Some agent prompts contain embedded examples (metis.md, momus.md) — apply non-obvious exemplar test.
