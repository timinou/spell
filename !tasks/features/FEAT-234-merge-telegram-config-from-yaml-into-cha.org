** Parser changes
Update =packages/spell-server/src/config/channels-parser.ts= to parse new KDL nodes:
- =upload-dir= — string argument, default =/tmp/spell-telegram-uploads=
- =idle-timeout= — number argument in seconds, default 300
- =max-sessions= — number argument, default 10
- =log-viewer-port= — optional number argument
- =default-project= — optional string argument
- =project= nodes — name + path arguments (repeatable)
- =user= nodes — numeric ID argument with children: modes, default-mode, idle-timeout, projects
- =bot-token-file= — alternative to inline bot-token; read token from file at load time

** Backwards compatibility
The minimal existing format (just bot-token + owners) MUST still work — all new fields have sensible defaults. When only bot-token and owners are present, the bot starts with defaults (no projects configured → the bot won't be useful for chat sessions, but notification hooks still work).

* Edge cases
- =bot-token= and =bot-token-file= are mutually exclusive — error if both present
- =bot-token-file= path must be absolute or relative to config dir
- =user= IDs are numeric Telegram user IDs but declared as KDL arguments — must parse as integers
- =idle-timeout null= on a user means never timeout — KDL supports null arguments
- =projects= on a user node is optional — empty means all projects allowed
