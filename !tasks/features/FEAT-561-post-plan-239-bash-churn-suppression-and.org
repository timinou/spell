* Edge Cases
- Some commands contain `sleep` as one part of a legitimate composite shell; detection must not blindly break useful scripts.
- Success digests must not mask warnings that materially change the next action.
- Unchanged-status summaries must invalidate when repo state, command args, or working directory changes.
- Transcript-spelunking detection must not suppress legitimate machine-readable data extraction the user explicitly requested.
- Failure paths must remain more informative than success paths, consistent with the post-PLAN-239 design direction.

* Acceptance Criteria
- Pure wait/poll bash commands no longer waste ordinary turns.
- Repeated verification/status loops become digest-first by default after PLAN-239 lands.
- Transcript-spelunking bash is summarized first instead of dumping raw JSONL-derived bodies.
- Auto-escalation to fuller output remains available without user confirmation.
- Focused bash tests cover sleep suppression, verification/status digests, transcript-spelunking handling, and truthful failure behavior.
