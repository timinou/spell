** In-scope
- Four gate executor implementations:

  - LLM-review: spawn subagent with review criteria, parse structured response
  - Artifact: check file existence + optional content validation (regex, JSON schema)
  - Human: present evidence (canvas or CLI), auto-approve timer
- Diff-aware failure dedup: track previous findings per gate, detect repeats

- Auto-approve timers: configurable per gate, server-side (not canvas-dependent)
- Virtual clock interface for testable timers
