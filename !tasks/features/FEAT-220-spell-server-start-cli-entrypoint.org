* Edge Cases
- `.spell/` directory does not exist: exit with `No .spell directory found. Run spell server init or create config manually.`
- Port already in use: exit with `EADDRINUSE` error message
- Invalid Telegram bot token: log error and continue without Telegram; daemon must not crash
- No goals in manifest: start anyway for Telegram-only or hook-only deployments
- Multiple instances on same port: second instance fails fast
- Missing `channels.kdl`: startup still succeeds with degraded notifications
- Shutdown during active goal execution: wait for inflight work until timeout, then kill remaining sessions and surface timeout in logs/postmortem
