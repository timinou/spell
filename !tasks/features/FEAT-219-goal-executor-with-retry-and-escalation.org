* Edge Cases
- Goal triggered while already running :: skip execution and log =goal already active=.
- RPC process exits with code 0 but no completion event :: treat as success.
- RPC process exits with non-zero code :: treat as failure.
- Temp sandbox file cleanup on crash :: use postmortem registration.
- Goal prompt is multi-line :: pass full text to RPC prompt command without normalization loss.
- State DB for goal history :: SQLite at =~/.spell/spell-server/goal-history.db=.
- Failure policy :: retry N times with backoff, then escalate via Telegram-capable hooks, create BUG org item, and pause execution.
