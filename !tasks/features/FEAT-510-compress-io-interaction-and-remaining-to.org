* Design Decisions
1. Apply compression contract from =specs/prompt-surface-compression.md= (FEAT-506)
2. For small files (<100 words): audit only, compress if any prose padding exists
3. For medium files (100-500 words): compress instruction prose, delete redundant examples
4. For canvas.md (~1,108 words): significant compression — action list is schema-implied, keep only non-obvious patterns (observe vs screenshot, QML lifecycle)
5. For browser.md: keep action catalog (useful lookup), compress examples to 2 (observe + click_id pattern)
6. Preserve ALL Handlebars conditionals in every file
