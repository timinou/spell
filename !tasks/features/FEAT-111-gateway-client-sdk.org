** Implementation
1. Implement =packages/gateway/src/client.ts=:
   - GatewayClient class with #socket, #pending (Map<id, resolver>), #connected state
   - =constructor(socketPath?)=: use default socket path if not provided
   - =#connect()=: create net.createConnection to socket, set up NDJSON parser for responses
   - =#ensureDaemon()=: try connect → if fail, spawn daemon binary → retry connect with backoff [100, 200, 400, 500]ms
   - =#request(type, params)=: generate unique ID, send NDJSON line, return promise from #pending map
   - Public methods: register(opts), deregister(alias), list(), status(alias?), cleanup(sessionId), certInfo()
   - =getAliasUrl(alias)=: return =https://${alias}.localhost=
   - =dispose()=: close socket connection
2. Export GatewayClient and types from index.ts
3. Write tests — tests will need to start a real daemon instance

** Edge Cases
- Socket path from environment: check $XDG_RUNTIME_DIR first, fall back to /tmp/spell-gateway-{uid}.sock
- Daemon binary not found: throw descriptive error with build instructions
- Response timeout: reject pending promise after 10s with timeout error
- Socket write after close: queue request, reconnect, retry
- Concurrent dispose + request: request rejects with disposed error
