** Validation Flow
1. User clicks 'Refresh All' in ServicesPanel
2. Bridge event: ={type: 'validate_services'}=
3. Agent receives event, iterates services, for each:
   a. Launches browser (or reuses existing) with service's storageName
   b. Navigates to service's =loginUrl=
   c. Uses =browser:observe= to inspect page
   d. Determines login status via LLM judgment
   e. Updates registry =lastValidated= + =status=
4. Agent sends =service_list_update= back to BrowseShell with refreshed data
5. Dashboard and ServicesPanel update

5. Run tests

- Service has no =loginUrl= -> skip in validation, status remains unchanged
- Agent takes long to validate (many services) -> status updates arrive incrementally per service
