* Scope
=OrgHookExecutor= in =packages/spell-server/src/hooks/org.ts= is a stub that only logs debug messages. It never creates org items. A configured =org= hook silently does nothing, breaking the escalation/audit trail contract.

** Fix
- Implement real org item creation using =Bun.spawn= to call the =spell= CLI with org subcommands, or use the org API from =@oh-my-pi/pi-emacs= if available
- On failure: create a BUG org item with goal name, error message, run ID in body
- On success/complete: create a feature note or skip (configurable via =target.category=)
- Graceful degradation: if org tooling is unavailable (not installed, no .tasks/ dir), log a warning and skip — do not crash the hook chain
- Add test coverage for both creation and degradation paths

The simplest reliable approach: use =Bun.$= to run =spell org create= as a subprocess, catching errors for graceful degradation.
