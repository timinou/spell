* Initial Message

Allow line-slice on a symbol target. Two semantics, sign-disambiguated:

| Form                              | Semantics                                              |
|-----------------------------------+--------------------------------------------------------|
| =foo.ts::Bar.method=              | symbol body (current)                                  |
| =foo.ts::Bar.method:80-90=        | absolute lines 80..90 — must intersect symbol span     |
| =foo.ts::Bar.method:5-15=         | absolute lines 5..15 — error if symbol starts past 15  |
| =foo.ts::Bar.method:±5=           | symbol span EXTENDED by 5 lines on each side           |
| =foo.ts::Bar.method:-5..+10=      | (start - 5) to (end + 10), inclusive (relative)        |
| =foo.ts::Bar.method:0..+5=        | symbol-end to symbol-end+5 (trailing context only)     |
| =foo.ts::Bar.method:-3..0=        | symbol-start-3 to symbol-start (leading context only)  |
| =foo.ts::Bar.method:+5..+10=      | symbol-end+5 to symbol-end+10 (after-block context)    |

Disambiguation: bare digits ⇒ absolute file lines. Signed digits (=+= or =-=) ⇒ relative to symbol boundaries. =±N= ⇒ shorthand for =-N..+N=.

* Semantics
- Absolute: =Bar.method:A-B= where A,B unsigned. Result = lines max(A, sym.start)..min(B, sym.end). If empty intersection ⇒ explicit diagnostic =symbol-slice-disjoint=
- Relative: =Bar.method:-X..+Y= = lines (sym.start - X)..(sym.end + Y), clamped to [1, file.lineCount]
- =±N= = =-N..+N=
- Output: ONE sliced text body (same shape as FEAT-716 range form)

- Symbol resolves to multiple matches (overload) ⇒ apply slice to each, return one node per match
- Symbol not found ⇒ existing symbol-not-found diagnostic, slice not attempted
- Inline arrow / nested symbol whose span is single-line ⇒ relative slice still works
- Comments + leading/trailing whitespace inside symbol body preserved
