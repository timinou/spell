* Design Decisions

1. Preserve XML tags, Handlebars placeholders, RFC 2119 keywords, tool names, file paths, and behavioral constraints exactly where they carry executable meaning.
2. Apply notation-first language from `<language>` to prose in `system-prompt.md` and `plan-mode-active.md`: shorter directives, denser semantics, less narrative glue.
3. Keep structural meaning stable unless a local reorder clearly improves instruction salience; no behavioral change, no new policy, no removed requirement.
4. Because `/plan` and `/ultraplan` share `plan-mode-active.md`, rewrite both standard and conditional ultraplan sections in one pass so voice stays internally consistent.
5. Prefer durable tests that anchor on preserved contract phrases, section presence, conditional rendering, and ordering. Update exact-string assertions only where the requested copy change makes them obsolete.
