* Edge Cases
- Mode config loaded but mode not active -> sections not injected (only active mode's config applies)
- Gate toggle for a gate that doesn't exist in current mode (e.g., `gates.aphrodite: false` in non-design plan) -> silently ignored
- Custom decomposition with empty array -> uses default sections (treat empty as "not specified")
- Chat mode config present but plan mode active -> only plan mode injection applies, not chat
- Very large context section (>10KB) -> no truncation at injection layer; let the LLM context window be the limit
- Handlebars special characters in mode content ({{ or }}) -> triple-stache prevents escaping; document that users should avoid Handlebars syntax in MODE.md body
