* Context

Implement caveman as two parts:
1. Prompt injection in =buildSystemPrompt= (system-prompt.ts) — works for main session AND subagents
2. Built-in inline extension for =/caveman= command, animated fire status bar, config dialog, session persistence

Depends on settings schema and prompt template from [[id:FEAT-376-caveman-extension-settings-schema-and-pr]].

* Design Decisions

1. Prompt injection in =buildSystemPrompt= based on settings — NOT in =before_agent_start= hook. This ensures subagents get caveman prompt too.
2. =caveman.affectSubagents= setting controls whether subagents get the prompt. Main session always gets it if level ≠ off.
3. Extension factory in =packages/coding-agent/src/extensibility/extensions/caveman.ts=, wired via =inlineExtensions.push()= in =sdk.ts=
4. Runtime =/caveman= toggle uses =settings.override("caveman.defaultLevel", level)= — in-memory only, not persisted to kdl
5. Config dialog uses =settings.set()= — persists to kdl
6. Session persistence via =appendEntry("caveman-level", { level })= — on resume, extension calls =settings.override()= to restore
7. =thinkingMode= is independent from output level. Binary: caveman (PhD-caveman notation) or normal.

* Part 2: Extension Module

** File to Create: =packages/coding-agent/src/extensibility/extensions/caveman.ts=

Structure:

#+begin_src typescript
import type { Settings } from "../../config/settings";
import type { ExtensionFactory } from "./types";

const LEVELS = ["off", "lite", "full", "ultra", "wenyan-lite", "wenyan", "wenyan-ultra"] as const;
type Level = (typeof LEVELS)[number];

// Animation: 8 braille frames, 256-color ANSI fire palette
// Colors: R=196, O=208, Y=220, W=230, E=52
// Frames cycle color pairs on braille chars: ⠠⠄, ⠔⠂, ⠊⠑, etc.
// Speed: lite=300ms, full=200ms, ultra=100ms
// Timer type: NodeJS.Timeout (not ReturnType<>)

// Label map: lite→LITE, full→CAVEMAN, ultra→ULTRA, wenyan→文言文, etc.

export function createCavemanExtension(settings: Settings): ExtensionFactory {
    return (pi) => {
        let level: Level = "off";
        let timer: NodeJS.Timeout | undefined;

        // session_start:
        //   1. Check session entries for "caveman-level" (resume case) — use LAST entry
        //   2. If resuming: settings.override("caveman.defaultLevel", sessionLevel)
        //   3. If new session: read settings.get("caveman.defaultLevel")
        //   4. Set local level variable
        //   5. syncStatus(ctx)

        // session_shutdown:
        //   clearInterval(timer)

        // /caveman command:
        //   No args → toggle off ↔ full
        //   "config" → open config dialog
        //   Valid level → set it
        //   Invalid → ctx.ui.notify error
        //   On change:
        //     settings.override("caveman.defaultLevel", level) — in-memory only
        //     appendEntry("caveman-level", { level }) — for session resume
        //     syncStatus(ctx)
        //     ctx.ui.notify

        // /caveman config:
        //   ctx.ui.custom() with SettingsList
        //   4 settings: defaultLevel, showStatus, thinkingMode, affectSubagents
        //   On change: settings.set() — persists to kdl
        //   Follow pattern from modes/components/plugin-settings.ts

        // Status bar animation:
        //   syncStatus reads settings.get("caveman.showStatus")
        //   If off or level=off: ui.setStatus("caveman", "") to clear
        //   If on: setInterval with fire frames, ui.setStatus("caveman", frame + label)
    };
}
#+end_src

* Edge Cases

1. Session resume: if session has =caveman-level= entries, use the LAST one (most recent), call =settings.override()= to restore
2. Multiple rapid toggles: always clear timer before setting new one
3. =buildSystemPrompt= with caveman level "off": template renders nothing (=cavemanActive= is false)
4. Subagent with =caveman.affectSubagents= false: =cavemanActive= is false in subagent prompt
5. =settings.override= is in-memory only, does NOT survive process restart — session entries handle that
6. Timer cleanup: =session_shutdown= MUST clear interval
7. Config dialog changes =settings.set()= which also updates in-memory state, so =buildSystemPrompt= sees changes immediately
