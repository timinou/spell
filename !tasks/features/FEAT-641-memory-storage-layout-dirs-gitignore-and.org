* Intention & Purpose

Establish the on-disk layout for graph memory and ensure
=<repo>/.spell/memory/= stays out of git. Migrate any pre-existing
=MEMORY.org= or legacy memory files at first invocation. This FEAT is
the small, mechanical complement to FEAT-640: FEAT-640 writes through
=remember=; this FEAT ensures the directories exist and are gitignored.

* Context & Narrative

Spec: =specs/org-graph-memory.md=, layout block. Concepts:

- =<repo>/.spell/memory/episodes/<YYYY-MM-DD>.org= — daily file, level-1 = rollout, level-2 = episode
- =<repo>/.spell/memory/concepts/<slug>.org= — one file per concept
- =<repo>/.spell/memory/cache/memory_summary.md= — derived projection
- =<repo>/.spell/memory/migrated/<ts>.org= — quarantined legacy content

Existing project memory dir resolution lives in =@oh-my-pi/pi-utils=
=getMemoriesDir(cwd)= → =~/.spell/agent/memory/<cwd-hash>/=. This FEAT
introduces the per-repo directory at =<cwd>/.spell/memory/= as the new
home for graph-memory items, while keeping the legacy
=getMemoriesDir(cwd)= as a read-side fallback for existing data.

* Edge Cases

- Repo root not a git checkout: skip gitignore write; do not error
- =cwd= inside a worktree: gitignore goes to the worktree's gitignore (not the bare repo)
- Legacy =MEMORY.org= currently being read by another process: file rename is atomic on same filesystem; document the same-fs assumption
- Disk full during mkdir: bubble error
- Case-insensitive filesystem (macOS HFS+): =.spell= and =.SPELL= collide; honor whatever the user has, do not normalize case
- Existing =.gitignore= ends without newline: append with leading "
"
