* Context
This module parses a KDL document (from spell.kdl) into a =RawSettings= object — the same nested dict format that the Settings singleton uses internally. It replaces the YAML loading path (=YAML.parse(content)=) with KDL-based loading.

* Design Decisions
- New file: =packages/coding-agent/src/config/kdl-reader.ts=
- Uses =KDL_SETTINGS_MAP= from =kdl-settings-map.ts= to know where each setting lives in the KDL tree
- Uses helpers from =kdl-helpers.ts= for node access
- Unknown KDL nodes are silently ignored (forward compatibility)
- Parse errors in individual blocks log warnings (via =logger=) but don't fail the whole load — returns partial results
- Returns =RawSettings= (same type as =Settings.#global= / =Settings.#project=)
- The =RawSettings= type is =Record<string, unknown>= with nested objects for dot-path segments (e.g., ={compaction: {enabled: true}}= for =compaction.enabled=)

** Step 2: Implement =kdlDocumentToSettings=
File: =packages/coding-agent/src/config/kdl-reader.ts=

#+begin_src typescript
import { type Document, parse } from "@bgotink/kdl";
import { logger } from "@oh-my-pi/pi-utils";
import type { RawSettings } from "./settings";
import { KDL_SETTINGS_MAP } from "./kdl-settings-map";
import { getStringArgument, getBooleanArgument, getNumberArgument, getStringProperty, getBooleanProperty, getNumberProperty, getDocumentNode, getChildNode } from "./kdl-helpers";

export function kdlDocumentToSettings(doc: Document): RawSettings {
  const result: RawSettings = {};

  for (const [settingPath, mapping] of Object.entries(KDL_SETTINGS_MAP)) {
    try {
      const blockNode = getDocumentNode(doc, mapping.block);
      if (!blockNode) continue;

      // Navigate to the target node within the block
      let targetNode = blockNode;
      if (mapping.nodePath) {
        const parts = mapping.nodePath.split(".");
        for (const part of parts) {
          const child = getChildNode(targetNode, part);
          if (!child) { targetNode = null; break; }
          targetNode = child;
        }
      }
      if (!targetNode) continue;

      // Extract value based on accessor type
      let value: unknown;
      if (mapping.accessor === "argument") {
        value = targetNode.getArgument(mapping.argumentIndex ?? 0);
      } else {
        value = targetNode.getProperty(mapping.propertyName!);
      }

      if (value === undefined) continue;

      // Set in RawSettings using dot-path segments
      setByPath(result, settingPath.split("."), value);
    } catch (err) {
      logger.warn("kdl-reader: error reading setting", { path: settingPath, error: err });
    }
  }

  return result;
}
#+end_src

** Step 3: Implement =loadKdlSettings=
#+begin_src typescript
import { isEnoent } from "@oh-my-pi/pi-utils";

export async function loadKdlSettings(filePath: string): Promise<RawSettings> {
  try {
    const content = await Bun.file(filePath).text();
    const doc = parse(content);
    return kdlDocumentToSettings(doc);
  } catch (err) {
    if (isEnoent(err)) return {};
    logger.warn("kdl-reader: failed to load", { filePath, error: err instanceof Error ? err.message : String(err) });
    return {};
  }
}
#+end_src

Note: Import =setByPath= from settings.ts or extract it to a shared utility. Currently it's a module-private function in settings.ts — you'll need to either export it or duplicate the simple logic (it's ~10 lines of nested object creation).

* Edge Cases
- KDL boolean =#true= / =#false= maps directly to JS boolean — no coercion needed
- KDL numbers map directly to JS numbers
- KDL strings map directly to JS strings
- KDL null maps to JS null — treat as "unset" (skip, don't write to RawSettings)
- Nested blocks (e.g., =appearance { status-line { left "pi" "model" } }=) require multi-level child navigation
- Settings with multiple string arguments (e.g., status-line segments) need special handling via =getStringArguments()=
