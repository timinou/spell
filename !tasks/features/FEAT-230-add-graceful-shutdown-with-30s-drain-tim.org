* Scope
=server.ts= =stop()= (line 96-101) is immediate: =scheduler.stop(); httpServer.stop(); await sessionManager.killAll();=. No drain timeout, no wait for inflight goals. Restarts/upgrades abruptly terminate active goals, risking partial work and confusing state.

** Fix in =packages/spell-server/src/server.ts=
- =stop()= must:
  1. Stop scheduler (prevent new goals from firing)
  2. Stop HTTP server (stop accepting new requests)
  3. Wait for all active executor goals to complete, with a configurable timeout (default 30s)
  4. After timeout, force-kill remaining sessions via =sessionManager.killAll()=
  5. Log which goals were force-killed vs completed gracefully

- Add a =getInflightGoals(): string[]= method to =GoalExecutionController= that returns goal names currently in =running= state
- The drain loop: poll =getInflightGoals()= every 1s until empty or timeout exceeded

** Fix in =packages/spell-server/src/main.ts=
- Signal handler should log "draining N inflight goals..." before calling =stop()=
- Second SIGTERM/SIGINT during drain should force immediate exit
