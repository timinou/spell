* Scope

New utility that converts a ~FluidPlanWithComponents~ into ~TodoPhase[]~ compatible with todo_write's data model.

** File
- CREATE: ~packages/coding-agent/src/orchestrators/fluid/plan-to-todos.ts~

** Mapping Rules
- One phase per (component, wave) pair
- Phase name: ~component-N-wave-M~ or just ~wave-M~ for single-component plans
- Each ~FluidPlanAgent~ in a wave becomes a ~TodoItem~ in that phase
- ~FluidPlanAgent.orgItemId~ → ~TodoItem.orgItemId~
- ~orgItemClosingId~ set on the LAST task for each org item (across all waves)
- ~FluidPlanAgent.dependsOn~ → ~TodoItem.blockers~ (mapped to task IDs)
- ~FluidPlanAgent.effort~ → included in task details
- ~FluidPlanAgent.priority~ → included in task details
- ~FluidPlanAgent.body~ → ~TodoItem.details~
- ~FluidPlanAgent.deferred~ → skip (do not create a task for deferred agents)
- Task content: ~FluidPlanAgent.task~
- Task ID: auto-generated by todo_write (~task-N~), but the converter should produce stable ordering

** Edge Cases
- Single-component plans: simplify phase names to ~wave-N~
- Agents with no orgItemId: still create tasks, just without org linkage
- Agents with dependsOn referencing other agents in the same wave: cross-wave blockers use task IDs, intra-wave blockers also expressed
- Empty waves (all agents deferred): skip the phase entirely
- FluidPlanWithComponents.warnings: log but don't block conversion

** Interface

#+begin_src typescript
export function fluidPlanToTodoPhases(plan: FluidPlanWithComponents): TodoPhase[];
#+end_src
