* Edge Cases

- Missing/broken `[[id:…]]` link: skip silently (validator handles).
- Empty child body: render with no truncation marker.
- Non-org plan: section omitted by `{{#if childItems}}` guard.
- Unicode in body: byte-based truncation.
- Large plan exceeding `approvedPromptMaxBytes`: truncate trailing children, never mid-child.

* Acceptance Criteria

1. Fresh session after approval shows `## Child Item Specifications` with N `### <id>` subsections (N = number of `[[id:…]]` links in PLAN body).
2. Truncation marker `…(elided — fetch via \`org get <ID>\`)` appears exactly when child body exceeds `plan.injectedChildItemMaxBytes`.
3. `bun check:ts` passes.
4. Both new test files pass.
5. Non-org file-backed plan flow regression-tested green.
6. Subsequent execution session emits no `org get <childId>` before first `todo_write`.
