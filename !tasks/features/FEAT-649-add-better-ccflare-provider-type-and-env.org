* Intention &amp; Purpose

Register ~better-ccflare~ as a known provider in Spell's type system and wire up env var resolution so downstream code can dispatch on it.

* Context &amp; Narrative

better-ccflare is an Anthropic-compatible proxy running at ~localhost:8080~. It delegates to configured OAuth accounts when no client auth is sent, or maps ~btr-~ API keys to backend accounts. Spell currently has no concept of a better-ccflare provider — all models with ~api: "anthropic-messages"~ use the full Anthropic auth flow which breaks OAuth passthrough.

This item defines the type-level contract: provider name, env var mapping, and model config surface.

* Scope

In-scope:
- Add ~"better-ccflare"~ to ~KnownProvider~ union in ~packages/ai/src/types.ts~
- Add ~better-ccflare~ entry to ~serviceProviderMap~ in ~packages/ai/src/stream.ts~, resolving ~ANTHROPIC_AUTH_TOKEN~ env var (falls back to empty string — provider handles missing key)
- Export ~resolveAnthropicBaseUrl~ from anthropic.ts (currently private) so better-ccflare provider can reuse it with different defaults
- Add ~better-ccflare~ case to ~resolveAnthropicBaseUrl~: when ~model.provider === "better-ccflare"~, base URL from ~ANTHROPIC_BASE_URL~ env or ~model.baseUrl~ config, defaulting to ~http://localhost:8080~

Out-of-scope:
- Model discovery / model catalog entries (separate item)
- Auth header behavior (separate item)
- Actual provider streaming code (separate item)

* Existing Patterns

- Provider registration: ~serviceProviderMap~ in ~packages/ai/src/stream.ts~ maps provider name → env var resolver function. Example: ~anthropic: () => $pickenv("ANTHROPIC_OAUTH_TOKEN", "ANTHROPIC_AUTH_TOKEN", "ANTHROPIC_API_KEY")~
- Type union: ~KnownProvider~ in ~packages/ai/src/types.ts:87-92~
- Base URL resolution: ~resolveAnthropicBaseUrl~ in ~packages/ai/src/providers/anthropic.ts:428-450~, checks ~model.provider === "anthropic"~ and ~model.provider === "github-copilot"~
- ~$pickenv~ utility: ~packages/ai/src/stream.ts~ imports from ~@oh-my-pi/pi-utils~

* Tests

- ~packages/ai/test/better-ccflare-provider.test.ts~:
  1. ~getEnvApiKey("better-ccflare")~ returns ~ANTHROPIC_AUTH_TOKEN~ when set
  2. ~getEnvApiKey("better-ccflare")~ returns undefined when ~ANTHROPIC_AUTH_TOKEN~ is unset
  3. ~resolveAnthropicBaseUrl~ returns ~ANTHROPIC_BASE_URL~ for better-ccflare provider when set
  4. ~resolveAnthropicBaseUrl~ returns ~http://localhost:8080~ for better-ccflare when no env/base URL set
  5. ~resolveAnthropicBaseUrl~ returns KDL baseUrl for better-ccflare when set (model.baseUrl takes priority)

* Edge Cases

- ~ANTHROPIC_AUTH_TOKEN~ set to empty string: ~$pickenv~ should return undefined (falsy check), triggering OAuth passthrough
- ~ANTHROPIC_BASE_URL~ set to non-localhost URL: provider respects it (user may have remote better-ccflare)
- Model with ~provider: "better-ccflare"~ but ~api: "openai-completions"~: this should never happen; model config validation catches it
- Coexistence with ~provider: "anthropic"~ in same session: models with different providers resolve different env vars, no conflict
