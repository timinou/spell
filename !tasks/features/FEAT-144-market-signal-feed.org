:PROPERTIES:
:CUSTOM_ID: FEAT-144-market-signal-feed::implement-diff-engine

:END:
Compare current scrape snapshot vs previous snapshot stored in SQLite. Classify each ad as new, removed, or changed (field-level diff). Emit structured diff result with ad IDs and change types.

:PROPERTIES:

:END:
Write diff results to digest table. Dashboard badge reads unread count. Feed panel lists digest items with timestamp, source, change summary. Mark-as-read action clears badge.

* Edge Cases
- Signal source URL unreachable: log error, skip diff, do not clear previous snapshot
- First run (no previous snapshot): treat all scraped ads as "new"
- signals.json missing or malformed: disable scheduling, surface config error in dashboard

* Acceptance Criteria
- Scheduled scrape runs at time configured in signals.json
- Diff output correctly identifies new and removed ads between two snapshots
- Dashboard badge shows count of unread digest items after a scrape run
