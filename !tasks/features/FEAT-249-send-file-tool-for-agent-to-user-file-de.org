* Initial Message

the telegram pdf upload to the user does not work my man. it should. I want it to work. is it registered through a tool call? how does the telegram bridge handle giving ht eability to send tool calls?

* Scope
New builtin tool =send_file= in coding-agent that allows the agent to explicitly send files (PDFs, images, CSVs, any type) to the user. In Telegram context, the bridge intercepts the tool result and delivers via Telegram Bot API. Outside Telegram, the tool still works but just reports metadata.

* Design
** Tool parameters
- =path= (required string): File path relative to CWD or absolute
- =caption= (optional string): Text caption to accompany the file in Telegram
- =filename= (optional string): Override display filename (defaults to basename of path)

** Tool result shape
Returns path-based delivery metadata in =details= (no base64 through the JSON pipe):
#+begin_src typescript
{
  content: [{ type: "text", text: "File queued for delivery: report.pdf (245KB)" }],
  details: {
    delivery: {
      type: "document" | "photo",
      absolutePath: "/abs/path/to/file",
      fileName: "report.pdf",
      mimeType: "application/pdf",
      caption: "Monthly report",
      fileSize: 251000,
    }
  }
}
#+end_src

** Validation
- File must exist (ENOENT -> tool error)
- File size <= 50MB (Telegram bot limit)
- MIME type inferred from file extension via lookup table; fallback =application/octet-stream=
- Image MIME types (=image/*=) produce =type: "photo"=; all else =type: "document"=
