* Initial Message

is the cache control at the system level prompt? as in, is there a way to make the system prompt a cache checkpoint so that i re-use cache when I start a new session (or a new planning session for example)? do you understand me?

* Goal
Reorder the system prompt template so stable content forms a maximal prefix, and change =buildSystemPrompt()= to return =SystemPromptBlock[]= instead of a single string. This is the core change that enables cross-session cache reuse.

* Design Decisions
- Maximum stable prefix: Preamble + Workspace + Context files + Identity + Environment (tools/skills/rules) + Rules/Contract = ~90% of prompt
- Dynamic suffix: Now section (cwd, date) + append prompt (memory, MCP instructions, services)
- The =appendPrompt= currently sits between Context and Identity sections in the template. It must move to the end (after Rules, inside or adjacent to the Now section)
- =buildSystemPrompt= returns =SystemPromptBlock[]= with two blocks: =[{ text: stablePrefix, stable: true }, { text: dynamicSuffix, stable: false }]=
- Agent layer (=AgentState=, =AgentContext=) accepts =SystemPrompt= union type (changed in FEAT-370)
- A =CACHE_BOUNDARY= Handlebars helper emits a unique marker. After rendering, the output is split at this marker to produce two blocks
- The marker must not appear in any dynamic content (use a UUID-like string)

** =packages/coding-agent/src/system-prompt.ts= — Return SystemPromptBlock[]

*** Change =buildSystemPrompt= return type
From: =Promise<string>= → =Promise<SystemPromptBlock[]>=

After =renderPromptTemplate()= returns the rendered string, split at the cache boundary marker:

#+begin_src typescript
import type { SystemPromptBlock } from "@oh-my-pi/pi-ai";
import { CACHE_BOUNDARY_MARKER } from "./config/prompt-templates";

// At the end of buildSystemPrompt, instead of:
//   return renderPromptTemplate(template, data);
// Do:
const rendered = renderPromptTemplate(template, data);
const boundaryIndex = rendered.indexOf(CACHE_BOUNDARY_MARKER);
if (boundaryIndex === -1) {
  // No boundary found (custom prompt template or NULL_PROMPT)
  return [{ text: rendered, stable: true }];
}
const stablePrefix = rendered.slice(0, boundaryIndex);
const dynamicSuffix = rendered.slice(boundaryIndex + CACHE_BOUNDARY_MARKER.length);
const blocks: SystemPromptBlock[] = [{ text: stablePrefix, stable: true }];
if (dynamicSuffix.trim().length > 0) {
  blocks.push({ text: dynamicSuffix, stable: false });
}
return blocks;
#+end_src

* Edge Cases
- =NULL_PROMPT=true= env var: returns =[""]= as single block (backward compat)
- Template without ={{CACHE_BOUNDARY}}=: returns single stable block (backward compat for custom templates)
- Empty dynamic section (no date, no append): single stable block returned (no empty dynamic block)
- Timeout during prompt prep: falls back to minimal prompt — still returns blocks (single stable block with minimal content)
