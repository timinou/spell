* Edge Cases

- Pseudo-classes vs kernel sigils: =:hover= → =:= is kernel field axis; CSS payload must preserve =:= internally; backtick-quote required for selectors starting with =:=.
- Quoted attribute values with kernel chars: =[data-foo=":hover"]= — quote preserved; round-trip identity.
- =@media= rules: matched by =¶media-query= anchor; not part of NameLexer.
- =--custom-property: value;= — =¶custom-property= anchor + =#property[--name]= qualifier.
- =@keyframes name { ... }=: =¶keyframe= anchor; name extracted as separate field.
