* Scope

The web must show what a terminal session is doing. External sessions already can opt into a
low-fi =event_log= (=turn_start/turn_end/tool_call/assistant_text/plan_decision/error=). Make
this the live transcript feed.

** Coding-agent side
- Ensure interactive sessions emit =event_log= entries for: user message submitted (NEW kind
  =user_message= OR reuse =assistant_text= taxonomy — extend =EventLogEntryKind= in BOTH
  =types.ts= with =user_message=), assistant text (final), tool_call start/end, turn start/end.
- Gate behind the existing flag but DEFAULT-ON when the session is bridge-connected to a server
  the user controls? Keep opt-in via =SPELL_BRIDGE_EVENT_LOG=1= AND enable automatically when an
  =inject_input= capable server is present. Decide minimal: enable event-log when bridge connects
  (the whole point is remote visibility). Clip text to existing =EVENT_LOG_TEXT_MAX=.
- Hook points: =interactive-mode.ts= session.subscribe handler already sees session events;
  forward a compact mapping to =sessionBridge.emitEventLog(...)=.

** Server side
- Registry already keeps a ring buffer (=getRecentLog=). On web =subscribe events= for an
  external session, backfill recent entries to that connection (replay), then live-forward.
- =ws/server.ts= =#tapEvents= currently only taps the spawned hub; add external backfill +
  the existing =onEventLog= fanout already forwards =external_event_log=.

* Existing patterns

- =SocketSessionRegistry.appendEventLog / getRecentLog / onEventLog= already exist.
- =ws/server.ts registerFanout()= already forwards =external_event_log=. The missing piece is
  (a) richer emission from interactive-mode, (b) backfill-on-subscribe.

* Edge cases

- High-volume sessions: ring buffer cap (50) already bounds memory; clip text.
- Privacy: only emit when bridge-connected (user's own server) — document this.
- Don't double-emit when terminal and remote both active.

* Tests

- spell-server: subscribing to events backfills =getRecentLog= entries to the connection.

- Memory bounded; text clipped.
