* Context
The =tree-sitter-grammars/tree-sitter-markdown= repository contains TWO grammars:
1. Block structure: =tree-sitter-markdown/src= (already in recipes as =markdown=)
2. Inline structure: =tree-sitter-markdown-inline/src= (MISSING)

The inline grammar is needed for full markdown parsing fidelity — without it, inline elements (bold, italic, links, code spans) are opaque text blobs.

Additionally, several commonly-used languages with available tree-sitter grammars are missing from the recipe list.

* Scope

** =packages/emacs/elisp/pi-treesit-recipes.el=

*** Add markdown-inline grammar
#+begin_src elisp
(markdown-inline
 :url "https://github.com/tree-sitter-grammars/tree-sitter-markdown"
 :source-dir "tree-sitter-markdown-inline/src"
 :requires markdown)
#+end_src
No =:exts= or =:ts-mode= — this grammar is injected into markdown buffers for inline ranges, not used standalone. The =:requires markdown= ensures markdown block grammar is compiled first.

*** Add LaTeX grammar
#+begin_src elisp
(latex
 :ts-mode latex-ts-mode
 :url "https://github.com/latex-lsp/tree-sitter-latex"
 :exts ("tex" "sty" "cls" "ltx"))
#+end_src

* Edge Cases
- The =markdown-inline= grammar uses =:requires markdown= so it compiles after the block grammar. Do not add =:exts= — it's an injection grammar, not a standalone parser.
- LaTeX grammar from =latex-lsp= — verify URL is valid before adding. If not, use =https://github.com/latex-lsp/tree-sitter-latex=.
- Some grammars may fail to compile on certain platforms (missing C compiler). The existing =pi-prelude--install-grammar= handles this gracefully by recording in =pi-prelude--unavailable=.
