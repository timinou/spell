* Grammar (final)

| Input              | Desugars to (semantic)                 | Range fields              |
|--------------------+----------------------------------------+---------------------------|
| =foo.ts=           | full file                              | n/a                       |
| =foo.ts:50=        | first 50 lines (head)                  | start=None, end=Some(50)  |
| =foo.ts:-50=       | last 50 lines (tail)                   | start=Some(-50), end=None |
| =foo.ts:80-130=    | lines 80..=130                         | start=80, end=130         |
| =foo.ts:80-=       | line 80 to EOF                         | start=80, end=None        |
| =foo.ts:80+50=     | 50 lines starting at line 80 (=80..129)| start=80, end=129         |
| =foo.ts:80-130#raw=| same range, with #raw qualifier        | start=80, end=130         |

Internally, the shorthand desugars to the same internal representation as `foo.ts::§line[A..B]` (after FEAT-line-range-slice-shape lands and makes the range form return a sliced body).

* Disambiguation rules
- Only triggers when the path-prefix preceding `:` does NOT contain `://`
- Only triggers when the segment after `:` matches one of the regexes: =^-?\d+$=, =^\d+-\d*$=, =^-\d+$=, =^\d+\+\d+$=
- Bare digits without `-`/`+` => head N (matches `:50`)
- Symbol form (=::Symbol=) takes precedence (double-colon)
- Qualifiers (`#raw`, `#stat`, etc.) apply to the result and remain compatible

- Invalid bounds (`:0-`, `:1-1000000` against 50-line file) ⇒ clamp + warning, not error
