* Initial Message

bro. now that the Task tool and the todo write tool are well integrated, can you have a thing where I see in the TUI when a subtask is being spun by an agent? And can you see how often subtasks are being launched, and if they are token efficient?

* Goal

Wire the existing (but dead) subagent status line segment to the new SubagentTracker, and enhance it to show running count + aggregate cost + most active agent's current activity. Currently =setSubagentCount= exists but is never called — the subagents segment is always hidden.

* Design Decisions

- Replace =setSubagentCount(count: number)= with =setSubagentInfo(info: SubagentInfo | null)= on StatusLineComponent
- Expand =SegmentContext.subagentCount= to =SegmentContext.subagentInfo: SubagentInfo | null=
- Format: =3 agents · $0.42 · editing src/foo.ts= (count, cost, most active agent activity)
- When only 1 agent: =1 agent · $0.12 · grep: finding tests= (singular)
- Activity shows =currentTool: lastIntent= (truncated to fit)
- When no agents running, segment is hidden (same as now)
- Use =statusLineSubagents= theme color (already exists in theme)

* Edge Cases

- Status line width is limited — activity text must be truncated. Use =truncateToWidth()= with max ~25 chars for the activity portion
- Cost of $0.00 — omit cost segment entirely
- Most active agent has no =currentTool= (idle between tools) — show =lastIntent= or omit activity
- Multiple agents running but only one active — show the one that has =currentTool= set
- Pending agents (not yet running) — include pending count separately if >0: =2 running · 1 pending=. Actually, simpler: show total =runningCount + pendingCount= as just the count.

- When all subtasks complete, the indicator disappears
