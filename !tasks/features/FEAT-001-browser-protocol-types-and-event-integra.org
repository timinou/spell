*** BrowserAction union type
type BrowserAction = "browser:goto" | "browser:back" | "browser:forward" | "browser:reload" | "browser:evaluate" | "browser:click" | "browser:type" | "browser:fill" | "browser:press" | "browser:scroll" | "browser:drag" | "browser:observe" | "browser:get_text" | "browser:get_html" | "browser:get_attribute" | "browser:wait_for_selector" | "browser:extract_readable" | "browser:screenshot"
*** BrowserCommand interface hierarchy
- BrowserCommandBase: { action: BrowserAction; _rid?: string; timeout?: number }
- BrowserGotoCommand: extends base + { url: string; waitUntil?: "load" | "domcontentloaded" }
- BrowserEvaluateCommand: extends base + { script: string }
- BrowserClickCommand: extends base + { x?: number; y?: number; selector?: string; elementId?: number }
- BrowserTypeCommand: extends base + { text: string; selector?: string }
- BrowserFillCommand: extends base + { selector: string; value: string }
- BrowserPressCommand: extends base + { key: string; modifiers?: string }
- BrowserScrollCommand: extends base + { deltaX?: number; deltaY: number; x?: number; y?: number }
- BrowserDragCommand: extends base + { fromX: number; fromY: number; toX: number; toY: number }
- BrowserObserveCommand: extends base + { includeAll?: boolean; viewportOnly?: boolean }
- BrowserGetTextCommand: extends base + { selector: string }
- BrowserGetHtmlCommand: extends base + { selector: string }
- BrowserGetAttributeCommand: extends base + { selector: string; attribute: string }
- BrowserWaitCommand: extends base + { selector: string }
- BrowserExtractReadableCommand: extends base + { format?: "text" | "markdown" }
- BrowserScreenshotCommand: extends base + { fullPage?: boolean; selector?: string }
- BrowserCommand = union of all above
*** BrowserErrorCode enum
enum BrowserErrorCode { TIMEOUT, NOT_FOUND, STALE_TARGET, NAVIGATION_FAILED, PERMISSION_DENIED, EVAL_ERROR, WEBENGINE_UNAVAILABLE, INVALID_COMMAND, SCHEME_DENIED, WINDOW_CLOSED }
*** BrowserResult and BrowserError types
- BrowserResult: { type: "browser:result"; _rid: string; success: true; data: unknown }
- BrowserError: { type: "browser:error"; _rid: string; code: BrowserErrorCode; message: string; retryable: boolean }
- BrowserResponse = BrowserResult | BrowserError
*** BrowserEvent types
- BrowserLoadedEvent: { type: "browser:loaded"; url: string; title: string }
- BrowserUrlChangedEvent: { type: "browser:url_changed"; url: string }
- BrowserConsoleEvent: { type: "browser:console"; level: string; message: string; lineNumber: number; sourceId: string }
- BrowserLoadFailedEvent: { type: "browser:load_failed"; url: string; error: string }
- BrowserStateChangedEvent: { type: "browser:state_changed"; state: "idle" | "loading" | "interactive" | "error" }
- BrowserEvent = union of all above
*** Command idempotency classification
- isSafeToRetry(action: BrowserAction): boolean — returns true for observe, get_text, get_html, get_attribute, screenshot, extract_readable
- isSideEffecting(action: BrowserAction): boolean — returns true for click, type, fill, press, scroll, drag, goto
*** Export isBrowserEvent(name?: string): boolean helper for event classification
