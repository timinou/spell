* Scope
Create an STT provider interface and two implementations: Deepgram (HTTP batch) and OpenAI Whisper API. These accept raw audio bytes and return transcription text.

* Design

** Interface

#+begin_src typescript
interface SttResult {
  text: string;
  confidence?: number;
  language?: string;
}

interface SttProvider {
  /** Transcribe audio bytes to text */
  transcribe(audio: Buffer, options: {
    mimeType: string;      // e.g. "audio/ogg", "audio/mpeg"
    language?: string;     // BCP-47 hint
  }): Promise<SttResult>;
}
#+end_src

** Factory

#+begin_src typescript
function createSttProvider(config: SttConfig): SttProvider;
#+end_src

Dispatches on =config.provider= to instantiate the right implementation.

** Deepgram Implementation
- HTTP POST to =https://api.deepgram.com/v1/listen=
- Headers: =Authorization: Token <api-key>=, =Content-Type: <mimeType>=
- Query params: =model= (default =nova-2=), =language=, =smart_format=true=, =punctuate=true=
- Body: raw audio bytes
- Response: JSON with =results.channels[0].alternatives[0].transcript=
- Deepgram natively handles OGG Opus, MP3, WAV, M4A -- no format conversion needed

** OpenAI Whisper Implementation
- HTTP POST multipart to =https://api.openai.com/v1/audio/transcriptions=
- Headers: =Authorization: Bearer <api-key>=
- Form fields: =file= (audio blob), =model= (default =whisper-1=), =language=, =response_format=json=
- Response: JSON with =text= field
- Whisper accepts OGG, MP3, WAV, M4A, WebM, FLAC -- no format conversion needed

** Error Handling
- Network/HTTP errors: wrap in descriptive error with provider name and HTTP status
- Empty transcription: return ={text: ""}= (caller decides how to handle)
- Rate limiting: log warning, propagate error to caller
- Invalid audio: propagate provider error message
