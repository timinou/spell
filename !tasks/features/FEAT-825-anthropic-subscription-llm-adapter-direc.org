       where cch = Base16-lower(sha256(JSON.encode(params)))[0..4] (first 5 hex chars of the body payload hash),

   normalizeCacheControlTtlOrdering). For v0 a SIMPLE policy (cache system + last tool block) is acceptable;
   note the cap of 4 must hold or the API 400s.
6. TLS: Req/Finch `connect_options: [transport_opts: [...]]` — default ciphers + SNI are fine.
   Do NOT add JA3 spoofing (verified unnecessary).
7. max_tokens: ensure ≥ thinking.budget_tokens + buffer when thinking enabled (port ensureMaxTokensForThinking).
8. Streaming: parse SSE events message_start/content_block_start/delta/stop, message_delta —
