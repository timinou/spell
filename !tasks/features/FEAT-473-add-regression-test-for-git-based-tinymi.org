* Context

Typst LSP support depends on =.git= being in Tinymist's =rootMarkers= (=packages/coding-agent/src/lsp/defaults.json=, lines 125-133). Without =.git=, the current =loadConfig()= implementation would not activate Tinymist in ordinary repos (most repos lack =typst.toml=). This deviation has no test coverage — a cleanup could silently break Typst LSP.

** Test cases

*** 1. Tinymist selected for .typ file in git repo

#+begin_src typescript
it("selects tinymist for .typ files in a repo with .git marker", () => {
    const tempDir = TempDir.createSync("@spell-lsp-tinymist-");
    try {
        // Create .git directory marker
        fs.mkdirSync(path.join(tempDir.path(), ".git"));
        const config = loadConfig(tempDir.path());
        const server = getServerForFile(config, path.join(tempDir.path(), "doc.typ"));
        expect(server).not.toBeNull();
        expect(server![0]).toBe("tinymist");
        expect(server![1].initOptions?.formatterMode).toBe("typstyle");
    } finally {
        tempDir.removeSync();
    }
});
#+end_src
