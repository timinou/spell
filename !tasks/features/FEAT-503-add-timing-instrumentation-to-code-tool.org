* Problem
The code tool can hang during execution. The native =executeCodeBuffer= is synchronous (blocks the event loop), and =executeCodeGraph= runs on a worker thread. When operations are slow or stuck, there is no diagnostic output to identify the cause.

Potential hang sources identified during investigation:
1. *Tree-sitter re-parse*: After edit, the buffer re-parses. Pathological input could cause long parse times.
2. *=buffer.save()= I/O*: Sync =fs::write= in the Rust crate. Slow on NFS, very large files, or full disks.
3. *=registry().lock()=*: =parking_lot::Mutex= in =code_buffer.rs=. Single-threaded access from JS, but if Rust code panics mid-operation, internal state could be corrupt.
4. *Graph building*: =executeCodeGraph= builds the full code graph. Large repos with many files can take seconds to minutes.
5. *Semantic search*: Vector operations in the graph engine.

* Design Decisions
1. Wrap every =executeCodeBuffer= and =executeCodeGraph= call with =performance.now()= timing.
2. Log every call via =logger.debug("code tool operation", { command, file, durationMs })=.
3. Log a warning via =logger.warn= when any operation exceeds 2000ms.
4. No runtime behavior changes — this is diagnostic instrumentation only.

* Implementation

** Modify =packages/coding-agent/src/tools/code.ts=

This item depends on FEAT-502 (auto-save) because the auto-save adds a second =executeCodeBuffer= call that also needs instrumentation. Apply timing AFTER the auto-save changes are in place.

*** Add timing helper

Add a module-level helper function:

#+begin_src typescript
function timedCodeBuffer(options: CodeBufferOptions): CodeBufferResult {
    const start = performance.now();
    const result = executeCodeBuffer(options);
    const durationMs = Math.round(performance.now() - start);
    const file = options.file ? path.basename(options.file) : undefined;
    logger.debug("code buffer operation", { command: options.command, file, durationMs });
    if (durationMs > 2000) {
        logger.warn("slow code buffer operation", { command: options.command, file, durationMs });
    }
    return result;
}
#+end_src

Import =CodeBufferOptions= and =CodeBufferResult= from =@oh-my-pi/pi-natives= (they are already available via the existing import of =executeCodeBuffer=). Import type only — use =import type { CodeBufferOptions, CodeBufferResult }=.

*** Replace all =executeCodeBuffer= calls

Replace every direct call to =executeCodeBuffer(...)= in the =execute()= method with =timedCodeBuffer(...)=. This includes:
1. The main operation call
2. The auto-save call (added by FEAT-502)
