** Structured output schema
The task must return:
#+begin_src json
{
  "properties": {
    "summary": { "type": "string" },
    "filesChanged": {
      "elements": { "type": "string" }
    },
    "surfaceDslChanges": {
      "properties": {
        "standard": { "type": "string" },
        "project": { "type": "string" }
      }
    },
    "journeyDslChanges": { "type": "string" },
    "scenarioDslChanges": { "type": "string" }
  }
}
#+end_src

Where:
- ~summary~ — human-readable summary of what was done
- ~filesChanged~ — list of file paths modified
- ~surfaceDslChanges.standard~ — changes to DjinnUI standard components
- ~surfaceDslChanges.project~ — changes to agentmaker-specific components
- ~journeyDslChanges~ — changes to E2E journey test DSL
- ~scenarioDslChanges~ — changes to scenario/test infrastructure
