* Target
NEW module `SpellAgent.Credentials` in the new `beam/spell_agent/` app.

* Change
Read Spell's existing `~/.spell/agent/agent.db` (SQLite) READ-ONLY and return the
Anthropic OAuth credential as a struct/map.

- Dep: `{:exqlite, "~> 0.27"}` + `{:jason, "~> 1.4"}` (jason already used across beam/).
- Path: default `Path.expand("~/.spell/agent/agent.db")`, overridable via
  `SPELL_AGENT_DB` env for testing.
- Schema (verified): table `auth_credentials(id, provider, credential_type, data TEXT,
  disabled_cause, identity_key, created_at, updated_at)`.
- Query: `SELECT data FROM auth_credentials WHERE provider='anthropic' AND credential_type='oauth'
  AND disabled_cause IS NULL ORDER BY updated_at DESC LIMIT 1`.
- `data` is JSON: `{"access":"sk-ant-oat01…","refresh":"…","expires":<unix ms int>}`.
  Decode with Jason → `%SpellAgent.Credentials{access, refresh, expires_ms, provider: "anthropic"}`.
- Open the DB with mode `:readonly` (Exqlite `Exqlite.Sqlite3.open(path, mode: :readonly)`)
  so the parallel TS Spell is never write-locked.
- Public API:
  - `load(provider \\ "anthropic") :: {:ok, t} | {:error, reason}`
  - `expired?(t, skew_ms \\ 300_000) :: boolean` (now_ms > expires_ms - skew)

* Edge
- Multiple anthropic rows exist (verified: 7) — ORDER BY updated_at DESC picks freshest.
- DB missing / row missing → `{:error, :no_credential}` (clear, not a crash).
- `expires` stored as integer unix MILLIS (verified: 1777907810140) — not seconds. Compare with `System.os_time(:millisecond)`.
- Do NOT write to agent.db in this FEAT (read-only). Token-refresh persistence is FEAT (adapter/OAuth), deferred.

* Accept
- `mix test` in beam/spell_agent: a test against a fixture SQLite (or the real db when present)
  returns `{:ok, %Credentials{access: "sk-ant-" <> _, expires_ms: e}}` with `e > 0`.
- `expired?/2` returns true for a past `expires_ms`, false for a future one.
- App compiles; no write handle opened on agent.db (assert mode readonly).
