* Problem

~org-mcp--collect-graph-nodes-from-file~ in ~org-dependency-graph.el~ only scans for headlines with TODO keywords. File-level items with ~#+DEPENDS:~ are invisible to the dependency graph.

* Implementation

** Update ~org-mcp--collect-graph-nodes-from-file~

Mirror the change in org-next-wave.el:
1. Call ~org-tasks--parse-file-frontmatter~ first
2. If file-level item found, include it as a graph node
3. Also scan heading-level items for sub-outline support
4. Return combined nodes, deduplicating by custom_id

** Ensure edge building handles both formats

~org-mcp--build-edges~ already parses DEPENDS/BLOCKS from the alist ~depends~ and ~blocks~ fields using ~org-mcp--parse-space-separated~. File-level items set these fields from ~#+DEPENDS:~ / ~#+BLOCKS:~, so edge building should work without modification.
