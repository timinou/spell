* Goal

Implement tree-sitter-based structural edit operations for org files in =pi-org-engine=,
replacing the line-based text manipulation in =org-writer.ts=. All operations produce
=Vec&lt;TextEdit&gt;= that are applied via =CodeBuffer::edit_batch()=.

* Operations to implement

Each function takes =&CodeBuffer= + operation-specific args, returns =Vec&lt;TextEdit&gt;=.

** 1. =create_item(buffer, params) -> Vec<TextEdit>=

Serialize a new org item (heading or file-level) and insert at the correct position.
- If buffer is empty or has no headings: create file-level item with =#+= frontmatter
- If buffer has content: append heading-level item at end of file

Serialization follows the same format as current =org-writer.ts::serializeFileItem()=
and =serializeHeading()=.

** 2. =update_state(buffer, custom_id, new_state, todo_keywords) -> Option<Vec<TextEdit>>=

Locate the item by CUSTOM_ID (walk tree to find property_drawer with matching property).
For heading-level items: find the =item= child of =headline=, replace the TODO keyword.
For file-level items: find the =#+STATE:= directive, replace the value.

** 3. =update_title(buffer, custom_id, new_title, todo_keywords) -> Option<Vec<TextEdit>>=

Same locate logic. Replace the title portion of the =item= node (after the TODO keyword).

** 4. =replace_body(buffer, custom_id, new_body) -> Option<Vec<TextEdit>>=

Locate item. Find the =body= child of its =section=. Replace the entire body range with
new content. If no body exists, insert after =property_drawer= (or after =headline= if
no drawer).

** 5. =append_body(buffer, custom_id, text) -> Option<Vec<TextEdit>>=

Locate item. Find end of body (or end of property_drawer if no body). Insert text
at that position.

** 6. =set_property(buffer, custom_id, key, value) -> Option<Vec<TextEdit>>=

Locate item's =property_drawer=. Find existing =property= node with matching key and
replace, or insert new property line before =:END:=.
If no property_drawer exists, create one after the headline.

** 7. =append_note(buffer, custom_id, note_text) -> Option<Vec<TextEdit>>=

Locate item. Insert a dated NOTE entry in the body (=NOTE [YYYY-MM-DD]: text=).

** 8. =edit_section(buffer, custom_id, section_name, body, mode) -> Option<Vec<TextEdit>>=

Locate item. Find named sub-heading (=* section_name=). Replace or append to its body.
Reuses logic from current =pi-org-engine/src/section.rs= but produces TextEdits instead
of new source strings.

* Edge cases

- Item not found: return =None=
- File-level vs heading-level: different edit strategies for state/title/body
- Missing property_drawer: must create =:PROPERTIES:....:END:= block
- UTF-8 byte offsets: all TextEdit positions are byte offsets into rope, not character offsets
- Heading with no body: insert after property_drawer or headline
- Nested sections: update only targets the correct level
