* Problem

97% of org items (672 of 688) use file-level format:
#+begin_example
#+TITLE: My Feature
#+STATE: ITEM
#+CUSTOM_ID: FEAT-001-my-feature
#+EFFORT: 2h
#+PRIORITY: #A
#+LAYER: backend
#+DEPENDS: FEAT-002 FEAT-003
#+end_example

The Elisp wave/graph tools (~org-mcp--collect-full-items-from-file~, ~org-mcp--collect-graph-nodes-from-file~) only scan heading-level items (~* STATE Title~ with ~:PROPERTIES:~ drawer). They miss all file-level items.

* Design

Add a new function ~org-tasks--parse-file-frontmatter~ to ~org-tasks.el~ that:

1. Scans ~#+KEY: value~ lines at the top of the file (fast regex, no ~org-element-parse-buffer~)
2. Extracts: ~CUSTOM_ID~, ~STATE~, ~TITLE~, ~DEPENDS~, ~BLOCKS~, ~PRIORITY~, ~EFFORT~, ~AGENT~, ~LAYER~
3. Returns an alist matching the existing item shape, or nil if no ~#+CUSTOM_ID:~ found

Performance rationale: ~org-element-parse-buffer~ costs ~30-50ms per file. For 672 files that's 20-34 seconds, exceeding the 30s timeout. A regex-based scanner handles the frontmatter in <1ms per file.

Add a higher-level ~org-tasks--collect-items-from-file~ that:
1. Tries file-level parsing first (fast path for 97% of files)
2. Falls back to heading-level ~org-element-parse-buffer~ only when needed
3. Returns unified item alist shape regardless of source

* Implementation

** org-tasks.el: ~org-tasks--parse-file-frontmatter~

#+begin_src elisp
(defun org-tasks--parse-file-frontmatter (file)
  "Parse file-level #+KEY: value frontmatter from FILE.
Returns alist with custom_id, title, state, priority, effort,
agent, layer, depends, blocks — or nil if no #+CUSTOM_ID found."
  (with-temp-buffer
    (insert-file-contents file nil 0 2048) ; only read first 2KB
    (goto-char (point-min))
    (let ((props (make-hash-table :test 'equal)))
      (while (looking-at "^#\\+\\([A-Za-z_]+\\):\\s-*\\(.*\\)$")
        (puthash (upcase (match-string 1)) (string-trim (match-string 2)) props)
        (forward-line 1))
      (when-let ((custom-id (gethash "CUSTOM_ID" props)))
        (let* ((state-str (gethash "STATE" props))
               (state (when (and state-str
                                (member state-str org-tasks-todo-keywords))
                        state-str))
               (priority-raw (gethash "PRIORITY" props))
               (priority (when priority-raw
                          (replace-regexp-in-string "^#" "" priority-raw))))
          `((custom_id . ,custom-id)
            (title . ,(or (gethash "TITLE" props) ""))
            (state . ,(or state ""))
            (priority . ,(or priority ""))
            (effort . ,(or (gethash "EFFORT" props) ""))
            (agent . ,(or (gethash "AGENT" props) ""))
            (layer . ,(or (gethash "LAYER" props) ""))
            (depends . ,(or (gethash "DEPENDS" props) ""))
            (blocks . ,(or (gethash "BLOCKS" props) ""))))))))
#+end_src
