In the "Planning Workflow" procedure section (currently lines 187-210), restructure the phases:

Current phases: Understand → Design → Review → Write Plan

New phases:
1. **Explore** — read code, run browser, research (existing Phase 1)
2. **Decide** — ask all clarifying questions, settle ALL design decisions, document them explicitly in conversation before creating ANY org items. Must state decisions as a numbered list before proceeding.
