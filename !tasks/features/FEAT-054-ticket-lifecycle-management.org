* Scope
Implement the hybrid ticket lifecycle: loop transitions tickets to DOING when an iteration starts working on them, agent transitions to DONE when satisfied, loop verifies via per-ticket gates.

** In-Scope
- Ticket state transitions following org keywords: ITEM -> DOING -> DONE, plus BLOCKED, HOLD
- LoopManager integration: =startTicket(loopId, ticketId)= transitions to DOING, updates manifest
- Agent-side: =loop_done= reports which tickets were completed this iteration
- Per-ticket gate verification on DONE transition
- Org sync per-ticket: update individual ticket .org files on state change
- Event emission: =ticket.state_changed= events in the loop event log
- Dependency resolution: when ticket completes, check if any BLOCKER-blocked tickets can unblock
- TRIGGER execution: when ticket completes, apply TRIGGER rules (transition referenced tickets)

- Child loop spawning for tickets (handled by agent during iteration)

class TicketManager {
  startTicket(loopId: string, ticketId: string, iteration: number): ManifestTicket;
  completeTicket(loopId: string, ticketId: string, iteration: number): ManifestTicket;
  blockTicket(loopId: string, ticketId: string, reason: string): ManifestTicket;
  holdTicket(loopId: string, ticketId: string): ManifestTicket;
  resolveBlockers(loopId: string, completedTicketId: string): string[]; // Returns newly unblocked IDs
  applyTriggers(loopId: string, completedTicketId: string): string[];   // Returns triggered IDs
  getAvailableTickets(loopId: string): ManifestTicket[];  // ITEM tickets with no unresolved blockers
}
