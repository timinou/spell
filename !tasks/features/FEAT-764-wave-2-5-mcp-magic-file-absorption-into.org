* Goal

Absorb the Spell-owned MCP config files (=~/.spell/agent/mcp.json= and =<cwd>/.spell/mcp.json=) into =spell.kdl= as an inline =mcp= block.

* Why deferred from WAVE 2

The MCP server schema is rich (stdio/http/sse types, env vars, OAuth config, transport options, headers, args). Modeling all of it in KDL needs care to keep the on-disk shape both readable and future-proof. The =settings-schema.ts= record type only handles =Record<string, string>= today; absorbing MCP either:
  - extends the schema's =record= shape to support nested values, OR
  - special-cases the =mcp= block in the KDL writer/reader (similar to =writeTreeStringRecord=, =writeAllowedFolders= today)

The right approach is the second \u2014 add a dedicated =writeMcpServers= helper that handles the polymorphic shape. Same pattern the writer already uses for other complex Records.

* Proposed schema

#+begin_src kdl
mcp {
  server "memory" {
    type "stdio"
    command "mcp-memory"
    args "--db" "./memory.db"
    env "FOO" "bar"
  }
  server "github" {
    type "stdio"
    command "mcp-github"
    env "GITHUB_TOKEN" "$GITHUB_TOKEN"
  }
  server "exa-http" {
    type "http"
    url "https://mcp.exa.ai/sse?exaApiKey=..."
    headers "X-Foo" "bar"
  }
  disabled-servers "old-server"
}
#+end_src

* Implementation surface

- =packages/coding-agent/src/config/settings-schema.ts= \u2014 add =mcp.servers= as Record<string, McpServerEntry>
- =packages/coding-agent/src/config/kdl-settings-map.ts= \u2014 add =mcp.servers= mapping with special-case writer
- =packages/coding-agent/src/config/kdl-writer.ts= \u2014 add =writeMcpServers= helper alongside existing =writeTreeStringRecord=
- =packages/coding-agent/src/config/kdl-reader.ts= \u2014 add =readMcpServers= helper
- =packages/coding-agent/src/discovery/builtin.ts= \u2014 MCP capability provider reads from Settings instead of mcp.json
- =packages/coding-agent/src/migration/translate.ts= \u2014 mcp.json schema translator
- =packages/coding-agent/src/migration/detect.ts= \u2014 add mcp.json candidates

* Non-goals

- Foreign =.mcp.json= files (=.claude/=, =.cursor/=, =.vscode/=) stay native \u2014 discovery providers continue reading them as foreign formats.
- OAuth credential storage stays in =auth-storage= (sqlite), not in KDL.
