* Design Decisions

2. Drop "Respond terse like smart caveman." — no persona/roleplay framing.
3. Replace with direct instruction: "Terse mode active. Every response: substance only, grammar optional."

5. Keep the per-level conditional blocks — they're essential for the level system.
6. Keep auto-clarity and boundaries sections — they're safety valves.
7. Keep Bad/Good contrast example — it calibrates the register concretely.
8. Handlebars variable names (=cavemanActive=, =cavemanLite=, =cavemanFull=, etc.) stay unchanged.
