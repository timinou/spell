* Initial Message

is the cache control at the system level prompt? as in, is there a way to make the system prompt a cache checkpoint so that i re-use cache when I start a new session (or a new planning session for example)? do you understand me?

* Goal
Derive the OpenAI =prompt_cache_key= from a hash of the stable system prompt content instead of =sessionId= alone. This enables cross-session cache reuse for OpenAI-family providers by ensuring that sessions with identical stable prompts share the same cache key.

* Design Decisions
- Hash the stable block text (via =systemPromptStablePrefix()=) using =Bun.hash()=
- Combine with sessionId: =prompt_cache_key= becomes ={stableHash}-{sessionId}= when stable prefix exists, or ={sessionId}= when no stable prefix (backward compat)
- Actually, OpenAI docs say: "Use the prompt_cache_key parameter consistently across requests that share common prefixes." So we should use ONLY the stable hash for cross-session sharing. Within a session, the conversation prefix is automatically cached by OpenAI's prefix matching.
- Final design: =prompt_cache_key= = hash of stable system prompt text. If no stable blocks, fall back to sessionId.
- This means different sessions with the same stable system prompt share a cache key, enabling OpenAI server routing to warm cache nodes.

import type { SystemPrompt } from "./types";

export function resolveOpenAICacheParams(
  cacheRetention: CacheRetention | undefined,
  sessionId: string | undefined,
  systemPrompt?: SystemPrompt,
): OpenAICacheParams {
  const retention = resolveCacheRetention(cacheRetention);
  if (retention === "none") return {};

  // Derive cache key from stable prompt content for cross-session reuse
  let cacheKey: string | undefined;
  const stableText = systemPromptStablePrefix(systemPrompt);
  if (stableText) {
    // Bun.hash returns bigint; convert to hex string for a compact, deterministic key
    cacheKey = Bun.hash(stableText).toString(16);
  } else if (sessionId) {
    cacheKey = sessionId;
  }

  if (!cacheKey) return {};

  return {
    prompt_cache_key: cacheKey,
    prompt_cache_retention: retention === "long" ? "24h" : undefined,
  };
}
#+end_src

* Edge Cases
- Very long stable prompt: =Bun.hash()= handles arbitrary length input efficiently
- Empty stable text: =systemPromptStablePrefix= returns undefined → falls back to sessionId
- =sessionId= is undefined AND no stable blocks: returns empty object (no caching)
