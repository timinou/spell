* Problem

There is no way for the TypeScript/bridge layer to force a hard page reload that clears all state (helper cache, DOM, HTTP cache). The existing =browser:goto= with the same URL does a soft navigation. =reloadPage()= uses cached resources.

When the agent or an extension detects that a page is in a bad state (e.g., after server restart), there's no reliable way to recover programmatically.

* Implementation

** 1. Add =browser:force_reload= to =executeActiveCommand= switch (SpellBrowser.qml line 1542)

#+begin_src qml
case "browser:force_reload":
    executeForceReloadCommand(command)
    return
#+end_src

** 2. Add =executeForceReloadCommand= function

#+begin_src qml
function executeForceReloadCommand(command) {
    // Reset all browser state
    helperReady = false
    loadStateHistory = []
    recovering = false
    lastError = ""
    clearObservedElements()

    browserState = "loading"
    statusText = "Force reloading..."
    emitState(true)

    webView.stop()
    webView.reloadAndBypassCache()
    // Completion handled by onLoadingChanged -> LoadSucceededStatus
}
#+end_src

The command completes when =LoadSucceededStatus= fires (existing =onLoadingChanged= handler checks for =activeCommand.action === "browser:goto"= — extend to also check for ="browser:force_reload"=).
