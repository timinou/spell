* Initial Message

yo. how would you gain by getting the code tool interface to be xml instead of json, when communicating with the LLM

* Goal

Rewrite =formatCodeToolContent()= in =code-result.ts= to produce compact, hashline-style output instead of verbose prose. The hashline edit tool (=packages/coding-agent/src/patch/index.ts=) returns terse status + compact diff previews. Apply the same philosophy to all code tool commands.

The output is what the LLM reads back as the tool result. Making it compact and structured means the LLM spends fewer tokens parsing, and humans reading transcripts understand results faster.

* Design Decisions

- =edit=: Use =buildCompactHashlineDiffPreview()= from =packages/coding-agent/src/patch/hashline.ts= to produce a compact diff preview instead of dumping the full raw diff. Format: =Edited <path>
Changes: +N -M
Diff preview:
<compact diff>=
- =outline=: Tighten labels. =Outline <path> (N top, M total)= instead of =(N top-level, M total symbols)=
- =navigate=: Collapse metadata lines. Combine =parent=, =editable scope=, =symbol kind= onto fewer lines. Use pipe separators.
- =undo/redo=: Compact. =Undo <path> (N entries)= instead of =applied N history entries.=
- =diff=: Keep current format (already shows hunks directly)
- =save=: Keep current (already one-liner)
- =buffers=: Keep current (already compact list)
- =languages=: Keep current (already compact list)
- =read=: No change (raw text)
- =graph=: No change (already optimized by native engine)
- =error=: No change (=Error: <message>=)

* Import for buildCompactHashlineDiffPreview

The function is in =packages/coding-agent/src/patch/hashline.ts= and is already exported. Import it in =code-result.ts=:

#+begin_src typescript
import { buildCompactHashlineDiffPreview } from "../patch/hashline";
#+end_src

Use it in the edit branch:
#+begin_src typescript
if (details.command === "edit") {
    const label = details.displayPath ? ` ${details.displayPath}` : "";
    const header = `Edited${label}`;
    if (details.data.diff.trim().length === 0) return header;
    const preview = buildCompactHashlineDiffPreview(details.data.diff);
    const changes = `Changes: +${preview.addedLines} -${preview.removedLines}`;
    const diffBlock = preview.preview ? `
Diff preview:
${preview.preview}` : "";
    return `${header}
${changes}${diffBlock}`;
}
#+end_src

* Edge Cases

- Empty diff (no actual changes after edit) → just show =Edited <path>= with no diff section
- Very long diffs → =buildCompactHashlineDiffPreview= already handles truncation with =maxOutputLines= (default 16)
- Navigate with no items and no references → omit the items/refs line entirely
- Navigate with items but no references (or vice versa) → only show what's present
