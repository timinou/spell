* Edge Cases

- Broken `[[id:…]]` link: `validatePlanItem` raises an issue before `ExitPlanModeTool` returns success; never reaches the prompt path.
- Empty child body: heading + properties bullet only, no body, no truncation marker (scenario 7).
- Non-org plan (no `itemId`): `childItems === undefined`; `{{#if childItems}}` omits the section.
- UTF-8 boundary: `safeTruncateUtf8` guarantees code-point-boundary truncation; tested via scenario 5 and T-3.
- Global cap exceeded: trailing children dropped whole; omission summary emitted (scenario 6).
- Duplicate `[[id:X]]` in PLAN body: validator dedupes via `Map`; child appears once.
- Momus regression: s5 switches Momus from `extractIdLinks` to `validatePlanItem`. Only invoked post-approval, which guarantees `validation.valid`. Strict superset for valid plans.
- Settings ≤ 0 or missing: clamp `perChildMaxBytes` and `globalMaxBytes` to `1` inside `buildChildItemSpecs`.
