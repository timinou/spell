Add a =/voice= toggle command and per-session voice state to the Telegram bot. This lets users override the KDL-configured reply mode on a per-session basis.

* Design

** Session State Extension
Add =voiceReplyOverride?: VoiceReplyMode= to =ChatSession= in =bridge-types.ts=.

When set, this overrides both global and per-user voice reply mode for the session. Cleared on =/clear=.

** =/voice= Command

#+begin_example
/voice         -- toggle: off → mirror → always → off
/voice on      -- set to "always" (always reply with voice)
/voice off     -- set to "never" (never reply with voice)
/voice mirror  -- set to "mirror" (voice reply only to voice input)
/voice status  -- show current effective mode
#+end_example

Replies with a confirmation message showing the new effective mode.
