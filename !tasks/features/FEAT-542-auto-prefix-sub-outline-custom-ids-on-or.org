* Scope

When =org create= or =org update body== is called with a body containing sub-heading =:CUSTOM_ID:= properties, automatically rewrite those IDs to use the parent item's full CUSTOM_ID as prefix. Also rewrite =:DEPENDS:= references within the same body that reference local sub-outline IDs.

*In scope*:
- Auto-prefix sub-outline =:CUSTOM_ID:= values in body on =org create= (prefix with generated parent ID)
- Auto-prefix sub-outline =:CUSTOM_ID:= values in body on =org update body== (prefix with item's existing ID)
- Auto-prefix =:DEPENDS:= values within body that reference local sub-outline IDs
- Return the rewritten body and body length in the create/update response
- Skip prefixing if the ID already starts with =PARENT_ID::=

*Out of scope*:
- Changing the ID generation algorithm itself
- Modifying the native Rust engine
- Changing =org update append== behavior (append doesn't replace full body so auto-prefix is ambiguous)

* Existing Patterns
- =packages/org/src/tool.ts= — =cmdCreate()= generates the ID via =generateId()= then passes body to =executeOrg({ command: \"createItem\", ... body })=
- =packages/org/src/tool.ts= — =cmdUpdate()= passes body to =executeOrg({ command: \"updateItem\", ... body })=
- =packages/coding-agent/src/loop/ingestion/org-depend.ts= — =extractHeadings()= and =parseOrgDependProperties()= parse sub-outline headings from body content — reuse for detection
- =packages/org/src/tool.ts= — =normalizeOrgBody()= already preprocesses body text

The body rewriting should happen in TypeScript in =cmdCreate= / =cmdUpdate= AFTER the ID is known but BEFORE passing to the native engine.

** Implement rewriteSubOutlineIds function
:PROPERTIES:
:CUSTOM_ID: FEAT-542-auto-prefix-sub-outline-custom-ids-on-or::rewrite-impl
:DEPENDS: FEAT-542-auto-prefix-sub-outline-custom-ids-on-or::rewrite-tests
:END:
- File: =packages/org/src/sub-outline-rewrite.ts=
- Export =rewriteSubOutlineIds(parentId: string, body: string): { body: string; rewrites: Map<string, string> }=
- Algorithm:
  1. Parse all sub-headings with CUSTOM_ID from body
  2. Collect local IDs that don't already start with parentId::
  3. Build rewrite map: shortId to parentId::shortId
  4. Walk body line by line, replace CUSTOM_ID: shortId to CUSTOM_ID: parentId::shortId
  5. Walk body line by line, replace DEPENDS entries that match local short IDs
  6. Return rewritten body + the rewrite map

- In =cmdUpdate=: when =body= is provided, call =rewriteSubOutlineIds(args.id, body)= before passing to =executeOrg=
- Add =body= and =bodyLength= to the success response object
- Export the rewrite function from =packages/org/src/index.ts=

* Edge Cases
- Body with no headings: pass through unchanged
- Body with headings but no CUSTOM_ID properties: pass through unchanged
- DEPENDS referencing a non-local ID: leave unchanged
- DEPENDS with mixed local and cross-item IDs on same line: only rewrite the local ones
- Empty body string: pass through unchanged
- Body with CUSTOM_ID already prefixed: skip
- =org update append== does NOT auto-prefix
