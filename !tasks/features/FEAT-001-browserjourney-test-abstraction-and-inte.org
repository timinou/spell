*** Class: BrowserJourney extends QmlJourney
Constructor: private, use static launch()
Static launch(options?: { initialUrl?, width?, height?, settleMs?, assertTimeout?, props? }): Promise<BrowserJourney>
  - Launches canvas/BrowserWindow.qml via QmlJourney.launch
  - Waits for browser:state_changed to "idle" or "interactive"

*** Browser control methods (all return Promise):
- navigateTo(url: string, waitUntil?: "load" | "domcontentloaded"): sends browser:goto with _rid, waits for browser:result or browser:error
- evaluateInPage(script: string): sends browser:evaluate with _rid, returns result data
- clickElement(opts: { x?: number; y?: number; selector?: string; elementId?: number }): sends browser:click with _rid
- typeInPage(text: string, selector?: string): sends browser:type with _rid
- fillInput(selector: string, value: string): sends browser:fill with _rid
- pressKey(key: string, modifiers?: string): sends browser:press with _rid
- scrollPage(deltaY: number, opts?: { deltaX?, x?, y? }): sends browser:scroll with _rid
- observePage(opts?: { includeAll?, viewportOnly? }): sends browser:observe with _rid, returns observation array
- getPageText(selector: string): sends browser:get_text with _rid, returns string
- waitForElement(selector: string, timeout?: number): sends browser:wait_for_selector with _rid
- screenshotPage(opts?: { fullPage?, selector? }): sends browser:screenshot with _rid
- extractReadable(format?: "text" | "markdown"): sends browser:extract_readable with _rid
- dragOnPage(from: {x,y}, to: {x,y}): sends browser:drag with _rid

*** Assertion methods:
- expectPageUrl(url: string, timeout?): poll currentUrl until match
- expectPageTitle(title: string, timeout?): poll pageTitle until match
- expectPageLoaded(timeout?): wait for browserState === "interactive"
- expectPageText(text: string, timeout?): evaluateInPage + check text inclusion

*** Internal helpers:
- #sendBrowserCommand(payload): sends via agentSends, manages _rid
- #waitForBrowserResult(rid, timeout): waits for matching browser:result or browser:error event
- #createRid(prefix): generates unique request ID
- #currentRidCounter: number

*** WebEngine availability probe:
- Export function: webEngineOffscreenAvailable(): boolean
  - Launch minimal QML with WebEngineView in offscreen mode
  - Return true if loads without error, false if WebEngine unavailable
  - Cache result for session
  - Or simpler: check if bridge binary exists + test import QtWebEngine in eval
