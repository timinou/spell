## Edge Cases
- Preview compilation error: show error overlay on preview pane with line numbers
- Large document (50+ pages): throttle preview updates to max 1/sec
- Agent and user edit simultaneously: last-write-wins on file, both see each other's changes on next sync
- Template with missing data.yaml: show template with placeholder values, prompt to fill data
- WebEngineView fails to load Monaco: show fallback textarea

## Acceptance Criteria
- Editor shows Typst syntax highlighting (keywords, strings, functions in different colors)
- Preview updates within 500ms of editor change
- Clicking preview element moves editor cursor to correct source line
- Template selection populates editor and preview
- Agent writing .typ file updates editor and preview in real-time
