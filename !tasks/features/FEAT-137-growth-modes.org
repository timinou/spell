## Scope
IN: 6 growth modes implemented as .spell/modes/*.md files using existing ModeConfigFrontmatter: /intel, /strategy, /pitch, /review, /campaign, /brief. Each mode has: tool restrictions (allow/deny), readOnly flag, workspace layout coupling (extended frontmatter), subagent gates (Greek mythology naming: Hermes for strategy, Apollo for brand, Athena for intel completeness, Ares for campaign thoroughness), mode escalation paths (guided, show recommended next step on exit). /brief: lightweight one quality-gate round then editor opens with first version.

## Edge Cases
- Entering mode while agent is mid-response: queue mode activation until turn ends
- /campaign chains: if intel gate fails, don't proceed to strategy
- /brief one-round gate: if gate fails, show issues but still open editor (lightweight = don't block)
- Mode with workspace that has no panels loaded yet: load panels first, then switch
- Slash command for mode not in growth domain: error 'mode not available in this domain'

## Acceptance Criteria
- Typing /intel in chat drawer activates intel mode + switches to Research workspace
- In /intel mode, attempting to write a file fails with mode restriction error
- Exiting /intel shows 'Recommended next: /strategy' suggestion
- /pitch mode runs Apollo brand guardian gate before allowing exit
- /brief generates one-round quality gate then opens editor with result
- /campaign chains through intel->strategy->pitch automatically
