* Problem
Automated coverage does not exercise the worker IPC contract from the pi-natives side. The missing-worker error path is covered, but successful semantic indexing, malformed worker responses, and worker restart-after-failure are only manually verified. A protocol drift between worker and host could pass =cargo test= and break runtime.

* Approach: Rust Mock Worker Binary
Create a mock worker as a small Rust binary in =crates/pi-natives/tests/mock-worker/=. This binary:
- Reads JSONL commands from stdin (same protocol as the real worker)
- Returns controlled JSONL responses to stdout
- Behavior controlled via CLI args or environment variables

The mock worker is built as a =[[test]]= binary target in =crates/pi-natives/Cargo.toml= (or a separate workspace crate) so =cargo test= builds it automatically.

* Files to Create
** =crates/pi-natives/tests/mock-worker/main.rs=
A standalone binary that speaks the embedding worker JSONL protocol:
#+begin_src rust
// Reads {"command":"embed_batch","texts":[...],"batch_size":N}
// Returns {"ok":true,"vectors":[[...],[...],...]}
// Reads {"command":"embed_query","text":"..."}
// Returns {"ok":true,"vector":[...]}
#+end_src

Modes controlled by environment:
- =MOCK_WORKER_MODE=normal= — returns valid vectors of consistent dimension (default dim=4)
- =MOCK_WORKER_MODE=count_mismatch= — returns fewer vectors than input texts
- =MOCK_WORKER_MODE=dimension_mismatch= — returns vectors with inconsistent dimensions
- =MOCK_WORKER_MODE=crash_after_n= (=MOCK_WORKER_CRASH_AFTER=N=) — crashes (exit 1) after N successful responses
- =MOCK_WORKER_MODE=malformed_json= — returns invalid JSON
- =MOCK_WORKER_MODE=error= — returns ={"ok":false,"error":"simulated error"}=

* Test Scenarios

** Happy Path Tests
1. *Successful embed_batch*: mock returns N vectors of consistent dimension for N texts → =embed_batch()= returns =Ok(Vec<Vec<f32>>)= with correct count and dimensions
2. *Successful embed_query*: mock returns a single vector → =embed_query()= returns =Ok(Vec<f32>)=
3. *Full semantic index build*: mock returns valid vectors → =build_semantic_index()= returns =Ok(count)= with count > 0, vector cache file is created on disk

** Validation Error Tests (depend on FEAT-504 validation changes)
4. *Count mismatch*: mock returns fewer vectors than texts → =embed_batch()= succeeds but =build_semantic_index()= returns error with "returned N vectors for M chunks"
5. *Dimension mismatch*: mock returns vectors with inconsistent lengths → =embed_batch()= returns error with "inconsistent vector dimensions"
6. *Malformed JSON*: mock returns garbage → =embed_batch()= returns error with "malformed worker response"

** Error Handling Tests
7. *Worker error response*: mock returns ={"ok":false,"error":"..."}= → =embed_batch()= returns error
8. *Worker crash*: mock exits immediately → =embed_batch()= returns error, subsequent call spawns a new worker (restart behavior via =with_worker= error path at lines 155-158)

** Integration Test
9. *Search after index build*: build index with mock → run semantic search with mock embed_query → verify hits are returned (not empty)

* Implementation Notes
