* Scope

** In-Scope
- Manifest summary display when loop_launch is called or =/loop launch= is used:
  - Ticket list with ID, title, state, effort, priority
  - Dependency chain overview (topological order)
  - Gate overview (count by type: N command, M artifact, K llm-review gates)
