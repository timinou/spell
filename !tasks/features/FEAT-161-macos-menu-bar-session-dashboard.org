* Goal

macOS menu bar icon (systray) + QML popover window showing all active spell sessions. The macOS equivalent of the DankMaterialShell session list + Quickshell SpellStatusService.

* Architecture

** Session status daemon service

New file: =packages/macos/src/session-service.ts=

Uses =StatusFileReader= from =@oh-my-pi/pi-desktop-common= to poll =~/.spell/status/= every 2s. Maintains a live list of active sessions sorted by urgency (needs_input/pending_approval first, then error, running, idle, completed).

Detects status transitions and triggers macOS notifications via =QSystemTrayIcon.showMessage()=. Deduplicates notifications per windowId — same session won't re-notify for the same status.

** Menu bar icon

Uses existing =QmlBridge.createSystray()= to show a spell icon (◆ glyph or icon file) in the macOS menu bar. The context menu provides basic session list as fallback, but primary interaction is via the QML popover.

Icon badge behavior:
- Default icon when all sessions idle/completed
- Highlighted/colored icon when any session needs attention (needs_input or pending_approval)
- Tooltip shows summary: "3 sessions (1 needs input)"

** QML popover window

New file: =packages/macos/qml/SessionDashboard.qml=

A frameless, popover-style QML window that opens near the menu bar when the systray icon is clicked (=systray_activated= event). Content:

- Header: "Spell Sessions" with session count
- Session list (repeater):
  - Colored status dot (Catppuccin palette from =STATUS_COLORS=)
  - Project name (bold)
  - Session title (truncated, secondary text)
  - Status label (e.g., "Needs Input", "Running")
  - Click handler → focus terminal via =osascript=
- Grouped by urgency: attention-needed sessions first, separated from the rest
- Empty state: "No active sessions"
- Footer: "Overview: Cmd+Opt+O" (showing the configured global hotkey)

Window positioning: opens as a small panel anchored near the top-right of the screen (where the menu bar icon lives). Uses =Qt.FramelessWindowHint | Qt.WindowStaysOnTopHint=. Dismisses on click-outside or Escape.

** Focus terminal (macOS)

New file: =packages/macos/src/focus-window.ts=

Uses =osascript= to bring a terminal window to front by PID:
#+begin_src typescript
async function focusTerminalByPid(pid: number): Promise<void> {
  // Find the app owning this PID, then activate it
  await $`osascript -e 'tell application "System Events" to set frontmost of (first process whose unix id is ${pid}) to true'`.quiet().nothrow();
}
#+end_src

Falls back gracefully if the process is gone.

** Integration point

The session service runs as part of the QML daemon lifecycle on macOS. It's started when the daemon starts (or when the first macOS-specific client connects) and stopped on daemon shutdown.

Entry: =packages/macos/src/index.ts= exports a =startMacOSDesktopIntegration()= function that:
1. Creates systray icon
2. Starts status file polling
3. Registers systray_activated handler → toggle QML popover
4. Registers systray_click handler → handle menu actions
