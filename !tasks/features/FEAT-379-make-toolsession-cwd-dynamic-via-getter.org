* Initial Message

the /move command should also move where tools liek the Org tool save their files

* Problem
~toolSession.cwd~ is set as a static string value at construction time in ~createAgentSession()~ (sdk.ts line ~985). After ~/move~, ~sessionManager.cwd~ is updated but ~toolSession.cwd~ remains stale. Every tool that reads ~this.session.cwd~ at runtime gets the wrong directory.

* Approach
Change the ~cwd~ property on the ~toolSession~ object from a static value to a getter backed by ~sessionManager.getCwd()~.

TypeScript note: a getter on an object literal satisfies a ~cwd: string~ interface declaration — no ~ToolSession~ interface change needed.

* Implementation

** File: ~packages/coding-agent/src/sdk.ts~

In the ~toolSession~ object literal (around line 985), change:
#+begin_src typescript
const toolSession: ToolSession = {
    cwd,
    // ...
};
#+end_src

To:
#+begin_src typescript
const toolSession: ToolSession = {
    get cwd() { return sessionManager.getCwd(); },
    // ...
};
#+end_src

The ~sessionManager.getCwd()~ method already returns the live cwd — it is updated by ~sessionManager.moveTo()~ which ~/move~ calls.
