* Section Editing Implementation Detail

The current =org-edit-section= elisp tool:
1. Opens file in Emacs buffer
2. Finds item by CUSTOM_ID
3. Navigates to named section heading within item body
4. Replaces or appends body content
5. Saves buffer

Native replacement:
1. Call =executeOrg({ command: "section_range", file, custom_id, section })= → =\{ start_byte, end_byte \}=
2. Read file with =Bun.file(path).text()=
3. If mode "replace": =content.slice(0, start_byte) + newBody + content.slice(end_byte)=
4. If mode "append": =content.slice(0, end_byte) + "\
" + newBody + content.slice(end_byte)=
5. Write via =atomicWrite(path, newContent)=

* Edge Cases

- Section not found: =section_range= returns error, tool returns descriptive error message
- Empty query string: returns all items (no filter)
- Large org directories (100+ files): query should complete in <1s
- Concurrent mutations: atomic-write + mutex prevents corruption (existing pattern)
- Backward compatibility: existing org files with file-level and heading-level formats both parse correctly
