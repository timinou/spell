* Edge Cases
- specPaths pointing to non-existent directory: return error, don't create loop
- orgItemIds referencing non-existent items: return warning per missing ID, create loop with valid items only
- Both specPaths and orgItemIds empty: reject (nothing to build manifest from)
- loop_launch called on a loop not in manifest_building state: reject
- loop_launch called before manifest has any tickets: reject with "empty manifest" error
- Auto-launch with Momus rejection: stay in manifest_building, agent must fix and re-launch
