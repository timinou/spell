* Problem

=GrowthShell.qml= has a single =mainPanelLoader= and =loadWorkspacePanel()= only resolves =position === \"main\"=. Every workspace except =general= and =review= maps =chat= to =position: \"secondary\"=, which means:

- =strategy=: dashboard (main) + chat (secondary) -> only dashboard loads, no chat
- =research=: intel (main) + chat (secondary) -> only intel loads, no chat
- =create=: editor (main) + chat (secondary) -> only editor loads, no chat
- =campaign=: planner (main) + chat (secondary) -> only planner loads, no chat

In practice, chat is only available in the =general= workspace (where it's the main panel). In all other workspaces, the user has no way to interact with the agent.

* Root Cause

=domain/growth/src/qml/panels/GrowthShell.qml= lines 37-61: =loadWorkspacePanel()= iterates workspace panels looking only for =position === \"main\"= and sets a single Loader. There is no secondary Loader.

* Fix

Replace the current ColumnLayout (main area + ChatDrawer) with a vertical =SplitView= containing two Loaders:

1. =mainPanelLoader= — loads the =position: \"main\"= panel
2. =secondaryPanelLoader= — loads the =position: \"secondary\"= panel

Layout structure:

#+begin_src qml
SplitView {
    orientation: Qt.Vertical
    Layout.fillWidth: true
    Layout.fillHeight: true

    // Main panel
    Rectangle {
        SplitView.fillHeight: true
        SplitView.preferredHeight: parent.height * mainFlex / (mainFlex + secondaryFlex)
        color: "#111827"

        Loader {
            id: mainPanelLoader
            anchors.fill: parent
        }

        Text {
            visible: !mainPanelLoader.item
            anchors.centerIn: parent
            text: "Select a workspace to begin"
            color: "#6B7280"
            font.pixelSize: 16
        }
    }

    // Secondary panel (chat, editor, etc.)
    Rectangle {
        SplitView.preferredHeight: parent.height * secondaryFlex / (mainFlex + secondaryFlex)
        visible: secondaryPanelLoader.source !== ""
        color: "#111827"

        Loader {
            id: secondaryPanelLoader
            anchors.fill: parent
        }
    }
}
#+end_src

Update =loadWorkspacePanel()= to also resolve =position === \"secondary\"= and set =secondaryPanelLoader.source=. Use workspace =flex= values (default 2:1) for the split ratio.

=ChatDrawer= is removed from the layout — the secondary Loader replaces it. ChatPanel.qml (loaded as the secondary panel) provides the full chat interface including input, message history, streaming indicators, and status bar.

Mirror in =GrowthShellTestHarness.qml=.

* Key Details

** ChatPanel.qml import resolution
ChatPanel.qml lives at =packages/coding-agent/src/modes/qml/panels/ChatPanel.qml= and imports:
- =import ".." as SpellUI= -> resolves to =packages/coding-agent/src/modes/qml/= (contains =qmldir= with SpellUI module)
- =import "delegates" as Delegates= -> resolves to =panels/delegates/= subdirectory

Qt resolves imports relative to the loaded file's URL, not the Loader's URL. Since =qml-mode.ts= passes the absolute path via =bridge.props.panels=, ChatPanel.qml's imports resolve correctly when loaded via Loader in GrowthShell.

** Flex values from manifest
Workspace panels have optional =flex= properties: =\{ panelId: \"dashboard\", position: \"main\", flex: 2 \}=. Use these to set the =SplitView.preferredHeight= ratio. Default flex is 1 for panels without a =flex= property.

** Workspaces without secondary
=general= has only =main= (chat). =review= has =main= (dashboard) + =secondary= (editor, not chat). The secondary Loader simply gets =source = \"\"= and is not visible when no secondary panel exists.
