* Problem

When ~OrgTool#ensureInner()~ detects a cwd change (after ~/move~), it disposes the old inner tool and updates ~#projectRoot~ BEFORE constructing the replacement. If ~#createInner()~ throws, the tool is stuck: ~#projectRoot~ matches the new cwd so no retry happens, but ~#inner~ was already disposed.

Same pattern in ~WriteTool#getWritethrough()~: ~#writethroughCwd~ is updated before ~#createWritethrough()~ runs. If it throws, subsequent calls see matching cwd and skip rebuild.

Additionally, ~OrgTool#ensureInner()~ does not refresh ~this.description~ after a successful rebuild, so stale description text persists if the new project has different org config.

All three functions involved (~loadOrgConfig~, ~createOrgTool~, ~createLspWritethrough~) are synchronous calls that can throw.

async #ensureInner(): Promise<void> {
    const projectRoot = this.#session.cwd ?? getProjectDir();
    if (projectRoot === this.#projectRoot) return;
    const newInner = this.#createInner(projectRoot);
    await this.#inner.dispose?.();
    this.#inner = newInner;
    this.#projectRoot = projectRoot;
    this.description = this.#inner.description;
}
#+end_src
