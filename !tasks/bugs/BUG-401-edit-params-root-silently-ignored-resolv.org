* Initial Message

many Edit errors have "Scope preview: " empty. THen the sessions end up using python to edit code, which is horrendous. Can you look at the session jsonl using jq and tell me where the codepath + edit tools fail, and when the sessions have to rely on bash for things that should be code editing? investigate please, thanks.

* Symptom

Agents pass =edit { root: "/abs/path", operations:[{target:"rel.ts", ...}] }=
expecting =target= to resolve against the supplied root. It silently does not.
=resolveCwdRelativePath= is called with =session.cwd= and the user-supplied
=params.root= is dropped on the floor. The kernel then opens a wrong (or
non-existent) path → empty buffer → "Scope preview: " empty (see BUG-402).

* Repro

#+begin_src
edit { root: "/tmp/",
       operations:[{ target:"test_scope.ts",
                     action:{ kind:"fileFindReplace", find:"function isInsideRoot",
                              content:"REPLACED" }}] }
→ edit error: Patch 1: find text not found in scope. Scope preview:    ← empty
#+end_src

Same call with =target: "/tmp/test_scope.ts"= (absolute) succeeds.

* Root cause

=packages/coding-agent/src/tools/edit.ts:208,353-358=

#+begin_src ts
const resolved = resolveCwdRelativePath(sessionCwd, op.target, { mode: "file" });
// ...
const chunks = await executeCodePath({
  target: nodePath.relative(this.session.cwd, targetPath),
  root: this.session.cwd,    // ← params.root never threaded here
  ...
});
#+end_src

=editSchema.root= is declared (=packages/coding-agent/src/tools/codepath-types.ts:172=)
but never consulted; the schema documents the parameter as live.

* Fix

Thread =params.root= into both path resolution and the kernel call:

#+begin_src ts
const effectiveCwd = params.root
  ? nodePath.isAbsolute(params.root) ? params.root : nodePath.resolve(sessionCwd, params.root)
  : sessionCwd;
const resolved = resolveCwdRelativePath(effectiveCwd, op.target, { mode: "file" });
// ...
root: effectiveCwd,
target: nodePath.relative(effectiveCwd, targetPath),
#+end_src

Sandbox / =enforcePathWrite= still gates against =sessionCwd= — =params.root=
must be inside the sandbox root or the call rejects.
