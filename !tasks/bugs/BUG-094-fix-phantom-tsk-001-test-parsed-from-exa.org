* Problem

~FEAT-004-add-section-level-mutation-to-org-update.org~ contains a test fixture inside a ~#+begin_example~ block at line 125-142:

#+begin_example
,* ITEM Test Task
:PROPERTIES:
:CUSTOM_ID: TSK-001-test
:EFFORT: 1h
:END:
#+end_example

In org-mode, headlines (~* ...~) always take precedence over blocks. The ~org-element-parse-buffer~ parser treats ~* ITEM Test Task~ as a real heading, terminating the example block. This creates a phantom item that pollutes wave/graph results.

The TypeScript ~org-reader.ts~ also has this bug — it does not skip ~#+begin_example~ blocks during line-by-line scanning.

* Fix

Indent the ~*~ inside the example block to prevent headline parsing:

#+begin_example
,* ITEM Test Task
#+end_example

Using the org-mode comma escape prefix (~,*~) is the canonical way to include literal headline-like text inside blocks. When rendered, the comma is stripped. When parsed, it is not a headline.
