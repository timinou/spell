* Problem

~org-tasks-todo-keywords~ is ~("ITEM" "DOING" "REVIEW" "DONE" "BLOCKED")~ but the TypeScript ~DEFAULT_TODO_KEYWORDS~ includes ~"INIT"~. The Elisp ~org-tasks--setup-keywords~ also omits INIT from the ~#+TODO:~ declaration it inserts.

Items with ~#+STATE: INIT~ or heading ~* INIT Title~ are invisible to all Elisp tools.

* Fix

1. Add ~"INIT"~ to ~org-tasks-todo-keywords~ defcustom default
2. Add ~"INIT(I)"~ to the ~#+TODO:~ line in ~org-tasks--setup-keywords~
3. Add ~"INIT(I)"~ to the ~org-todo-keywords~ setq-local in ~org-tasks--setup-keywords~
