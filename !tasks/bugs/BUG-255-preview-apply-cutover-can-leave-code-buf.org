* Tests
Enumerate end-user workflows first; each must be written as a failing test before implementation:
1. Preview a structural rewrite, apply through `resolve`, then `code read` and raw filesystem-backed follow-up both observe identical updated content.
2. Preview a structural rewrite, discard through `resolve`, then later `code read` and filesystem-backed follow-up both observe the original content.
3. Apply a preview, then run a second mutating `code edit` on the same file; the second edit must target the newly applied content, not a stale pre-preview buffer.
4. Preview/apply on one file must not invalidate unrelated clean buffers.
5. If persistence fails after apply, the tool surfaces a hard error and does not claim success.
