Pattern: once a malformed image block lands in the persisted transcript, every replay
re-sends it; only manual JSONL surgery recovers.

* Mitigation: three-layer defense
1. Producer-side magic-byte sniff at =marshal.rs::content_to_dto= (Content::Image arm) —
   bytes-vs-declared-mime sanity, downgrade to text on unrecognized formats. Catches
   the mislabeled-file family.
2. Shared validator =packages/ai/src/image-validation.ts= used by every provider mapper
   before serialization. Substitutes a text marker on failure; never throws.
3. Session-write guard in =packages/coding-agent/src/session/session-manager.ts= using
   the same validator before JSONL append. Bad blocks never enter the transcript.

* Acceptance
- Validator: empty / URI-shaped / non-base64 / mime-mismatch / oversize → =ok:false=.
- Anthropic provider: URI-shaped data → text block, no API call attempted with bad data.
- Session: bad image block in =appendMessage= → JSONL contains text marker, image type absent.
- Session reload after bad-block insert → no 400 on next turn.
