Addresses audit finding 2.

* Problem

=mainPanelLoader= in =GrowthShell.qml= has no =onStatusChanged= handler or error overlay. If a panel QML file fails to load (bad path, syntax error, import failure), the user sees the placeholder "Select a workspace to begin" with no error feedback.

The default =shell.qml= (=packages/coding-agent/src/modes/qml/shell.qml= lines 269-329) has:
- =onStatusChanged= on each Loader delegate that tracks =activePanelLoaderStatus=
- An error overlay (=Rectangle= with "Failed to load panel", the failed source path, and a "Retry" button)

GrowthShell needs a simplified version since it has a single Loader instead of a Repeater.

* Fix

In =domain/growth/src/qml/panels/GrowthShell.qml=, add to the panel area Rectangle (after =mainPanelLoader=):

1. Add =property int panelLoaderStatus: Loader.Null= at root level
2. Add =onStatusChanged: root.panelLoaderStatus = status= to =mainPanelLoader=
3. Add error overlay Rectangle after the placeholder Text:
   - Visible when =panelLoaderStatus === Loader.Error=
   - Shows "Failed to load panel" in =#EF4444= (error red)
   - Shows the failed source path in monospace
   - Has a "Retry" button that clears and re-sets Loader source

Mirror in =GrowthShellTestHarness.qml=.

* Reference

=packages/coding-agent/src/modes/qml/shell.qml= lines 14-19 (=activePanelLoaderStatus=), 269-271 (=onStatusChanged=), 277-330 (error overlay).

GrowthShell does NOT use SpellUI theme, so use hardcoded colors matching the existing palette (=#111827= background, =#EF4444= error, =#6B7280= secondary text).

* Acceptance Criteria
- When =mainPanelLoader.source= points to a non-existent file, the error overlay shows "Failed to load panel" (test via =harness.evaluate=)
- =bun test domain/growth/test/panels/growth-shell.test.ts= passes
- New test: set Loader source to a bad path, assert error text is visible
