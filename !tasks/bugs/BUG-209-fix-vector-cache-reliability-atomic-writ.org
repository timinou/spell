* Problem

Two reliability issues in the vector cache layer:

1. =save_vector_cache()= writes directly with =File::create()= — a crash or interruption leaves a partial =workspace-vectors.bin= that is later treated as "no vectors" (silent degradation) or fails to deserialize (swallowed by =.ok()?=).

2. =compute_fingerprint_hash()= manually hashes a hand-picked subset of =GraphFingerprint= fields (root, git_head, per-file path/size/modified_at_ms). If =GraphFingerprint= gains new fields, the hash won't include them, causing stale vectors to appear "fresh."

* Design Decisions

1. *Atomic vector cache writes*: write to =workspace-vectors.tmp.bin=, then =fs::rename()= to =workspace-vectors.bin=. On the same filesystem, rename is atomic. Follow the same pattern as =CacheStore::save()= (which also uses =File::create= directly — but since both are on the same filesystem and cache corruption is recoverable by rebuilding, the rename pattern is the improvement).

2. *Derive Hash on GraphFingerprint*: Add =#[derive(Hash)]= to =GraphFingerprint= and =FileFingerprint= in =cache.rs=. Replace the manual field-by-field hashing in =compute_fingerprint_hash()= with =fp.hash(&mut hasher)=. This ensures any future field additions to the fingerprint automatically invalidate the vector cache.

Replace direct write with atomic temp+rename:
#+begin_src rust
fn save_vector_cache(
    cache: &CacheStore,
    vectors: &pi_code_vectors::PersistedVectorIndex,
) -> napi::Result<()> {
    let dir = cache.directory();
    fs::create_dir_all(dir)
        .map_err(|e| Error::from_reason(format!("Failed to create cache dir: {e}")))?;
    let final_path = dir.join(format!("{VECTORS_CACHE_NAME}.bin"));
    let tmp_path = dir.join(format!("{VECTORS_CACHE_NAME}.tmp.bin"));
    let file = fs::File::create(&tmp_path)
        .map_err(|e| Error::from_reason(format!("Failed to create vector cache temp: {e}")))?;
    pi_code_vectors::serialize_index(BufWriter::new(file), vectors)
        .map_err(|e| Error::from_reason(format!("Failed to write vector cache: {e}")))?;
    fs::rename(&tmp_path, &final_path)
        .map_err(|e| Error::from_reason(format!("Failed to finalize vector cache: {e}")))?;
    Ok(())
}
#+end_src

*** =compute_fingerprint_hash()= (~line 310)
Replace manual hashing with derived =Hash=:
#+begin_src rust
fn compute_fingerprint_hash(cache: &CacheStore, _root: &Path) -> u64 {
    let entry = cache.load(CACHE_NAME).ok().flatten();
    let Some(entry) = entry else {
        return 0;
    };
    let mut hasher = DefaultHasher::new();
    entry.fingerprint.hash(&mut hasher);
    hasher.finish()
}
#+end_src
This uses the derived =Hash= impl on =GraphFingerprint= which hashes all fields transitively.
