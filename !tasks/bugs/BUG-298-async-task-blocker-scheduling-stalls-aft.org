* Edge Cases
- Concurrency: with `maxConcurrency=2`, when A completes both B and C are candidates (C depends on B, so only B is actually ready). `readyTaskIds` must treat completion as transitively relevant.
- Cycle detection: `buildBatchGraph` rejects cycles; downstream code does not need to re-check.
