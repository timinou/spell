* Scope
In scope:
- Remove the bundled ~quick_task~ agent’s default ~scopeRestricted: true~ behavior so mechanical subagents do not hard-fail solely because ~filesDeps~ was omitted or too narrow.
- Remove the bundled ~task~ agent prompt’s default “investigate → create sniper todos → delegate each slice to quick_task” workflow. The default should become: execute directly unless explicit constraints or caller instructions justify delegation.
- Preserve narrow-scope execution as an explicit opt-in path via existing ~scopeRestricted~ agent metadata, not as the bundled default.
- Update package-local tests so the new default and the opt-in narrow path are both covered.

Out of scope:
- Removing the ~quick_task~ agent entirely.
- Changing general spawn policy semantics or recursion-depth policy.
- Changing session cwd / worktree root behavior. That is handled separately.

Rationale: current defaults create false-negative task aborts in normal multi-file work. The failure is policy/default driven, not an intentional user safety choice.
