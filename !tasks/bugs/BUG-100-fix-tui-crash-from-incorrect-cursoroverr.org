why?

The voice-agent's mic icon (🎤) causes a TUI crash when the rendered bottom
border line exceeds terminal width by 1 column. Root cause:
~cursorOverrideWidth~ is hardcoded to 1, but the emoji occupies 2 terminal
columns. The 1-column undercount propagates through padding math, producing a
145-column line in a 144-column terminal.

* Root Cause
- ~interactive-mode.ts:1724,1737~: ~this.editor.cursorOverrideWidth = 1~
- ~theme.ts:284~: ~"icon.mic": "🎤"~ — actual width is 2
- Width varies by theme: 🎤=2, nerd ~\uf130~=1, ASCII "MIC"=3
- Hardcoded 1 is wrong for default and ASCII themes

* Fix — Two Layers
** Layer 1: Fix the caller (interactive-mode.ts)
Replace both hardcoded ~cursorOverrideWidth = 1~ assignments with
~visibleWidth(theme.icon.mic)~.

Files:
- ~packages/coding-agent/src/modes/interactive-mode.ts~ (lines 1724, 1737)

** Layer 2: Defense-in-depth in editor (editor.ts)
When ~cursorOverrideWidth~ is not provided, auto-compute it from
~visibleWidth(this.cursorOverride)~ instead of defaulting to 1.

Files:
- ~packages/tui/src/components/editor.ts~ (line 637)

- With default theme (🎤 emoji), voice recording state must not crash
- ~bun check:ts~ passes
