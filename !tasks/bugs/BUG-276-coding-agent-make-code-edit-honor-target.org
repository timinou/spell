* Edge Cases
- Top-level =file= disagrees with the file root implied by =operations[].targetId=: hard-fail truthfully; do not silently pick one.
- Relative =targetId= with =root= must resolve identically in TS and Rust; no double-rooting and no cwd-relative drift.
- Absolute =targetId= must not be re-rooted.
- Missing parent directories for create should still fail truthfully if the native engine cannot materialize them; this item only fixes false freshness failures on the documented create path.
- Multi-file =operations= must remain rejected atomically.
- Existing stale managed buffers must still report the current actionable freshness guidance; the missing-file fix must not weaken that guard.
