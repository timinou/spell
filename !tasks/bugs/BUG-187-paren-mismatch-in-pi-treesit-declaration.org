* Pre-existing Test Bug: let vs let*

In ~test-outline.el~, the yaml/toml/json tests use ~let~ where they need ~let*~:

#+begin_src elisp
;; BAD: `let` binds in parallel — `names` cannot reference `entries`
(let ((entries (pi-outline-get file))
      (names (mapcar (lambda (entry) (alist-get 'name entry)) entries))
      (types (mapcar (lambda (entry) (alist-get 'type entry)) entries)))
#+end_src

Fix: change =let= to =let*= in these three tests:
- ~test-outline-yaml-entries~ (line ~85)
- ~test-outline-toml-entries~ (same pattern)
- ~test-outline-json-entries~ (same pattern)

     (test-outline--with-tmp-file test-outline--elixir-source ".ex"
       (lambda (file)
         (let* ((entries (pi-outline-get file))
                (names (mapcar (lambda (e) (alist-get 'name e)) entries))
                (types (mapcar (lambda (e) (alist-get 'type e)) entries)))
           (should (listp entries))
           (should (>= (length entries) 1))
           (should (member "MyApp.HelloController" names))
           (should (member "defmodule" types))))))
