* Problem

=resolveDefaultConfigDir()= in =packages/coding-agent/src/commands/server.ts= uses a bare =catch {}= that swallows all =fs.stat= failures, not just ENOENT. The planned contract was: fall back to =~/.spell/= only when the local =./.spell/= directory is absent. Permission errors (EACCES), transient I/O errors, and other unexpected stat failures are silently treated as "absent", causing the server to load config from the wrong directory without any diagnostic.

** Change
1. Import =isEnoent= from =@oh-my-pi/pi-utils= (already imported in the file's neighbors; the pattern is well established in the codebase).
2. Replace the bare =catch {}= with a =catch (err)= that re-throws non-ENOENT errors.

The result:
#+begin_src typescript
try {
    const stats = await fs.stat(cwdConfig);
    if (stats.isDirectory()) {
        return cwdConfig;
    }
} catch (err) {
    if (!isEnoent(err)) throw err;
}
return path.join(os.homedir(), ".spell");
