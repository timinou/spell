* Scope
Two defects in the Telegram bridge message routing that silently degrade the user experience.

** Finding 3: =respawnSession= omits Telegram system prompt
=respawnSession()= in =commands/index.ts= calls =processManager.getOrCreate()= without =appendSystemPrompt=. Sessions created by =/project=, =/mode=, =/lock=, =/unlock= start without the mobile-optimized Telegram prompt. Later messages reuse these sessions, so responses remain un-optimized for the rest of the session's lifetime. This means audit finding #9 from PLAN-085 is only partially fixed.

** Finding 4: Photo-only and document-only messages silently dropped
=createMessageHandler= in =bot.ts= gates on =ctx.message?.text= and passes to =next()= if text is absent. Messages containing only a photo or only a document never reach the bridge pipeline, even though =handleTelegramMessage= in =telegram-to-rpc.ts= already handles photo extraction (=collectImages=) and document extraction (=readDocumentContext=), including the fallback prompt "User sent an image without text."

* Sequencing: test-first
Write failing tests that demonstrate both defects *before* implementing the fixes. Implementation makes the tests pass.

* Fix (makes tests pass)

** Add =telegramPrompt= to =CommandContext=
The telegram prompt is already loaded once in =startBot()=. Instead of passing it as a separate parameter through =createMessageHandler=, add it to =CommandContext=:
#+BEGIN_SRC typescript
export interface CommandContext {
    config: TelegramBridgeConfig;
    processManager: ProcessManager;
    telegramPrompt: string;
}
#+END_SRC

In =startBot()=:
#+BEGIN_SRC typescript
const cmdCtx: CommandContext = {
    config,
    processManager,
    telegramPrompt,
};
#+END_SRC

** Simplify =createMessageHandler= signature
Change from =createMessageHandler(config, processManager, telegramPrompt)= to =createMessageHandler(cmdCtx: CommandContext)=. The handler body uses =cmdCtx.config=, =cmdCtx.processManager=, =cmdCtx.telegramPrompt= directly. Export the function for testing (used by BUG-092).

In =startBot=: =bot.use(createMessageHandler(cmdCtx))=

** Pass prompt in =respawnSession=
#+BEGIN_SRC typescript
await cmdCtx.processManager.getOrCreate(chatId, ctx.authState.userId, {
    project,
    mode,
    tools: resolveModeTools(mode),
    appendSystemPrompt: cmdCtx.telegramPrompt,
    sessionPath: existingSession?.sessionPath,
});
#+END_SRC

** Loosen message guard for attachments
Replace the text-only gate in =createMessageHandler=:
#+BEGIN_SRC typescript
const message = ctx.message;
if (!message) {
    await next();
    return;
}
// Skip commands
if (message.text?.startsWith("/")) {
    await next();
    return;
}
// Only process messages with text, photos, or documents
const hasContent = message.text || (message.photo && message.photo.length > 0) || message.document;
if (!hasContent) {
    await next();
    return;
}
#+END_SRC

Adjust logging: =messageLength: message.text?.length ?? 0=
