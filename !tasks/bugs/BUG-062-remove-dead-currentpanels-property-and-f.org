* Problem

Three related dead-code / correctness issues in =GrowthShell.qml=:

1. =property var currentPanels: []= (line 17) is assigned in the =workspace_layout= handler (line 193) but never read anywhere. =loadWorkspacePanel()= resolves panels entirely from the =workspaces= array + =panelRegistry=. The property misleads readers into thinking the TS layout payload drives panel loading.

2. The comment on line 194 says "TS may override layout -- re-resolve panels" but =loadWorkspacePanel()= ignores =currentPanels=. The comment is an outright lie. Since TS's =sendWorkspaceLayout= sends the exact same panel slots that the local workspace definition already has, this is fine. Remove the dead code and the misleading comment.

3. =iconFor()= creates a fresh JS object literal on every call. Not a performance issue at 6 calls, but wasteful. Hoist the map to a =property var iconMap= initialized once.

* Fix

In =domain/growth/src/qml/panels/GrowthShell.qml=:
- Remove =property var currentPanels: []=
- In the =workspace_layout= handler, remove =currentPanels = payload.panels=. Keep the =loadWorkspacePanel()= call but fix the comment to: "Acknowledge workspace_layout from TS"
- Add =property var iconMap: ({...})= initialized inline, change =iconFor= to read =iconMap[name]= instead of creating a new object

In =domain/growth/src/qml/panels/GrowthShellTestHarness.qml=:
- Mirror all above changes
