* Required design decisions to implement
1. Live streaming path and transcript rebuild path must consume the same normalized code-tool details contract.
2. `ToolExecutionComponent` must prefer structured code-tool details over reparsing arbitrary raw JSON text.
3. The code-tool renderer must show compact, semantically labeled output in both collapsed and expanded views while preserving access to richer diff/read detail when expanded.
4. New-session full cutover is allowed; do not keep old code-tool schema branches alive just for transcript replay.
5. If `session/messages.ts` or compaction serialization needs adjustments, keep the rule intact: `content` is model-visible, `details` is not. The fix location is the code-tool content contract, not a caller-side workaround.
