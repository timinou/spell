** Problem
~#exitPlanMode()~ in ~interactive-mode.ts~ updates ~planModeEnabled~, ~planModePaused~, and other flags but never calls ~this.#niriListener?.()~. The niri controller (~packages/niri/src/controller.ts~) only re-derives agent status and writes to ~~/.spell/status/<windowId>.json~ when the listener fires. Without the call, the DMS/QuickShell ~SpellStatusService~ (~~/.dotfiles/wm/quickshell/dms/Services/SpellStatusService.qml~) keeps polling the stale status file and the actionableCount/pendingApprovalCount never update.

Session events from tool/model restoration (~setActiveToolsByName~, ~setModelTemporary~) fire /before/ the flags are updated (lines 882-889), so the session subscribe callback computes the old status. The flags update on lines 893-894 with no subsequent notification.

- ~clearUserPaused~ correctly calls ~this.#niriListener?.()~ (line 1564)
