* Root Cause

=buildTransformedCodexRequestBody= in =packages/ai/src/providers/openai-codex-responses.ts= spreads =resolveOpenAICacheParams(options?.cacheRetention, options?.sessionId)= which returns:
#+begin_src typescript

#+end_src

The result flows through =transformRequestBody= in =packages/ai/src/providers/openai-codex/request-transformer.ts=, which normalizes the request for the chatgpt.com Codex endpoint. It already strips parameters not supported by that endpoint (=max_output_tokens=, =max_completion_tokens= — see lines 154-155). =prompt_cache_retention= needs the same treatment.

The =RequestBody= TypeScript interface (line 48) already declares =prompt_cache_retention?: "in_memory" | "24h"= — the type is correct and should remain. Only the runtime value must be stripped before transmission.
