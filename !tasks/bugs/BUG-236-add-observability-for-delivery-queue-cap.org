* Problem
When the delivery queue exceeds =MAX_PENDING_DELIVERIES= (200), oldest deliveries are silently discarded via =splice(0, excess)=. No log message is emitted and no state change is surfaced. The job record remains but the caller misses the completion notification, perceiving the result as lost. This happens in two places: =#enqueueDelivery()= (line 363-364) and the failed-delivery requeue path in =#runDeliveryLoop()= (lines 415-417).

** 2. Extract a shared helper for cap enforcement
Replace the duplicated splice logic in both =#enqueueDelivery()= (lines 363-364) and =#runDeliveryLoop()= (lines 415-417) with a shared helper:
#+begin_src typescript
#capDeliveryQueue(): void {
	if (this.#deliveries.length <= MAX_PENDING_DELIVERIES) return;
	const excess = this.#deliveries.length - MAX_PENDING_DELIVERIES;
	const dropped = this.#deliveries.splice(0, excess);
	const droppedJobIds = [...new Set(dropped.map(d => d.jobId))];
	for (const jobId of droppedJobIds) {
		const job = this.#jobs.get(jobId);
		if (job) job.deliveryDropped = true;
	}
	logger.warn("Delivery queue overflow: dropped oldest deliveries", {
		droppedCount: excess,
		droppedJobIds,
		queueSize: this.#deliveries.length,
	});
}
#+end_src
