* Problem
In =crates/pi-natives/src/grep.rs=, each =CollectedMatch= stores context lines in =SmallVec<[ContextLine; 8]>=. While the SmallVec starts inline (8 elements), it can grow to heap allocation without bound if large context windows are requested. For a search with 10k+ matches each with 50+ context lines, this can consume gigabytes.

* Solution
Cap the maximum context lines per match. The grep module already has =max_count= for limiting total matches, but there's no cap on context size per match.

* Design Decisions
- Hard cap of 50 lines for context_before and context_after per match
- This is a safety limit, not a user-facing config — most grep callers use 3-5 context lines
- If the caller requests more than 50 via the JS API, silently cap to 50
- Also validate context_before/context_after parameters at the NAPI boundary

* Files to Modify
- =crates/pi-natives/src/grep.rs= — Add max context validation in =MatchCollector= or the search parameters

* Specific Change
In the function that sets up context_before/context_after counts (likely where =SearchParams= is constructed from the NAPI options), clamp the values:

#+begin_src rust
const MAX_CONTEXT_LINES: usize = 50;

// When constructing SearchParams from JS options:
let context_before = options.context_before.unwrap_or(0).min(MAX_CONTEXT_LINES);
let context_after = options.context_after.unwrap_or(0).min(MAX_CONTEXT_LINES);
#+end_src

Find the exact location by searching for where =context_before= and =context_after= are parsed from the NAPI options object. The JS-side type is in =packages/natives/src/grep/types.ts=.

* Acceptance Criteria
- Context lines per match never exceed 50 (before + after independently capped)
- Existing grep functionality unchanged for normal use (3-5 context lines)
- =cargo test -p pi-natives= passes (existing grep tests)
- Memory usage is bounded for pathological inputs

* Testing
- Existing grep tests in =crates/pi-natives/src/grep.rs= should pass unchanged
- No new tests needed (this is a safety clamp, not user-facing behavior change)
