* Root Cause
The agent loop in ~packages/agent/src/agent-loop.ts~ runs ~while (true)~ with no turn or tool-call budget. The only exits are: model produces end_turn (no tool calls), error, or external abort.

The ~submit_result~ enforcement mechanism in ~executor.ts~ (lines 1129-1156) runs AFTER ~session.prompt(task)~ returns. But ~session.prompt~ delegates to the agent loop, which never returns if the model keeps producing tool calls in every turn.

In the observed session, a ~task~ subagent given a gap-analysis assignment made 97 tool calls over 12 minutes without converging. No timeout or budget stopped it.

** Observed in session
Session ~14aac2bfa1d2ab39~, subagent ~4-MetisAnalysis~ (agent type: ~task~). 97 tool calls (36 read, 30 grep, 13 find, 13 fetch, 5 web_search). Never called ~submit_result~. Session was manually aborted by user.
