* Context

=crates/pi-code-engine/build.rs= generates grammar modules from =node-types.json= files found in the cargo registry. The =find_node_types_json()= function (lines 111-151) scans =~/.cargo/registry/src/= for directories matching a package prefix and returns the FIRST match. If multiple versions of a grammar crate exist in the registry cache (e.g., =codebook-tree-sitter-typst-0.12.0= and =codebook-tree-sitter-typst-0.12.1=), the generated grammar rules may not match the version Cargo actually linked.

This affects ALL five grammar entries (typescript, rust, python, typst, elixir), not just Typst. The =GRAMMARS= array (lines 51-77) uses identical prefix-matching for all.

Grammar crates do not use =links= keys, so =DEP_*= environment variables are unavailable. No new build-dependencies are needed — the fix uses string parsing of =Cargo.toml=.

* Design

** 1. Add version extraction from Cargo.toml

Add a helper function that reads the dependency version spec from Cargo.toml:

#+begin_src rust
/// Extract the version spec for a dependency from Cargo.toml.
/// Handles both `name = "version"` and `name = { version = "..." }` forms.
fn dependency_version(dep_name: &str) -> Option<String> {
    let manifest_dir = env::var("CARGO_MANIFEST_DIR").ok()?;
    let cargo_toml = fs::read_to_string(Path::new(&manifest_dir).join("Cargo.toml")).ok()?;
    for line in cargo_toml.lines() {
        let trimmed = line.trim();
        if !trimmed.starts_with(dep_name) {
            continue;
        }
        let after_name = trimmed[dep_name.len()..].trim_start();
        if !after_name.starts_with('=') {
            continue;
        }
        // Extract the first quoted string (version spec)
        if let Some(start) = after_name.find('"') {
            if let Some(end) = after_name[start + 1..].find('"') {
                return Some(after_name[start + 1..start + 1 + end].to_string());
            }
        }
    }
    None
}
#+end_src

    let mut candidates: Vec<std::path::PathBuf> = Vec::new();

    for entry in entries.flatten() {
        // ... existing nested loop ...
        if name_str.starts_with(grammar.package_prefix) {
            let candidate = crate_entry.path().join(grammar.json_subpath);
            if candidate.exists() {
                // If we have a version spec, check if directory name matches
                if let Some(ref spec) = version_spec {
                    let dir_version = &name_str[grammar.package_prefix.len()..];
                    if dir_version == spec.as_str() || dir_version.starts_with(&format!("{spec}.")) {
                        // Exact or compatible match — use immediately
                        return Ok(candidate);
                    }
                }
                candidates.push(candidate);
            }
        }
    }

    // Fallback to first candidate (existing behavior)
    candidates.into_iter().next().ok_or_else(|| format!(
        "node-types.json not found for {} (searched {})",
        grammar.name, registry_src.display()
    ))
}
#+end_src

The version matching logic:
- Extract the version suffix from the directory name (everything after the prefix)
- Compare against the Cargo.toml version spec
- Exact match (e.g., ="0.12.1"= matches directory =codebook-tree-sitter-typst-0.12.1=) → use immediately
- Compatible match (e.g., ="0.23"= matches =tree-sitter-typescript-0.23.2= because ="0.23.2".starts_with("0.23.")=) → use immediately
- No match → fall back to first candidate (graceful degradation)
