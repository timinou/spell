* Scope
Test: test/modes/components/subagent-viewer/viewer-component.test.ts "forwards tool events to event handler" (and related tests in the file) crash with:
#+BEGIN_EXAMPLE
TypeError: undefined is not an object (evaluating 'theme.bold')
#+END_EXAMPLE

Root cause: `src/modes/theme/theme.ts:1689` declares `export var theme: Theme;` without assignment. It is populated only by `initTheme()` / `setThemeInstance()` during app startup. `src/modes/components/subagent-viewer/viewer-component.ts:15` imports that bare binding. Tests never call `initTheme()`, so `theme` is `undefined` at render time.

Settled design: remove the module-level import and inject theme through the component's existing `SubagentViewerContext` DI seam. This eliminates the bug class, not just the symptom.

In scope:
- Add `theme: Theme` to `SubagentViewerContext` in `src/modes/components/subagent-viewer/types.ts`.
- Remove `import { theme } from "../../theme/theme"` from `viewer-component.ts`; use `this.#ctx.theme` instead.
- Update the sole production caller of `SubagentViewerComponent` to pass the current theme.
- Update the test to pass a theme (e.g. via `getThemeByName("dark")`).

Out of scope: remove `export var theme` from `theme.ts` \u2014 many other components still depend on it; converting them is a larger refactor.
