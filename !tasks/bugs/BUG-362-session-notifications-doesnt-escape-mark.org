* Reproduction
In ~packages/spell-server/src/telegram/session-notifications.ts~,
~formatBlockingEventNotification~ builds caption lines that interpolate session
titles, project paths, and (for plan_approval) ~planSummary~ without escaping.

Telegram's ~Markdown~ / ~MarkdownV2~ parse modes treat ~* _ ` [~ as formatting
characters; raw titles containing them either break the message (~"Bad Request:
can't parse entities"~) or silently mis-render.

2. Trigger any ~ask~ / ~plan_approval~ event.
3. Telegram returns 400 OR message renders with collapsed formatting.

* Expected
Caption renders the title literally, with special chars escaped per the active parse mode.
