* Root cause
- =crates/pi-natives/src/code_path/marshal.rs::stage_artifact= externalises image bytes for
  =Content::Image= when len > 256 KiB, emitting =artifact_uri= inside =ContentDto=.
- =packages/coding-agent/src/tools/codepath-result.ts::extractImages= leaks the URI into
  =ImageContent.data= via =content.value ?? content.artifactUri=.
- =packages/ai/src/providers/anthropic.ts::convertContentBlocks= passes =data= verbatim into
  =source.base64.data=.
- No JS resolver exists for =artifact://blobs/code-path/*= URIs.

* Scope
Producer-side fix only. Defense-in-depth handled by sibling BUG.

- =crates/pi-natives/src/code_path/marshal.rs=

* Acceptance
- =Content::Image { bytes: Some(_) }= always produces inline base64; never =artifact_uri=.
- =extractImages= never emits image block whose =data= is a URI or empty.
- Bytes that do not match a supported image format → downgrade to =extracted_text= with diagnostic.
