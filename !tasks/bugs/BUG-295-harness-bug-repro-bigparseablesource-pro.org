- "blocks ~97% shrink of an existing code-supported file on disk" \u2014 writes big source, then attempts to shrink it. Currently passes because the shrink check fires before the parse check.

Both will continue to work with a valid TS fix because the content will still be >~89KB (above the 256B shrink-guard floor) and parseable.
