* Cause

=packages/ai/src/utils/idle-iterator.ts:52=

#+begin_src ts
const DEFAULT_TOOL_ARGUMENT_STREAM_IDLE_TIMEOUT_MS = 180_000;
#+end_src

180s is too short for legitimate model behavior on long tool-arg payloads (large file content, big diffs, multi-thousand-token JSON). Opus-4 with extended thinking + heavy context routinely pauses 2–5 minutes between input_json_delta events while doing internal generation. This default fires the watchdog on healthy connections.

The =PI_TOOL_ARGUMENT_STREAM_IDLE_TIMEOUT_MS= env knob exists but is undocumented and the surfaced error message doesn't mention it.

NB: this fix is independent of BUG-350 (ping handling); both are needed because real silence between deltas can still exceed any reasonable threshold.

* Fix

1. Raise =DEFAULT_TOOL_ARGUMENT_STREAM_IDLE_TIMEOUT_MS= to 600_000 (10 min). Empirical evidence shows opus-4 long-content tool calls fit in this window when the connection is healthy (BUG-350 pings + this).
2. Surface the override in the diagnostic error message: append "Override with PI_TOOL_ARGUMENT_STREAM_IDLE_TIMEOUT_MS=<ms> or =0= to disable." to =formatToolCallStreamDiagnosticMessage= when the diagnostic is =stalled_incomplete_tool_args=.

* Acceptance

- Diagnostic message tells the user how to override it
- Test asserting default value
- Test asserting message content for stalled_incomplete_tool_args
