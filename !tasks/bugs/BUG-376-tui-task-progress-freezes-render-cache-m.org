* Scope

In:
- (1) Add a periodic heartbeat in =runSubprocess= (=packages/coding-agent/src/task/executor.ts=) so subagent =progress= forwards to the parent even when no =AgentEvent= arrives. Today =scheduleProgress= only fires from event handlers, so a long-running child tool (bash sleep, slow read) leaves the parent stuck on the last partial.
- (3) Include the live =progress= content signature in the =renderResult= cache key (=packages/coding-agent/src/task/render.ts=) so the cached lines actually reflect freshness of =progress[].durationMs= / =status= / =toolCount= / =tokens= / =currentTool= when the heartbeat ticks. Today the key only mixes =expanded=, =isPartial=, =spinnerFrame=, =width=; that means any future caller that reuses a renderer across content changes (or any time-dependent read inside the renderer) silently serves stale lines.
- (4) Change the default =subagentViewer= binding from =ctrl+tab= to =alt+j= (=packages/coding-agent/src/config/keybindings.ts=). Ghostty's default bindings consume =ctrl+tab=/=ctrl+shift+tab= for tab cycling, so the kitty CSI-u sequence =\x1b[9;5u= never reaches Spell.

Out:
- Scroll-on-update behavior in normal screen buffer (filed elsewhere if approved).
- Niri overview frame throttling (filed elsewhere if approved).
- Any change to the keybinding parser, kitty negotiation, or terminal layer.
- Any change to the eventBus or session stream contract.

Rationale:
- Repo evidence (=packages/coding-agent/src/task/executor.ts:894-916=): =scheduleProgress= only runs from inside =processEvent= / =processSessionEvent= / final =scheduleProgress(true)= after =runSubagent= returns. No timer drives it.
- Repo evidence (=packages/coding-agent/src/task/render.ts:524-528=): cache key omits =details.progress=, =progress.durationMs=, =progress.status=, =progress.currentTool=.

* Existing Patterns

* Tests

Workflows the new tests must lock:
1. Heartbeat: while a subagent is running and emitting no events, the parent =onProgress= callback still receives ticks at a bounded interval (e.g. <=600ms).
2. Heartbeat: heartbeat stops once the subagent run resolves (no leaked interval after completion / abort).
3. Heartbeat: heartbeat shares the existing 150ms coalescer (does not produce extra emissions back-to-back with real events).
4. Render cache: =renderResult= produces different output for two distinct =details.progress= snapshots that share the same =(expanded, isPartial, spinnerFrame, width)= options.
5. Render cache: =renderResult= still hits its cache (no recompute) for two consecutive renders with identical options *and* identical progress signature.
6. Keybindings default: =DEFAULT_APP_KEYBINDINGS.subagentViewer === "alt+j"=.
7. Keybindings display: =KeybindingsManager.inMemory({}).getDisplayString("subagentViewer")= reflects the new default.

* Edge Cases

- Heartbeat must not fire after subprocess resolution; otherwise the post-completion =scheduleProgress(true)= at the bottom of =runSubprocess= races against a stale tick.
- Heartbeat must coexist with =PROGRESS_COALESCE_MS=: it must not bypass coalescing, since real events should still take priority and back-to-back emits would amplify cost in nested =task= batches.
- Cache key extension must not be sensitive to incidental ordering differences in =details.progress= (the producer sorts by =index= already; tests should encode that invariant rather than rely on it).
- Cache key must remain stable when only =Date.now()=-derived data changes within the same =durationMs= bucket (avoid per-frame recompute storm when nothing else changed).
- Keybinding change must not collide with another configured =alt+j= binding; grep the config tree before landing.
- If a user has already pinned =subagentViewer: ctrl+tab= in their kdl, the user-config still wins; the change is to the *default* only.

* Acceptance Criteria

- Subagents that go silent for >1s still produce visible progress ticks on the parent (durationMs advances).
- =renderResult= cache invalidates when progress content changes and continues to cache-hit when it does not.
- =ctrl+tab= is no longer the default; =alt+j= opens the subagent viewer out of the box.
- All new and existing tests pass.
