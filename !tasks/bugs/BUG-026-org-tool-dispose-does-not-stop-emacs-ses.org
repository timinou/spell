* Initial Message

Yo bro are emacs sessions properly disposed of at the end of all spell sessions regardless of the exist mode?

The org tool's =dispose()= (=packages/org/src/tool.ts:890=) only nulls the promise references:

#+begin_src typescript
async dispose() {
    emacsSessionPromise = null;
    orgClientPromise = null;
}
#+end_src

It never calls =session.stop()= on the resolved =EmacsSession=. This means the org Emacs daemon (=spell-org-*=) never receives a graceful =kill-emacs= through the normal =session.dispose()= → =#disposeTools()= chain.

The org daemon has direct =process.on("exit"/"SIGINT"/"SIGTERM")= handlers as a fallback, but those call =proc.kill()= which is ineffective after =--daemon= fork (see sibling item).

* Affected files
- =packages/org/src/tool.ts= — fix =dispose()= method

* Fix
In =dispose()=, if =emacsSessionPromise= has resolved, await it and call =.stop()= on the session. Handle the case where the promise is still pending (race).

#+begin_src typescript
async dispose() {
    const sessionPromise = emacsSessionPromise;
    emacsSessionPromise = null;
    orgClientPromise = null;
    if (sessionPromise) {
        try {
            const session = await sessionPromise;
            await session.stop();
        } catch {
            // Session may have already died or never started
        }
    }
}
#+end_src
