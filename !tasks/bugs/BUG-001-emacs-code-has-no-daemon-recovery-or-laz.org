* Implementation

** New file: packages/emacs/src/session-manager.ts
EmacsSessionManager class:
- Constructor takes: emacsPath, projectRoot, sessionId (the same params warmupEmacs takes)
- getSession(): Promise<EmacsSession | null> — the lazy factory:
  1. Fast path: if #session is non-null and isAlive(), return it
  2. If #session exists but !isAlive(): clear it, fall through to restart
  3. If circuit breaker is tripped (N failures within cooldown): return null, log once
  4. Attempt startEmacsSession() with stored params
  5. On success: store session, reset failure count, return session
  6. On failure: increment failure count, log, return null
- setSession(session): void — allows SDK warmup to inject pre-started session
- dispose(): Promise<void> — stops daemon and clears state

Circuit breaker config:
- MAX_CONSECUTIVE_FAILURES = 3
- COOLDOWN_MS = 60_000 (1 minute after 3 failures)
- After cooldown expires, reset and allow another attempt
