* Problem

Two test gaps identified in AUD-051 after PLAN-169 (caveman thinking prompt positioning fix):

1. No test covers =cavemanActive=true= + =cavemanThinking=false= — if future template logic
   accidentally keys =<thinking-mode>= off =cavemanActive= instead of =cavemanThinking=, the
   suite wouldn't catch it.

2. No composition-level test exercises the real =buildSystemPrompt= path. The existing tests
   render individual templates in isolation. If prompt assembly in =system-prompt.ts= changes
   (e.g., =appendPrompt= reintroduces thinking instructions), the isolated template tests
   would still pass.

* Implementation

** Fix 1: Template-level flag isolation test

Add inside the existing =describe("system Handlebars prompt templates")= block, after the
existing caveman tests (after the test ="caveman template does not contain thinking
instructions"= at ~line 229):

#+begin_src typescript
test("system-prompt omits thinking-mode when cavemanActive but cavemanThinking is false", async () => {
    const templatePath = path.join(systemPromptsDir, "system-prompt.md");
    const template = await Bun.file(templatePath).text();

    const rendered = renderPromptTemplate(template, {
        ...baseRenderContext,
        cavemanActive: true,
        cavemanThinking: false,
    });

    expect(rendered).not.toContain("<thinking-mode>");
});
#+end_src

This verifies the template keys on =cavemanThinking=, not =cavemanActive=. The scenario is
real: =cavemanActive=true= with =thinkingMode="normal"= produces =cavemanThinking=false=
(see =system-prompt.ts= line 513: =cavemanThinking: cavemanThinkingMode === "caveman" && cavemanActive=).

#+begin_src typescript
describe("caveman prompt composition", () => {
    test("buildSystemPrompt places thinking instructions in stable block only", async () => {
        const blocks = await buildSystemPrompt({
            settings: Settings.isolated({
                "caveman.defaultLevel": "full",
                "caveman.thinkingMode": "caveman",
            }),
            contextFiles: [],
            skills: [],
            rules: [],
        });

        const stableBlock = blocks.find(b => b.stable);
        const dynamicBlock = blocks.find(b => !b.stable);

        expect(stableBlock).toBeDefined();
        expect(stableBlock!.text).toContain("<thinking-mode>");
        expect(stableBlock!.text).toContain("PhD-caveman");
        expect(stableBlock!.text).toContain("EVERY thinking block MUST");

        if (dynamicBlock) {
            expect(dynamicBlock.text).not.toContain("thinking-mode");
        }
    });

    test("buildSystemPrompt omits thinking instructions when thinkingMode is normal", async () => {
        const blocks = await buildSystemPrompt({
            settings: Settings.isolated({
                "caveman.defaultLevel": "full",
                "caveman.thinkingMode": "normal",
            }),
            contextFiles: [],
            skills: [],
            rules: [],
        });

        const allText = blocks.map(b => b.text).join("");
        expect(allText).not.toContain("<thinking-mode>");
    });
});
#+end_src

** Existing patterns to follow
