* Goal

Fix ~StatusFileWriter.writeIfChanged()~ so that changes to recovery metadata (~sessionId~, ~sessionFile~, ~cwd~, ~workspaceName~) force a re-write even when the status and session title have not changed.

* Context

The dedup key is currently ~`${status}\0${sessionTitle}`~. Recovery metadata is set via separate ~setSessionInfo()~ and ~setWorkspaceName()~ calls that happen asynchronously after the first write (e.g., after niri workspace query completes). If the first write fires before metadata is available, subsequent writes with identical status/title are silently skipped, leaving the status file permanently incomplete. ~spell recover~ then skips the session or loses its workspace assignment.

* Design Decision

Add a ~#metadataVersion~ counter (starts at 0) that increments each time ~setSessionInfo()~ or ~setWorkspaceName()~ is called. Include it in the dedup key: ~`${status}\0${sessionTitle}\0${this.#metadataVersion}`~. This forces a re-write whenever metadata changes, without changing the ~writeIfChanged~ signature or adding complexity to callers.

it("re-writes when recovery metadata is set after initial write", async () => {
    const writer = new StatusFileWriter(TEST_DIR);
    writer.setWindowId(50);

    // First write — no metadata
    writer.writeIfChanged("running", "myapp", "session-1");
    await Bun.sleep(50);

    let data = await Bun.file(path.join(TEST_DIR, "50.json")).json();
    expect(data.sessionId).toBeUndefined();

    // Set metadata — same status/title
    writer.setSessionInfo({
        sessionId: "sess-50",
        sessionFile: "/tmp/sess-50.jsonl",
        cwd: "/work/myapp",
    });
    writer.writeIfChanged("running", "myapp", "session-1");
    await Bun.sleep(50);

    data = await Bun.file(path.join(TEST_DIR, "50.json")).json();
    expect(data.sessionId).toBe("sess-50");
    expect(data.cwd).toBe("/work/myapp");
});

it("re-writes when workspace name is set after initial write", async () => {
    const writer = new StatusFileWriter(TEST_DIR);
    writer.setWindowId(51);

    writer.writeIfChanged("running", "myapp", "session-1");
    await Bun.sleep(50);

    let data = await Bun.file(path.join(TEST_DIR, "51.json")).json();
    expect(data.workspaceName).toBeUndefined();

* Edge Cases

- ~setSessionInfo~ called multiple times (e.g., session renames): each call increments the counter, so each triggers a re-write. This is correct — the latest metadata should always be persisted.
- Counter overflow: ~Number.MAX_SAFE_INTEGER~ is unreachable in practice (would require ~9e15 metadata changes in a single session).
