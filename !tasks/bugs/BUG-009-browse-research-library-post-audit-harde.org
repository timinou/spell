** Fix 1: normalizeUrlForDedup drops port (TS)

** Fix 2: QML normalizeUrl diverges from TS normalizeUrlForDedup
- File: ~packages/coding-agent/src/modes/qml/panels/FindingsPanel.qml~ lines 52-66
- Two divergences:
  1. QML lowercases entire URL including path. TS preserves path case. Case-sensitive paths like ~/API/v1~ vs ~/api/v1~ treated differently
  2. QML strips trailing slash from end of entire string. TS strips from ~pathname~ before appending ~search~. For ~https://example.com/path/?q=1~: TS → ~https://example.com/path?q=1~, QML → ~https://example.com/path/?q=1~
- Fix: rewrite QML normalizeUrl using regex to extract scheme, host (with port), path, query. Lowercase only scheme+host. Strip trailing slash from path only. Reassemble

** Fix 3: findingsCount drifts from actual unique findings
- File: ~packages/coding-agent/src/modes/qml/BrowseShell.qml~
- Bug: ~findingsCount~ incremented on every message (lines 388, 399, 195) including dedup merges and restores. Never corrected
- Fix: remove ~findingsCount += 1~ increments. After forwarding to findings panel, read back actual count via ~Qt.callLater~:
  #+begin_example
  forwardToFindingsPanel(payload)
  Qt.callLater(function() {
      var panel = getFindingsPanelItem()
      if (panel) findingsCount = panel.findingCount()
  })
  #+end_example
- Apply in all three locations: ~type: "finding"~ handler, ~findings_batch~ handler (after loop), ~restoreFindingsFromState~ (after loop)

** Fix 4: SearchGroupDelegate parseSources() called redundantly
- File: ~packages/coding-agent/src/modes/qml/panels/delegates/SearchGroupDelegate.qml~
- Performance: ~JSON.parse(sourcesJson)~ invoked ~57 times for 10 expanded sources
- Fix: cache in ~property var cachedSources: []~, update on ~onSourcesJsonChanged~ and ~Component.onCompleted~. Replace all ~parseSources()~ calls with ~root.cachedSources~. Delete ~parseSources()~
