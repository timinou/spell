* Context

W2 (`beam/ptc_runner-vendored/lib/ptc_runner/lisp/handle_store.ex`) parks any tool
result > 256KB (`@handle_park_bytes 262_144`) into two kinds of bucket:
- exec-scoped buckets — released at execute teardown (fine).
- a PERSISTENT session bucket `@session_bucket :__session_bindings__` — created by
  W3 session bindings (`rehome/3`, `put`) and *never released*.

W3 also grows `PtcRuntime.Peer` `State.memory` (a `%{}` map) by one entry per
`(def x v)` across the whole session.

Today sessions are short ⇒ tolerable. Two forces make it fatal:
1. D-3 "execute as the sole tool lane" → far more, longer-lived programs.
2. **W4 unattended re-execution** (FEAT, sibling item) → a stored dashboard/rollup
   tile re-running every tick parks a handle EVERY tick, none reaped. Slow leak →
   GUARANTEED unbounded growth. This is why the reaper is a HARD prereq for W4-read.

Error class: this is "alive-and-scary #2 — resource-leak under sole-lane" from the
execute substrate analysis (specs/beam-orchestrator/07-execute-substrate-status.md).

* Fix

A reaper over the *session-lifetime* stores (NOT the exec buckets — those already
release):
- Eviction policy in `handle_store.ex` for `@session_bucket`: LRU keyed by
  last-access, bounded by a configurable ceiling. Reuse the existing settings family
  — add `tools { execute session-store-mb=N }` mirroring `execute max-heap-mb`
  (FEAT-791 precedent: `resolveMaxHeapWords` in execute.ts; thread mb→bytes once at
  the Node boundary, clamp in peer.ex). Default conservative (e.g. 64MB).
- Bound `Peer State.memory` the same way (evict oldest binding when the session
  store exceeds ceiling).
- Evicted binding semantics (per D-6: bindings are a CACHE, never durable truth):
  reading an evicted `bind/<key>` must FAIL LOUD with a typed value
  `{"err" => "binding <key> evicted (session store ceiling); re-run to rebind"}`,
  NOT `memory_exceeded`, NOT a stale value, NOT a silent nil.
- Touch-on-access: every projection/read of a session handle updates its LRU stamp,
  so a hot binding survives and a cold one is the eviction victim.
