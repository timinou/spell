* Problem
=execute_code_buffer= in =crates/pi-natives/src/code_buffer.rs= uses ~30 error sites that convert errors via =engine_err= / =json_err= + =?= operator, causing NAPI to throw JS exceptions. The TypeScript =CodeTool.execute()= has two error paths:
- =if (result.error)= — structured error with command/file/cwd context (good path)
- =catch (err)= — generic fallback with just the error message (fragile path)

All operational errors (LanguageNotFound, file too large, binary file, missing field, unknown operation) route through the fragile path. This creates inconsistent error handling and makes the agent-facing error messages less useful.

* Design Decisions
1. Extract the body of =execute_code_buffer= into a private =execute_code_buffer_inner= function
2. The outer =execute_code_buffer= calls =_inner= and converts any =Err= to =Ok(json_response(json!(e.to_string()), true))=
3. Zero changes to internal =?= operators — they all continue working as before
4. The TypeScript =catch= block remains as a safety net for truly unexpected errors (panics, etc.) but should never fire for operational errors

*** Wrap with error-to-envelope converter

The NAPI-exported function becomes:

#+begin_src rust
#[napi(js_name = "executeCodeBuffer")]
pub fn execute_code_buffer(options: Value) -> Result<Value> {
    match execute_code_buffer_inner(&options) {
        Ok(value) => Ok(value),
        Err(e) => Ok(json_response(json!(e.to_string()), true)),
    }
}
#+end_src

This means =execute_code_buffer= can NEVER return =Err= / throw a JS exception for operational errors. Every error becomes a structured =\{ output: "error message", error: true \}= response.

Note: the inner function takes =&Value= (borrow) since the outer function owns the =Value=.

** Add Rust test

In the existing =mod tests= block in =code_buffer.rs=, add a test that calls =execute_code_buffer= directly (not through NAPI) for a file with an unsupported extension. The test needs a temp file with e.g. =.md= extension:

#+begin_src rust
#[test]
fn unsupported_language_returns_error_envelope() {
    let dir = tempfile::tempdir().expect("tempdir");
    let md_file = dir.path().join("readme.md");
    fs::write(&md_file, "# Hello").expect("write");
    let result = execute_code_buffer(json!({
        "command": "read",
        "file": md_file.to_str().unwrap()
    })).expect("should not throw");
    assert_eq!(result["error"], true);
    let output = result["output"].as_str().unwrap();
    assert!(output.contains("language not found"), "expected LanguageNotFound error, got: {output}");
}
#+end_src
