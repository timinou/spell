* Initial Message

Documented recipe =foo.ts::§symbol= and predicate =[kind="method"]= both return no-match. The kernel actually requires raw tree-sitter grammar kind names — =§function_declaration= (TS), =§function_item= (Rust), =§function_definition= (Python). Cross-language queries are impossible; agents must know per-language grammar vocabulary.

* Root Cause

=crates/pi-natives/src/code_path/code_resolver/walker.rs:442=:
#+begin_src rust

#+end_src

Direct tree-sitter =node.kind()= equality. No alias layer, no per-dialect translation.
