* Problem
In =packages/ai/src/providers/cursor.ts= (lines 128-129), two module-level Maps grow indefinitely:

#+begin_src typescript
const conversationStateCache = new Map<string, ConversationStateStructure>();
const conversationBlobStores = new Map<string, Map<string, Uint8Array>>();
#+end_src

Each unique =conversationId= adds entries that are never evicted. In long-running sessions with conversation branching or tool testing, this accumulates hundreds of MB. There is no TTL, no max size, and no cleanup on session end.

* Solution
Add LRU-style eviction with a maximum cache size. When the cache exceeds the limit, evict the oldest entries.

* Design Decisions
- Max 20 conversation states cached (each state can be large with protobuf data)
- Max 20 blob stores cached
- Use simple eviction: when inserting a new entry and size > max, delete the oldest entry (first key in Map iteration order, since Map preserves insertion order)
- No external LRU dependency — use Map's insertion order + manual eviction
- When evicting a conversation state, also evict its corresponding blob store (and vice versa)

* Files to Modify
- =packages/ai/src/providers/cursor.ts= — Add eviction logic to the cache set operations

* Specific Changes

Add a helper function:
#+begin_src typescript
const MAX_CONVERSATION_CACHE = 20;

function evictOldest<K, V>(map: Map<K, V>, maxSize: number): void {
    while (map.size > maxSize) {
        const oldest = map.keys().next().value;
        if (oldest !== undefined) {
            map.delete(oldest);
        } else {
            break;
        }
    }
}
#+end_src

After each =conversationStateCache.set()= call, add =evictOldest(conversationStateCache, MAX_CONVERSATION_CACHE)=.
After each =conversationBlobStores.set()= call, add =evictOldest(conversationBlobStores, MAX_CONVERSATION_CACHE)=.

Also add cleanup of the matching cache when evicting from either:
#+begin_src typescript
function evictConversationCaches(): void {
    evictOldest(conversationStateCache, MAX_CONVERSATION_CACHE);
    evictOldest(conversationBlobStores, MAX_CONVERSATION_CACHE);
}
#+end_src
