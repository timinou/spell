The ChatDrawer at the bottom of GrowthShell renders in collapsed state (56px) but:
1. It blends into the dark background and looks like a window decoration
2. Even when expanded, it shows "No active agents" because no =agent_tabs_update= messages are sent
3. The chat input field has no wiring — messages sent via =bridge.send= go nowhere meaningful

* Root Cause

The ChatDrawer is a standalone QML component (=domain/growth/src/qml/panels/ChatDrawer.qml=) that:
- Expects =agent_tabs_update= messages to populate tabs — these are never sent by =qml-mode.ts=
- Has a chat input that sends ={ type: 'chat_message', text, agentId }= — but =qml-mode.ts= only handles ="prompt"=, ="abort"=, ="steer"=, ="workspace_switch"=, and ="restart"= events
- The collapsed bar is a 56px rectangle with 12px "Chat" text in =#9CA3AF= on =#1F2937= — barely visible

The =GrowthShellTestHarness.qml= replaced the ChatDrawer entirely with a static 56px rectangle, confirming it was never tested interactively.

* Fix

1. **Visibility**: Increase visual prominence of collapsed state:
   - Slightly lighter background or top border accent
   - Larger "Chat" label with an icon

2. **Message routing**: Map ChatDrawer's =chat_message= events to the session's =prompt= action in =qml-mode.ts=:
   - In =processQmlEvents=, add a =chat_message= case that calls =session.prompt(payload.text)=

3. **Agent status**: Wire =agent_start/agent_end= session events to ChatDrawer:
   - Send =agent_tabs_update= messages when agent state changes
   - At minimum, a single "Agent" tab that shows busy/idle

4. **Streaming responses**: Forward agent text output to the ChatDrawer:
   - Send =chat_response= messages as the agent streams
   - ChatDrawer needs a text area to display responses (currently missing)

Note: Items 3-4 are larger scope. Minimum viable fix is items 1-2.
