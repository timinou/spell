* Scope
- In-scope: Bash transcript-spelunking output from `transcript-spelunking`-matched commands (e.g. `jq`, `sed`, `head`, `tail`, `cat`, `awk`, `python3`, `ruby`) executed via `bash`.
- In-scope: keep context-pressure policy but allow call-site opt-in to return a bounded output chunk instead of a forced summary when the caller sets chunk controls.
- Out-of-scope: changing suppression behavior for non-transcript read/grep commands and changing default `read`/`grep` context-pressure rules.

* Existing Patterns
- `packages/coding-agent/src/tools/context-pressure-policy.ts`: central `classifyContextPressure` drives high-noise policy, with `ContextPressureMeta` fields `{category,presentation,persistence,summary}`.
- `packages/coding-agent/src/tools/bash.ts`: `head` and `tail` already exist as tool arguments and are applied post-exec via `applyHeadTail`.
- `packages/coding-agent/test/tools/bash-churn-policy.test.ts`: existing regression suite for high-noise bash output contract.
- `packages/coding-agent/test/tools/context-pressure-policy.test.ts`: policy fixture suite validating presentation/persistence combinations.
- `packages/coding-agent/src/prompts/tools/bash.md`: tool-call guidance surfaced to models.

* Tests
- Contract T1: Transcript bash commands without chunk options remain compact (existing behavior).
  - File: `packages/coding-agent/test/tools/context-pressure-policy.test.ts`
  - Scenario: `classifyContextPressure({toolName:'bash', params:{command:'jq "." /tmp/sess.jsonl'}})` returns `category='transcript-spelunking'`, `presentation='summary-first'`, `persistence='deny-raw'`.
- Contract T2: Transcript bash commands with explicit chunk options are allowed to return raw chunk payloads.
  - File: `packages/coding-agent/test/tools/context-pressure-policy.test.ts`
  - Scenario: same command with `{head: 25}` returns `persistence='allow-raw'` and `presentation='inline'`.
- Contract T3: Tool execution applies chunk options to suppress summary-first replacement.
  - File: `packages/coding-agent/test/tools/bash-churn-policy.test.ts`
  - Scenario: command `printf 'a
b
c
' | sed -n '1,10p'` with `head: 2`; assert output is chunked and not summary text.
