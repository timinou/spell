Out of scope:

Rationale:
- Current `BashTool.execute()` computes the full raw result text, then overwrites the visible tool-result content with `contextPressure.summary` whenever persistence is not `allow-raw`.
- The repo already has separate downstream mechanisms for compact reinjection and memory-safe persistence (`createMemorySafeToolResult()` and `getPrunedToolResultContent()`), so replacing the visible result is unnecessary coupling.
- The current behavior lies about command execution to operators: a real `mix test`/`bun test` result exists, but the user only sees the synthetic wrapper sentence.
