* Problem
~applyOrgLifecycleHooks~ in ~packages/coding-agent/src/tools/todo-write.ts~ catches org transition errors and logs them via ~logger.error~, but never pushes a notice to the ~notices~ array. The agent sees ~INFO: Org item X auto-transitioned to DOING~ on success, but gets no feedback when the org item is missing or the transition fails. The error is silently swallowed.

This was identified in PLAN-066 (FEAT-175) and claimed addressed by PLAN-068, but the ~catch~ blocks at lines 336-341 and 354-359 still only call ~logger.error~ without pushing a warning notice.

* Scope
- File: ~packages/coding-agent/src/tools/todo-write.ts~
- In ~applyOrgLifecycleHooks~, push a ~WARN:~ notice in each ~catch~ block alongside the ~logger.error~ call
- Example: ~notices.push(\`WARN: Failed to transition org item \${task.orgItemId} to DOING: \${error.message}\`)~
- Also push a notice when ~transitionOrgItemIfNeeded~ returns ~false~ for a missing item (the ~findItemById~ returning null path)
