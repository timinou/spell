* Context
The ~/audit~ slash command crashes with an unhandled ~AgentBusyError~ when invoked while the agent is streaming. The crash happens because ~handleAuditCommand()~ in ~interactive-mode.ts~ calls ~session.prompt()~ without the ~streamingBehavior~ option that ~prompt()~ requires when ~isStreaming~ is true.

The fix adds a streaming guard before any state mutation, matching the pattern used in ~input-controller.ts~. Warn-and-bail is preferred over followUp queueing because the followUp path hardcodes ~role: "user"~ while audit prompts require ~synthetic: true~ (→ ~role: "developer"~).
