* Context

** Problem
The agent has a reusable browser component (SpellBrowser.qml) and standalone BrowserWindow.qml in the QML stdlib, but no integrated browser experience where the user can watch the agent work in real time. The existing ~--canvas chat~ mode has no browser integration, and the ChatPanel's visual quality is below expectations (basic bubbles, poor reactivity, no structured content types).

** Approach
Create a new ~spell --canvas browse~ mode that launches a dedicated browser-first shell with:
- Tab bar across the top: Chat tab (default view) + dynamic browser tabs the agent opens
- Below the tab bar: active content fills the space (chat or live browser view)
- Linear/Notion-inspired ultra-minimal chat design with flowing text, no bubbles
- Research-specific 'finding' cards inline in chat with URL, title, excerpt, 'view in tab' action
- Collapsible findings accumulator panel for all research results
- Tab persistence across sessions via ~--resume~

** Key Design Decisions
- New top-level ~BrowseShell.qml~ (like FluidShell.qml), NOT a panel inside shell.qml — the layout is incompatible with shell.qml's panel-switcher model
- New ~BrowseChatPanel.qml~ with new Flow delegates — existing ChatPanel.qml and delegates are untouched to preserve ~--canvas chat~ stability
- ~BrowseEventMapper~ extends ~SessionEventMapper~ with finding/tab event hooks
- Tab lifecycle commands (~tab:open/close/list/switch~) added to the browser protocol alongside ~browser:*~ commands
- Optional ~tabId~ field on all ~browser:*~ commands (defaults to active tab)
- Shared WebEngineProfile across all browser tabs for cookie consistency
- Findings created via hybrid approach: agent sends 'finding' custom message with structured data
- Cross-component 'view in tab': finding card -> bridge event -> browse-mode.ts -> tab:switch command

** Showcase Use Case
Research assistant: user says "research X", agent opens browser tabs, navigates sites, extracts content, surfaces findings as styled cards in chat, user can click any tab to watch the agent work or click a finding to jump to its source tab.
