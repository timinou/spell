2. Phase→Group is a full rename using LSP + ast_edit, touching ~25 source files and ~12 test files. Schema keeps =phases= as a backward-compat alias.
3. Blocker resolution gets an optional context parameter with backward-compatible default.
4. Fluid-mode gets a SwarmScheduler pump loop for multi-task plans. Simple plans (≤2 tasks) keep the single-agent prompt chain.
5. Scheduler tests add 3 cases for live mutation and multi-level cascade.
