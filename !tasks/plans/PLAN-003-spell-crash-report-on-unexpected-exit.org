Why did it crash every time after make dev?

* Context

When spell crashes (uncaught exception, unhandled rejection, native SIGSEGV), the process exits and the terminal returns to prompt. The user has no actionable diagnostic information — no crash report, no pointer to logs, no session context. Investigating requires manually grepping =~/.spell/logs/= and correlating timestamps with session JSONL files.

The existing infrastructure is close but not wired together:
- =postmortem.ts= handles signals and fatal exceptions, runs cleanup, writes to stderr and log
- =report-bundle.ts= can create full diagnostic archives but only via manual =/debug= menu
- =system-info.ts= collects OS/arch/CPU/memory/versions
- Session state (ID, file, CWD, model) is available at runtime via =SessionManager=
- None of this is captured automatically on crash

** Approach

Add a lightweight =writeCrashReport= to =postmortem.ts= that fires synchronously (=writeFileSync=) in the uncaughtException/unhandledRejection handlers BEFORE cleanup runs. It writes a single JSON file to =~/.spell/reports/crash-TIMESTAMP.json= and prints a one-line breadcrumb to stderr.

Session context is injected via a =registerSessionContext= function called from =sdk.ts= after the session is created. The getter is synchronous — it reads already-available state, no I/O.

** Key decisions

- Sync write only (=fs.writeFileSync=) — process is dying, cannot await
- JSON not tar.gz — minimal overhead, no compression needed for a single small file
- Reports dir (=~/.spell/reports/=) reuses existing =getReportsDir()= — same place as manual debug bundles
- No crash report on clean SIGINT (Ctrl-C) or normal exit — only on exceptions and (optionally) SIGTERM if a session was active
- Session context is optional — crash during startup (before session exists) still produces a report with error + system info
- Existing cleanup behavior is unchanged — crash report fires first, then cleanup runs as before

** Critical file paths

- =packages/utils/src/postmortem.ts= — main implementation (writeCrashReport, registerSessionContext, handler hookup)
- =packages/coding-agent/src/sdk.ts= — register session context after line ~685
