* Initial Message

Add a "follow-ups" org category to the plan mode Org tool

* Context

The org system supports plan decomposition into child categories (projects, features, bugs). A "follow-ups" category is needed for post-plan action items, deferred work discovered during execution, loose ends, and items deliberately deferred during planning — work that doesn't cleanly fit as a feature, bug, or project.

** Approach
Add =followups= (prefix =FUP=, path =follow-ups=) to the default org config and register its description in the plan mode child-category mapper. The template already renders categories dynamically, so no prompt file changes are needed.

** Key decisions
- Prefix: =FUP=
- Category name: =followups= (no hyphen — matches existing convention: =projects=, =features=, =bugs=, =drafts=)
- Path: =follow-ups= (hyphenated for filesystem readability, consistent with how org paths can differ from logical names)
- Available as plan child items (not excluded like drafts/sessions)
- Description: "Post-plan action items and deferred work"
