* Locked decisions (from this conversation)

1. *Embedder* — =bge-m3= (BAAI/bge-m3, multilingual, 1024-dim, ~1.2 GB on disk, ~2.5 GB resident). One user-scoped subprocess; serves both org/memory AND code-graph lanes. =jina-v2-base-code= retires.
2. *HNSW backend* — =usearch= (Unum). Replaces =hnsw_rs=. mmap-backed =.uidx= files → multiple sessions share the on-disk vector index without a daemon.
3. *Tantivy* — *deleted*. =pi-org-recall= crate dies. BM25 served by extracted-and-generalized =pi-knowledge-core::bm25= (today's =pi-code-graph::search::SearchIndex=, 129 LOC pure Rust, BTreeMap inverted index, k1=1.5 b=0.75, camelCase/snake_case tokenization, exact-match boost). No tantivy. No feature flag. No legacy alias.
4. *Producers* — auto-write episodes on (a) compaction, (b) finished tasks (org item state→DONE with non-trivial work), (c) elective =memory.note=/=memory.save=. =MEMORY.md= LLM blob path retires; =memory_summary.md= becomes a deterministic projection.

* Problem

Across 13,544 historical Spell sessions on this machine, the =org recall= tool was invoked 2 times (~0.012% of 17,232 =org= calls). =org remember= / =timeline= / =subgraph=: 0. =:KIND:= drawer adoption in this repo: 2 of 1,875 .org files. =:RELATIONS:= drawer adoption: 2 of 1,875. =.spell/memory/episodes=: 0 files. =~/.spell/personal=: 0 files. =renderSessionStartSummary= (the projection that drives session-start recall): 0 call sites.

Yet the cost is paid in full per session:

- Tantivy =IndexWriter= 50 MB arena per repo handle (hard-coded =fts.rs:150=)
- =fastembed= + Jina v2 base code subprocess: ~500 MB resident per session
- ~40 MB tantivy rlib through =libpi_natives.so= (8 tantivy-* subcrates)
- BUG-382 capped per-session damage at 1 handle + 10-min idle TTL, but the multiplier across N concurrent sessions is unchanged (PLAN-309's territory)

Two crates already solve the same hybrid retrieval problem with ~one tenth the machinery:

- =pi-code-graph::search::SearchIndex= — pure-Rust BM25, 129 LOC, 0 external deps, bincode-serializable, already exercised on the ~12k-symbol code corpus
- =pi-workspace-cache::CacheStore= — engine.bin format + fingerprint + atomic rename
- =pi-code-vectors::VectorIndex= — hnsw_rs wrapper + bincode persistence

=pi-org-recall= reinvented all three (tantivy / VecIndex String-shim / hand-rolled HashMap-of-edges TypedGraph) instead of consuming them. The convergence undoes that.

* Goal

One =pi-knowledge-core= crate. Two consumers: =pi-code-graph= (code intelligence) and =pi-org-engine= (org/memory). Zero tantivy. Zero =hnsw_rs= (replaced by =usearch=). One user-scoped =pi-embedding-worker= subprocess serving both lanes with =bge-m3=. Memory becomes a first-class tool surface (=memory= top-level tool + =memory://= URIs + =/memory= TUI panel). Producers wire on compaction + task-completion + elective.

* Non-goals

- *No backwards compatibility* with =engine.bin= / =vec.bin= / =fts/= on disk. Old caches discarded on first run (version stamp mismatch → rebuild). One-shot, no migration tool.
- *No PLAN-309 daemon.* Embedder is one user-scoped subprocess (XDG_RUNTIME_DIR socket, flock pidfile, 30-min idle exit). Index state lives on disk, mmap'd via usearch — no IPC layer for it.
- *No SurrealDB / SQLite / external DB.* Org files remain the source of truth.
- *No code-graph behavior change* visible to its consumers. The crate gets refactored under it but the existing =hybrid_search= API stays.
- *No new edge kinds beyond what FEAT-631 already defined.* This plan is infra cutover, not vocabulary expansion.

- R3 — *On-disk cache rebuild on first run* — every developer pays a 30–90 s rebuild once after this lands. Acceptable; document in MIGRATION note. No rollback path.
- R4 — *Loop test brittleness* — stub-LLM tests may drift if model behavior changes. Mitigation: stub is local deterministic JSON, not a real model.
- R5 — *PLAN-309 obsolescence* — that plan stays in DOING/ITEM state; W10.5 closes it with a deviation note. No code from PLAN-309 lands.
- R6 — *Notify watcher reliability on macOS/WSL* — inotify is Linux-only; =notify= crate abstracts FSEvents/inotify/ReadDirectoryChangesW but edge cases exist. Mitigation: keep fingerprint-on-demand path as fallback (already in =pi-workspace-cache=).
- R7 — *Embedder spawn race* — two sessions starting in parallel both try to spawn the worker. Mitigation: flock pidfile; loser blocks on socket connect.
- R8 — *Compaction producer over-writes* — if every consolidation writes new episodes, =.spell/memory/episodes/= grows unbounded. Mitigation: idempotency key = (rollout_id, content hash); dedupe at write site.
