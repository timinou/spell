* Context

** Problem

Spell's desktop integration is Linux-only. The Niri overview (full-screen overlay on compositor overview open) and DankMaterialShell session dashboard (taskbar widget with session list, toasts, click-to-focus) have no macOS equivalents. Mac users get nothing — no session dashboard, no overview, no global hotkey to check agent status.

** Current state

- =packages/niri/= implements the terminal overlay and status file writer. Tightly coupled to Niri compositor IPC (=NIRI_SOCKET=).
- Status files at =~/.spell/status/<windowId>.json= are the cross-platform data layer — already contain =status=, =windowId=, =pid=, =projectName=, =sessionTitle=, =updatedAt=.
- The QML bridge daemon (=packages/qml/bridge/=) is cross-platform (Qt6 on macOS), already has =QSystemTrayIcon= support (menu bar icon on macOS), and socket-based IPC.
- No global hotkey support exists in the QML bridge.
- No macOS-specific integration code exists.

** Approach

Three pillars:

1. *Shared module* (=packages/desktop-common/=): Extract platform-agnostic logic (status types, derivation, snapshot building, status file I/O, color palette) from niri so both Linux and macOS integrations share one source of truth.

2. *Menu bar session dashboard*: Use existing QSystemTrayIcon (maps to NSStatusItem on macOS) for a menu bar icon. On click, open a QML popover window showing all active sessions grouped by urgency, with click-to-focus (via =osascript=). macOS notifications on needs_input/pending_approval transitions.

3. *Overview overlay*: Add global hotkey registration to the QML bridge (Carbon =RegisterEventHotKey= on macOS). Default Cmd+Opt+O toggles a QML overlay showing agent status, todo phases, project info — same data as the terminal overlay but in a native floating window. For bonus Mission Control integration, ship a Hammerspoon Lua script (=com.apple.expose.awake= notification) with a =spell setup hammerspoon= auto-install command.

** Key decisions

1. *Qt-first*: Global hotkey and systray use Qt/Carbon APIs. No Electron, no separate Swift binary. The QML daemon is already running; adding hotkey registration is incremental.
2. *Hammerspoon is optional bonus*: Primary experience works without Hammerspoon. For users who have it, Mission Control detection comes free.
3. *Status files stay*: File-based IPC at 2s poll is sufficient for dashboard refresh. No new socket protocol for status.
4. *osascript for focus*: =System Events= scripting brings terminal windows to front by PID. Works with any terminal app (iTerm2, Ghostty, Terminal.app, Kitty).
5. *Shared desktop-common package*: Avoids duplicating types and logic. Both niri and macOS packages depend on it.
