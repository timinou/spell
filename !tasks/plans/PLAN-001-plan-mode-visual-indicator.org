* Initial Message

give me a tint or a hint or something in the overlay mode to know that I'm in plan mode.

* Problem

When plan mode is active, the only visual indicator is a small "Plan" label in the status line segment. The editor border — the most prominent visual element — stays unchanged. Users want an obvious, at-a-glance cue that they're in plan mode.

* Approach

Add a plan mode border color to the editor and a whimsical label. Two changes:

1. *Editor border tint* — When plan mode is active, tint the editor border using a dedicated =planMode= color (similar to =bashMode= / =pythonMode=). This makes the entire input area visually distinct.

2. *Whimsical status segment* — Change the plan mode status label to something playful, e.g. a crystal ball or blueprint metaphor: =Scheming= or =Plotting= instead of plain "Plan". The icon already has some personality (=◈= / =🗺=), so the label can match.

* Key files

| File | Change |
|------|--------|
| =src/modes/theme/theme.ts= | Add =planMode= to =ColorsSchema=, =ThemeColor= union, and add =getPlanModeBorderColor()= method |
| =src/modes/theme/defaults/*.json= (99 files) | Add ="planMode"= color to every theme — use a soft purple/lavender tint as default, adapt per theme palette |
| =src/modes/interactive-mode.ts= | Update =updateEditorBorderColor()= to check =planModeEnabled= before bash/python/thinking checks |
| =src/modes/components/status-line/segments.ts= | Change plan mode label from "Plan" to something whimsical like "Plotting" |
| =src/modes/interactive-mode.ts= | Call =updateEditorBorderColor()= from =#enterPlanMode()= and =#exitPlanMode()= |
