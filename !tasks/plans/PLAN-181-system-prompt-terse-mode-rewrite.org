* Initial Message

Read about caveman-phd and the system prompt and let's exchange on your ideal format. Rid it from the labels and make it yours.

* Context

Rewrite the coding agent's system prompt and caveman output template for token efficiency, clarity,
and authenticity. The current prompt borrows framing from the Brussee "caveman" viral skill — persona
roleplay ("respond like smart caveman"), branding ("PhD-caveman notation"), and a taxonomic symbol
vocabulary table. This plan replaces all of it with direct instruction: terse mode for output,
notation mode for thinking.

** Guiding principle

Grammar is predictable; meaning is not. Strip what's predictable.

The model doesn't need a costume or a brand. It needs permission and shape.
The caveman-micro research confirms this: 6 lines of permission outperformed 552 tokens of tutorial.

** Key decisions

1. All "PhD-caveman" branding and caveman persona language stripped from prompt content.
2. Thinking compression framed as "notation" — symbols carry logic, structure replaces narrative.
3. Output compression framed as "terse mode" — substance only, grammar optional.
4. Code-level identifiers (=caveman.*= settings keys, =/caveman= command) stay unchanged.
5. =<behavior>= and =<code-integrity>= de-duplicated. =Design Integrity= compressed. ~640 tokens saved.
6. All three thinking examples kept (question, decision, investigation patterns).
7. Per-level output examples and auto-clarity safety valve preserved.

** Scope

- 3 template/config files modified
- 1 test file updated
- No settings key or enum value changes (migration scope excluded)
- No extension code logic changes
