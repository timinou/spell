* Initial Message

PLAN-317 (just shipped) fixed the most visible affordance failures around edit. Post-ship dogfood surfaced six more, plus the discovery that =EdgeResolverImpl= has zero production call sites — =def→= / =ref→= / =call→= syntax parses but the kernel's =DispatchEngine::dispatch= is documented as a stub. Agents fall back to bash for code navigation.

This plan:
1. Fixes the W0 affordance bugs (BUG-405 / 410 / 411 / 412 / 413).
2. Wires =pi-code-graph= as the production backend for edge queries (the missing 95%).
3. Augments =pi-code-graph= per-language extractors so it covers what was historically LSP territory (implementations, module paths, re-exports, written signatures).
4. Closes BUG-409 (status index) as a natural consequence of #2.

Explicitly NOT in scope: LSP bridge (rejected in favor of maximal pi-code-graph development). Type-aware reference resolution and inferred-type hover are deferred to FUP-090 / FUP-091 with explicit design-pass requirements.

* Scope

In:
- =crates/pi-code-path=: parser/walker glob+predicate hardening, diagnostic re-classification, =§kind= alias layer.
- =crates/pi-code-engine=: patch substring-fallback word-boundary refusal, single-prefix error contract.
- =crates/pi-natives=: =EdgeResolverImpl= production wiring, workspace-scoped =CodeGraph= cache with watcher invalidation, =graph_stats= handler, =EditFailure= sum-type for error propagation, kind-alias dispatch.
- =crates/pi-code-graph=: extractor enhancements — Implements/Inherits/Dispatches edges, module-path resolution (tsconfig, Cargo, Python), written-signature capture in =SymbolNode.detail=, re-export following.
- =packages/coding-agent=: schemas, prompts, recipe corrections in =find.md=, =Informational= diagnostic suppression in renderer.

Out:
- LSP integration of any kind (deferred indefinitely; FUPs cover the rare residual cases).
- Type inference (FUP-090).
- Inferred-type hover (FUP-091).
- Live diagnostics from a type checker.

Rationale: dogfood after PLAN-317 showed that empty result patterns and bash-fallback patterns were caused by ~5 distinct ergonomic bugs and one missing-implementation (=EdgeResolverImpl= never instantiated in production). Fixing the bugs without wiring the graph would leave =def→= permanently dead. Wiring the graph without the bugs would surface the bugs more visibly. Bundle.
