* Initial Message

Below the "Initial message" part of plans, add an instruction to say that they can use jq to look up information in the planning session transcript

* Context

When a plan is approved and execution begins, the executing agent starts a fresh session with no memory of the planning conversation. Currently, any context not captured in the plan body or org items is lost. By telling the executor about the planning transcript and how to query it with jq, we give it a fallback for recovering design decisions, Q&A, or rationale that wasn't explicitly copied into the plan.

The change threads the planning session's JSONL transcript path through to the execution prompt template, where a conditional instruction tells the agent how to use jq on it.

Key decisions:
1. Transcript path captured before session rotation, passed as template variable
2. Instruction lives in the prompt template, not the org item body (ephemeral, session-specific)
3. Omitted when persist is disabled (no transcript file)
