* Context

GrowthShell's chat is completely non-functional due to three architectural gaps:

1. *No message forwarding*: =GrowthShell.qml= drops all bridge messages except =workspace_layout=. Session events (=message_start=, =message_update=, =message_end=, =tool_start/update/end=, =agent_busy=, =user_message=) from =SessionEventMapper= (=packages/coding-agent/src/modes/qml-event-mapper.ts=) never reach loaded panels. The working =shell.qml= routes every message via =forwardToActivePanel(payload)= which calls =item.handleMessage(payload)= on the loaded panel.

2. *No secondary panel support*: =loadWorkspacePanel()= only resolves =position === \"main\"=. Most workspaces map chat to =position: \"secondary\"=, so chat is only available in the General workspace. In strategy/research/create/campaign workspaces, the user has no way to interact with the agent.

3. *ChatDrawer is not a chat interface*: It has an input bar that sends =chat_message= events and a static label. No message model, no ListView, no streaming support. It cannot display agent responses.

** Approach

Replace the current ColumnLayout (main area + ChatDrawer) with a vertical =SplitView= containing two Loaders:
- =mainPanelLoader= loads the =position: \"main\"= panel (dashboard, intel, editor, planner, or ChatPanel for General)
- =secondaryPanelLoader= loads the =position: \"secondary\"= panel (usually ChatPanel for chat-enabled workspaces)

Add message forwarding that routes ALL bridge messages to BOTH loaded panels. Each panel's =handleMessage= only processes event types it understands; the rest are no-ops.

ChatDrawer is removed from the layout. The builtin =ChatPanel.qml= (=packages/coding-agent/src/modes/qml/panels/ChatPanel.qml=) loaded as the secondary panel provides the full chat interface: message history, streaming, tool calls, input bar, status bar.

** Key Technical Details

*** ChatPanel.qml import resolution
ChatPanel.qml imports =".." as SpellUI= (resolves to =packages/coding-agent/src/modes/qml/= containing =qmldir= with SpellUI module) and ="delegates" as Delegates= (resolves to =panels/delegates/=). Qt resolves imports relative to the loaded file's URL, so loading via absolute path from GrowthShell's Loader resolves correctly.

*** Message flow
=qml-mode.ts= subscribes to =AgentSessionEvent=, maps via =SessionEventMapper=, sends to bridge as =bridge.sendMessage(\"shell\", payload)=. GrowthShell receives via =bridge.onMessageReceived=. New forwarding calls =handleMessage(payload)= on both Loader items.

*** Workspace flex values
Manifest workspaces have optional =flex= properties (e.g. =\{ panelId: \"dashboard\", position: \"main\", flex: 2 \}=). These control the =SplitView.preferredHeight= ratio. Default flex: 1.

*** Dead code cleanup (subsumes BUG-062)
=currentPanels= property (set but never read) is removed during the rewrite.
