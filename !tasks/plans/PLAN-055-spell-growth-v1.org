* Context

Spell Growth is a non-coding distribution of Spell that transforms the coding agent into a growth/marketing workspace. Canvas-first QML desktop app with workspace layouts tightly coupled to behavioral modes, native TypeScript scraper framework, live Typst document editing with WASM preview, and comprehensive competitive intelligence capabilities.

** Problem
Growth practitioners at ORA Ventures use fragmented tools: manual Typst creation, separate Python FB Ad Library scrapers, scattered files across BackDesk-C, no unified workspace.

** Approach
Build domain abstraction layer in Spell core, then build growth infrastructure (scraper, Typst, QML shell) in parallel, then wire panels and modes.

** Key Decisions
- Distribution: Auto-detected from .spell/domain.json. Internal ORA tool, architected for extraction.
- Canvas: Always-canvas. QML primary, TUI launcher. Chat is persistent bottom drawer.
- Workspace = Mode (tight coupling): Switching workspace activates default mode. Overridable.
- Scraper: Native TS with Puppeteer (reuse stealth scripts). YAML configs. Platform-native normalized SQLite.
- Typst Editor: Monaco/CodeMirror in WebEngineView + tree-sitter-typst WASM. typst-ts WASM SVG preview. Click-to-code.
- Modes: .spell/modes/*.md using existing ModeConfigFrontmatter. 6 modes: /intel, /strategy, /pitch, /review, /campaign, /brief.
- Subagent Gates: Athena (completeness), Hermes (strategy), Apollo (brand), Ares (campaign).
- Data Hydration: YAML files for Typst via built-in yaml() function.
- Brand Guardian: Full gate (tree-sitter + compile + LLM). Configurable via rules.
- Example Branding: Spell brand (public repo). ORA brand via .spell/growth/branding.json config path.
- Deliverable Lifecycle: Org items (state) + filesystem (.typ) + SQLite (metadata).
- Testing: Layer separation + user journey org spike + QmlJourney E2E + full lifecycle tests.
- Config: .spell/domain.json + .spell/growth/ directory.
- Font Loading: Custom fonts in typst-ts WASM VFS. Part of Typst integration.
- Scope: Full V1 including all panels, modes, scraper, editor, planner, signals, analyzer, template builder.
