* Initial Message

What would it take for Spell's org mode to be a fully featured graph that also includes memories, simlar to the SurrealDB plan in the kdl worktree?

* Context

Turn Spell's org subsystem into a fully featured graph with first-class
episodic + semantic memory, hybrid recall (BM25 + HNSW vector +
typed-graph), live patch subscriptions, atomic cross-file edits, and a
cross-repo personal store — all without introducing SurrealDB or any
external daemon.

Source-of-truth spec: =[[file:../../specs/org-graph-memory.md][specs/org-graph-memory.md]]=.

The plan is materially the answer to the conversation that asked "what
would it take for Spell's org mode to be a fully featured graph that
also includes memories, similar to the SurrealDB plan in the kdl
worktree?". The four canonical objections to staying file-based were
each demolished:

- LIVE SELECT → broker-routed org edits + OrgItemPatch in PeerCommitted (FEAT-639)
- ANN at scale → hnswlib-rs swap; flat brute-force deleted (FEAT-633)
- Namespacing → dropped; per-repo scope is enough
- One query language → tantivy BM25 + HNSW + typed-graph + RRF fusion in =pi-org-recall= (FEAT-636)
- Atomic cross-record → MultiIntent / MultiCommit / journal recovery in =pi-edit-broker= (FEAT-638)

Files stay diffable. No new daemons. The broker we already have becomes
the LIVE substrate. Memory becomes typed org items via =remember()=,
=MEMORY.md= is replaced by a deterministic projection over the concept
graph.

** Settled decisions

1. Scope cutoff: v1 = everything except artifact unification (FUP-068)
2. Edge syntax: dedicated =:RELATIONS:= drawer with KIND: target-id lines (FEAT-631)
3. Memory storage: per-cwd =<repo>/.spell/memory/episodes/<YYYY-MM-DD>.org= + =concepts/<slug>.org= (FEAT-641)
4. Memory pipeline: hard cutover; SQLite job queue stays, MEMORY.md vanishes, =memory_summary.md= becomes a recall projection (FEAT-640)
5. Vector runtime: subprocess via =pi-embedding-worker= (FEAT-635)
6. Vector struct: HNSW always, =hnswlib-rs= from day 1, flat code path deleted (FEAT-633)
7. Cross-repo personal store in v1; artifact unification deferred (FUP-068)

** Replacement for MEMORY.md

A deterministic projection at =<repo>/.spell/memory/cache/memory_summary.md=:

- top 12 concepts by =recency × confidence × backlink-count= via =recall({ profile: "session-start", scope: ["concept"] })=
- top 5 active workflow items
- top 3 last-24h episodes about the cwd

Rendered through =packages/coding-agent/src/prompts/memories/session-start.md.hbs=.
The =memory://root/memory_summary.md= URL keeps resolving.
