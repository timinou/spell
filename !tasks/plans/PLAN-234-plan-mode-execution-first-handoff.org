* Implementation Strategy
** Wave traversal rule
Execute the child DAG in dependency order. Do not start validator or orchestration rewrites until the prompt contract is explicit enough to test against.

** Contract-first, tests-first
1. Use `specs/plan-mode-prompt-guidance-2026.md` as the source of truth for wording and invariants.
2. Update prompt tests before changing prompt text where feasible.
3. Update validation tests before changing `exit_plan_mode` enforcement.
4. Update approved-plan / todo / task prompt tests before changing orchestration wording.

** Cross-surface synchronization rule
Whenever the execution-first contract changes, update all affected representations in the same implementation pass:
- prompt text
- prompt tests
- validator rules
- validator tests
- orchestration guidance
Do not leave a partial migration where prompt examples, validator expectations, and approved-plan execution guidance disagree.

** Handoff quality rule
The finished system should let a fresh execution agent answer, from the plan artifact alone:
- what to do first
- which files/tests belong to each wave
- when to parallelize vs serialize
- which verification closes each child item
If those answers still depend on re-reading findings-only context, the work is incomplete.
