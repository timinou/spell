* Context

The Phoenix Inspector's \"Quick Fix\" button dispatches a task-tier event through the canvas
bridge (=_tier: \"task\"=) which routes to =CanvasTaskManager= via =CANVAS_TASK_CHANNEL=. The
infrastructure is wired end-to-end: QML sends the payload, canvas.ts classifies and enqueues
it, the task manager spawns an executor via =runSubprocess=, and the result should flow back
via =bridge.sendMessage= with =action: \"task_result\"=.

** What's broken

The task subagent spawns (confirmed: 6 spawns in today's logs) but *never completes*. Zero
completion logs, zero error logs, zero abort logs. The task initializes fully (~200ms for
tools + prompt) then goes silent — the =session.prompt()= call appears to hang indefinitely.

Root causes (in order of likelihood):
1. *Silent hang at API call*: =pi/smol= resolves but the provider connection hangs without
   timeout. No error surfaces because there's no timeout guard around the executor call.
2. *No lifecycle logging*: CanvasTaskManager has zero structured logging between spawn and
   result. Impossible to diagnose without adding instrumentation.
3. *No immediate QML feedback*: unlike the agent tier which sends an immediate reply via
   =_rid= callback, the task tier has no acknowledgment — QML shows a spinner with no
   confirmation that the request was received.

** Approach

Four items, executed in dependency order:
1. *Fix the hang* ([[id:BUG-130-canvas-task-subagent-hangs-silently-at-s]]): add timeout, lifecycle logging,
   immediate QML ack. This is the P0 — without it, nothing else matters.
2. *Add pi/sniper model role* ([[id:FEAT-251-add-pi-sniper-model-role-for-canvas-quic]]): configure
   =openai-codex/gpt-5.3-codex-spark= as the default canvas-task model with =pi/smol= fallback.
3. *Stream progress to QML + TUI* ([[id:FEAT-252-stream-canvas-task-progress-to-qml-and-t]]): subscribe
   to executor progress events and relay them to QML as =task_progress= messages, plus TUI badge.
4. *Polish Quick Fix UX* ([[id:FEAT-253-polish-quick-fix-ux-result-display-retry]]): structured result
   display, retry button, model picker.

** Key decisions
- *pi/sniper* is the new model role name for canvas quick-task, resolving to
  =openai-codex/gpt-5.3-codex-spark= with =pi/smol= fallback chain.
- *Reply-before-turn* pattern: QML gets immediate ack before expensive work starts
  (same pattern as the agent tier fix in commit b94f0944d).
- *Timeout*: 120s default, configurable via settings. After timeout, task is aborted
  and QML receives a clear error.
