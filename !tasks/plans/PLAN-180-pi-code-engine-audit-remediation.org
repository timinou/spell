* Context

Post-implementation audit of =pi-code-engine= (=AUD-054=) found 14 issues ranging from dead code to correctness bugs. This plan addresses all 14 findings organized into three work items by coupling and risk.

Key decisions:
1. CRDT errors propagate as =CodeEngineError::Buffer= — no rollback, the buffer is corrupt if CRDT diverges from rope.
2. Batch undo uses compound =Revision= with =Vec<TextEdit>= for forwards/inverses — single =undo()= call reverts entire batch.
3. Transpose validates non-overlap; adjacent nodes (shared boundary) use a single combined edit.
4. Indent =adjust_indent()= handles dedent by stripping leading whitespace (capped at available whitespace, never strips content).
5. Splice applies =adjust_indent()= from node indent to parent indent on kept text.
6. Dead code confidence: functions/classes → "high", other symbol kinds → "medium", entry-point files → "low".

All changes are in Rust crates (=pi-code-engine=, =pi-code-graph=, =pi-natives=). No TypeScript changes.
