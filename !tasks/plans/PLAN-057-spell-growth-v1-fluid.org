Spell Growth is a non-coding distribution of Spell that transforms the coding agent into a growth/marketing workspace. Canvas-first QML desktop app with workspace layouts tightly coupled to behavioral modes, native TypeScript scraper framework, live Typst document editing with WASM preview, and comprehensive competitive intelligence capabilities.

This plan has IDENTICAL SCOPE to PLAN-055-spell-growth-v1 but uses fluid orchestration instead of the old manual wave system. The execution manifest references ~98 sub-outline steps as individual FluidAgentNode entries. The org-fluid-plan Elisp MCP tool computes connected components and wave layers from the dependency DAG. The FluidOrchestrator with QueueScheduler handles concurrent execution based on resolved dependencies.
