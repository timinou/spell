* Context

** Problem
The ~formatSummary~ function in ~todo-write.ts~ injects gate directives when gated tasks are completed and emits phase completion summaries. This is the core value proposition of the todo gates feature (PLAN-022). However, ~formatSummary~ is module-private and has zero direct test coverage. A refactor that breaks the injection would pass all existing tests.

** Approach
Export ~formatSummary~ and ~FormatSummaryOptions~ from ~todo-write.ts~. It is a pure function with well-defined inputs — no mock ToolSession needed. Add 6 test scenarios to the existing ~todo-write-gates.test.ts~ file covering: gate directive injection for each gate type, absence of directives for non-gated tasks, phase completion aggregates, and blocked task rendering in the summary text.

** Key decisions
- Export the pure function rather than testing through execute() — avoids ToolSession mock complexity
- Extend existing test file rather than creating a new one — tests are thematically related
