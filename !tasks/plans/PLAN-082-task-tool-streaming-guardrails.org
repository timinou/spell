- *No streaming feedback*: The TUI showed only \"Working... (esc to interrupt)\" because the ~_i~
  intent field hadn't been parsed yet from the partial JSON

  single tool call's arguments

  against undefined, causing a caught error that degrades the preview to a bare \"Task\" label

- 30KB calls succeed but take ~2.5 minutes to generate at ~60-80 tokens/sec
