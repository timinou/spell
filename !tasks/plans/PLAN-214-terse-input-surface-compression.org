* Initial Message

Look at PLAN 181 and PLAN 207. With the same freedom, can you tell me how you could express yourself even more by applying the terse thinking mode to the whole surface of what is sent to the llm?

* Context

The system prompt is the agent's declaration of being. Four prior plans shaped the Identity section into compressed, honest self-knowledge. But the Identity section is the *smallest* part of what the LLM receives (~2,200 tokens). Three untouched layers dwarf it:

| Layer | Tokens | Compressed? |
|-------|--------|-------------|
| Identity (role→principles) | ~2,200 | Yes (PLAN-181/209) |
| AGENTS.md context file | ~5,500 | No |
| Tool descriptions (API) | ~12,000-15,000 | No |
| Plan-mode overlays | ~4,500 | Partially (23% cut) |
| Subagent/agent/misc | ~2,000 | No |

PLAN-181 found the principle: "Grammar is predictable; meaning is not."
PLAN-209 found the corollary: "Less content, better placed."

This plan extends both to the entire input surface: "The model knows more than we teach it. Teach only what it can't derive."

The model can reconstruct what namespace imports look like from "namespace imports only." It can produce correct JSON from a parameter schema without 10 examples. It understands code blocks without tutorials on block boundaries (though it does need the block-boundary-traveling rule itself).

** Approach

Permanent, aggressive compression of ALL prompt files (.md sources). Not conditional on terse mode — the model never needs tutorials. This subsumes FUP-047 (tool description normalization) and FUP-048 (subagent/overlay normalization).

** Key Decisions

1. AGENTS.md compressed in place — becomes terse constraint notation. Developers read constraints, not tutorials.
2. All 41 tool .md files compressed permanently. Each: one capability sentence + constraints + non-obvious examples only.
3. Plan-mode overlays further compressed. Deduplicate repeated blocks. Notation over prose.
4. Agent/subagent/compaction/memory prompts: audit + compress where verbose.
5. Compression is permanent — source .md files become terse.
6. Contract spec written first (=specs/prompt-surface-compression.md=) — all items reference it.
7. Handlebars conditionals preserved exactly in all files.
8. Examples survive only if they pass the non-obvious exemplar test: would the model get the pattern wrong without it?
9. Testing via semantic anchor assertions in existing test files. No snapshot tests.
10. Target: ~57% reduction on compressible surface (~22,000 → ~9,500 tokens).
