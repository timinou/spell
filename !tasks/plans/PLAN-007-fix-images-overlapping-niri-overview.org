* Initial Message

[Image #1] can you please make sure images are not overlapping niri overview modes?

* Context

When niri overview mode is opened, the coding-agent's TUI shows an OverviewComponent as a full-screen overlay. However, inline images rendered via Kitty graphics protocol (used by Ghostty) punch through the overlay. This happens because the TUI's overlay compositing logic (~tui.ts#compositeLineAt~) explicitly skips lines containing image protocol escape sequences to avoid corrupting them.

The fix has two parts:
1. Add a ~clearImagePlacements()~ utility in the TUI package that sends the Kitty graphics delete command
2. Modify the NiriOverviewController to suppress images when the overview opens and restore them when it closes

** Approach

When overview opens:
- Save current image protocol
- Send Kitty delete command to clear existing visual placements
- Set image protocol to null (suppresses future image rendering)
- Force full TUI re-render (produces clean lines without image sequences)
- Show overlay (now compositing works on all lines)

When overview closes:
- Hide overlay
- Restore saved image protocol
- Force full TUI re-render (images get re-sent via Kitty protocol)
