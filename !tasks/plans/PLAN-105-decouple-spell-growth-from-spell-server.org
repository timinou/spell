* Initial Message

what is part of spell-gworth (packages/spell-growth)? what is the purpose of the code? Why can't it be an extension in ../growth?

* Context
~packages/spell-growth~ is a first-party action pack containing growth-specific business logic (article discovery, persona scoring, feed sending, publication export, curation writeback). It is hardcoded into ~spell-server~ via ~registerGrowthActions()~ called from ~createServerActionRegistry()~ in ~packages/spell-server/src/actions/index.ts~. This means every spell-server instance loads growth actions regardless of whether it runs a growth project.

The growth business logic in spell-growth is effectively dead code in the runtime path: the ~GoalExecutionController~ converts action specs into prompts for a coding-agent session. The typed TS functions (~ingestDiscoveryCandidates~, ~sendGrowthFeed~, etc.) are never called by the executor. They serve only as test fixtures and typed specifications.

** Approach
1. Add KDL-declarative action descriptor support to the manifest parser, so projects can declare their own actions in ~autonomy.kdl~ without TypeScript registration
2. Remove the hardcoded ~spell-growth~ dependency from ~spell-server~
3. Delete ~packages/spell-growth/~ entirely
4. Update ~../growth/~ to declare action descriptors in KDL
5. Extract the URL canonicalization utility to ~pi-utils~ before deletion

** Key decisions
- Action descriptors use ~source="project"~ (not ~"first-party"~) when declared in KDL
- No TypeScript action handler code anywhere -- the agent-prompted execution model continues unchanged
- Direct tool dispatch (executing tool sequences without LLM) is deferred to a follow-up
- URL canonicalization (~normalizeCanonicalUrl~, ~normalizePublishedAt~) moves to ~pi-utils~; all other spell-growth code dies
- Growth cutover tests that imported spell-growth TS code are deleted (they tested code that no longer exists)
- Exa client in spell-growth is deleted (duplicates existing Exa integration in coding-agent)

** Key files
- ~packages/spell-server/src/actions/index.ts~ -- remove growth coupling
- ~packages/spell-server/src/actions/types.ts~ -- widen ~ActionDescriptor.source~ type
