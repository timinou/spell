* Context

When a PLAN org item is approved via `exit_plan_mode`, the executing session receives only the PLAN item's own body (via `planContent` in `plan-mode-approved.md`) plus a bare Execution Manifest with `[[id:…]]` links. Every linked FEAT/BUG/FUP body must be re-fetched by the executing agent via `org get` before it can act.
