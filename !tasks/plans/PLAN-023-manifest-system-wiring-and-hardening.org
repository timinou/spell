** Problem
The manifest orchestration system (PLAN-020) delivered well-tested, individually correct modules — but failed to wire them into the LoopManager runtime. The audit found 5 P1 integration gaps (modules exported but never called), 2 P1 bugs (resume state, silently dropped ticket data), and 4 P2 correctness bugs (persistence round-trip, drift merge). The agent-facing contract (tools, prompts) promises manifest-driven workflow, but the runtime silently falls back to pre-manifest behavior.

** Approach
TDD — write failing tests first, then implement fixes. Three phases:
1. Fix correctness bugs in existing modules (kernel resume, persistence round-trip, drift merge) — independent, parallelizable
2. Wire ticket completion pipeline into LoopManager.markDone() — the core feedback loop
3. Wire persistence lifecycle and prompt injection — depends on pipeline being in place

** Key Design Decisions
*** Kernel stays ticket-ignorant
=completedTickets= / =activeTickets= are processed by =LoopManager.markDone()= via =TicketLifecycleManager= BEFORE calling =kernel.done()=. The kernel's =LoopDoneOptions= is NOT modified. This preserves the kernel as a pure state machine.

*** Ticket gates before standard gates
=onTicketComplete= gate evaluation fires per-ticket BEFORE the standard =evaluateLoopGates= call. This ensures ticket gate failures are visible to the next iteration's planning prompt.

*** Manifest prompt injection: two locations
- =manifest-building-active.md= in =agent-session.ts= (phase coordinator doesn't run during =manifest_building= state)
- =buildManifestPromptContext()= in =phase-coordinator.ts= (enriches iteration/reflection prompts)

*** Manifest authority model
- During =manifest_building=: org files on disk are authoritative (agent creates tickets via org tool)
- During iteration: =LoopSnapshot.manifest= is authoritative (runtime mutates in-memory)
- =launch()= is the reconciliation point: reads org files, populates snapshot
- Write order: TLM mutates in-memory → =writeManifest= to org → set on snapshot → checkpoint

*** resume() fix
Use =stateBeforePause= directly when it's a valid target from =paused= (lookup against =ALLOWED_TRANSITIONS[paused]=), otherwise fall back to =iterating=. Not a switch — a lookup.
