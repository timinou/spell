* Context

** Problem
Subagents create variable-quality todo items when planning work. The weak guidance ("MAY use todo_write") produces vague tasks that require exploration and questions to execute. This wastes tokens and time.

** Approach: The Sniper Pattern
Define and enforce a "sniper todo" pattern: tasks so precise they can be executed mechanically — exact files, exact changes, exact acceptance. Aim, fire, done.

The cascade makes this powerful:
1. Parent dispatches a ~task~ agent
2. Task agent investigates, then creates sniper todos via ~todo_write~
3. Task agent dispatches each sniper todo to ~quick_task~ via the ~task~ tool using ~todoRef~
4. Quick_task agents execute mechanically in parallel
5. Task agent verifies results

The key enabler: todoRef-derived assignment. When ~todoRef~ is set and ~assignment~ is omitted, the system auto-constructs the assignment from the todo's content+details. Zero duplication, zero friction.

** Key Decisions
1. Sniper format: ~content~ = ultra-terse verb+target (5-10 words); ~details~ = full execution spec
2. Prompt strength: MUST for ~task~ agents, SHOULD for others
3. ~assignment~ becomes optional in TaskItem schema; auto-derived from todoRef when missing
4. TUI shows first line of child task ~details~ regardless of status (dimmed, truncated)
5. Task agent prompt teaches plan-then-delegate workflow with concrete example
