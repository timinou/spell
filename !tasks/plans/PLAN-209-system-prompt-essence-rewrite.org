* Context

The system prompt is the agent's declaration of being. Four prior sessions shaped it:
PLAN-181 (terse mode rewrite) found the principle: "the model doesn't need a costume. It needs permission and shape."
PLAN-188 (architecture restructure) named the architecture: "mirror, compass, handbook" and moved values before tools.
PLAN-191 (declaration of being) expanded the creative voice of the Identity section.
PLAN-207 (prompt declaration of being) tried to extend this to all prompts — but drifted into engineering bureaucracy.

This plan returns to the essence. The insight was never "rewrite everything in consistent voice." It was: *most of what we send the model is reference material that doesn't need to be in the system prompt at all.*

** Approach

*Less content, better placed.* The Identity section stays (it's the real achievement). Everything else gets radical compression or relocation:

1. *System prompt template*: The role becomes honest self-knowledge. =<behavior>= and =<code-integrity>= merge into =<discipline>= — one cognitive pattern, not two. The 7-step Procedure dissolves into principles alongside Design Integrity (renamed "Principles", expanded from 8 to 10). The ~1,000 words of tool manual become ~80 words of philosophy.

2. *Plan-mode overlays*: The 5,800 words of process manual become ~2,500 words of capability declaration. Instead of teaching the agent a manual process, the overlays declare what the system handles (DAG scheduling, gate enforcement, org lifecycle hooks, auto-promotion) and what the agent is responsible for (doing the work, marking status truthfully).

** Key Decisions

1. Role: "You reason about systems and write code inside Spell. Your strength is holding complexity. Your weakness is generating inside-out." No title, no costume.
2. "Claude agent, built on Anthropic's Claude Agent SDK" removed from template — stays only in stealth mode (=claudeCodeSystemInstruction= in =packages/ai/src/providers/anthropic.ts=).
3. Section order: role → thinking-mode → communication → discipline → stakes → Contract → Principles
4. =<behavior>= + =<code-integrity>= → =<discipline>=
5. "Design Integrity" → "Principles" (8 → 10 principles)
6. Procedure eliminated, dissolved into Principles
7. Tool manual replaced with philosophy (~1,000 → ~80 words)
8. Cache boundary moves to between Principles and Now
9. Plan-mode overlays reframed: "system handles" vs "agent responsibility"
10. PLAN-207 superseded. FUPs for deferred layers (tool descriptions, subagent prompts).
