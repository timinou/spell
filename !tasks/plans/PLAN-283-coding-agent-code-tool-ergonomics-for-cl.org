* Context
User tested Spell `code` tool affordances in `~/code/ora/clojend` against Clojure and EDN files. Clojure structure-aware reading, file-local symbols, workspace symbols, scoped edits, and graph exploration are viable, but daily ergonomics are not yet smooth.

Settled design decisions:
1. Scope includes generic code-tool work, Clojure-specific work, and EDN-specific work in one plan.
2. File-local command output stays local/concise; commands accept both local target IDs and fully-qualified workspace/graph target IDs.
3. Scoped literal edits support both safer `findAndReplace` substring fallback and an explicit `rawTextReplace` action.
4. `code undo`/`code redo` must work after auto-save within the live managed buffer session.
5. `code diff` shows unsaved buffer-vs-disk hunks when dirty plus uncommitted git working-tree diff for code-tool-edited files from journal/history, tagged by editing session/agent.
6. EDN becomes data-ergonomic: outlines by map keys/vector indexes with target IDs such as `file::[:books 0 :title]`; EDN remains data-only, no graph/code semantics.
7. Clojure context keeps keywords but sections/collapses them under “Data keywords”.
8. Clojure navigation prioritizes semantic forms: defn body forms, let bindings, cond branches, map entries; raw token children are not default.
9. `.spell/graph` artifacts remain project-local generated caches, but must be ignored, status-labeled, and documented.

Repository evidence checked in current repo:
- `packages/coding-agent/src/tools/code.ts`: file/graph command routing, schema, staged edit + save finalization, targetId parsing.
- `packages/coding-agent/src/tools/code-result.ts`: diff/history/result formatting.
- `crates/pi-natives/src/code_buffer.rs`: native file command dispatcher, target resolution, action handling, save/diff/undo/redo.
- `crates/pi-code-engine/src/resolve.rs`: local declaration symbol resolver and current not-found diagnostics.
- `crates/pi-code-engine/src/buffer.rs`: history, saved revision, undo/redo, save behavior, edit transactions.
- `crates/pi-code-engine/src/language/mod.rs`: Clojure and EDN profiles.
- `crates/pi-code-engine/src/navigate.rs`: current children/siblings implementation.
- `crates/pi-code-graph/src/language/clojure.rs`: keyword symbol/reference extraction.
- `crates/pi-natives/src/code_graph.rs`: graph/vector cache status and artifact paths.
