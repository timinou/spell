* Context

Session rotation (plan approval, /clear, fork, switch) calls ~#disposeTools()~ which
permanently kills the ~EmacsSessionManager~ and ~OrgSessionManager~. The same tool
instances remain registered and reference the disposed managers, causing every subsequent
~code~ tool call to return "Emacs daemon unavailable".

The fix splits ~toolSession~ lifecycle into ~softReset()~ (preserves daemons) and
~dispose()~ (full teardown). Session rotation uses soft reset; only process shutdown
uses full dispose.

Key decisions:
1. ~softReset?()~ added to ~ToolSession~ interface
2. ~#disposeTools(mode)~ accepts "soft" | "hard"
3. ~newSession~, ~fork~, ~switchSession~ use "soft"; ~dispose~ uses "hard"
4. Individual tool ~dispose()~ still runs on all rotations (browser tabs, canvas bridges should clean up)
5. ~emacsSessionManager~ and ~orgSessionManager~ survive rotation
6. ~qmlRemoteServer~ stopped on rotation, ~gatewayClient~ gets session cleanup only
