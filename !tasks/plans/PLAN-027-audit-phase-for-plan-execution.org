* Initial Message

I want you to create a /audit phase (that is automatically launched for any implementation that used ultraplan, and is asked to be launched for the /plan phases) that injects something like this as a follow-up prompt upon completion of the plan:

"""
anything to work on as a follow-up for polish or hardening? show me your audit before I validate
"""


Then, if the audit brought anything to light, activates an ultraplan on implementing the audit advices.

* Context

The coding-agent has a robust plan mode (/plan, /ultraplan) but no post-execution quality gate. After a plan executes, there is no systematic check for polish, hardening, edge cases, or low-effort/high-reward improvements that the implementing agent noticed during execution.

** Problem
- Plans execute and complete, but implementation quality depends entirely on the initial plan's foresight
- Agents accumulate insights during implementation (missed edge cases, refactoring opportunities, API improvements) that are lost when execution completes
- No structured feedback loop between implementation experience and follow-up work

** Approach
Create an /audit phase that runs after plan execution completes:
- *Automatic* for ultraplan: audit prompt injected as follow-up after agent finishes executing
- *Suggested* for /plan: popup selector offers audit after execution ("Run audit" / "Skip audit")
- *Manual*: /audit slash command available anytime outside plan mode
- *Recursive with depth limit*: audit findings auto-escalate to ultraplan for implementation (max 2 cycles)

** Key Design Decisions
1. *State split*: ~AuditState~ (pending/active, per-session) on AgentSession; audit depth (per-lifecycle) on InteractiveMode. Depth survives ~handleClearCommand~ / session resets.
2. *Suggest mode bridge*: Promise-based callback registered by InteractiveMode on AgentSession. Session calls callback, awaits boolean response (popup result).
3. *Escalation approval*: Audit-driven ultraplan goes through normal approval selector. Human reviews the plan before execution. The "automatic" part is entering ultraplan mode, not approving the plan.
4. *[AUDIT_CLEAN] marker*: Agent concludes with ~[AUDIT_CLEAN]~ if no findings. Detection via case-insensitive regex ~/\[AUDIT[_\s]?CLEAN\]/i~. Absence defaults to "clean" (avoids runaway escalation).
5. *Depth reset*: Resets to 0 on any non-audit-escalation plan approval. Increments on each audit→ultraplan escalation.
6. *#checkTodoCompletion change*: Returns ~Promise<boolean>~ (true = reminder sent). Audit check runs only when false (all complete or no todos).
7. *UI indicators*: Top-left overlay badge ("Audit 1/2") coexists with plan mode overlay at top-right. Status line audit segment.
8. *Abort/error handling*: Clears audit state. No stale flags.
