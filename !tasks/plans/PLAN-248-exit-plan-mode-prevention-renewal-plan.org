* Context

Empirical failure study of `exit_plan_mode` over 292 recent agent sessions
(see `/tmp/epm_analysis/`):

- 104 total `exit_plan_mode` tool invocations
- 70% first-call failure rate
- 80% of sessions needed 2+ attempts (max observed: 7)
- 100% eventually succeeded — cost paid in tokens and turns, not outcomes

Top failure categories:
- invalid-suboutline-namespace (22)
- broken-suboutline-depends (9)          ← cascade from (1)
- missing-child-properties (7)
- missing-suboutline-steps (2)
- not-in-plan-mode (2)                    ← double-call race
- broken-child-depends (1)

Two root causes explain 40/46 failures:
1. Agent cannot know the auto-assigned parent CUSTOM_ID slug at the time it
   drafts suboutline CUSTOM_IDs, and guesses the bare numeric prefix.
2. Agent is asked to include EFFORT, PRIORITY, LAYER on every child, but
   EFFORT and PRIORITY carry no planning value here and are fabricated,
   causing "missing" errors when they are omitted.

User decision (confirmed): EFFORT and PRIORITY **REMOVED** from the
required property set and from the codebase; LAYER is the only required
property; DEPENDS is encouraged. Agents must learn this at item-creation
time, not at exit time.

The remaining double-call and missing-suboutline-steps cases are handled
by (a) making exit idempotent and (b) the informative create response +
new suboutline-add tool that physically prevents wrong prefixes.

A seventh item was discovered during this very planning session: the
shared `pi-code-engine` `BufferRegistry` caches ropes process-wide with
no disk-revalidation, and `save()` clobbers external edits. This made
the plan authoring sequence itself corrupt FEAT-564. Fixing this is a
prerequisite for any future plan that mixes engine writes with external
file mutations, so it ships in the same plan.

* Approach

Layered defense, cheapest-first:
1. **Foundation** — fix the BufferRegistry staleness bug (BUG-279) so
   subsequent work on the org/coding-agent layer can mix engine and
   external writes safely.
2. **Structural prevention** — make it impossible or hard to produce the
   wrong prefix at all (N5 suboutline-add; N3 prefix template echo).
3. **Input tolerance** — accept the form agents actually produce when
   they still write bodies by hand (N1 wrong-prefix rewrite + lenient
   validator + fix-hints).
4. **Requirement simplification** — stop demanding data that has no
   value, so agents do not need to guess it (N2 drop EFFORT/PRIORITY).
5. **Teach up-front** — move the authoring rules into the prompt that
   precedes authoring, not the error surfaced after (N4).
6. **Forgive benign races** — idempotent double-call (N6).
