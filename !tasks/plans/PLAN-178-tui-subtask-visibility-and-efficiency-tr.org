* Initial Message

bro. now that the Task tool and the todo write tool are well integrated, can you have a thing where I see in the TUI when a subtask is being spun by an agent? And can you see how often subtasks are being launched, and if they are token efficient?

* Context

The Task tool and todo_write are deeply integrated for delegation tracking, but the TUI gives poor visibility into running subtasks. Current state:

- *Status bar*: Has a =subagents= segment with =setSubagentCount()= that is *never called* — completely dead code. The segment would show a count badge, but it never appears.
- *Todo panel*: Shows =[delegated]= label on delegated tasks, but no live activity (what tool the subtask is running, how much it's costing).
- *Inline rendering*: Task tool's =renderResult()= shows per-agent progress with spinner, tokens, cost, current tool. This only appears in the chat output block while the tool is running. No efficiency metrics after completion.
- *Session exit*: Shows total tokens/cost for the session, including subtask tokens (they're accumulated), but *no breakdown* of subtask vs parent usage.
- *SubagentViewerComponent*: Full detailed overlay accessible via Ctrl+Tab — shows tool timeline, cost, per-agent stats. This is the deep-dive view; what's missing is the at-a-glance indicators.

*Approach*: Create a centralized =SubagentTracker= that subscribes to the existing =TASK_SUBAGENT_PROGRESS_CHANNEL= EventBus channel, then wire it into the status line, todo panel, task render, and session exit.

*Key decisions*:
1. SubagentTracker is the single source of truth for running subtask state — status line, todo panel, and exit summary all query it
2. Status line shows: =N agents · $0.42 · editing src/foo.ts= (count + cost + most active agent activity)
3. Todo panel replaces =[delegated]= with live spinner + tool activity for in-progress tasks
4. Inline efficiency line after batch completion: =Efficiency: 45K avg/task · 68% cache · 2.3x parallel=
5. Session exit line: =Subtasks: 8 launched · 320K tokens · $1.23 · 40K avg/task · 72% cache=
