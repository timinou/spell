* Context
Org items created by subtasks (via the =task= tool) have their =* Initial Message= section
populated with the entire subtask assignment/context blob instead of the user's original message.

The root cause is ~buildSessionContext()~ in =packages/coding-agent/src/tools/org.ts= which
unconditionally reads ~session.getFirstUserMessage()~. In subtask sessions (taskDepth > 0),
that returns the parent agent's assignment text, not the actual user input.

The fix gates ~initialMessage~ on ~taskDepth === 0~. The ~taskDepth~ field already exists on
the =ToolSession= interface. Items created by subtasks still retain =SESSION_ID= and
=TRANSCRIPT_PATH= for traceability.
