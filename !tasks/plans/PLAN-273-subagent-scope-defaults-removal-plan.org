Settled decisions:
1. Keep parent-session / subagent cwd default unchanged.
2. Remove bundled ~quick_task~ scope restriction by default.

5. Fix outside-cwd aborts at the mutation boundary by deriving a truthful effective edit root from explicit targets, not by re-rooting sessions.
6. Add regression tests at both task/prompt and code/task boundary levels before implementation.
