* Approach

** ITEM Replace top/bottom borders with a full-frame wrapping container
:PROPERTIES:
:EFFORT: 25m
:END:

Replace the two separate =UserPausedBorderComponent= instances with a single =UserPausedFrameContainer= that wraps all main TUI children and draws a 4-sided frame when paused.

*** Design

The TUI renders a flat list of lines via =Container.render(width)=. A wrapping container can override =render()= to:
- When not paused: delegate to =super.render(width)= (pass-through)
- When paused: delegate to =super.render(width - 2)= (narrower for side borders), then frame every line with =║= left/right, and add top (=╔═══╗=) / bottom (=╚═══╝=) double-line borders

Double-line box characters (=║═╔╗╚╝=) give a naturally thicker look compared to single-line (=│─┌┐└┘=).

Color: purple. Reuse =planMode= color =#9b7ec8= from the theme. Change =getUserPausedBorderColor()= to return =planMode= instead of =warning=.

*** Render implementation

#+begin_src typescript
class UserPausedFrameContainer extends Container {
  constructor(private readonly isPaused: () => boolean) { super(); }

  invalidate(): void {
    for (const child of this.children) child.invalidate();
  }

  render(width: number): string[] {
    if (!this.isPaused()) {
      return super.render(width);
    }
    const colorize = theme.getUserPausedBorderColor();
    const innerWidth = Math.max(1, width - 2);
    const childLines = super.render(innerWidth);

    const h = "═".repeat(Math.max(1, width - 2));
    const top = colorize(`╔${h}╗`);
    const bot = colorize(`╚${h}╝`);
    const v = colorize("║");

    const framedLines = childLines.map(line => {
      const vis = visibleWidth(line);
      const pad = Math.max(0, innerWidth - vis);
      return v + line + padding(pad) + v;
    });

    return [top, ...framedLines, bot];
  }
}
#+end_src
