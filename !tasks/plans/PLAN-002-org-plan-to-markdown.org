* Problem

Plan content is org-mode text (~* Heading~, ~** Sub-heading~, ~~code~~). It is consumed in two places that interpret it as markdown:

1. *TUI plan preview* — ~interactive-mode.ts:931~ passes raw org to ~new Markdown(planContent, ...)~. In markdown, ~* text~ is an unordered list item, so org headings render as bullets.
2. *LLM prompts* — ~plan-mode-approved.md~ and ~plan-mode-reference.md~ inject raw ~{{planContent}}~ under a ~## Plan~ heading. The executing LLM reads ~* Problem~ as a list item instead of a section heading.

* Solution

~orgToMarkdown()~ already exists in ~@oh-my-pi/pi-org~ (file: ~packages/org/src/org-parse.ts~). It uses a full AST pipeline: uniorg parse → hast → mdast → CommonMark. It handles headings, src blocks, links, and strips PROPERTIES drawers. It is already exported from the package and ~@oh-my-pi/pi-org~ is already a dependency of ~packages/coding-agent~.

Wire ~orgToMarkdown~ into both consumption sites. No new utility needed.
