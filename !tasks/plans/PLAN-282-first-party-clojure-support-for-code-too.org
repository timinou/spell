* Context
User requested a deep implementation approach for first-party Clojure integration in Spell's Rust-backed code tool. Settled decisions:
1. Scope: first-party semantic support, not parser-only. Include MVP native support plus dedicated namespace graph, aliases, `:refer`, tests, protocols, and keyword indexing.
2. Runtime: no runtime execution in this plan. Leave seams for optional future nREPL/clj-kondo/clojure-lsp enrichment; normal `code index` remains pure/static. Deferred follow-up item created but intentionally not linked into this execution plan: FUP-066-optional-clojure-runtime-and-analyzer-en.
3. EDN: add EDN as a separate data-language profile with read/form navigation/edit semantics and no graph capability.
4. Graph model: add Clojure-specific symbol and edge kinds for namespaces, vars, protocols, tests, aliases, and keywords instead of collapsing them into generic class/method/import concepts.
5. Dependency-root detection: parse `deps.edn` and `project.clj` enough to discover source/test paths; degrade to conventional roots when parsing fails.

Key current-repo findings:
- `crates/pi-code-engine/src/language/mod.rs` registers built-in profiles for TypeScript, Rust, Python, HTML, CSS, Typst, Markdown, Elixir, Org, and text; Clojure is absent.
- `crates/pi-code-engine/src/language/profile.rs` defines `LanguageProfile`, the central abstraction for outline/read/navigate/resolve/edit/graph behavior.
- `crates/pi-code-engine/build.rs` generates grammar metadata from tree-sitter node-types; Clojure must be added there.
- `crates/pi-code-graph/src/language.rs` defines `LanguageExtractor` and `ImportResolver`; Clojure should use a dedicated extractor/resolver.
- `crates/pi-code-graph/src/model.rs` currently lacks Clojure-specific symbol/edge kinds.
- `crates/pi-natives/src/language/mod.rs` implements ast-grep language support; Clojure must be added to `SupportLang` and extension dispatch.
- `packages/coding-agent/src/tools/code.ts` can inject language-specific hints; Clojure should add one to guide agents toward form-safe edits and macro honesty.
- `packages/coding-agent/src/lsp/utils.ts` already maps `.clj` to `clojure`; `.cljs`, `.cljc`, and `.bb` must be verified/added.
- Verbatim design report saved at `specs/clojure-code-tool-first-party-integration.md` for cross-session reference.

Non-goals:
- Full macro expansion.
- Runtime nREPL execution during indexing.
- JAR/classpath indexing.
- Perfect dynamic var/eval resolution.
- Treating EDN as graph-capable Clojure code.
