* Context

Build a generic loop orchestration system for Spell, inspired by Ralph Wiggum's iterative agent loop pattern but rebuilt from scratch using Spell's native primitives (EventBus, org items, canvas, prompt templates). The system enables long-running autonomous agent loops with recursive decomposition, multi-gate validation, three-way LLM switching (planning/coding/review), and a canvas dashboard for monitoring and control.

** Origin
Ralph Wiggum (@tmustier/pi-ralph-wiggum v0.1.6) implements iterative agent loops with file-based state, context refresh between iterations, and optional reflection checkpoints. Its 802 lines use Pi's ExtensionAPI. Rather than porting it, we absorb the pattern and rebuild with Spell idioms for deeper integration with org, canvas, plan mode, and the model registry.

** Key Design Decisions
- Absorb pattern, don't vendor: rebuild using Spell's EventBus, org items as primary state, .local/!tracks/ for runtime telemetry
- Contracts first: TypeBox schemas for all event types stabilized before any consumer
- Recursive loops: depth-limited (default 3) with escalation at limit, policy-per-edge for child failures (default retry(2)-then-block)
- Concurrent loops: configurable limit (default 2), smart isolation (shared tree when safe, worktree when paths overlap)
- Three-way LLM switching: plan -> code -> review per iteration, with structured HandoffArtifact between switches
- Dedicated review model role: must be configured before any loop workflow starts
- Four gate types: command, LLM-review, artifact, human. Configurable triggers. Diff-aware failure dedup with immediate escalation on repeated findings
- Auto-approve: configurable per gate (default 5min for human gates), toggle in GUI/TUI
- Canvas dashboard + CLI fallback: timers server-side, canvas is view-only, reconnect rebuilds from org+tracks
- Git integration: reject dirty tree (propose checkpoint), checkpoint commits with loop metadata, opt-in worktrees, spec drift detection at reflection
- 6 validation domains at MVP: code, test, architecture, ui, security, documentation
- Spec ingestion: org-to-org import with minimal format requirements (CUSTOM_ID headings + [[id:]] links), readiness validation workflow before launch
- TDD throughout: tests defined before implementation for every item
- State hierarchy: org authoritative for semantic state, .local/!tracks/ authoritative for runtime telemetry, event log enables crash recovery
- Budgets and safeguards: wall-clock (4h default), iteration count (200 default), runaway detection (5 idle iterations), kill switch

** Architecture
New code lives in packages/coding-agent/src/loop/ with contracts, gates, persistence, recursion, orchestration, git, domains, ingestion, safeguards, and replay subdirectories. Tests in packages/coding-agent/test/loop/ and test/integration/loop/. Canvas dashboard in src/modes/qml/LoopDashboard.qml. Org-ql extensions in packages/org/elisp/tools/. Three new test helpers: LoopJourney, IntegrationJourney, virtual-clock, stub-llm.
