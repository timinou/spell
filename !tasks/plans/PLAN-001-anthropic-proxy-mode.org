* Problem

When =models.yml= configures anthropic with =baseUrl: http://localhost:8080=, the user still needs =ANTHROPIC_API_KEY="sk-ant-oat" spell= to make it work because:  # pragma: allowlist secret
1. Without an API key, spell refuses to start (auth validation fails)
2. =isAnthropicOAuthToken()= misdetects the key type, sending wrong auth headers

The user wants: =baseUrl: http://localhost:8080= + =proxy: true= in models.yml, no apiKey needed.

* Approach

=proxy: true= on a provider means:
- Treat it as keyless (like ollama/llama.cpp) — add to =#keylessProviders= so =getApiKey()= returns =kNoAuth= ("N/A"), bypassing all API key resolution
- Force =isOAuth: true= in the streaming layer so =Authorization: Bearer= is used (not =X-Api-Key=)
- Skip API key validation for this provider
