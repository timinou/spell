- TUI working status: ~packages/coding-agent/src/modes/controllers/event-controller.ts~ and ~packages/coding-agent/src/modes/interactive-mode.ts~.

Recommended approach only:
1. Update pi-ai Anthropic idle timeout default to 180,000ms.
2. Preserve and prioritize ~PI_ANTHROPIC_STREAM_IDLE_TIMEOUT_MS~.
3. Add public pi-ai runtime override setter for coding-agent config.
4. Add coding-agent setting ~providers.anthropicStreamIdleTimeoutMs~ default 180000; ~0~ disables.
5. Wire settings at session creation and via settings hook for future requests.
6. Add terminal keepalive timer for assistant stream silence; show phase/elapsed/last-event/timeout without raw thinking content.

Non-goals:

- No OpenAI/Bedrock default change.
- No provider-wide transport rewrite.
- No transcript mutation or synthetic assistant deltas for keepalive.
