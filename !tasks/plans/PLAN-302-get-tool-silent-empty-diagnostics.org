* Context

Session `14d54f5d0e274ba8` (2026-05-05, agentmaker) traced 7 `get` tool calls → 5 failures. Agent abandoned `get` and fell back to `bash sed/grep/cat` for all subsequent file reading.

Three root causes identified:
1. Zero-matches resolution (glob or file-not-found) produces `§not-found` node without diagnostic when suffix fallback finds nothing → `formatForTool` returns `""`
2. "Did you mean" suggestions lack CWD context → agent repeats wrong path prefix across calls
3. No safety-net guard against empty output in `formatForTool` → any future regression silently breaks the tool

Each bug is a 5-15 line surgical fix. No architecture changes. The existing FEAT-688/711/683 scaffolding (suffix fallback, ENOENT distinction, degenerate-result hints) is already in place — these three fill the remaining diagnostic gaps.
