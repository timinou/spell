* Initial Message

what's left to completely remove the emacs part of the code tool? clean and final break

* Context

The org tool currently depends on an Emacs daemon for advanced operations: complex queries (date ranges, clocked time, effort filtering), dependency graph computation, wave scheduling, and section editing. This creates a heavy runtime dependency (Emacs 29.1+, socat) and architectural inconsistency — the code tool already uses a native Rust engine (pi-code-engine with tree-sitter), while the org tool relies on MCP calls to an Emacs daemon over Unix socket.

The org tool is already ~80% native TypeScript (init, create, get, update, note, set, archive, simple queries). Only 5 specific =callTool= operations go through Emacs: =org-ql-query=, =org-edit-section=, =org-compute-waves=, =org-next-wave=, and =org-dependency-graph=.

** Approach

Build a new Rust crate =pi-org-engine= with tree-sitter-org for incremental org-mode parsing, a native query engine (replacing org-ql), and native graph algorithms (replacing elisp graph tools). Expose through NAPI in =pi-natives= following the =executeCodeBuffer= pattern. Migrate the org tool to use the native engine, remove the Emacs bridge, remove the =pi-emacs= package entirely.

** Key Decisions

1. New Rust crate =crates/pi-org-engine/= following pi-code-engine architecture
2. Vendored tree-sitter-org grammar (milisims, MIT) in workspace crate =crates/tree-sitter-org/= — published crate requires tree-sitter <0.21, project uses 0.25
3. Tree-sitter provides document structure; custom Rust extracts semantics (TODO states, properties, timestamps, CLOCK entries, effort)
4. Query engine replaces org-ql: keyword syntax supported, raw sexp dropped
5. Graph engine replaces elisp: iterative DFS cycle detection, Kahn's algorithm for waves, union-find for connected components
6. NAPI bridge: single =executeOrg= function, command dispatch pattern
7. Writes stay in TypeScript (org-writer.ts); section editing uses native byte ranges
8. Uniorg + 6 npm deps removed; org-to-markdown conversion in Rust
9. Full clock/effort support: CLOCK parsing, duration aggregation, effort normalization
10. =packages/emacs/= removed entirely (76 combobulate .el files, MCP server, daemon management)
11. =packages/org/elisp/= removed (MCP tools superseded by Rust engine, ERT tests by Rust tests)
12. AGENTS.md "Elisp-First Policy" replaced with "Native-First Policy"
