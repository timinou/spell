Post-implementation audit of PLAN-077 (task auto-roster) identified 5 bugs across 3 categories: serialization bypass, orphan state, and UX regression. All issues are in ~packages/coding-agent/src/task/index.ts~ and ~packages/coding-agent/src/tools/todo-write.ts~.

** Approach
All 5 bugs are code-independent (Metis gap analysis confirmed no real cross-dependencies). Each bug item owns its tests inline (TDD: write tests first, then implement fix). Former standalone test items (FEAT-202, FEAT-203) have been dissolved into BUG-077 and BUG-078 respectively.

** Key Design Decisions
1. *BUG-077 (reentrancy)*: Use ~AsyncLocalStorage~ from ~node:async_hooks~ instead of depth counter. A depth counter stored in a WeakMap shares state across async contexts and has the same bypass bug as the WeakSet. ALS associates state with the async execution context, correctly distinguishing nested calls (bypass) from concurrent calls (queue).
2. *BUG-078 (orphan items)*: Guard pattern before ~#autoCreateTodoRefs~: ~if (asyncEnabled && !blocking && !asyncJobManager)~ return error. Preserves sync and async+blocking paths.
3. *BUG-079 (double-count)*: 4 fix sites (lines 670, 674, 785, 786, 791), not 2. Use ~failedJobs~ as single source of truth; keep ~failedSchedules~ only for text content.
4. *BUG-080 (synthetic sessionId)*: Use ~sessionId: \"skipped\"~ sentinel in ~#finalizeSkippedTodoRef~. 1-line change, no type modifications to ~TodoDelegation~.
5. *BUG-081 (phase names)*: Exact-match skip-list for structural headings (Goal, Non-goals, Constraints, API Contract, Acceptance). No substring matching.
