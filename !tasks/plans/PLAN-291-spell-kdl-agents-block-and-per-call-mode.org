* Context

** Goal
Extend task tool customisation so users can declaratively assign models (and other defaults) to groups of agents (e.g. "all explore agents → anthropic/claude-haiku-4-5") via `spell.kdl`, plus expose a per-call `model` override on the task tool's JSON schema so a calling agent can pick a model for a single dispatch.

** Background (from planning session)
- Today's only override surfaces are settings DB (`task.agentModelOverrides[name]` exact-name only, `task.disabledAgents[]`) and bundled/user agent markdown frontmatter (`model:`, `thinkingLevel:`, `tools:`).
- `spell.kdl` currently parses only `domain`, `import`, `layer`, `policy`. The `policy` node configures org-item layer gates — orthogonal to subagent dispatch.
- A separate branch worktree `/home/user/code/ora/spell_kdl-config` already migrated the full settings system into `spell.kdl` form: `loadUserSpellKdl`, `mergeSpellConfigs(user, project)`, `kdlDocumentToSettings`, plus `tasks { }`, `keybindings { }`, `modes { }`, `providers { }` blocks. That branch's last main merge is `e0aa813bd`; current main HEAD at planning time is `5987345a4`. Branch is +13k/-42k versus main across 564 files.

** Settled decisions
1. Two-phase delivery: rebase/merge `spell_kdl-config` config-only diff onto main first (FEAT-643), then add `agents { }` selector layer on top (FEAT-644…648). Branch's task/scheduler refactors are NOT in scope — config layer only.
2. Selector forms: positional bare-string argument on each `rule`. Auto-detect: contains `*` or `?` → glob; otherwise exact match. Wildcards: `*`, `?`.
3. Specificity (highest → lowest): exact > prefix-glob (`name*`) > suffix-glob (`*name`) > infix (`*name*`) > catch-all (`*`).
4. Tie-breaker: same-specificity ties resolve by last-declared. Conflicts surface as `agentRuleConflicts` on TaskToolDetails and as a yellow warning in the `/agents` dashboard inspector.
5. Config home: project `spell.kdl` (cwd) + user `~/.spell/spell.kdl`. Project rules merge after user → project wins ties.
6. Resolution precedence (highest → lowest): per-call task `model` > per-call batch `model` > project spell.kdl rule > user spell.kdl rule > settings DB (`task.agentModelOverrides[name]` retained as escape hatch) > frontmatter `model:` > role alias > parent active model.
7. v1 rule keys: `model`, `thinking-level`, `tools` (replace, not append), `disabled` (boolean). v2 deferred to FUPs: `spawns`, `prepend-tools`, `append-tools`, parent-context-aware rules.
8. v1 per-call shape: `model: string` per task item + batch-level `model: string` default. Item wins over batch.
