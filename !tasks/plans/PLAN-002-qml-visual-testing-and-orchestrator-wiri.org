* Decisions (settled)

** Input simulation: QGuiApplication::sendEvent(), NOT QTest

Qt6::Test is not linked and we avoid adding a build dependency. ~QMouseEvent~, ~QKeyEvent~, ~QWheelEvent~ are from QtGui, transitively available via Qt6::Quick (already linked). Use ~QGuiApplication::sendEvent(rootWindow, &event)~ where ~rootWindow~ is the ~QQuickWindow*~ obtained from ~qobject_cast<QQuickWindow*>(engine->rootObjects().first())~. The window does its own hit-testing internally via the scene graph.

** sendEvent target is always QQuickWindow

Never send events to a QQuickItem directly. Qt's event delivery pipeline is: window -> scene graph -> item. Coordinates in QMouseEvent are window-local. For selector-based click: resolve item via walkTree, compute center = ~scenePosition + (width/2, height/2)~, then ~QGuiApplication::sendEvent(rootWindow, &mouseEvent)~ with that center as position.

** Bridge delivery fix: setBridge() method on CanvasOrchestratorManager (Option A)

Add ~#bridge~ field + ~setBridge()~ method. Make ~getBridge~ optional in options. Call ~setBridge(bridge)~ from qml-mode.ts after bridge creation, ~setBridge(undefined)~ on dispose. Two files changed.

** Escalate tool: customTools field on ExecutorOptions

Add ~customTools?: CustomTool[]~ to ~ExecutorOptions~. Merge with MCP proxy tools in ~runSubprocess()~ session creation. The orchestrator manager creates the escalate proxy tool and passes it via this field. Follows existing MCP proxy pattern. Does NOT use onEscalate callback — the tool carries its own handler via closure.

** Interactive element detection for observe()

The codebase uses ~SpellUI.StateLayer~ (custom MouseArea wrapper) for all clickable surfaces, NOT standard Qt Button controls. The interactive element whitelist for ~observe()~:
- ~QQuickMouseArea~ (catches StateLayer's inner MouseArea)
- ~QQuickTextEdit~
- ~QQuickTextInput~
- ~QQuickFlickable~ (scrollable containers)

Detection in C++: ~matchesSelector~ gains an ~interactive~ boolean filter. When true, checks if className starts with any of the above prefixes.

** settle() implementation

~settle()~ sends an eval command with expression ~"true"~ and waits for ~eval_result~. This forces a round-trip through the C++ event loop, guaranteeing synchronous property bindings and signal handlers have completed. Accepts optional ~delayMs~ parameter (default 50) for animation-dependent assertions — sleeps after the eval round-trip.

** Input result confirmation events

All input commands (~click~, ~type~, ~press~, ~scroll~) return an ~input_result~ event. The harness waits for this before returning. No fire-and-forget. Consistent with existing protocol pattern (screenshot, query, eval all return results).

** Scroll convention

Positive ~deltaY~ = scroll up (away from user). Matches Qt ~QWheelEvent::angleDelta()~ convention. No inversion.

** Key name mapping

Minimal lookup table in C++: Return, Enter, Escape, Tab, Backspace, Delete, Up, Down, Left, Right, Space, Home, End, PageUp, PageDown. Single-character keys (a-z, 0-9, punctuation) mapped via ~QChar~. Unknown keys return error in ~input_result~. Implemented as ~static QHash<QString, int>~ initialized once.

** Tests don't need real LLM

PROJ-F integration tests simulate the agent side via ~sendMessage()~ / ~agentSends()~. Tests verify QML UI responds correctly to the message protocol. No model provider needed.

*** Escalation flow (step by step)
1. QML button click sends ~{ _tier: "orchestrator", _scope: "Review this diff" }~
2. canvas.ts ~#flushEvents~ routes to ~CANVAS_ORCHESTRATOR_CHANNEL~ at P1
3. CanvasOrchestratorManager receives event, calls ~#handleRequest~
4. ~#handleRequest~ creates escalate proxy tool + orchestrator agent definition
5. Calls ~runSubprocess()~ with customTools containing the escalate tool
6. Orchestrator agent runs, decides it needs full capabilities
7. Orchestrator calls ~escalate~ tool with reason + assignment
8. Escalate proxy callback spawns a full agent via second ~runSubprocess()~
9. Full agent completes, result flows back through the callback
10. Orchestrator receives result text, completes its turn
11. CanvasOrchestratorManager sends result to canvas via ~this.#bridge~

*** Edge cases
- Orchestrator aborted mid-escalation: same AbortController signal cancels both. The escalate callback catches the abort and returns an error string (not throws).
- Escalated agent fails: callback catches, returns error text. Orchestrator can report it gracefully.
- Multiple escalations from same orchestrator: each creates a new subprocess. They run sequentially within the orchestrator's agent loop.

void WindowManager::clickInWindow(QLocalSocket *client, const QString &id, const QJsonObject &msg) {
    auto it = m_windows.find(id);
    if (it == m_windows.end()) { /* error event */ return; }

    auto *rootWin = qobject_cast<QQuickWindow *>(it->engine->rootObjects().first());
    if (!rootWin) { /* error: not a QQuickWindow */ return; }

    double x, y;

    if (msg.contains("selector")) {
        // Selector mode: find element, compute center
        QJsonArray items;
        auto *rootItem = rootWin->contentItem();
        QuerySelector sel = parseSelector(msg["selector"].toObject());
        QJsonArray props;
        walkTree(rootItem, sel, props, true /* includeGeometry */, 20, 0,
                 QString(rootItem->metaObject()->className()), items);

        if (items.isEmpty()) {
            // error: no element matching selector
            QJsonObject ev;
            ev["type"] = "input_result";
            ev["id"] = id;
            ev["command"] = "click";
            ev["success"] = false;
            ev["error"] = "No element found matching selector";
            writeEventToOwner(id, ev);
            return;
        }

        QJsonObject geom = items[0].toObject()["geometry"].toObject();
        QJsonObject scenePos = items[0].toObject()["scenePosition"].toObject();
        x = scenePos["x"].toDouble() + geom["width"].toDouble() / 2.0;
        y = scenePos["y"].toDouble() + geom["height"].toDouble() / 2.0;
    } else {
        x = msg["x"].toDouble();
        y = msg["y"].toDouble();
    }

    QPointF pos(x, y);
    QPointF globalPos = rootWin->mapToGlobal(pos);

    QMouseEvent press(QEvent::MouseButtonPress, pos, globalPos,
                      Qt::LeftButton, Qt::LeftButton, Qt::NoModifier);
    QGuiApplication::sendEvent(rootWin, &press);

    QMouseEvent release(QEvent::MouseButtonRelease, pos, globalPos,
                        Qt::LeftButton, Qt::NoButton, Qt::NoModifier);
    QGuiApplication::sendEvent(rootWin, &release);

    QJsonObject ev;
    ev["type"] = "input_result";
    ev["id"] = id;
    ev["command"] = "click";
    ev["success"] = true;
    ev["x"] = x;
    ev["y"] = y;
    writeEventToOwner(id, ev);
}

void WindowManager::typeInWindow(QLocalSocket *client, const QString &id, const QString &text) {
    auto it = m_windows.find(id);
    if (it == m_windows.end()) { /* error */ return; }
    auto *rootWin = qobject_cast<QQuickWindow *>(it->engine->rootObjects().first());
    if (!rootWin) { /* error */ return; }

        QKeyEvent press(QEvent::KeyPress, 0, Qt::NoModifier, QString(ch));
        QKeyEvent release(QEvent::KeyRelease, 0, Qt::NoModifier, QString(ch));

    ev["type"] = "input_result";
    ev["id"] = id;
    ev["command"] = "type";
    ev["success"] = true;
    ev["length"] = text.length();

}

void WindowManager::pressKeyInWindow(QLocalSocket *client, const QString &id,
                                     const QString &key, const QString &modifiers) {
    // ... window lookup ...
    static const QHash<QString, int> keyMap = buildKeyMap();

    int qtKey;
    QString text;
    if (key.length() == 1) {
        qtKey = QChar(key[0]).toUpper().unicode();
        text = key;
    } else {
        auto found = keyMap.constFind(key);
        if (found == keyMap.constEnd()) {
            // error: unknown key name
            return;
        }
        qtKey = *found;
        if (qtKey == Qt::Key_Space) text = " ";
    }

    Qt::KeyboardModifiers mods = Qt::NoModifier;
    // Parse modifiers string if provided ("Shift", "Ctrl", "Alt", "Shift+Ctrl")

    QKeyEvent release(QEvent::KeyRelease, qtKey, mods, text);

async observe(): Promise<ObservationEntry[]> {
  const interactiveTypes = ["QQuickMouseArea", "QQuickTextEdit", "QQuickTextInput", "QQuickFlickable"];
  const allItems: ObservationEntry[] = [];
  let nextId = 1;

  for (const typeName of interactiveTypes) {
    const items = await this.findItems(
      { type: typeName, visible: true },
      { includeGeometry: true, properties: ["text", "objectName"] },
    );
    for (const item of items) {
      if (!item.geometry || item.geometry.width <= 0 || item.geometry.height <= 0) continue;
      allItems.push({
        id: nextId++,
        className: item.className,
        objectName: item.objectName,
        text: item.properties.text as string | undefined,
        geometry: item.geometry,
        scenePosition: item.scenePosition ?? { x: item.geometry.x, y: item.geometry.y },
        enabled: item.enabled,
        visible: item.visible,
      });
    }
  }

  this.#lastObservation = allItems;
  return allItems;
}

async clickId(id: number): Promise<void> {
  if (!this.#lastObservation) throw new Error("Call observe() before clickId()");
  const entry = this.#lastObservation.find(e => e.id === id);
  if (!entry) throw new Error(`No observed element with id ${id}`);
  const x = entry.scenePosition.x + entry.geometry.width / 2;
  const y = entry.scenePosition.y + entry.geometry.height / 2;
  await this.clickAt(x, y);

*** QmlJourney API Reference

The ~QmlJourney~ class wraps ~QmlTestHarness~ for integration testing. All paths are resolved relative to the QML modes directory (~packages/coding-agent/src/modes/qml/~).

*Lifecycle:*

| ~teardown()~ | Calls harness.teardown(). |

*Agent simulation — things the agent sends to QML:*

| Method | Description |
|--------+-------------|
| ~agentSends(payload)~ | Sends a message to QML via bridge. This is how you simulate agent actions (adding panels, sending dashboard updates, streaming messages). Wraps ~harness.sendMessage(payload)~. |

    }
  }

    const dir = path.resolve(import.meta.dir, "../integration/screenshots");

  }

    return this.#harness.findItems(...args);
  }
