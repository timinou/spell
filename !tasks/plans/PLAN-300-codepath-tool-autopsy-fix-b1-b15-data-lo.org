** Settled design decisions

1. *B1 routing*: FsResolver.supports() now takes &CodePath; rejects Delete/Move/Rename/Create/Write when query or non-FS qualifier is present. CodeResolver claims symbol-target Delete (already does). Diagnostic SymbolDeleteWithoutResolver added to types.rs.
2. *B2/B10 routing*: Add `is_text_qualifier_only(cp)` predicate (no query, qualifier in {raw,bytes,lines,text,match,image}) → route to TextResolver. Format param remains a presentation hint, not a routing override.
3. *B3 normalizer*: edit.ts copies `lines`, `pos`, `end`, `diff` into kernel JSON. Schema already accepts; pure propagation fix.
4. *B4 wrap*: Replace full-buffer parse-validity check with subtree parse (scoped to wrap-region byte range). Diagnostic identifies first-error node when subtree fails. Reject still preserved for genuinely malformed templates.
5. *B5 force*: `evaluateWriteGuards` accepts `force` flag; shrink guard skipped under force; parse-regression always on. Force ≠ break-the-file.
6. *B6 manage*: Add `command:"manage"` branch in execute_code_path_inner BEFORE target parsing. Subcommand handlers in new `manage.rs`. Target optional when manage. Implements save/index/languages/buffers/undo/redo/status/watcherStatus/lockStatus/diff.
7. *B7 LINE#ID*: text axes emit `path:line:N#XX` locator with 2-char base32 hash of line content (CRC-32 truncated). Display formats as `LINE#ID:` prefix. `pos:"5#XY"` validates hash on edit; AnchorMismatch diagnostic on drift.
8. *B8 positional*: Line numbers are ABSOLUTE; symbol target = enforcement scope. Error message includes target line range and remediation hint. Relative-line semantics rejected as it would conflict with LINE#ID anchors.
9. *B9 clone*: `Action::Clone` gets optional `content: ActionContent`; when present, clone is renamed to that identifier. Identifier validated per language.
10. *B11 name lexers*: Each dialect's `NameLexer::matches()` consults the per-language NameExtractor via a NameLexerContext. TS interfaces, type aliases, classes resolve correctly; Python classes; Go structs/interfaces; Haskell data/class; CSS selector classes.
11. *B12 stat render*: Pure TS-side fix. codepath-result.ts recognizes §file/§dir/§symlink with stat metadata; renders `path [§file size=N mtime=ISO]`.
12. *B13 diff*: manage.ts.renderResult selects `language: "diff"` when subcommand=="diff"; matches edit.ts pattern.
13. *B14 not-found*: get.ts catches ENOENT/EACCES from stat probe; emits PATH_NOT_FOUND/PATH_NOT_READABLE before kernel call. Trailing-slash hint deferred.
14. *B15 transaction*: Default best-effort first-failure-abort preserved. New opt-in `transaction:"strict"` on CodePathOptions snapshots target files before action loop, restores all on any failure. Diagnostic mentions rollback count.
