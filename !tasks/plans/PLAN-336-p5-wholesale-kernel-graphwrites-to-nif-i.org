* P5.1 — graph edges + writes cut over to the NIF

Today only the BEAM READ lane works; a PTC program over the BEAM can read code
but cannot follow `def→/ref→/call→` or apply an edit through the kernel.
- Add host-agnostic edge + mutation entries callable by the NIF. Edges are the
  cheaper half (resolver already CancellationToken-clean). Writes require the
  buffer-registry state to be reachable host-agnostically (the harder half;
  may stage as P5.1a edges, P5.1b writes).
- Mirror the NAPI dispatch: `edge_dispatch::resolve` / `mutation::try_apply`.
- Gate: NIF edge/write result byte-identical to NAPI (extend kernel_parity
  discipline to edges + a mutation round-trip).
Enables: full graph + write parity for the BEAM execute substrate (`tool/find`
edges, a future `tool/edit`).

* P5.2 — code-graph INDEX wholesale into the warm BEAM kernel

Today (GT-7, "two-kernels RAM"): the index builds NODE-side
(code_graph.rs::run_code_graph → ensure_graph); the BEAM has its own resident
runtime. N agents on a node ⇒ N index builds ⇒ N RAM copies.
- Add a host-agnostic index entry (wrapping pi-code-graph's CodeGraphBuilder +
  CacheStore) the NIF can drive; index resident in the ONE warm BEAM kernel.
- Cancellation via FUP-132's probe (per-caller abort of a shared walk).
- Open: embeddings worker (pi-knowledge-worker) interaction — the index build
  calls out to the embedding daemon; that lane must be reachable from the BEAM
  side (or the index build stays embeddings-free and the semantic lane is added
  later).
Enables (THE bet, spec 09:53): one warm kernel, N agents, index built ONCE per
node, shared. Resolves GT-7.

* P5.3 — N-3 zero-copy HandleStore: ETS-style copy → ResourceArc

Today HandleStore avoids the copy on READS (projections run in-owner) at the
cost of a GenServer.call per projection; large terms still get copied once into
the owner at `put`.
- Back large handles with a rustler ResourceArc so payloads cross the NIF
  boundary by reference, not copy. Language semantics unchanged (handle.ex
  contract identical) → lands after gates green without touching D-2.
Enables: true zero-copy for large tool results / pmap fan-out. Lowest-risk of
the three.
