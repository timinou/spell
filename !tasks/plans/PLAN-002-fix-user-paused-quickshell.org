* Initial Message

why does hitting user_paused on a session not update the spell indicator in quickshell?

* Problem

Toggling user_paused (Alt+Shift+U) does not update the Quickshell/Niri status indicator.

Root cause: ~handleToggleUserPause()~ in ~packages/coding-agent/src/modes/interactive-mode.ts~ (line 1518) toggles ~#isUserPaused~ and calls ~this.ui.requestRender()~ but does NOT call ~this.#niriListener?.()~. Without that call, the NiriOverviewController never re-derives status and never writes the updated ~.spell/status/<windowId>.json~ file. Quickshell polls that file every 2s — no file change means no visual update.

Other state changes (e.g. ~isPendingApproval~ at line 1042) correctly call the niri listener.

* Fix

** ITEM Add niriListener call to handleToggleUserPause
:PROPERTIES:
:EFFORT: 5m
:END:

File: ~packages/coding-agent/src/modes/interactive-mode.ts~, line ~1524 (after ~this.ui.requestRender()~).

Add: ~this.#niriListener?.();~

This matches the pattern used at lines 1042 and 1045 for other state transitions.

* Verification

- Toggle user_paused with Alt+Shift+U while in needs_input state
- Confirm ~.spell/status/<windowId>.json~ updates to show ~"status": "user_paused"~
- Confirm Quickshell workspace dot changes to mauve
- Toggle again, confirm it reverts to ~needs_input~ with yellow blinking
