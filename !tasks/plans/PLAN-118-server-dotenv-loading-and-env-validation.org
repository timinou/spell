* Initial Message

enable reading from the local .env with a setting toggle on the server kdl when i run spell server and the right config is on in the kdl. show at the start which env variables have been got and which ones are missing. fail if any env required by the kdl is missing, explain with a message which config I need to add

* Context
The spell-server KDL config supports =env()= references in =autonomy.kdl= (full syntax with type coercion, defaults, optional) and partially in =channels.kdl= (voice API keys only, via a local =resolveEnvValue()= function). The =server.kdl= parser has no env support at all — values are always literal.

The user wants to:
1. Toggle =.env= loading from the config directory via a KDL setting
2. See at startup which env vars were loaded and which are missing
3. Fail hard if any required env var is missing, with an actionable error message

** Approach
- Add =dotenv true= top-level node to =server.kdl= to enable .env loading from config dir
- Extract shared env resolution module from =manifest/parser.ts= (DRY — three parsers need it)
- Extend =env()= syntax support to =server.kdl= and generalize in =channels.kdl=
- Pre-validation scan: before parsing configs, regex-scan all KDL files for =env()= refs, validate them all at once, report found/missing, fail with an aggregated error listing all missing vars (not one at a time)
- The dotenv toggle controls .env file loading. =env()= syntax always resolves against =process.env= regardless of toggle — the toggle just populates process.env from a file first

** Key decisions
- =dotenv= config is loader-level, not part of =SpellServerConfig= (it's meta-config about how to load config)
- =parseDotenvConfig= is a separate function, extracted first from server.kdl text before full parsing
- Pre-validation scan runs only when dotenv is enabled (when disabled, parser-level errors handle missing vars as before)
- =parseEnvFile= exported from =@oh-my-pi/pi-utils= for reuse (DRY with existing implementation)
- Startup report uses =console.error= (stderr) — spell-server is a daemon, not TUI

** KDL syntax example
#+begin_example
dotenv true

http {
  port 8787
  auth {
    username "admin"
    password "env(HTTP_PASSWORD)"
  }
  webhook-secret "env(WEBHOOK_SECRET)"
}
#+end_example
