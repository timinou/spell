* Design Decisions

- *Name*: =semantic= as KDL block + module path. Covers the whole pi-code-graph
  surface (tree-sitter extractors + LSP-backed inference are both "semantic"
  sources of code understanding). No KDL-level separation between graph
  options and inference options.
- *Trait shape*: =SemanticBackend= (role-suffix avoids =Semantic= reading
  oddly as a noun in trait-object positions).
- *Crate placement*: =pi-code-graph::semantic/=. No new crate. LSP client code
  lives under =pi-code-graph::semantic::lsp/=.
- *BM25 home*: =pi-knowledge-core::bm25= (one BM25 rule). Incremental API
  added there benefits org/memory too. =pi-code-graph::search.rs= deleted.
- *Persistence*: =pi-workspace-cache::CacheStore= primitive reused. Schema
  version bumped to handle the tombstone-bearing =SearchIndex= shape.
- *Vendored backends*: abandoned. LSP-spawn only.
- *Expert only*: PLAN-319 wires exactly one LSP (Expert for Elixir).
  Multi-language fans out in PLAN-320.

* BM25 Incremental API (W0 design lock-in)

#+begin_src rust
impl SearchIndex {
    // bulk (unchanged signature)
    pub fn from_docs<D: Document>(docs: &[D]) -> Self;

    // incremental
    pub fn add_doc<D: Document>(&mut self, doc: D) -> Result<(), IndexError>;
    pub fn remove_doc(&mut self, id: &str) -> bool;
    pub fn upsert_doc<D: Document>(&mut self, doc: D);
    pub fn upsert_batch<I, D>(&mut self, docs: I)
        where I: IntoIterator<Item = D>, D: Document;

    // maintenance
    pub fn compact(&mut self);
    pub fn len(&self) -> usize;
}
#+end_src

** Invariants (test suite)

| I1  | =add(D) + remove(D.id)= ≡ pre-state                             |
| I2  | =remove(id)= purges id-unique terms from inverted index         |
| I3  | =from_docs(corpus)= ≡ =empty.upsert_batch(corpus)=              |
| I4  | =upsert_batch(xs)= ≡ loop of =upsert_doc=                       |
| I5  | =total_tokens = Σ live doc tokens=, avg recomputed correctly    |
| I6  | =term_doc_freq[t] = \|{d: t ∈ d.tokens, d live}\|=              |
| I7  | bincode roundtrip preserves tombstones + id_to_index            |
| I8  | =compact()= preserves search results bit-identically            |
| I9  | incremental scores ≡ rebuild scores (load-bearing parity test)  |
| I10 | =add_doc= on duplicate id is hard error (caller must upsert)    |
