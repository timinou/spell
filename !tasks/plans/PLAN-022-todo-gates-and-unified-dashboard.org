* Context

** Problem
Plan implementations build artifacts and commit at the end of each plan, but individual phases within them produce no intermediate commits or artifact verification. A 14-FEAT plan across 4 phases results in one giant blob at the end. The AI has no mechanism to know which tasks require commits, artifacts, or verification commands.

** Approach
Extend todo_write with optional gate properties (GATE_COMMIT, GATE_ARTIFACT, GATE_CMD, GATE_LLM, VERIFY_CMD) per task, using soft enforcement (instruction injection in tool response text, no syscalls). Add blocked computed state via BLOCKER dependencies. Extend the QML dashboard with a context-adaptive TodoPanel that shows task state and lets users toggle gates. Add =/gui= slash command for manual dashboard access.

** Key Decisions (settled with user)
- *Enforcement*: Soft only. Text injection in =formatSummary()=, zero git checks, zero syscalls. AI self-polices.
- *Gate durability*: Fix =#cloneTodoPhases()= to preserve =details= AND gate fields. Gates survive session reload. TDD.
- *Gate authorship*: Both AI (via =InputTask= schema extension) and user (via QML panel). AI encouraged via prompt.
- *Phase completion hooks*: In =applyOps()= — detect last task in phase completing via before/after state comparison. Append directive to response.
- *Blocked status*: Computed from =pending + unresolved blockers=. Not a new enum value. =normalizeInProgressTask= skips blocked tasks.
- *Dashboard architecture*: Context-adaptive section in DashboardPanel.qml. Shows loop section when loop active, TODO section when tasks exist, both when both. Auto-registers when any task has gate properties.
- *Slash command*: =/gui= — opens/focuses the dashboard panel.
- *QML scope v1*: View-only + gate toggles. No task manipulation from QML.
- *Journal persistence*: Gate properties written as org properties in =.local/!journal/todos/= files.
- *GATE_COMMIT semantics*: Instruction only — text in response, zero git validation. Simplest and cheapest.
- *Dependencies*: =:BLOCKER: task-2= style, informational. Missing blocker ref (auto-cleared task) = resolved.
