# FS Dialect

Always present. Addresses files, directories, and symlinks in the project tree via glob syntax. Serves as the foundation for cross-dialect queries that combine file-system locators with code-level predicates.

---

## A · NamePayload shape

```rust
pub struct FsName {
    segments: Vec<GlobSegment>,
}

pub enum GlobSegment {
    Literal(String),            // exact path fragment: src, utils, foo.ts
    Star,                       // *    — matches any sequence except /
    DoubleStar,                 // **   — matches any number of directories
    Question,                   // ?    — matches any single char except /
    CharClass(Vec<char>),       // [abc] — matches one of the listed chars
    Brace(Vec<String>),         // {ts,rs} — alternation of literal suffixes
}

pub struct FsLexer;

impl NameLexer for FsLexer {
    fn parse<'s>(&self, input: &'s str) -> IResult<'s, NamePayload>;
    fn render(&self, n: &NamePayload) -> String;   // canonical glob string
    fn matches(&self, n: &NamePayload, node: &NodeRef,
               _profile: &LanguageProfile, _src: &str) -> bool;
}
```

### Composition rules

```
src/**/*.ts           recursive descent + extension filter        — segments: 4
tests/**/*.{ts,rs}    brace expansion over two extensions         — segments: 4, brace: 2
src/utils?            single-char wildcard in leaf                — segments: 2
src/[[:alpha:]]       character class (POSIX style supported)     — segments: 2
`weird::path.rs`      backtick-quoted when payload contains ::    — literal segment
```

The `FsLexer` is implemented with `winnow`. It parses POSIX-like globs with the extensions above. `render()` collapses the segment vector back into a canonical glob string (no redundant braces, sorted alternations). `matches()` compares the `FsName` against a `NodeRef`'s project-relative path; it does **not** open the file or read its contents.

## B · Registries

### Node kinds (`§name`)

```
§dir         directory
§file        regular file
§symlink     symbolic link
```

### Anchors (`¶name`)

```
¶hidden      leading-dot file or directory (.gitignore, .env, etc.)
¶ignored     matches .gitignore (excluded by default; this anchor opts back in)
¶lockfile    bun.lock, Cargo.lock, package-lock.json, yarn.lock, etc.
¶code        extension belongs to a registered code LanguageProfile
¶doc         md, org, txt, rst, adoc
¶image       png, jpg, jpeg, gif, webp, svg
¶binary      not detected as text (UTF-8 sniff fails)
¶large       size > 1 MiB
```

### Qualifiers (`#name`)

```
#listing               one-level child NodeRefs (non-recursive)
#tree[depth=N]         recursive listing capped at depth N (default unbounded)
#stat                  metadata only: size, mtime, kind, optional hash
```

### Predicates

```
[ext=ts]               extension match (no leading dot)
[lang=rust]            registered language match
[size>1000]            byte-size comparison; <, >, <=, >=, =
[size>1K]              K/M/G suffixes accepted
[mtime>2026-01-01]     RFC3339 or YYYY-MM-DD shorthand
[name="*.test.ts"]     glob match against leaf name only
[depth=N]              walk depth from locator root (root = 0)
[empty]                empty file (size=0) or empty directory
[text]                 synonym for ¬¶binary
```

### Edges

The FS dialect does not define any edge axis (`→`) because it is not a code-graph traversal layer. Cross-file set operations (`|`, `&`, `-`) operate on `NodeSet` values returned by `FsLocator` and are handled uniformly by the query algebra.

## C · Worked examples

```
src/**/*.ts
src/**/*.ts :: §file[ext=test.ts]
src/ :: §dir[¶hidden][name="node_modules"]
src/ :: §file[¶code][size>1000]
src/**/*.{ts,rs} :: §file[¶ignored]
src/ :: §file[ext=lock]#stat
src/ :: #tree[depth=2]
```

## D · Edge cases

```
D-1  Glob crossing project root via ..: rejected at parse time with a
     span diagnostic, unless a root-projection option overrides the
     restriction.

D-2  Symbolic-link cycle: the walker (built on the `ignore` crate)
     detects and skips cycles automatically. No infinite loop.

D-3  Permission-denied entries: emit a per-NodeRef diagnostic;
     the walk continues. Do not abort the entire query.

D-4  Globstar with no slash separator (foo**bar): reject at parse
     time with a span diagnostic. ** must appear between / boundaries.

D-5  Path with CodePath-significant characters (::, /, #): the entire
     payload must be backtick-quoted to prevent kernel mis-tokenisation.
         src/`weird::name.rs` :: §file

D-6  [name=…] always matches against the leaf name, never the full
     project-relative path. src/utils/helper.ts with [name="*.ts"]
     matches; [name="src/*"] does not.

D-7  [size>…] supports K/M/G suffixes (case-insensitive, powers of 1024).
     [size>1M] is equivalent to [size>1048576].

D-8  [mtime>…] accepts RFC3339 (2026-01-01T00:00:00Z) or the
     YYYY-MM-DD shorthand (2026-01-01, treated as start of day UTC).

D-9  Cross-file NodeSet returned by FsLocator: set combinators
     (union |, intersect &, difference -) work uniformly across
     all dialects. The FS dialect is not special-cased.
```
