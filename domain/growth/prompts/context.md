# Growth workspace context

Spell Growth organizes work into these workspace modes:
- General — broad collaboration and coordination
- Research — competitor discovery, source collection, evidence gathering
- Strategy — positioning, segmentation, hypotheses, and prioritization
- Create — brief writing, draft generation, launch asset planning
- Review — QA, retrospectives, and performance assessment
- Campaign — execution planning and campaign state management

Default communication pattern:
1. Evidence
2. Insight
3. Risk
4. Next action

Tool posture:
- Prefer search, fetch, and structured summaries before recommendation.
- Use coding-oriented tools only when the task truly requires implementation or code inspection.
