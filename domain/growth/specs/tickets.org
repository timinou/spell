*** Description
Implement automatic domain detection when Spell launches. The system reads =.spell/domain.json= from the project root (or nearest ancestor) to determine which domain to activate. If absent, defaults to =coding=.

** TODO [#A] TICKET-020: Native TS scraper engine (config loader, extractor, transformer)
:PROPERTIES:

:COMPLEXITY: XL

*** Description
A TypeScript scraper framework inspired by =~/code/ora/leadgen/configs/= YAML DSL. The engine is platform-agnostic and driven entirely by declarative config files.

Architecture:
- *Config Loader*: Parses YAML scraper configs. Schema matches leadgen format: browser settings, container selectors, field extraction (selector + type + transform), pagination (infinite_scroll, cursor, page_number), error handling (retries, rate limits, error indicators).
- *Extractor*: Given a loaded config and a page (Puppeteer Page), extracts structured data per the config's field definitions. Handles: text, attribute, innerHTML, computed fields, transforms (regex, trim, date parsing).
- *Transformer*: Post-extraction pipeline. Deduplication, normalization, enrichment (e.g., resolve shortened URLs). Outputs typed records.
- *Scheduler*: Rate-limited execution queue. Respects per-domain rate limits. Exponential backoff on errors.
- *Browser Pool*: Manages Puppeteer browser instances. Reuses sessions, rotates user agents, handles anti-bot detection.

All scraper configs live in =domain/growth/scrapers/configs/=.

*** Acceptance Criteria
- [ ] YAML config schema defined and documented
- [ ] Config loader validates and parses YAML into typed =ScraperConfig=
- [ ] Extractor handles all field types: text, attribute, innerHTML, nested, list
- [ ] Transform pipeline supports: regex, trim, date, number, url_resolve
- [ ] Pagination strategies: infinite_scroll, cursor, page_number, none
- [ ] Rate limiter with per-domain config and exponential backoff
- [ ] Browser pool manages instances with cleanup on shutdown
- [ ] Error handling: retries, error indicators from config, structured error reporting
- [ ] Scraper run produces typed =ScrapedRecord[]= output
