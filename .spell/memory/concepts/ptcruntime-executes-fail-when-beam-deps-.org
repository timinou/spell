** ITEM PtcRuntime executes fail when beam deps not compiled

The `execute` tool's PTC-Lisp BEAM runtime depends on Hex packages (ptc_runner, jason, nimble_parsec, telemetry, stream_data) being fetched and compiled in `beam/ptc_runtime/`. When they are missing, `mix run --no-halt` exits immediately with code 1, and the Node-side transport reports `PtcRuntime exited (code=1, signal=null)`.

## Detection
- Every execute call fails in ~500ms with the same error, even `42`
- No log files appear in `PTC_RUNTIME_LOG_DIR` — the runtime never reaches Logger
- Manual `mix run --no-halt` in the beam dir also fails with code 1
- `ls beam/ptc_runtime/deps/` is empty, `_build/dev/lib/` is empty

## Fix
```bash
cd beam/ptc_runtime
mix local.hex --force
mix deps.get
mix compile
```

## Prevention
Added to `install.sh`:
- System dependencies now include `elixir` (pacman/apt/brew)
- `mix local.hex --force && mix deps.get && mix compile` runs during install
