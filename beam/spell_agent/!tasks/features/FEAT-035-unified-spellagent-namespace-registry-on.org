* Summary
The positive counterpart to BUG-026. Today a namespace's verbs are registered by N ad-hoc Map.merge sites (tools.ex native/freeform, session.ex build_session_tools chain, per-namespace tools() builders) with no single abstraction. Introduce ONE `SpellAgent.Namespace` behaviour/registry so a namespace is declared once and every consumer derives from it.

* The one declaration
A namespace declares:
- prefix (e.g. "hist", "harness")
- effect_profile (:pure | :read | :mutating | :meta) — governs whether it is safe inside a reaction, attenuable, etc.
- verbs: [ {name, params, doc, fn/2 | ptc_source} ]
- routing: reflected/open (verbs discovered) vs enumerated (fixed list)

* Consumers that DERIVE from it (no parallel mirrors)
1. tools-map assembly (replaces the Map.merge chain in tools.ex + session.ex build_session_tools).
2. analyzer legality — the set of legal ns prefixes handed to ptc_runner (replaces hardcoded @bounded_namespaces; @qualified_keys deleted, see BUG-026).
3. inventory / capability description (see the B3 FEAT).
4. atom-safety — nothing about a verb is interned; the registry guarantees binary routing.

* Session vs static
Some namespaces are session-scoped (hist/clock/mesh close over session_id + store). The registry must support BOTH static (view/theme/harness) and session-parametric (a builder fn taking session context) declarations, so build_session_tools becomes "fold the registry's session-namespaces with this session's context" rather than a hand-written merge chain.

* Acceptance
- A single `Namespace` registry lists every namespace; tools.ex + session.ex assemble the tools map by folding it (no ad-hoc merges).
- Adding a namespace = one declaration; it shows up in the tools map, the analyzer legality set, and the inventory automatically.
- The attenuation ceiling (opts[:tools]) and the "always-merge session verbs" rule are expressed as registry metadata (effect_profile / session-scope), not hand-coded in build_session_tools.
- Tests: a drift test (every declared verb is PTC-callable), an attenuation test (a child only gets its ceiling), an inventory-completeness test.
