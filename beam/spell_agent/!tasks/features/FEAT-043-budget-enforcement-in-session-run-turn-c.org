* Summary
Budget ({turns, cost_ceiling}) is THREADED through spawn/clock/run but not ENFORCED as an early-exit in Session.run — the A5 gap noted in PLAN-014. This is a hard precondition for two things: (1) the reduction rate-controller needs a truthful `remaining_turns` (FEAT-036), and (2) loop/continue self-continuation is unsafe without an enforced ceiling (FEAT for A4). Close it: make the budget a real, enforced bound the mind cannot exceed.

* Evidence
- lib/spell_agent/session.ex:run/2 — max_turns passed to SubAgent, but no cost_ceiling enforcement, no early-exit when a passed budget is reached.
- lib/spell_agent/clock.ex — wakes carry :budget {turns, cost_ceiling} but the woken run does not enforce cost.
- lib/spell_agent/mesh/spawn.ex — children inherit budget args; enforcement is downstream-absent.

* Design
- Thread a Budget struct into Session.run that bounds BOTH turns (already partial via max_turns) AND cumulative cost (sum of per-turn LLM cost from the adapter's usage).
- Enforce as an early, graceful exit: when the ceiling is hit, end the run with a clear {:error, :budget_exhausted} (or a partial :ok with a budget-exhausted marker) — never a crash, never silent over-run.
- The ceiling is a BODY invariant the mind cannot raise (a child's budget clamps to the parent's remaining, like capability attenuation).
- Surface remaining_turns / remaining_cost as a value the loop can read (feeds Mission.decide in FEAT-036).

* Acceptance
- A run with a turn or cost ceiling stops at the ceiling with a clear outcome, verified by a test.
- A child cannot be granted more budget than the parent's remaining (clamp test).
- remaining_turns/remaining_cost is queryable at the turn boundary (consumed by FEAT-036).
