* Decision: Req.Test + a thin spell-owned cassette (NOT a hex VCR lib)
Investigated (2026-06-21):
- =req_cassette= (lostbean): async-safe, built on Req.Test, has ReqLLM support —
  BUT pins =req ~> 0.5.15=; we are on =req 0.6.1=. Version conflict; would need a
  forced override and risks drift.
- =reqord=, =req_vcr=: similar VCR-style, also Req-version sensitive, impose their
  own =Case= module.
- Our adapter (=SpellAgent.Anthropic=) is NOT generic: subscription OAuth, custom
  Claude-Code headers, system-block injection, =proxy_= tool prefixing, and SSE
  collected-then-folded. We want to exercise =parse_response/1= (the SSE folder)
  too — so wire-level recording is the right granularity.

∴ Build on =Req.Test= (ships with req 0.6.1, async-safe, no global mock) plus a
small =SpellAgent.LlmCassette= owning the record/replay + on-disk format. No new
runtime dep; full control over the subscription specifics.

* Design
** Injectable Req options seam
=Anthropic.call_with_token/3= currently calls =Req.post(@messages_url, ...)= with
fixed options. Add an injectable =:req_options= (threaded from =call/2= via the
request map or app config) so a test can pass =plug: {Req.Test, CassetteStub}=.
Production passes nothing → real Finch transport unchanged.

** Cassette format (wire-level)
=test/fixtures/llm/<name>.cassette= — a term/JSON file holding an ORDERED list of
interactions, each:
- =request_digest=: =sha256= of the canonicalized request body (model + messages
  + tools + system), the match key. Canonicalization must strip the volatile
  billing-header =cch= + =rand3= so the digest is stable across runs.
- =status=, =response_headers=, =sse_body=: the RAW =text/event-stream= bytes, so
  replay drives the SAME =parse_response/1= path as production.
Sensitive-data filtering: redact =authorization: Bearer ...= and any token before
write (a =filter/1= callback, mirroring req_cassette's posture).

** Modes
- =:replay= (default in CI): serve from cassette; error if the digest is missing.
- =:record_missing=: hit the real subscription once (gated =@tag :live= +
  credential present), write the cassette, then replay thereafter.
- =:record=: force overwrite (intentional refresh of a transcript).
Selected by env (=LLM_CASSETTE=record_missing=) so default =mix test= is offline.

** Replay mechanics
=Req.Test.stub(CassetteStub, fn conn -> ... end)= reads the request body, computes
the digest, looks up the interaction, and returns the recorded SSE with the
recorded status/headers. =Anthropic.callback/1= bound to this stub becomes the
=llm:= for =Session.run/2=.

* API surface (to be documented in moduledoc + a guide)
- =LlmCassette.with_cassette(name, opts, fn -> ... end)= — scopes a stub for the
  block; returns the block value.
- =LlmCassette.llm(name)= — an =llm:= callback bound to a cassette, for
  =Session.run(prompt, llm: LlmCassette.llm("two_turn_tool_use"))=.
- =LlmCassette.record?/0=, =LlmCassette.mode/0= — env-driven mode.
- =LlmCassette.path/1=, =LlmCassette.digest/1= — introspection.
Each with @doc + @spec; a =docs/llm-cassettes.md= guide with the record→commit
workflow and the redaction guarantee.

* Acceptance
- =Session.run(prompt, llm: LlmCassette.llm(name))= drives the real
  =PtcRunner.SubAgent= loop offline from a committed cassette, exercising
  =Anthropic.parse_response/1= (SSE fold) on replay.
- A recorded cassette contains NO bearer token (redaction verified by a test).
- Default =mix test= needs no network/credential; =--include live= +
  =LLM_CASSETTE=record_missing= records.
- Digest is stable across runs despite the volatile billing header.
