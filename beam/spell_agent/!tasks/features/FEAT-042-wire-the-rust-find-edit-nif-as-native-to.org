* Summary
The Rust kernel find/edit NIF (pi_kernel_nif over pi-code-engine/pi-code-path) is not wired — stub NIFs exist but return hardcoded shapes. The agent's only file surface today is `sh` (cat/rg) + the parse-gated code-* tools. Wiring find/edit gives symbol-aware navigation (callers/defs/refs) and structural edits as first-class native tools, and forces the namespace-registry seam to be right (this is a concrete new native namespace to register cleanly).

* The B2 link (the "ugly seam" the user named)

* Design

- Bound the NIF calls (see the NIF-sandbox bug) — size/time caps, crash → error tool result.
- Teach them in the auto-generated capability description (FEAT-034) as the preferred navigation/edit surface alongside code-* and sh.
