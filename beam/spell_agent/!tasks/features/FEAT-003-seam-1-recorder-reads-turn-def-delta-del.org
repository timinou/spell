* Problem
Recorder.build_node computes a node's env delta by SNAPSHOT-DIFFING two full
memory maps: `binds = map_delta(prev_mem, turn.memory)` (recorder.ex:248). This
re-derives what the runtime already computed at eval time (now on turn.def_delta
via FEAT-001). The snapshot-diff approach also forced BUG-001 B1's deletion-by-
omission hack (deleted_marker), which is unrepresentable garbage now that
def_delta has no `removed` set (PTC has no undef).
