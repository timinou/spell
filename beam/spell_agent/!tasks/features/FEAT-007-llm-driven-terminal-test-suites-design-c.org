* Goal
Ship the PLAN-347 LLM integration test layer: drive the REAL agent loop +
inspector App from an LLM cassette through a REAL headless terminal, asserting on
both semantics (the Store forest) and appearance (the rendered buffer).

Two complementary suites sharing one cassette (FEAT: LLM cassettes) and one
buffer accessor (ex_ratatui PATCH-2, =Runtime.buffer/1=, LANDED):

** Design C — loop-correctness (structured + visual, dual-channel)
Per cassette scenario: run =Session.run(prompt, llm: LlmCassette.llm(name))=
under the App in =test_mode=, then assert:
- STRUCTURED: the Store forest shape (runs/tools/llm spans, turns, statuses) —
  the =scene_store_test= style already shipped in PLAN-347.
- VISUAL: a final =Runtime.buffer/1= snapshot shows the expected end state.
Decouples "did the loop do the right thing" from "did it render right": when one
breaks you know which.

** Design A — visual regression (golden transcript)
Capture =Runtime.buffer/1= at QUIESCENCE (after the run Task exits; NOT every
tick, to avoid frame-count coupling) and commit the frame(s) as a =.transcript=
text baseline under =test/snapshots/llm/=. Extends the PLAN-347 snapshot infra
(=Snapshot=, =mix spell.gallery --snapshot=) with an =--record-llm= flow. Text
diffs in review; regenerate intentionally.

* Prerequisites (ordering)
1. ex_ratatui PATCH-2 — =Runtime.buffer/1=. ✅ LANDED.
2. BUG-009 + BUG-010 — render robustness (malformed widget degrades to a gap, not

* API surface (documented)
- =LlmTerminal.run_scenario(name, opts)= — boots App in test_mode with a
  cassette llm + a fresh Store, runs the prompt, waits for quiescence, returns
  =%{store_forest, buffer, result}=. The single entry both designs build on.
- =LlmTerminal.await_quiescence(app, timeout)= — blocks until the mission Task
  exits and the final render settled (monitors the Task ref the App tracks).
- =assert_forest/2=, =assert_screen/2= — thin assertion helpers (Design B sugar)
  over the returned forest + buffer.
Each with @doc/@spec + a =docs/llm-terminal-tests.md= guide describing the
record→run→assert→commit loop and the quiescence model (WHY we snapshot at
quiescence, not per frame).

* Acceptance
- A two-turn tool-use cassette drives a green Design-C test: forest has the
  expected run+tool+llm spans AND the buffer shows the final answer.
- A Design-A =.transcript= baseline exists, asserted equal on replay; tampering
  fails, regeneration restores (mirror the PLAN-347 snapshot drift test).
- Suites are offline + async-friendly; default =mix test= needs no network.
- A run that emits a (previously) unencodable widget renders a degraded-but-valid
  frame (depends on BUG-009/010) rather than freezing/raising.

* Non-goals
- Token-by-token streaming UI (=Anthropic.stream/2=) — separate later nicety.
- Multi-provider cassettes — v0 is Anthropic-only, matching the adapter.
