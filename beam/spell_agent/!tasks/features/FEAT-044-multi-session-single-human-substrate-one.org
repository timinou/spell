* Summary
One human running and watching MULTIPLE concurrent agent sessions is a first-class alpha capability (NOT to be deferred). The primitives exist and are solid (spawn-session/await-session, ParallelBudget, Join, Region, blackboard, attenuation) and read-only viewers exist (SessionBrowser, SessionRegistry, mix spell.sessions/mesh), but they are fragmented: THREE spawn entry points, a read-only browser separate from the main TUI, no human-initiated spawn, and no live focus-switching between concurrent sessions. Consolidate into a coherent multi-session substrate. Multi-mesh coordination STAYS (it is the coordination fabric for the many sessions), it is just re-framed for the single-human-many-sessions use case rather than an autonomous swarm.
