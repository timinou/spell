* Problem
Node.form is currently set to `turn.program` — a STRING (the raw emitted source).
The lens form-walkers (Lens.collect_defs/collect_calls, lens.ex:196/221) match
tuple AST shapes {:def,name,val,meta} and {:tool_call,name,args}. On a STRING
they match nothing -> silently return [] (the string/tuple ambiguity the prior
session flagged: "defs"/"form_tools" lens fields are quietly empty). Move C
(turn.form, via FEAT-001) gives the real executed CoreAST. Point Node.form at it
so the walkers operate on the actual tree.
