  - `mix spell.mesh.watch REGION`            interactive single-region tail (TUI).
  - `mix spell.mesh.watch --list`            print all regions to stdout, exit.
  - `mix spell.mesh.watch --tail REGION`     stream REGION records to stdout (tail -f).
  - `mix spell.mesh.watch --fold REGION:kind:reduce`  print a fold result, exit

  interactive is a 2-pane reader (records left, selected-record payload right) —
  literally SessionBrowser with a mesh project/2. Reuse SessionView formatting.

  t0/t1) so baselines are stable across runs.
