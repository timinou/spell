* Design (the wiring)
At the turn boundary in SpellAgent.Session.run (per-turn, zero inference):
1. Compute the cheap estimate: run hist/reducibility (tok_full, tok_reduced, reducible_tokens) over the current node slice.
2. Feed {tok_full, tok_reduced, remaining_turns (from max_turns - turn), window_soft, window_hard (config)} to Mission.decide/1.
3. On :cache → do nothing (append tail; the existing verbatim path).
4. On {:reduce, tier} → route the continuation tape through hist/reduce {tier}, memoized via Mission.memoized_reduce (session, watermark, policy_hash).
5. The reduced tape becomes the next turn's initial_messages (the I-frame keyframe / new cache anchor).

* The dependency: budget must be ENFORCED, not just threaded
`remaining_turns` is the economic trigger input. Today max_turns is passed but the budget ceiling is not enforced as an early-exit (the A5 gap). This wiring needs a real remaining-turns signal. Confirm/close the budget-enforcement gap as part of this (or as a hard blocker sub-item) so decide/1 reads a truthful K.

* Where the loop boundary is
PtcRunner.SubAgent.run owns the turn loop; Session.run wraps it with initial_messages/initial_memory. The reduce decision belongs at the point where the NEXT turn's tape is assembled — either a per-turn hook in the SubAgent (preferred, so it fires every turn) or a re-entry seam. Investigate whether the vendored SubAgent exposes a per-turn tape hook; if not, this may need a ptc_runner patch (a `before_turn` callback that can rewrite the tape). Flag that in the design wave.
