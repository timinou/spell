* The gaps (verified)
1. SYSTEM INTENTS hardcoded before reaction dispatch. app/quit, mode/insert, frame/leader are resolved in app.ex (handle_key_event, ~L368-410) BEFORE the keymap→intent→reaction path, so the agent cannot rebind or redefine them. Violates "no if focus==" for the system layer. FIX: route system intents through the SAME resolver as everything else (they become reactions with a protected/default binding the agent may override).

FIX: allow a bounded extension map on the gaze (namespaced, atom-safe) so reactions can thread new state without a struct change — or document the closed set as intentional and make the clip explicit/validated.
4. INSERT mode only works on :prompt. The modal table implies general modality. FIX: make mode a first-class per-context concern (or scope the claim).
