* Goal
The reflexive self-call: a native tool that lets a running session spawn a child
session, bounded by the global ParallelBudget, handing the child an attenuated
capability set and a region. This is the Fork-A initiator and the thing webhooks/
watches invoke for Fork B. The fixed point eval(eval) made a first-class tool.

04-surface.org §2 (the contract) + §3/§5 (showcases), 02 §8 (budget/termination),

- add "spawn-session" => &spawn_session/1 to meta_tools/0 (beside define-tool/

  ["prompt","region","tools","budget","await"]).
- spawn_session(args):
  1. ParallelBudget.try_acquire(budget) where budget is the app's mesh budget
     (FEAT-013 wiring / app state). On :no_budget -> raise
     "parallel_capacity_exceeded" (the invoke_tool contract turns a raise into an
     LLM-facing error — same as define_tool's raises). D11.
  2. region: args["region"] present -> join it (rendezvous / Fork B); :auto or
     absent -> Mesh.Region.fork_a(goal, session_id) (Fork A). The minted id is the
     child's write-capability.
  3. attenuate tools (D12): child_tools = Map.take(build_tools_map(), args["tools"])
     |> Map.merge(Mesh.verbs(child_sid, region: region, store: store)). The child
     gets ONLY the named subset + its mesh verbs — capability attenuation.
  4. await:
     - true  -> Session.run(prompt, llm: ..., max_turns: budget.max_turns,
                  session_id: child_sid, region: region) synchronously; return the
                  child's result; ParallelBudget.release in an after: block.
     - false -> spawn under a linked Task (or Task.Supervisor) that runs
                  Session.run and releases the slot on exit; return
                  {:session child_sid, :region region} immediately (fire-and-forget).
- the child is a FULL Session.run/2 (lib/spell_agent/session.ex) so it gets its own
  Hist history + auto-registers in SessionRegistry (register/2, pid-monitored) —
  no extra membership code; a crashed child self-unregisters.

* Edge cases
- budget exhausted mid-fan-out: the Nth spawn fails fast; the parent's fold simply
  sees fewer findings (a threshold watch with a ttl handles the shortfall, PT-1/PT-4).
- await:false child crashes: the Task's exit releases the slot (link/monitor);
  SessionRegistry drops it; its already-posted findings PERSIST (PT-4 dead author).
- recursion: a child that itself spawns acquires its OWN slot from the same global
  budget — the cap holds across all depths (D11, the ParallelBudget invariant).
- llm inheritance: the child inherits the parent's llm callback (pass opts[:llm]
  through) unless overridden — same resolution order as SubAgent.as_tool.
