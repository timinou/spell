While verifying the W3 premise, found a SMALL real redundancy (not the W3 vision):
- `App.sync_layout_gaze/1` (app.ex:748) writes the gaze into `LayoutRegistry.tree` via `from_ui` on every `reproject` (per event).

Retiring %Ui{} would force on-demand `to_ui` for the reaction algebra — INTRODUCING the round-trip W3 claimed to remove, across 17 test files / 168 reaction tests. ∴ W3 abandoned as net-negative.
