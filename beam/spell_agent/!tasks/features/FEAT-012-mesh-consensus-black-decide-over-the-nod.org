- decide(%{region, question, quorum, fold, store}) -> {:verdict id, :leader node,
  :payload} | {:pending reason}:
  1. SEAL (DC-8): watermark := max lamport currently in region (Mesh.Store.region).
     Commit the watermark as the FIRST Ra step so every leader agrees on the
     boundary.
  2. verdict id := hash(region <> to_string(question) <> watermark) — idempotent:
     a re-elected leader commits the SAME id (a second commit is a no-op collapse).
  3. NODE-level Ra leader-election (the cluster Khepri already runs via
     khepri_cluster.erl). The leader evaluates :fold ONCE
     (PtcRunner.Lisp.run, sandboxed, over findings WHERE lamport <= watermark),
     then Mesh.Store.put the :verdict record (kind :verdict, :watermark set).
  4. quorum := NODE quorum (:majority default). Sub-quorum -> {:pending}, caller
     retries. A session that triggered decide may EXIT immediately after — its
     finding persists and is folded regardless (DC-7).

* PRE-CODING CORRECTION (oracle MeshFinalCheck, agent://1-MeshFinalCheck — P1.2)
The sealed watermark is a STORE SEQUENCE / LOG INDEX, not a Lamport scalar.
- "max lamport in region" is NOT a stable frontier: a late record can carry a
  lamport below a previously-sealed watermark (records arrive in the Raft log out
  of lamport order), so folding lamport ≤ w is non-deterministic across leader
  re-election → broken verdict idempotency.
- FIX: decide seals against the per-region monotonic SEQ the store assigns
  (FEAT-009). watermark = the committed store seq at seal time (in Khepri, the
  Raft log index of the seal command; in Memory, the per-region counter value).
  The fold takes records WHERE seq <= watermark — a stable, totally-ordered set,
  so any re-elected leader folds the identical set → identical verdict id.
- verdict id = hash(region <> question <> watermark_seq). %MeshRecord :watermark
  field holds the SEQ (integer), not a lamport.
- seal MUST be the first committed Ra step (Khepri) or an atomic counter read
  (Memory) so the frontier is fixed before any fold.
