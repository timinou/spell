   {:hash,_} node index is NEVER touched. :claim/:intention never dedup.

   total order — mirrors recorder.ex max_seq. Mesh.Clock is NOT built.

   multi-node is best-effort (that is FEAT-012/013's problem, not this PLAN's).
4. Fork-A re-goal is owner+liveness gated (P1.3): SessionRegistry.live?(owner).
