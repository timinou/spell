* Moves (new capabilities; all WRITE-path / Elixir-core; sandbox still cannot reach state)
** Move A - Turn.def_delta at the eval source
PtcRunner already computes the def-delta at {:def name val} (eval.ex builds new_user_ns) then throws it away; Turn.memory is a full env SNAPSHOT, so Hist.map_delta + TurnEvent.memory_diff both reverse-engineer it and inherit the BUG-001 deletion blind spot. Emit `def_delta: %{introduced: %{name=>val}, removed: [name]}` on Turn. Deletes Hist.map_delta + the B1 deleted_marker dance; deletion becomes explicit (an undef is reported, not inferred from omission). Generally useful to any Step consumer; fixes a bug CLASS at source.
** Move B - Step.freeze/1 at the handle owner
Realize.walk exists because Hist, from OUTSIDE, must materialize handles before the runtime GCs their backing store (a race won only by timing). The runtime owns HandleStore and knows lifetimes. `PtcRunner.Step.freeze(step) :: %Step{}` inlines/tombstones handles at the right moment. Deletes Realize.walk from Hist's hot path; kills the race. Clean "Step safe to persist/serialize" API.
** Move C - native AST on Turn + lossless trace (extend TurnEvent)
turn.program is a STRING; the runtime parsed it to CoreAST to run it then handed back the string, so Lens structural walkers re-parse/re-walk and only work when something already holds the tuple form. Carry the executed CoreAST on Turn (+ attach span subtree). Collapses Recorder.build_node toward 1:1 Step->Node; makes Lens defs/form_tools extraction trivial+correct; subsumes the deferred `form_tree` (Move D). FRAMING (load-bearing): the runtime emits a lossless structured trace it ALREADY computes internally; it MUST NOT know about Hist. "Stop discarding structure," not "emit Hist nodes." Ship with an AST-drift contract test.
