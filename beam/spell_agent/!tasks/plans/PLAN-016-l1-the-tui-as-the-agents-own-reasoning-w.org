* The boundary dissolved
OUTPUT vs WORKSPACE. A UI is something rendered FOR a human to look at — one-way.
This makes the rendered interface a surface the agent shapes FOR ITSELF, to think
with: it authors a headless view over its OWN run-trace, renders it to an ASCII
buffer (no screen), and reads that buffer back as reasoning input. The renderer
reads its own output. The TUI becomes EXTERNAL WORKING MEMORY.

* The precise gap (what L−1 adds, nothing more)
1. Render over the agent's OWN LIVE trace bag (DataBag.build of live state), NOT a
   caller-supplied empty env. The data the view shows IS the run-trace.
2. A defined RENDER -> OBSERVE -> ACT cycle: the buffer returns as a tool result
   the agent reads back as reasoning input, within a turn.
3. A budget/fixpoint guard so the loop cannot spin (PROJ security note).

* The load-bearing seam (W0 proves this with running code FIRST)
A tool the agent calls mid-turn runs in the Session/mission process. The live
trace lives elsewhere: the FOREST in Tui.Store (separate process, reachable by
pid via Store.spans/1), the GAZE in App GenServer state (App-local). W0 decides
+ builds the cleanest provider seam:
  Option A (App-call): App injects a self-view provider closure into the mission's
    tool set capturing the App pid; the tool does GenServer.call(app, :self_view_bag)
    -> App builds DataBag.build(current_state, area) -> returns the live bag.
    Faithful to gaze + forest. One narrow handler.
  Option B (Store-pid read): provider captures the Store pid; reads Store.spans
    + a default gaze; builds a trace-focused bag. No App round-trip, no gaze
    fidelity. Sufficient for the trace-board demo.
W0 builds the SMALLEST end-to-end proof (render a list of data/forest span labels
over the LIVE forest, read the ASCII back) and PICKS the option from evidence.
Until W0 proves the round-trip, no wave builds on top.

* Capability discipline (inherited from PROJ-004, non-negotiable)
The self-view tool RENDERS; it never mutates. It is READ-ONLY by construction:
it builds a bag from live state and draws it to a throwaway terminal. No keymap
bind, no store write, no shell — same asymmetric-danger reasoning as the cell
tier. The render path is total (a malformed widget degrades to a gap; the
throwaway terminal is always restored).
