## Root cause (from trace + code analysis)

The layout is "plain string-keyed maps" with NO Node abstraction and NO optic. Every module re-discovers how to walk/read/update the tree. One concern (tree mechanics) wears nine shapes.

Evidence (traces in ~/.spell/traces, code in lib/spell_agent/tui/):
1. Every `layout/set` echoes the WHOLE tree back to the LLM, including hole codec maps (`%{"__hole__" => %{"node" => "sym", ...}}`). One slot set → ~370-line echo. (sess-555e turn 3.)
2. `theme/set` ×9 in one `do` → 9 full-palette dumps; no batch verb, no delta result. (sess-555e turn 2.)
3. No subtree addressing: `layout/set` replaces a WHOLE slot via `put_slot/3`. To change one leaf you re-emit the entire split. `Lens.put_at/3` exists in Elixir but is NOT exposed to PTC. The `lens/` surface has only focus·focused·focusables·at·tag (tag writes only the focused pane).
4. 72 walker clauses re-implementing `is_map and not is_struct`/`is_list`/`other` dispatch across: lens.ex (collect·find_node·map_pane_nodes·update_node), surface.ex (place·place_split), layout_diagnostic.ex (scan·place·place_split — a SECOND copy of surface's), hole_diff.ex (collect_deps·do_rebuild·table_walk), hole_resolver.ex (walk·walk_seq_elem), layout_registry.ex (put_slot), materialize.ex.
5. `Map.get(m, key) || Map.get(m, safe_atom(key))` + private `safe_atom/1` copied verbatim in 7 modules (lens·ptc·surface·render_probe·self_view·layout_registry·layout_diagnostic).
6. The `%Ui{}` round-trip: lens.ex claims the tree is canonical with gaze-as-tags, but the reaction algebra still speaks `%Ui{}`, so every intra-pane nav is `to_ui(tree) → react → from_ui(tree, ui)`. The struct is a derived mirror marshalled both ways each keystroke — the "state in a side-struct" boundary the philosophy doc claims dissolved.

## Design: lenses fix all six by design

A: One rose-tree + one traversal. `Tree`/`Node` with generic fold/map/update_at/find over {value, children}. 72 walker clauses → ~6. place_split lives once. Children-always-a-list + one key convention enforced in the constructor, not re-checked in 7 safe_atom copies.

B: Slot/path as composable lenses. lens = {get, put}; compose `slot("body") ∘ child(1) ∘ tag("focused")`. The whole layout/+lens/ surface becomes four ops over lenses: layout/set = put through slot(name); lens/at = get; lens/tag = put through focused∘tag(k); **lens/update {:path :fn} = over through a path lens** ← the missing verb (local edit, no whole-subtree resend). Lens laws (get∘put=id, put∘get=id) give the failure ladder a formal spine.

C: Zipper for the focus ring — deletes the %Ui{} round-trip. The ring IS a zipper over focusable leaves: `lens/focus next` = Zipper.right. Focus/cursor/scroll = zipper position + node tags. No to_ui/from_ui marshalling.

D: Small receipts, not tree echoes. Path-addressed over → set/tag return {slot, peek, changed-path}, not the whole tree. Holes print as `~form` tokens, never codec maps.

## Net
- 9 ad-hoc recursions → 1 Tree fold/map/update
- 7 safe_atom copies → 1 canonical Node accessor
- 2 place_split copies → 1
- %Ui round-trip → zipper position (no mirror)
- whole-slot resend → lens/update at path
- whole-tree echo → path-scoped receipt

"Correct by design": structural invariants (children-shape, key convention, get/put coherence) move from re-checked-everywhere to guaranteed-once by the Node type + lens laws.
