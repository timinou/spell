* Initial Message

how can you integrate these features in the spell.tui so that the conversation gains history?

* WHAT (done this session)

Interface refinements to SpellAgent.Hist, motivated by designing the spell.tui
integration. The integration revealed three gaps; rather than wire around them in
the TUI, the interfaces themselves were improved so consumers (TUI, headless
drivers, the hist/* namespace) consume them naturally.

Parent: PLAN-001-hist-homoiconic-conversation-history-sub.

* THE THREE UPGRADES

** U1 — Hist.View typed struct (lib/spell_agent/hist/view.ex)
Reconstitute.at/3 returned a naked %{} map; the namespace did Map.get(state, field)
with no type. Now returns %SpellAgent.Hist.View{session_id, cursor, tip, env, tools,
messages, nodes}. A struct is still a map, so existing %{env: env} = view
destructuring keeps working (verified: all prior tests green unchanged). New `tip`
field = the cursor node, so a renderer can highlight "you are here" for free.

** U2 — Node.prompt + interleaved transcript
to_messages/1 was assistant-only (for %Node{say}), so it could NOT render a faithful
user<->assistant scrollback - the exact thing a TUI history pane needs. Added
Node.prompt (String.t | nil), carried ONLY on a step's HEAD node (idx==1 in
Recorder.record_step, sourced from the prompt: opt). to_messages/1 now flat_maps each
node to [user prompt?] ++ [assistant say?] in path order, yielding a faithful
user->assistant->user->assistant transcript across many recorded runs. Model
rationale: a prompt is an ATTRIBUTE of where a step begins, not a node kind - no
schema pollution, no synthetic :user nodes.

** U3 — SpellAgent.Hist facade (lib/spell_agent/hist.ex)
Callers had to reach into 9 submodules and hand-roll "latest session" (I had even
invented Session.current/0 / last/1 in an earlier sketch - they did not exist). Now
one front door closing over a Store impl:
- new_session_id/0, default_store/0 (config :spell_agent, SpellAgent.Hist, store:;
  falls back to Store.Memory)
- record/3, resume/2 (-> {:ok, %View{}}), window/2, recall/3, distill/3
- verbs/2 (the hist/* tool map), sessions/1 (newest-first), latest/1 (or nil)
default_store + per-call store: opt means callers never thread impl by hand.
