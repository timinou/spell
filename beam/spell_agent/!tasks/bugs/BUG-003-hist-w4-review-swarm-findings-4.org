** B1 [P2] Window.distill summary-node id collides on repeated distill
File: lib/spell_agent/hist/window.ex (~L91-94)
The summary node id derives from `src` (built only from node_ids) + parent_id, so
distilling the SAME ids twice with different summaries overwrites the first summary
node (same content key) and mutates the prior mark's target. A second distillation
must APPEND, not overwrite. FIX: include the summary text (and/or a distill nonce)
in the synthetic node's identity so distinct distillations get distinct ids.

** B2 [P2] Window.distill accepts nonexistent node ids -> dangling summary
File: lib/spell_agent/hist/window.ex (~L89)
parent_id defaults to List.last(node_ids) with no existence check, so distilling
["ghost"] yields {:ok, ...} with a summary whose parent_id fetches :error, plus a
clearing mark pointing at detached history. FIX: fetch all node_ids (and explicit
parent) first; return {:error, :unknown_nodes} before any write if any is missing.

** B3 [P2] hist/inventory + hist/promote crash sandbox when ToolRegistry down
File: lib/spell_agent/hist/namespace.ex (~L53-54, promote ~L111)
Both delegate into Tools.* which call SpellAgent.ToolRegistry.get/1 -> Agent.get,
which EXITS :noproc if the registry GenServer isn't running. A PTC `hist/promote`
or `hist/inventory` (after a node has tools_defined) then crashes the sandbox
instead of returning data. FIX: guard the registry verbs (Process.whereis check or
caught exit) -> return %{"err"=>...} when the registry is absent.

** B4 [P2] hist/promote leaks raw {:error, reason} tuple into PTC surface
File: lib/spell_agent/hist/namespace.ex (~L113)
For a present tool arg, hist/promote returns Tools.promote/2 verbatim; on
{:error,:unknown_tool}/{:error,:native_tool} it leaks a raw tuple, unlike every
other verb that normalizes to %{"err"=>...}. FIX: wrap and convert {:error,reason}
-> %{"err"=>to_string(reason)}.
