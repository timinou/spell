* Symptom

=layout/set {:slot "body" :source (view/split …)}= returns ok, =layout/show= shows
the new node, but =App.render= output never contains it. Identical to BUG-007 but
for the =body= slot instead of a pane slot.

* Root cause (confirmed empirically)

=App.live_layout_tree/1= gates tree adoption on
=Lens.body_pane_slots(tree) == pane_names=. =body_pane_slots/1= reads the =slot=
of each direct child of the =body= split. The native body's children are =pane=
nodes with slots =["history","tree","detail"]= → gate passes. But the agent
reshapes =body= with =view/split=, whose children are widget nodes carrying NO
=slot= key →

  native body_pane_slots: ["history","tree","detail"]   gate: true
  after body shadow:      []                             gate: false → tree DISCARDED

When the gate fails, =render_tree= falls back to the native default EVERY FRAME —
the agent's whole shadow is thrown away. The gate's invariant ("body children ==
original pane names") structurally FORBIDS the exact feature the prompt advertises
(=body= = "your canvas for any interface").

BUG-007 fixed the pane-slot case (=set("detail", widget)= — the pane keeps its
slot) but never tested =set("body", split-with-fresh-children)= — the most natural,
most-documented operation. Its regression test cements the blind spot.

* The wider hostile experience (each an independent defect)

1. =layout/set= LIES — success without effect. =set/2= validates the node in
   isolation (lays out fine on an 80x24 probe) and returns =:ok=, but NEVER checks
   adoption. A node can be valid AND guaranteed-invisible. Both agent signals
   (=set= → ok, =show= → present) point the wrong way. Root of the whole flail.

2. The agent CANNOT SEE the screen. =Runtime.buffer/1= exists (BUG-011, landed)
   but is exposed only to tests, not as an agent tool. The agent reshaping the
   live UI has zero read-back of what rendered. Every diagnosis was a guess
   because observation was impossible.

3. The gate fails SILENTLY — no log, no telemetry, no agent-readable signal. The
   one place the system knows "I'm discarding your tree" says nothing.

4. The PROMPT teaches the broken path. =freeform_tui.md='s worked example IS the
   failing op (=layout/set {:slot "body" :source (view/split …)}=) and promises
   body is "your canvas for any interface."

5. Phantom diagnosis: agent blamed =["min" 0]= (the native body's own constraint,
   renders fine) — superstition bred by absence of evidence.

7. Terminal confabulation: turn 26 returned a confident description of a UI that
   does not exist and told the user to look for it. Honesty-trigger failing under
   pressure, CAUSED by defects 1-3.
