* Root cause (confirmed empirically)

=App.live_layout_tree/1= gates tree adoption on
=Lens.body_pane_slots(tree) == pane_names=. =body_pane_slots/1= reads the =slot=
of each direct child of the =body= split. The native body's children are =pane=
nodes with slots =["history","tree","detail"]= → gate passes. But the agent
reshapes =body= with =view/split=, whose children are widget nodes carrying NO
=slot= key →

  native body_pane_slots: ["history","tree","detail"]   gate: true
  after body shadow:      []                             gate: false → tree DISCARDED

When the gate fails, =render_tree= falls back to the native default EVERY FRAME —
the agent's whole shadow is thrown away. The gate's invariant ("body children ==
original pane names") structurally FORBIDS the exact feature the prompt advertises
(=body= = "your canvas for any interface").

BUG-007 fixed the pane-slot case (=set("detail", widget)= — the pane keeps its
slot) but never tested =set("body", split-with-fresh-children)= — the most natural,
most-documented operation. Its regression test cements the blind spot.

* Resolution (DONE)

Fixes A-E all landed in commit c9baa84e2 (fix(tui): freeform layout).

** A — adoption gate (the bug)
`App.live_layout_tree/1` now keys on the registry's FROZEN pane identity
(`LayoutRegistry.pane_identity/0`), captured at seed time, read atomically with
the tree via `tree_with_identity/0`. A body reshape drops the body's child slots
but cannot move the frozen identity, so the reshaped body is adopted. The old
gate recomputed `body_pane_slots/1` of the live tree (= [] after a view/split
reshape) and discarded everything.

** B — honest layout/set
`LayoutRegistry.set/2` rejects with `{:error, {:not_adoptable, slot}}` when the
registry's frozen identity is [] (unseeded → the App gate can never adopt → any
shadow is futile). The `layout/set` tool surfaces an err map naming the reason,
instead of a hollow ok. `adoptable?/0` is the self-check.

** C — screen-peek tool
New `SpellAgent.Tui.RenderProbe` + `layout/render` tool: renders a slot or node
to an ASCII buffer (re-renders standalone on a headless terminal; faithful for
view/* trees, pane nodes preview empty). Wired into `Tools.freeform_tools/0`.

** D — discard log
`live_layout_tree/1` logs the pane-identity mismatch instead of silently
falling back.

** E — prompt
`freeform_tui.md`: documents `layout/render`, adds 'see it before you trust it'
(verify a set with a peek), and states body reshaping is fully supported.
