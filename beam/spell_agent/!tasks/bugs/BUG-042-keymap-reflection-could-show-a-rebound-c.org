* Summary
`KeymapIntrospect.context_rows/1` applied a live `keymap/bind` override to every compiled chord, including `C-r` under `:global`. But `App.handle_event/2` checks `reset_layout_chord?/1` and short-circuits to the hardcoded emergency reset BEFORE the resolver (and thus before any live override) ever runs. So rebinding `C-r` made the palette SHOW and FIRE the new intent, while the actual key still reset the layout — the single source of truth lied about the one chord it matters most to get right (the emergency escape).

* Fix (LANDED)
`context_rows/1` pins the `{global, "C-r"}` row to its compiled intent (`app/reset-layout`) regardless of any live override, reflecting the TRUE, unoverridable behavior instead of a rebind a real keystroke can never trigger.

* Verification
`keymap_introspect_test.exs`: "a live rebind of C-r under :global does NOT change the reflected row's intent" — binds C-r to a different intent live, asserts the reflected row still reports `app/reset-layout`.
