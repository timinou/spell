* Summary
`define-tool` validates PTC SYNTAX + undefined-vars, but accepts several classes of definition that are guaranteed to fail or silently misbehave. The body should reject at DEFINE time what will certainly fail at CALL time — a tool the agent defines must be "indistinguishable from a built-in the moment after," and these gaps break that promise. Do NOT reduce scope; get all of them right.

* The footguns (each must be closed)
1. RUNTIME-CERTAIN failure accepted. A syntactically valid tool whose body ALWAYS raises (or references a tool that cannot exist) passes validation and only fails on first call. Add an optional/again-bounded define-time smoke: at minimum, validate that every `(tool/X)` / `(ns/verb)` the body calls resolves to a registered name (closed-world check against the assembled tools map), so a typo'd callee is caught at define time, not runtime.
   - lib/spell_agent/tools.ex:validate_source/1 (currently PtcRunner.Lisp.validate only).
2. SILENT scope degradation. `normalize_scope/1` maps an unrecognized scope (e.g. "permannet") to `:session` — a typo silently loses durability. The response echoes the resolved scope, but that is not enough. REJECT an unrecognized scope with a clear error listing the allowed values.
   - lib/spell_agent/tools.ex:normalize_scope/1.
3. RESERVED-atom param. A param named e.g. `:return` / `:fail` / other reserved special-form names normalizes fine, then fails at `data/<param>` bind time. Reject reserved/param-illegal names at define time with a clear message.
   - lib/spell_agent/tools.ex:param_atom/1, normalize_params/1.
4. RESERVED-name shadow already guarded (reserved_name?/1) — verify it also covers the `proxy_`-prefixed wire collision (a tool named `proxy_find` colliding with the wire-prefix of `find`). See anthropic.ex apply_tool_prefix/strip_tool_prefix. Add collision detection.

* Why this matters more than it looks
These are the difference between "the agent grows a reliable capability surface" and "the agent occasionally defines a tool that mysteriously fails three turns later." For a self-coding alpha, define-time integrity IS the trust boundary of the whole homoiconic loop.

* Acceptance
- A tool calling an unregistered tool/verb is rejected at define time naming the missing callee.
- An unrecognized `:scope` is rejected (not silently `:session`).
- A reserved/illegal param name is rejected at define time.
- A `proxy_`-colliding tool name is rejected.
- Tests cover each rejection path (real failure, asserted error message contract).
