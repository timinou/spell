A child SHOULD be able to use clock/* within its capability ceiling. That needs
the wake to carry the allowed tool set (+ resolved llm, store, region) so
Clock.run_wake re-enters Session.run with opts[:tools] = the ceiling, opts[:llm]
= the inherited callback, etc. This is the SAME ceiling-threading BUG-017 added to
the spawn seam, applied to the clock re-entry seam.

* Approach
- Clock.Namespace.tools/N takes an :allowed (+ :llm/:store/:region) option.
- A persisted Wake record carries the ceiling so a rehydrated wake re-enters with
  it (durable across restart). NB: tool maps are not serializable \u2014 persist the
  ALLOWED NAME LIST + region + store hint, rebuild the tools in run_wake.
- run_wake passes them into SpellAgent.run/2.
- Then clock/* can be restored to attenuated children safely.

whose woken turn can call ONLY find + its own ceiling verbs, never sh/define-tool.
