A path that takes a durable :ptc tool which PROVED USEFUL and promotes it to a
long-term Crystal: a distilled, LLM-free program carrying a provenance lineage
(DISTILLED_FROM) back to the turns/episodes that earned it.

* Why it was deferred
W3's job was "survive the session." Crystal promotion is a curation decision
("this is worth keeping forever, with evidence"), which needs:
- the trigger: who/what decides a tool is Crystal-worthy (manual? usage stats —
  ToolDef already carries a stats field; a threshold?).
- the provenance edge: DISTILLED_FROM from the Crystal to the episodes/turns that
  used the tool (the memory graph already has this edge kind).
- dedup: a promoted Crystal should supersede the durable ToolDef, not duplicate it
  (SUPERSEDES edge?).
That is a memory/provenance design, separate from the shell mechanics.

* Acceptance (when taken on)
- a durable sh tool can be promoted to a Crystal with a DISTILLED_FROM lineage to
  its source turns.
- the Crystal is re-runnable with no LLM (the existing Crystal contract).
- promotion is idempotent and supersedes (not duplicates) the durable record.
- a query can find "tools promoted from session X" via the provenance graph.
