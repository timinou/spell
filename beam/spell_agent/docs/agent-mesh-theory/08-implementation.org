* A0. Oracle final-check corrections (agent://1-MeshFinalCheck) — READ FIRST

A pre-coding adversarial review found a FATAL id flaw + several composition cracks
where a session-plane mechanism was asked for a node-plane guarantee. The
corrections, now binding on the FEATs:

| id | sev | correction |
|----+-----+-----------|
| P2.2 | FATAL | records keyed by store-assigned per-region =seq= ({:mesh,region,seq}), NOT content hash. content_hash is a FIELD; dedup uses a SEPARATE ={:mesh_hash,region,h}= index; the Hist ={:hash,_}= kind is never touched. :claim/:intention never dedup. |
| P2.1 | SERIOUS | DROP per-session Lamport (=Mesh.Clock= deleted). The store assigns a per-region monotonic seq atomically (ETS update_counter / Khepri R/W txn) — a true total order, no retrograde values. |
| P2.3 | SERIOUS | claim =:won?= is PROVISIONAL (local snapshot). Monotone-effect work tolerates it; expensive → mandatory =:settle_ms=; irreversible → =decide=. |
| P1.3 | SERIOUS | Fork-A re-goal accepted only from the recorded =:owner= while =SessionRegistry.live?(owner)=; dead owner → promote to Fork-B + =decide=. |
| P1.2 | SERIOUS | =decide= watermark = a store SEQ / log index (stable frontier), not a lamport scalar. verdict id = hash(region<>question<>watermark_seq). |
| P1.1 | SERIOUS | watch-firing exactly-once = node-plane micro-=decide= (Khepri) OR documented best-effort lease+settle (single-node/Memory). NOT unconditional claim-dedup across nodes. |

The single best move: *a store-owned per-region seq replaces the per-session
Lamport clock and resolves P2.1, P2.3, and P1.2's watermark at once* — and it is
exactly how =recorder.ex= already assigns node seq (=max_seq + idx=). It deletes a
module (=Mesh.Clock=) rather than adding one. The FEAT items (008-013) carry these
corrections inline under their "PRE-CODING CORRECTIONS" headings.

* C. New modules (the build), each with its contract + CodePath seams

** =SpellAgent.Mesh.Record= — the record struct + identity (FEAT-828)

#+begin_src
lib/spell_agent/mesh/record.ex
#+end_src

- =defstruct [:region, :kind, :id, :author, :lamport, :t, :payload, :parent,
  :watermark, :sealed]= (envelope from =02= §2, +DC-8/DC-9 fields).
- =id/1= : =:crypto.hash(:sha256, canonical(payload) <> region) |> Base.encode16=
  — mirrors =hist/node.ex= identity. =canonical/1= = deterministic term encode
  (=:erlang.term_to_binary(term, [:deterministic])=), NOT NL normalization.
- =new/1= : build + stamp =author= (session id), =t= (=System.system_time/1=),
  =lamport= (from the per-session clock, §F).
- pure, no deps beyond =:crypto=. Unit-testable in isolation (like =node.ex=).

** =SpellAgent.Mesh.Region= — A/B region minting + capability (FEAT-828)

#+begin_src
lib/spell_agent/mesh/region.ex
#+end_src

- =fork_a(goal, parent_session)= : =hash(goal <> parent_session <> nonce)= where
  =nonce = :crypto.strong_rand_bytes(16)=. Unforgeable → the capability token.
- =fork_b(key)= : =hash(canonical_structured(key))= for a structured key (a map/
  tuple — PR#, path, sha), OR =hash("slug:" <> slug)= for an explicit slug.
  *Rejects a bare natural-language string* with a clear error (DC-4 guard):
  callers must pass ={:structured, term}= or ={:slug, binary}=, never raw prose.
- =write_cap?(region_id, held)= : capability check at =post= time (D12).

** =SpellAgent.Mesh.Store= — the =:mesh= kind over =Hist.Store= (FEAT-829)

#+begin_src
lib/spell_agent/mesh/store.ex
#+end_src

- thin functions over the EXISTING =Hist.Store= behaviour (=store.ex=): NO new
  engine. Adds the =:mesh= kind to the key space:
  - =put(impl, %Record{})= → =Store.put(impl, {:mesh, region, rid}, record)= +
    index ={:hash, rid}= (reuse the recorder's =index_hash= idea, =recorder.ex:199=).
  - =region(impl, region_id)= → =Store.list(impl, :mesh, region_id)= (scoped list,
    exactly how =recorder.ex::max_seq= enumerates a session's nodes).
  - =by_kind/by_match/claims_for= : pure filters over =region/2= output.
- the =:mesh= kind is added to =store.ex= =@type kind= + both impls'
  =list/2= (Memory =list.ex=, Khepri path map =[:hist, :mesh, region, rid]=).

** =SpellAgent.Mesh.Clock= — per-session Lamport clock (FEAT-829)

#+begin_src
lib/spell_agent/mesh/clock.ex
#+end_src

- a tiny process-dictionary (or session-keyed ETS) Lamport counter:
  =tick_on_read(max_seen)= = =max(local, max_seen)+1=; =tick_on_write= = =local+1=
  (=02= §4.2, DC-5). Bound into every =post= (write) and =query= (read) so the
  =query=-then-=claim= pattern yields a valid causal order.

** =SpellAgent.Mesh.Namespace= — the six verbs (FEAT-830)

#+begin_src
lib/spell_agent/mesh/namespace.ex
#+end_src

- =tools(impl, session_id, region)= → a =%{"black/post" => fn args -> … end, …}=
  map, *mirroring =hist/namespace.ex::tools/2= exactly* (closures over
  =impl,session_id,region=). The six:
  - =black/post= → cap-check (D12) → =Mesh.Record.new= → =Mesh.Store.put= (monotone).
    Rejects =post= to a =:sealed= region (DC-9).
  - =black/query= → =Mesh.Store.by_match=; ambient (no cap). Ticks the read clock.
  - =black/claim= → append a =:claim= via =post=, then =fold= =argmin(lamport,sid)=
    over =claims_for(work)= (filtering expired leases); return =:won?=. Optional
    =:settle_ms= sleep+re-fold (DC-2).
  - =black/fold= → pure reduce over =region/2= (=count=/=group-by=/=rank=/predicate).
  - =black/watch= → =post= an =:intention=; the per-node =Mesh.Watcher= picks it up.
  - =black/decide= → delegate to =Mesh.Consensus.decide/1= (FEAT-832).
- *wired into the loop* by extending =session.ex::run/2='s tools merge:
  =Map.merge(…, Mesh.verbs(session_id, region: region, store: hist_store))= — the
  same seam =Hist.verbs= already uses.

** =SpellAgent.Tools= addition — =tool/spawn-session= (FEAT-831)

#+begin_src
lib/spell_agent/tools.ex  (add to meta_tools/0 + a spawn_session/1 host fn)
#+end_src

- a NATIVE tool (=meta_tools/0= map, beside =define-tool=). =spawn_session(args)=:
  1. =ParallelBudget.try_acquire(budget)= (the app's mesh budget) — on
     =:no_budget= raise =:parallel_capacity_exceeded= (D11).
  2. resolve region: =args["region"]= present → join (rendezvous); =:auto= →
     =Mesh.Region.fork_a(goal, session_id)=.
  3. attenuate tools: build the child's tools map = the named =:tools= subset of
     =build_tools_map()= + =Mesh.verbs(child_sid, region: region)= (D12).
  4. =:await true= → =Session.run(prompt, …)= synchronously, =ParallelBudget.release=
     in an =after=; =:await false= → spawn under a Task, return ={session, region}=
     immediately, release on the task's exit.
- the child is a full =Session.run/2= (=session.ex=), so it gets its own Hist
  history + appears in =SessionRegistry.live/0= for free.

** =SpellAgent.Mesh.Consensus= — =black/decide= over the node cluster (FEAT-832)

#+begin_src
lib/spell_agent/mesh/consensus.ex
#+end_src

- =decide(%{region, question, quorum, fold, watermark})=: a thin front over Ra
  (the cluster Khepri already runs, =khepri_cluster.erl=). Algorithm (DC-7/DC-8):
  1. seal: fix =watermark = max lamport in region= as the first committed step.
  2. the verdict id = =hash(region <> question <> watermark)= → idempotent: any
     leader (after re-election) commits the SAME id (DC-8).
  3. Ra leader-election among NODES; the leader evaluates =:fold= once (sandboxed
     =Lisp.run=, findings ≤ watermark), =Mesh.Store.put= the =:verdict=, commit.
  4. quorum = NODE quorum; non-quorum → ={:pending}=, retried by the caller.
- *single-node degeneration:* a 1-member Ra cluster commits locally with no real
  election (PT-10 graceful n=1). Distribution lights up when nodes join, zero
  session-code change (D13).
- requires =Store.Khepri= enabled; with =Store.Memory= (no Ra), =decide= runs the
  local fold + writes the verdict directly (single-node mode).

** =SpellAgent.Mesh.Watcher= — per-node trigger engine (FEAT-833)

#+begin_src
lib/spell_agent/mesh/watcher.ex
#+end_src

- a supervised GenServer, *one per BEAM node* (DC-6) — local infra, like
  =Tui.Store= attaches telemetry (=lib/spell_agent/tui/store.ex=). It tails the
  node's mesh write stream:
  - *Memory mode:* =Mesh.Store.put= broadcasts via =Phoenix.PubSub=-style
    =Registry= / a simple =:telemetry= event the watcher subscribes to (mirror the
    =Pane.events/0= dirty-filter pattern, =pane.ex=).
  - *Khepri mode:* a Khepri /trigger/ on the =[:hist, :mesh, *]= path (Khepri
    supports stored-procedure triggers) fires the watcher.
- on a matching =post= vs a stored =:intention='s =:when=: =black/claim= the firing
  (work = =hash(intention_id <> event_id)=) → only the winner runs =:do=
  (=Lisp.run=, =data/event= bound) → exactly-once across nodes (DC-6). Decrement
  =:fuel=; drop on fuel=0 or ttl-expiry. The =:do= action acquires a
  =ParallelBudget= slot if it spawns (D11).

* F. Cross-cutting invariants every FEAT must preserve

1. *No live handle/pid on the blackboard* — every record is frozen pure data
   (=node.ex= realization invariant). Enforce in =Mesh.Record.new=.
2. *Best-effort posture* — a sick mesh component NEVER fails a mission (the
   =SessionRegistry=/=Hist= posture: =rescue/catch → :ok=). Mesh is an enhancement.
3. *Monotone writes only via post; the one retract (re-goal) via owner/decide* (D3).
4. *Every spawn + watch-fire through ParallelBudget* (D11) — no exceptions.
5. *Reads ambient, region writes cap-gated* (D12) — enforce at =black/post=.
6. *Store-behaviour purity* — mesh logic written against =Hist.Store=, never a
   concrete engine, so Memory/Khepri swap is free (D13, the =store.ex= contract).
